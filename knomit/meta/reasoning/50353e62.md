# AI market diagnostic playbook: adoption arc positioning + competitive layer mapping as integrated framework

Two complementary methodology frameworks combine into a unified AI market diagnostic playbook.

Framework 1 — Enterprise adoption arc positioning (a5d507b1): Diagnose WHERE in the cycle a market sits via the three-stage sequence: (Stage 1) Production failure signals unmet need and pre-market-formation; (Stage 2) Architectural solutions displacing process patches signals market-formation; (Stage 3) Concrete enterprise ROI data (not benchmarks) signals commercial validation. This is the temporal diagnostic: it tells you when to enter and at what risk level.

Framework 2 — Competitive layer analysis (ccca194e): Diagnose WHO holds structural advantage by mapping four dynamics simultaneously: (a) what is commoditizing, (b) where dual hardware/software tracks are converging, (c) how fast stack layers are integrating, (d) which protocol is crossing the tipping point. This is the structural diagnostic: it tells you which players will capture value at which layers.

Integrated application: Start with the temporal diagnostic (which adoption stage is the market in?) to calibrate risk level and investment horizon. Then apply the structural diagnostic (which layer is commoditizing and which protocol is winning?) to identify specific positioning opportunities. The combined output is a hypothesis about which player, at which layer, at which point in the adoption arc, holds durable competitive advantage.

Example: AI coding market (Week 4-6 analysis): Temporal: Stage 2 → Stage 3 (Amazon Q failure → GitHub repo intelligence architectural response → Wispr/Ramp ROI validation underway). Structural: Silicon commoditizing above Qualcomm Wear/Nvidia; MCP crossing tipping point as protocol; GitHub claiming memory layer while Cursor/Claude Code compete at production layer. Combined: architectural-layer players (GitHub, Snowflake) are better positioned than model-layer players for durable margin during this particular cycle.

Pitfall: The frameworks are diagnostic, not predictive. Strong structural signals can still fail due to: geopolitical fractures (DeepSeek/Huawei creating substrate alternatives), regulatory intervention (RSP collapse compressing safety-posture advantage), or layer disintermediation (AI agents bypassing substrate layers via natural language interfaces entirely).
