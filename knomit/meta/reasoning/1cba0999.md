# Unified platform layer capture framework: substrate ownership, multi-context expansion, vertical value layer progression

Three complementary methodology lenses for identifying platform monopoly bids at different levels of abstraction.

Lens 1 — Substrate identification (f554850c): Determine whether any player controls a resource layer that ALL competing tools require as input. If yes, that player achieves meta-layer lock-in independent of which tool wins above it. Key signals: non-replicability (network effects, historical data moats), platform-agnostic value proposition, structural barriers to new entrant bootstrapping. The substrate owner profits from competition proliferation above it — like Qualcomm in mobile or GitHub in code.

Lens 2 — Multi-context expansion signal (b76e7616): When a company simultaneously announces infrastructure plays in 4+ deployment contexts (cloud, edge, physical AI, space) within a single product cycle, treat this as a strategic monopoly bid for contextual coverage rather than product diversification. The breadth signal is more important than depth of any individual announcement — contextual coverage prevents substrate alternatives from forming in adjacent markets.

Lens 3 — Vertical value layer progression (7a037496): For developer tool platforms, apply three-layer stack analysis: entry layer (scale developer capture), memory layer (institutional context that creates switching costs), production layer (highest-value workflow capture with premium pricing). The winner controls at least two adjacent layers: entry+memory creates lock-in, memory+production creates monetization. Overweighting the entry layer is the key pitfall — value resides in memory and production.

Integrated reading: A substrate player expanding across deployment contexts (Nvidia: cloud, space, physical, agents at GTC 2026) activates Lenses 1 and 2 simultaneously. A developer platform building all three layers (GitHub: 1B entry, repo intelligence memory, idea-to-production layer) activates Lens 3. When a single player shows all three signals, the monopoly thesis is structurally strongest.

Pitfall: These lenses diagnose structural advantage, not market share. Strong structural signals can still fail due to geopolitical fractures (DeepSeek/Huawei creating substrate alternatives in China), regulatory intervention, or disintermediation (AI agents bypassing substrate entirely via natural-language-only interfaces).
