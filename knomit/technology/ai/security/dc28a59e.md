# AI adoption creates structural security debt across all integration layers — coding, protocols, and marketplaces

A consistent pattern across three AI adoption layers: rapid deployment creates security vulnerabilities faster than defenses can scale.

Layer 1 — AI coding agents (e7dbcfa7, e738c3fc): DryRun Security tested Claude, Codex, and Gemini in real workflows — 87% of PRs introduced at least one vulnerability (insecure JWT defaults, weak token handling, missing rate limiting). Cisco LLM Security Leaderboard: 83% of organizations planned agentic AI deployment but only 29% felt ready to do so securely.

Layer 2 — MCP protocol integration (a79f3cfa): Survey of hundreds of AI leaders building agentic integrations: 70% worried about credential leaks and malicious MCP servers, 56% report MCP doesn't support enterprise search well, 51% report ambiguous tool definitions causing incorrect tool calls. Most teams plan to adopt MCP but enterprise security readiness is not there.

Layer 3 — Agent marketplaces (508986de): Independent audit of OpenClaw's 1,400+ community skill marketplace found 12% of skills contained prompt injection payloads capable of exfiltrating conversation history — patched via sandboxed execution in v3.2.

Meta-pattern: The security gap is not random — it is structurally produced by the adoption timeline. Developer adoption (entry layer) runs 12-18 months ahead of enterprise security certification (memory+production layer). Each new integration layer (coding → MCP → marketplaces) inherits the same pattern: enthusiast/developer adoption first, security primitives catch up later. The EY finding that AI's share of cybersecurity spend will quintuple (9% → 48%) is the market's recognition of this accumulated debt.

Implication: Security is not a feature that can be bolted onto AI-integrated systems post-hoc — it requires architectural decisions at the integration layer design stage. The compound risk: each layer's security gap creates exploitable surface area for the next layer's integration. Claude Code agents calling MCP servers that connect to OpenClaw marketplace skills — three stacked layers, each with identified vulnerabilities.

Falsification: If comprehensive security middleware (credential vault, server identity, scoped authorization) ships for MCP in H2 2026 with widespread enterprise adoption, the structural debt thesis compresses significantly.
