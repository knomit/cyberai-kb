# AlphaEvolve plus gradient-descent optimization improves the matrix multiplication exponent

Researchers from Google DeepMind, Carnegie Mellon, Columbia, and MIT improved the bound on the matrix multiplication exponent omega. They first recast the non-convex optimization problem of combination loss analysis as a gradient-descent problem, which alone improved the previous state-of-the-art bound by approximately 0.97 x 10^-4. They then used AlphaEvolve — Google's general-purpose LLM-based system for evolving code — to improve the optimization algorithm itself, raising the total improvement over SOTA to approximately 1.62 x 10^-4. Each evolved optimization program took roughly 5 hours on a single GPU to execute, and they used AlphaEvolve's 'evolving constructions' feature so each generation starts from the best solution point found by its parent. The authors note that larger improvements to omega likely require new mathematical ideas.
