# MathCode formalizes natural-language math into Lean 4 proofs

MathCode is a mathematical coding agent with a built-in formalization engine that converts plain-language problems into Lean 4 theorems and attempts formal proofs. It features a persistent Lean REPL, reusable theorem and axiom libraries, agent proving, and an Obsidian knowledge graph; the formalization and proving pipeline is based on the AUTOLEAN project.
