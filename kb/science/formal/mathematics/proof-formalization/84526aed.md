# Claude produced the first computer-verified proof of Fermat's Last Theorem

Claude produced the first complete computer-verified proof of Fermat's Last Theorem in 11 days using Lean, comprising 13 million lines of code and 29,500 intermediate theorems, verified via Prove2Me. Formalization work of this kind had previously been estimated in human-decades.
