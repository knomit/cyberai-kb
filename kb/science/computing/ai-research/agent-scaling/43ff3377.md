# Toby Ord: scaling agent swarms 10x underperforms giving one agent 10x tokens, but is faster

Toby Ord's 'Swarm Scaling' analysis (Sept 2026) argues that increasing the number of agents in a swarm by 10x yields less performance than giving a single agent 10x as many tokens, and the shortfall compounds at larger scale-ups. Swarms can complete tasks in much less wall-clock time because they run in parallel, so they are worth it mainly when a large premium is paid for speed. It does NOT mean swarms are never useful.
