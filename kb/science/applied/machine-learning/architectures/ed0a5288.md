# Full-bandwidth transformers feed the previous token's hidden state forward

Microsoft research on 'full-bandwidth transformers' feeds the previous token's top-layer hidden state back into the model alongside the next token embedding, allowing latent computation to continue across decoding steps rather than being bottlenecked through the sampled token.
