# LIFT transformer feeds hidden state to next token

LIFT is a transformer that feeds its internal state back into the next generation step rather than only the output token. Training stays parallel using states precomputed from an off-the-shelf model's next-token predictions; at inference it feeds back its own. LIFT models of 135M to 1B parameters beat token-matched standard transformers on language modeling, reasoning and procedural tasks; unproven at frontier scale.
