# PC-ALM: augmented-Lagrangian predictive coding trains 1,000-layer residual MLPs without backprop

Sakana AI published PC-ALM (Augmented Lagrangian Predictive Coding), a local-learning alternative to backpropagation. It extends standard predictive coding — which uses diffusive coupling between layers — by equipping each layer with a feedback-control dynamical system that distributes and propagates supervision credit through the network. PC-ALM trains residual MLPs up to 1,000 layers deep and nearly matches backpropagation's performance while using only layer-local dynamics. Depth without global gradient transport is the specific claim; the demonstrated architecture is residual MLPs, not transformers.
