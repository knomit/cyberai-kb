# LittleLearner is a 5B model constrained to fifth-grade knowledge

LittleLearner is a hosted 5-billion-parameter language model deliberately limited to what a fifth grader knows, runnable live in the browser. It was built as part of an experiment in creating controlled sandboxes for studying how models acquire knowledge.
