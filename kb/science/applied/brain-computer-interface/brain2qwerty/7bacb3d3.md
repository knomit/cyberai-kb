# Brain2Qwerty v2 improves non-invasive brain-to-text

Per The Batch, researchers (including Meta and CNRS collaborators) presented Brain2Qwerty v2, a non-invasive MEG-based system that translates brain activity into text. It achieved a 39% word error rate (down from 43% in v1), using an encoder, an aligner, and a fine-tuned Qwen3-4B language model; it was trained on 90 hours (22,000 examples) from 9 subjects, and training across multiple subjects outperformed single-subject training.
