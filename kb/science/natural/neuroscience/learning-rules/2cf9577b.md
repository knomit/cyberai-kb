# Sakana AI's 'Diffusing Blame' enables learning without weight transport under Dale's principle

Sakana AI's 'Diffusing Blame' is a neural-network technique that enforces Dale's principle while enabling effective learning in image classification and reinforcement learning. Based on Error Diffusion, it uses non-negative weight matrices to maintain separate excitatory and inhibitory streams, eliminating the need for weight transport, and shows strong alignment with true gradients — a step toward biologically plausible learning rules.
