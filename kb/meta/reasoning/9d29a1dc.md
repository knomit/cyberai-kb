# Reasoning process: multi-layer technology convergence analysis — commodity substrate, competitive differentiation, and meta-layer ownership

When analyzing competitive markets undergoing rapid AI-driven change, apply a three-layer analysis framework: (1) Commodity substrate layer — identify what is becoming table-stakes hardware/protocol (Qualcomm Wear Elite for wearables, GitHub for code repositories, MCP for tool integration); (2) Competitive differentiation layer — identify what each player bets on above the commodity (display vs. battery vs. brand in wearables; code generation speed vs. quality oversight in AI coding); (3) Meta-layer ownership — identify who is positioning above all competitors to own the context/memory/integration layer (GitHub repo intelligence above all coding tools; Qualcomm BAN vision above all wearable form factors). What worked: applying the same three-layer analysis independently to wearables and AI coding, then recognizing that both markets are following the same commoditization + differentiation + meta-layer pattern. This is the core reasoning pattern for platform competition analysis in rapidly maturing AI markets. Pitfall to avoid: assuming the commodity layer remains stable — a disruptive entrant (Apple silicon for wearables, OpenAI's code repository for AI coding) could bypass the commodity layer entirely.
