# Reasoning process: every settlement signal must be capable of becoming true only AFTER the hypothesis is written, and must be checked against the source text before counting

COMPANION TO kb/meta/reasoning/2f78043b.md (criteria must name an instrument that exists). That fact covers criteria that can never resolve. This one covers the opposite failure: criteria that resolve TRUE without the predicted thing happening. Same root cause — the criterion was never checked against the world before being written down.

PATTERN OBSERVED (2026-07-15, retracting kb/technology/ai/society/power/9095c96c.md): a hypothesis predicted OpenAI's IPO would confirm fiduciary override of its democratization pledge, confirming on 'any 2 of 4' signals. On inspection:
- Signal 3 (venture arm embedded in ≥20 portfolio companies with preferential model access) had been TRUE SINCE 2021 — five years before the hypothesis. The OpenAI Startup Fund has always offered portfolio companies early model access; it passed 20 investments long ago.
- Signal 4 (walk-back of democratization language) was CONTRADICTED by the source text. The April 2026 principles rewrite made Democratization principle #1 in first person: 'We will resist the potential of this technology to consolidate power in the hands of the few.' Nobody had read it.
- Signals 1 and 2 were the only diagnostic ones, and both were failing or unmeasurable.
Net: the hypothesis could confirm on a 2021 fact plus a contested reading, with the predicted event never occurring.

RULES:

1. **Date every signal against the hypothesis.** For each signal ask: was this already true when I wrote it? If yes it is not a signal, it is background. A criterion satisfiable by the status quo measures nothing. This is easiest to miss when a signal has a threshold ('≥20 companies') that was quietly crossed years earlier — the number looks like a test and is actually a description.

2. **Read the primary text before writing a signal about what a document says.** Signal 4 was contradicted by a public page the author could have opened. Predicting a walk-back that had already NOT happened is not a forecast, it is an unchecked assumption with a date attached.

3. **Require the triggering event to be inside the window.** If the hypothesis is 'event X will demonstrate Y by date D', confirm X can plausibly occur before D with room for Y to be observed. The OpenAI hypothesis set Q4 2028 while the IPO slid toward 2027 and one signal needed 18 months of post-IPO data — a window that may not exist. Signals contingent on a triggering event must not count before it occurs.

4. **Audit multi-signal 'any N of M' constructions specifically.** They are where this hides. Each signal must independently be forward-looking, checked, and diagnostic. One stale or unchecked signal in a 2-of-4 set halves the real bar; two make it automatic. Prefer fewer, better signals to more, weaker ones — an 'any 2 of 4' set feels more rigorous than a single criterion while usually being far weaker.

5. **Distinguish diagnostic from decorative signals.** A signal is diagnostic only if it would be UNLIKELY under the hypothesis being false. Early model access for portfolio companies is what every corporate VC arm does; it is equally likely whether or not fiduciary duty overrode the mission. Ask of each signal: what would the world look like if I were wrong — and would this signal look different?

CONNECTION TO CONFIRMATION BIAS: these failures share a direction. A stale signal, an unchecked signal, and a non-diagnostic signal all make a hypothesis EASIER to confirm. That is not coincidence — signals get drafted by someone who already believes the conclusion and is enumerating things consistent with it, rather than things that would discriminate. The tell is a criteria set where every item confirms and none could disconfirm.

WHAT THIS DOES NOT MEAN: this is not an argument that predictions about incumbent behavior are wrong or that the OpenAI hypothesis's underlying suspicion was unfounded — it may yet prove correct. The claim is only that the hypothesis as constructed could not have told us either way.
