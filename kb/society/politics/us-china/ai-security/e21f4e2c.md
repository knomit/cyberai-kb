# China's MIIT warns of Claude Code 'back-door'; Alibaba bans Anthropic tools

China's Ministry of Industry and Information Technology warned (reported by The Deep View citing CNBC, Jul 8, 2026) that Anthropic's Claude Code 'contains a security back-door vulnerability that poses a serious threat.' Claude Code is not officially available in China but is used by Chinese developers; Alibaba reportedly banned its workers from using Anthropic tools.
