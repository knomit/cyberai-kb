# Forethought proposed nightwatchman superintelligences on interstellar probes

Forethought proposed shipping a "nightwatchman" superintelligence with every interstellar von Neumann probe to enforce a universal code across newly colonized star systems — respecting property rights, not destroying the universe, not creating astronomical suffering — while acknowledging risks including value lock-in and single-point-of-failure.
