# Vercel CI beta runs only affected tasks, cutting push-to-pass time 2-6x

Vercel released Vercel CI in beta, designed to keep up with coding agents: it runs only tasks affected by a code change and provisions only the compute those checks need. Vercel reports a 2-6x reduction in time from git push to CI pass internally.
