# Codex added a 'persistent' reasoning-effort variant that rewrites to disabled

OpenAI's Codex added 'persistent' to its reasoning-effort protocol and TypeScript SDK types. When a user targets a custom Responses-compatible provider whose model-defined effort is literally 'persistent', it now deserializes to a new Persistent variant and is unconditionally rewritten to disabled — whereas it previously remained Custom("persistent") and was forwarded unchanged. Existing configurations and resumed sessions can therefore send a different value and change behavior or be rejected, so the alias should be limited to providers that define the translation.
