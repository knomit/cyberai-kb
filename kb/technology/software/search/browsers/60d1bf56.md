# DuckDuckGo installs up 30% as users reject Google AI search

DuckDuckGo installations jumped 30% as users pushed back against Google's AI Search overhaul (AI Overviews/AI Mode). This signals growing user resistance to AI-integrated search experiences imposed without opt-out.
