# diffium-db gives a live TUI diff of what an agent is changing in a database

diffium-db is a live terminal UI that shows what is changing in a database while an agent, a migration, or a person works. The user points it at a database, takes a baseline, and leaves it open; it renders one pane listing what changed and one pane showing the change itself, updating as changes happen. It addresses the observability gap created by letting agents write to databases.
