# Cursor launched Projects, a coordinator-agent abstraction for multi-month bodies of work

On 2026-09-10 Cursor launched Projects in beta. A Project is overseen by a coordinator agent that does not write code itself but delegates to subagents, so it is never blocked. Three capabilities define it: cloud-by-default execution (the Project runs on its own machine and spins up a local agent only when something must be tested on the user's machine), shared context files that sync across every cloud and local machine its agents use and accumulate research and codebase knowledge over time, and subscriptions that let the coordinator watch a Slack channel, run on a schedule, or follow all PRs without being prompted. Cursor reports that after several months of internal use, new users merge 30% more PRs and users who primarily use Projects merge six times as many.
