# Google brought Antigravity agents into Gemini Enterprise and major IDEs

Google added Antigravity to eligible Gemini Enterprise subscriptions and released extensions for VS Code, Visual Studio, JetBrains, and Zed. Developers get the same agent workspace across these editors, while administrators can configure sandbox, tool-permission, budget, identity, and audit controls.
