# Entire launches Git forge for agent-human collaboration

Entire introduced a Git forge for agent-human collaboration with Trails (code evaluations), faster distributed Git hosting, Continuous Memory for session syncing, CI integrations with Buildkite and Depot, and entire-graph / entire-brain commands for code and memory mapping.
