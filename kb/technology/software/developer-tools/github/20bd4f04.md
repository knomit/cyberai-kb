# GitHub CPO: rebuilding for machine-speed development; Anthropic building 'Scion' version control

In a Deep View Conversations episode from GitHub Universe 2026, GitHub chief product officer Mario Rodriguez said GitHub is rebuilding its foundations for machine-speed, agent-driven development and that AI demand accelerated its move to Azure. He responded to Anthropic's decision to build Scion, its own version control system, arguing for Git's continued role. His framework for who gets to build: 'lower the floor, raise the ceiling, and widen the walls'.
