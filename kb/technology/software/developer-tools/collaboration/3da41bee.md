# Slack Code adds code channels for collaborative human-agent development

Slack announced Slack Code, which introduces "code channels" where teams plan, write, and review software together with AI agents. It integrates tools from partners including GitHub, Anthropic, and Vercel, and lets engineers view code diffs and live previews directly inside Slack rather than switching to separate tabs.
