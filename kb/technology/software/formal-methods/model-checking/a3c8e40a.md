# Specula: agentic system that auto-derives TLA+ specs to model-check system code

Specula is an agentic system that automates software bug-finding by authoring and model-checking a formal specification of the code. It derives TLA+ specifications automatically from the code, checks code-spec conformance via trace validation, model-checks the spec to find concurrency bugs, and reproduces bugs at the code layer by writing timing-precise integration tests. Analysis notes it works well pragmatically but does not solve the composition problem (whether per-module guarantees compose into a system-level guarantee).
