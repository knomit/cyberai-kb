# Memoryfields proposes agent memory as portable Markdown files plus a SQLite vector index

Memoryfields proposes storing agent memory as portable Markdown files with optional YAML metadata, indexed by a SQLite vector store. The argument is that memory should be inspectable data the user can read and move, rather than a complex retrieval pipeline or a proprietary feature locked inside an agent product.
