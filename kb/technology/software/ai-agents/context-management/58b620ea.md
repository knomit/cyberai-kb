# Self-GC uses an LLM planner to fold, mask, or prune agent context instead of fixed rules

Xubin Hao and colleagues at Xiaohongshu (RedNote) built self-governing context (Self-GC), in which an LLM planner — rather than a fixed rule such as 'delete oldest' — decides what to keep, trim, or discard from an agent's context. When input tokens exceed 30% of the primary model's context window, the planner (Qwen3.6-Plus by default) chooses per item among: Fold (move content to separate storage with a short pointer note so it can be restored verbatim), Mask (shorten in place, keeping opening and closing text while cutting repetitive middle — suited to long logs), or Prune (delete outright, e.g. failed command logs). Actions are trialed on a copy, any action that would interfere with the current request is discarded, and the plan is applied only if it shortens history by at least 30%. Key insight: type- or age-based rules can't tell that an old tool output holds the only copy of a URL needed later while a recent one is already stale; an LLM can.
