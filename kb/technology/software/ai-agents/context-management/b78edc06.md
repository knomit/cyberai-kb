# Self-GC: an LLM planner folds, masks or prunes agent context instead of using fixed rules — removing 44% of tokens at 85% detail retention on hard conversations, versus rule-based baselines that cut more but retain less

MERGED from two records of the same Xiaohongshu (RedNote) research — one describing the mechanism, the other reporting its measured results. Split across two records, the method read as untested and the numbers read as unexplained.

THE METHOD. Xubin Hao and colleagues at Xiaohongshu (RedNote) built SELF-GOVERNING CONTEXT (Self-GC), in which an LLM PLANNER — rather than a fixed rule such as 'delete oldest' — decides what to keep, trim, or discard from an agent's context.

TRIGGER AND ACTIONS. When input tokens exceed 30% OF THE PRIMARY MODEL'S CONTEXT WINDOW, the planner (Qwen3.6-Plus by default) chooses per item among:
- FOLD — move content to separate storage with a short pointer note so it can be restored VERBATIM.
- MASK — shorten in place, keeping opening and closing text while cutting the repetitive middle; suited to long logs.
- PRUNE — delete outright, e.g. failed command logs.

SAFEGUARDS. Actions are TRIALED ON A COPY, any action that would interfere with the current request is DISCARDED, and the plan is applied only if it shortens history by AT LEAST 30%.

THE KEY INSIGHT. Type- or age-based rules cannot tell that an old tool output holds the ONLY COPY of a URL needed later while a recent one is already stale; an LLM can.

MEASURED RESULTS.
- HARD SET (33 especially demanding conversations): Self-GC removed 43.95% OF INPUT TOKENS and preserved the details the conversation later needed 84.85% OF THE TIME. Rule-based baselines removed MORE (61.90–69.87%) but retained needed details only 54.55–69.70% of the time.
- LARGER SET (332 conversations): Self-GC removed 31–34% of input tokens with 91.27–94.58% retention across three planner models (Qwen3.6-Plus, Qwen3.7-Max, GLM-5.1), versus 40.19–47.76% removal at 77.71–87.46% retention for rule-based methods.
- LIVE: running on real user accounts it removed 10–15% of input tokens.

CAVEAT — load-bearing. The evaluation measured DETAIL RETENTION (judged by GPT-5.5 on replayed real conversations), NOT FINAL OUTPUT QUALITY. A shortened-context system can retain the details and still produce worse answers. The results are also the authors' own and are not independently replicated in this corpus.
