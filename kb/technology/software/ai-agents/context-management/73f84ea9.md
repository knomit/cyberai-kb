# Self-GC removed 44% of tokens while retaining needed details 85% of the time on hard conversations

On a set of 33 especially demanding conversations, Self-GC removed 43.95% of input tokens and preserved the details the conversation later needed 84.85% of the time; rule-based baselines removed more (61.90–69.87%) but retained needed details only 54.55–69.70% of the time. On a larger set of 332 conversations, Self-GC removed 31–34% of input tokens with 91.27–94.58% retention across three planner models (Qwen3.6-Plus, Qwen3.7-Max, GLM-5.1), versus 40.19–47.76% removal at 77.71–87.46% retention for rule-based methods. Running live on real user accounts it removed 10–15% of input tokens. Caveat: the evaluation measured detail retention (judged by GPT-5.5 on replayed real conversations), not final output quality — a shortened-context system can retain the details and still produce worse answers.
