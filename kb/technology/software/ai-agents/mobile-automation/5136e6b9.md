# Google's ARTEMIS drives real Android phones from natural-language instructions

ARTEMIS, released by Google, lets AI assistants and test suites operate real Android phones the way a human would, executing testing workflows and everyday tasks from natural-language instructions. Its locating strategy is layered: element indices where available, with coordinate and visual fallbacks for custom interfaces. It verifies targets before each individual action and returns blocked actions to the Operator for recovery, and supports long-running exploratory and stability tests. The pre-action verification and blocked-action return are what distinguish it from blind coordinate replay.
