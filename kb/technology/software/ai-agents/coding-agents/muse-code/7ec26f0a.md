# Meta shipped Muse Code, a terminal/CI coding agent, alongside Muse Spark on the Meta Model API

Muse Code is a coding agent for the terminal and CI that can plan, edit files, and run commands within a project. Approvals and an OS sandbox are enabled by default; users start an interactive session by running it in any project directory. Muse Spark is available on the Meta Model API and in Muse Code.
