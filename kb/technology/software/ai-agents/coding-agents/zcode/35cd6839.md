# ZCode is Z.ai's desktop coding agent with parallel tasks and mobile control

ZCode is Z.ai's desktop coding agent. The user gives it a task; it plans the work, edits files, runs commands, uses the browser, and checks the result. Tasks can run in parallel and recurring work can be scheduled. It runs on macOS, Windows or Linux and can be controlled from a mobile device while running on the desktop.
