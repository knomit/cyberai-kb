# Hugging Face released Tau, a terminal coding agent built as a teaching reference

Hugging Face released Tau, an open-source coding agent that runs in the terminal: it reads files, edits code, runs commands, and maintains a durable session history while streaming its actions. Its stated purpose is pedagogical — to show the shape of a coding-agent system without the reader having to start from a large production codebase. It supports OpenAI-compatible endpoints. Because it is a teaching project, it should be read as a reference implementation rather than a production-hardened tool.
