# DeepSeek published the open-source agent harness it benchmarks its own models in

DeepSeek released DeepSeek Harness in developer preview — MIT-licensed and model-agnostic — treating models, tools, skills, sessions, sandboxes, storage, loops, scheduling, and user interfaces as configurable, swappable plugins. It logs everything the model ingests (system prompts, reasoning, tool calls and results, subagent scheduling, context injection) so any session can be resumed, forked, searched, or replayed. Its 'minimal mode' — shell plus file editor only — is the configuration DeepSeek used for its coding-agent benchmarks. It is built on a plugin kernel called Cordis, described in a paper by DeepSeek and Peking University. Publishing the harness matters because agentic performance is a joint function of model and scaffolding; a published harness turns unreproducible numbers into reproducible ones.
