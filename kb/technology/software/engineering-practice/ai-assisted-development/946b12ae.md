# Andrew Ng: software engineering fundamentals matter more, not less, under agentic coding

In The Batch (Aug 28, 2026), Andrew Ng argued that agentic coding raises rather than lowers the value of software fundamentals, because you cannot steer an agent toward the right tradeoffs — or even know which tradeoffs exist — without them. A novice vibe-coding without that understanding gets agents making bad calls on latency, availability, consistency, reliability, maintainability, simplicity, and cost. DeepLearning.AI's study of AI Engineering Skills identifies five areas that matter most: building full-stack applications; managing data (access patterns, data models, storage types, transactions, concurrency, governance, lifecycle — the foundation hardest to change later); designing system architectures (a moving target as a project moves from prototype to production to scale); making systems secure and reliable (testing strategy, graceful degradation, blast-radius containment, and 'shift left' security); and scaling and operating in production (SDLC, CI/CD, IaaS, observability, incident management, sharding/indexing/replication). Memorizing syntax is becoming obsolete; understanding how software works is not.
