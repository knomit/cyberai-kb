# Reasoning process: trusted-tool abuse pattern → EDR erosion hypothesis

When multiple unconnected threat actors independently arrive at the same evasion technique (living-off-the-land / trusted tool abuse), the pattern is structural, not coincidental — it reflects an underlying asymmetry in the detection model. Decisive evidence: diversity of tools used (Teams + QEMU + Deno + Obsidian + blockchain) across different actors shows the attack surface is the defender's trust model, not any specific tool. Pattern applied: attacker → defender asymmetry in cost of generating new LOTL variants vs. cost of writing detection rules. What worked: treating the diversity of tools as signal strength rather than noise. Pitfall avoided: do not recommend blocking specific tools — recommend redesigning the trust model.
