# SpaceX-Cursor $60B conditional acquisition deal to challenge Claude Code and Codex

SpaceX (which now owns xAI as a subsidiary) signed a conditional deal with Cursor on April 22, 2026: if a joint coding agent collaboration succeeds, SpaceX acquires Cursor for $60 billion later in 2026; if it fails, SpaceX pays Cursor $10 billion. Cursor was valued at $10B just 12 months prior. Cursor gains access to SpaceX's 'Colosus' supercomputer and xAI frontier models; xAI gains a fast track toward a coding/knowledge-work AI to compete with Claude Code and OpenAI Codex. Both are targeting 'the world's best coding and knowledge work AI.'
