# Prime Agent: a self-improving RLM-based coding harness from Prime Intellect

Prime Agent is a self-improving coding harness built around the Recursive Language Model (RLM) and a 'Continual Harness'. The RLM treats context as a variable and subagent delegation as function calls inside a persistent REPL, letting the model write language-model programs as actions over its own context. The Continual Harness lets the agent create, read, update, and delete the harness's state from its own trajectory.
