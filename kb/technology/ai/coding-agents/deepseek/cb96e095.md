# DeepSeek releases dsh-superagent prototype, a coding agent bundle for DeepSeek Harness

deepseek-ai published dsh-superagent-prototype on GitHub: a coding agent packaged as a bundle for DeepSeek Harness that can watch GitHub, open work items, work in its own agent session and directory and reply in the original conversation; it acts only when asked or when a team-written rule allows it.
