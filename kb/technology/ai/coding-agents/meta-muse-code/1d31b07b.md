# Meta releases Muse Code, a terminal coding agent on Muse Spark 1.2

On/around Aug 2026 Meta released Muse Code, a terminal-based coding agent powered by the Muse Spark 1.2 model. It is designed to handle complex repository-level software engineering tasks.
