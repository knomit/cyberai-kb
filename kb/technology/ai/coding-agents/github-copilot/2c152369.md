# GitHub Copilot Fusion routes between models, cutting cost 50-60% on complex work

GitHub COO Kyle Daigle (The Deep View Conversations, GitHub Universe) said Copilot Fusion can start with a cheaper model, escalate to a more capable one when needed, and bring a second model to check the first's work (Cascade and Critique approaches; tiers Standard, High, Max). GitHub teams and early enterprise customers report 50%-60% lower costs on complex work, up to 77% for certain workloads, with results matching high-end models about 40% faster. GitHub also plans to route some tasks to local models. These are vendor-reported figures.
