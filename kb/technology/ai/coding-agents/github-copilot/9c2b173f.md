# GitHub Copilot Fusion routes tasks across models to cut tokens and cost

Announced 2026-10-28 at GitHub Universe: Copilot Fusion is a multi-model orchestration feature in the GitHub Copilot app. Users pick Standard, High or Max effort; it starts with simpler/cheaper models and escalates to stronger ones as needed, via agents and subagents. Per the Artificial Analysis Coding Agent Index (as reported by The Deep View), Fusion Max is about as powerful as Claude Code with Opus 5.5 Max while using half the tokens and 40% less time. GitHub COO Kyle Daigle reports roughly 50-60% lower costs on complex work, up to 77% for some adopters. Admins can control which models Fusion may use; local models are planned as an option. Other GitHub Universe announcements: Projects, AI Scans, phone/desktop app switching.
