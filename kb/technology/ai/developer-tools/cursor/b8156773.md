# Cursor Router learns model selection from real developer traffic

Cursor Router selects which model handles a coding turn using signals from the current turn and recent conversation. It routes in two stages: first deciding whether a turn is simple enough for a price-efficient model, then, for demanding turns, choosing the frontier model most likely to perform well — classifying the turn against a taxonomy of tasks, domains and modifiers learned from real developer traffic.
