# Replit launched Free Mode powered by OpenAI's GPT-5.6 Luna

Replit introduced Free Mode, which lets users create substantially more (Replit claims 30x) using OpenAI's GPT-5.6 Luna without consuming credits on everyday tasks. The accompanying UI allows transitions from chat and tasks through to full builds. Core subscribers get the capability, with Pro users receiving higher usage limits.
