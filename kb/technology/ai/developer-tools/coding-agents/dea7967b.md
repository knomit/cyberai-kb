# Cursor added event-driven cloud agents that subscribe to PRs, Slack threads, and schedules

Cursor's August 19, 2026 release lets Cursor Agent subscribe to an event source and wake when something happens — monitoring pull requests, watching a Slack thread, or running scheduled tasks. Subscriptions are currently available only for cloud agents. Subagents can now run on their own virtual machines, and users can send steering messages to agents mid-run without interrupting them.
