# Google brought Antigravity agents into Gemini Enterprise subscriptions and major IDEs

Google added Antigravity to eligible Gemini Enterprise subscriptions and released extensions for VS Code, Visual Studio, JetBrains, and Zed. Developers can use the same agent workspace across all of these editors. Administrators can set sandbox, tool-permission, budget, identity, and audit controls.
