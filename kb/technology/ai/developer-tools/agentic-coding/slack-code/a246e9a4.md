# Slack Code adds code channels where teams and AI agents build software together

Slack launched Slack Code, which introduces "code channels" for collaborative software development with AI agents. Teams can plan, write, and review code together using integrated tools from partners including GitHub, Anthropic, and Vercel, without switching to isolated tabs. Engineers can view code diffs and live previews directly inside Slack.
