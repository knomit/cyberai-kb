# Celonis Context Model (CCM) + Ikigai Labs Acquisition: AI Business Context Layer (May 2026)

Celonis announced the Celonis Context Model (CCM), a digital twin of business operations that dynamically updates in real time. CCM aggregates structured and unstructured data from system logs, screens, policies, and process descriptions into a unified language AI can reason about. Simultaneously, Celonis acquired Ikigai Labs (MIT-founded, led by Dev Shah), which specializes in prediction, forecasting, time-series analysis, and what-if scenario simulation. Together, CCM + Ikigai allows enterprises to not just understand real-time operations but model future outcomes. Tested with AstraZeneca, Mercedes, Domino Foods. Celonis is Gartner Magic Quadrant leader for Process Intelligence. Co-CEO Alex Rinke: 'You need to teach [AI] how to be good at doing a specific job in that business.'
