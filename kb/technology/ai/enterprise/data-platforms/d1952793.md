# Snowflake Summit 2026: CoWork agent platform, Horizon governance hub, verified agent identities + Anthropic Claude partnership

Snowflake Summit 2026 (San Francisco): Snowflake announced a major AI-focused platform refresh. (1) Snowflake CoWork (renamed from Snowflake Intelligence): personal AI agent for knowledge workers integrating data, context, and tools. New features: Cortex Sense (unifies data, business definitions, operational knowledge), User Memory (schedule tasks + take actions with agents via Gmail/Slack), Skill Catalog (discover, share, reuse agent skills). (2) Horizon Catalog: central hub for AI governance, context, and security. Horizon Context (business definitions for all people, tools, and agents), Adaptive Compute (optimizes compute resources), verified agent identities, continuous security posture management, automatic defenses against jailbreak attempts and zero-day vulnerabilities. (3) Snowflake CoCo (renamed from Cortex Code): autonomous task execution; Datastream (eliminates data brokers/connectors/streaming infrastructure for fresh data access). (4) Anthropic partnership: significant momentum with Claude models on Snowflake Cortex AI. Daniela Amodei (Anthropic President): 'Trust is an accelerant. Trust is something that helps you go faster.'
