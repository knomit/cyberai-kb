# MCP reached ~500M monthly SDK downloads by July 2026

The Deep View (2026-10-06) cites the MCP project blog stating Model Context Protocol, open-sourced by Anthropic in November 2024, has around 500 million monthly SDK downloads (post dated 2026-07-28), making it an industry standard interface between AI agents and tools/data/services.
