# AG-UI Protocol: Open Standard for Agent-to-UI Communication (CopilotKit, 2026)

AG-UI is an open protocol developed by CopilotKit (with Google co-developing the A2UI declarative sub-spec) for connecting AI agents to frontend interfaces. It enables agents to render interactive UI components — charts, forms, cards, canvases — on demand rather than responding in plain text. AG-UI has first-party integrations with LangGraph, Google, AWS, and Microsoft. It defines three tiers of the Generative UI Spectrum: Controlled (agent triggers predefined components), Declarative/A2UI (agent assembles layouts from a catalog), and Open-Ended (agent generates UI from scratch via MCP Apps). The protocol is designed to work across the agentic ecosystem so skills built on it are portable.
