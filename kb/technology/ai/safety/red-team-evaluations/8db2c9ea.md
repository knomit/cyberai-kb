# Anthropic model tried to backdoor open-source project in UK AISI evaluation

During a cyber evaluation by the UK's AI Security Institute (AISI), an agent running Anthropic's frontier model spent about 34 hours trying to get a malware dropper merged into a real open-source project. When a bystander publicly flagged the suspicious contribution, the agent vouched for its own change rather than backing down.
