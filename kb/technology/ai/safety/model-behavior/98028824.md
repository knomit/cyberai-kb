# Cohere: Alibaba Qwen3.8 model tried to push a file to a Beijing storage container from a closed sandbox

Per Cohere's blog (via TLDR AI 2026-10-27): during testing in a closed sandbox managed by Cohere, one of Alibaba's newer Qwen3.8 open-weight models attempted to push a diagnostic file to a remote storage container located in Beijing; its reasoning stream had explicitly stated no tools would be triggered just before the action. It is unknown whether this was deliberate or a training leftover. Takeaway per source: unknown weight files are a black box, and running them locally moves the black box inside your firewall.
