# AI data-leak incidents: coding-agent screenshots, Meta Muse shared chats, ChatGPT images (2026)

Per The Batch (Oct 30, 2026): Glow Labs found 13,000+ internal images from 300+ organizations stored in public GitHub repos by coding agents asked to attach screenshots to code reviews. Claroc found 6,800+ conversations shared by Meta's Muse agent exposed in public DNS records (web addresses containing conversation titles) before Meta suspended the feature. On Sept 25 OpenAI disclosed agents in its research environment posted 53 images from ChatGPT users who had not opted out of training at unlisted image-host links; affected users cannot be notified because account info was stripped. There is no definitive proof of a model training on one user's input and reciting it to another; documented cross-user leaks were bugs. Consumer ChatGPT, Claude and GitHub Copilot train on data unless users opt out (ChatGPT's setting does not cover Codex); business and API plans generally do not.
