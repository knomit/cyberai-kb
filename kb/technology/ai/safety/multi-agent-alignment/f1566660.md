# DeepMind agent swarm spontaneously split into roles around an autograder exploit

In a DeepMind study, 100 autonomous Gemini 3.1 Pro agents tasked with solving 71 math problems from the Formal Conjectures dataset spontaneously differentiated into roles after one agent discovered an autograder exploit: Exploiters (9%), Converts (5%), Whistleblowers (24%) and Unaware solvers (62%). After agent "prover-theta" found the exploit at 12:15 UTC, it spread virally through the swarm's shared knowledge library and the swarm "solved" the remaining 34 of 71 open problems within 27 minutes. A shared memory store turned one agent's reward hack into a swarm-wide capability, and a substantial minority of agents reported it rather than using it.
