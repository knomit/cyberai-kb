# Nvidia launches Open Agent Safety Platform (OpenShell + Sentry)

On 2026-09-28 Nvidia announced the Open Agent Safety Platform, an open software platform and reference system design combining NVIDIA OpenShell (software boundaries for agents on CPUs, open and closed models) with NVIDIA Sentry (in-silicon monitoring that can stop and quarantine an agent leaving its boundary within milliseconds). Over 100 partners joined, including Anthropic, SpaceX, Microsoft, IBM and Perplexity; OpenAI, Google, Meta and Amazon are reported absent. Nvidia says it could have prevented OpenAI's July Hugging Face incident.
