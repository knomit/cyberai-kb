# Agent Data Injection (ADI): a new attack class against AI agents

A paper posted July 6, 2026 by researchers from Seoul National University, the University of Illinois Urbana-Champaign, and Largosoft describes a new attack class called agent data injection (ADI). Unlike classic prompt injection, ADI does not hijack the agent's task — it corrupts the data the agent trusts while the agent continues with the user's requested job. Attacker input is disguised as trusted data fields (e.g. a sender's name, a button's DOM ID), which lets it bypass most defenses built specifically against prompt injection. Demonstrated effects include making a shopping agent click 'Buy Now' from a planted product review, and making a coding assistant run an attacker's command from a fake GitHub thread comment.
