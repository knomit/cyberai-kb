# Runway's Solaris is an Interface World Model that generates UI frame by frame with no intermediate representation

Runway introduced Solaris, an 'Interface World Model' that generates real-time interactive interfaces frame by frame as the user interacts with them. Rendering and interaction are handled jointly — the model generates every frame and every response to user input — eliminating the need for an intermediate representation such as a DOM or scene graph. Runway positions it both as a new way to build websites, apps and online interfaces, and as a means of training agents in far more dynamic environments.
