# Microsoft launches MAI-Thinking-1 reasoning model

Microsoft launched MAI-Thinking-1, a reasoning model aimed at cost-efficient enterprise workloads across coding, math, and knowledge tasks.

**CORRECTION (2026-08-25).** This fact previously called it "a medium-sized reasoning model." That is wrong as stated. MAI-Thinking-1 is a 1-TRILLION-parameter mixture-of-experts model with 35B active per token. "Medium-sized" is defensible only as a description of the active count, and a reader will not take it that way — they will take away a mid-tier model, which this is not.

Canonical spec, benchmarks and training detail live at `kb/technology/ai/models/microsoft/mai-thinking-1/mai-thinking-1.md`; cite that, not this. That record also carries the reconciliation of the three conflicting sizes this corpus gives for the model.

The cost-efficiency framing above is retained because 35B active per token is a genuine serving-cost argument. It is not a claim about model size.
