# OpenAI GPT-5.4 - agentic professional model with 1M context, computer-use, tool searching

OpenAI released GPT-5.4, described as 'most capable and efficient frontier model for professional work.' Available in ChatGPT ('GPT-5.4 Thinking'), API, Codex; also GPT-5.4 Pro for maximum performance. Key capabilities: (1) Adjustable coarse mid-response + upfront thinking plans for improved deep web research; (2) SOTA computer-use for complex agentic workflows; (3) Up to 1 million token context; (4) Tool searching (agents find and connect tools without sacrificing intelligence); (5) Improved token efficiency. Performance: Mercor CEO Brendan Foody: best model on APEX-Agents (long-horizon task benchmark). Box: 78% metadata extraction accuracy (up from 72% with GPT-5.2). Targets enterprise market directly against Anthropic. Released same week as Claude #1 App Store controversy over Pentagon ban.
