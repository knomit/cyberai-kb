# Qwen-Image-3.0 image generation model released

Qwen-Image-3.0 is the third-generation foundational image generation model in Alibaba's Qwen-Image series. It supports up to 4.5k-token input, native rendering of 12 languages, and can simulate mainstream interfaces such as web pages, games, and livestreams.
