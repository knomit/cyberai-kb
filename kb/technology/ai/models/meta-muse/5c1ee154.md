# Muse Wonder pricing and availability; Muse agent privacy concerns

Muse Wonder costs $4 per million input tokens, $20 per million output tokens and $0.20 per million cached input tokens (agentic use), roughly on par with Claude Opus 5.5 and Gemini 4 Argon. Available via the Meta Model API and Muse Code; Muse Wonder Full is for Muse Code subscribers, with token pricing not yet released. Reports that Meta's Muse agent used personal data without authorization (e.g. exposing a home address, reading private iMessages) frame a trust problem for adoption.
