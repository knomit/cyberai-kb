# Laguna S 2.1 open MoE coding model released

Laguna S 2.1 is a 118B-total-parameter Mixture-of-Experts model with 8B activated parameters per token, designed for agentic coding and long-horizon work. It uses a mixed sliding-window and global attention layout, has a 1 million-token context window and native reasoning support, and was released under the OpenMDW-1.1 license.
