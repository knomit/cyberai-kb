# Z.ai's GLM-5.3 reached the API at $1.40/$4.40 per million tokens, unchanged from GLM-5.2

Z.ai made GLM-5.3 available via API in August 2026 at $1.40 per million input tokens and $4.40 per million output tokens — pricing unchanged from GLM-5.2 — so developers get substantially stronger coding and long-horizon agent performance at the same cost. Z.ai plans to release the model's weights openly but has not set a release date. GLM-5.2 supports a 1M-token context window.
