# Z.ai releases GLM-5.1: 754B MoE open-weights model capable of 8-hour autonomous coding sessions

Z.ai (Zhipu AI) released GLM-5.1 — a 754B parameter MoE (40B active per token) open-weights model optimized for agentic coding. Key feature: can work autonomously on a single task for up to 8 hours, cycling through planning/execution/evaluation/strategy-revision loops hundreds of times. Highest-scoring open-weights model on Artificial Analysis Intelligence Index (51 in reasoning mode, behind Gemini 3.1 Pro and GPT-5.4 at 57). Led SWE-Bench Pro with 58.4% (vs GPT-5.4 57.7%, Claude Opus 4.6 57.3%). Third on Arena Code leaderboard (1,530 Elo). API pricing: $1.40/$0.26/$4.40 per million input/cached/output tokens. MIT license. Available on HuggingFace.
