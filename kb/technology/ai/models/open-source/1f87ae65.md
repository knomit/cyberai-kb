# Nemotron 3 Super 120B: Fastest Open-Weights Agentic Model, Hybrid Mamba-2/MoE Architecture

Nvidia released Nemotron 3 Super 120B-A12B (March 2026): First US-origin open-weights leader since Meta Llama 4. Architecture: Hybrid mamba-2/transformer/mixture-of-experts with multi-token prediction layers. 120B params, 12B active per token. 25T pretraining tokens, 20 natural languages, 43 programming languages. 1M-token context window. Performance: 442 tokens/sec (fastest open-weights in class, vs gpt-oss-120B at 278 t/s, Gemini 3.1 Flash-Lite at 266 t/s). PinchBench (agentic): 85.6%, beating Kimi K2.5 (1T params, 84.8%), GLM-5 (744B, 84.1%), Qwen3.5-122B (84.5%). RULER 1M tokens: 91.75% (vs Qwen3.5 91.33%, gpt-oss-120B 22.3%). Price: $0.30/$0.80 per 1M input/output tokens. Open weights + training data + recipes under license that terminates if safety guardrails removed or patent litigation filed against Nvidia. RL training: 3 stages (math/coding/science, GitHub issues with test execution reward, RLHF). Fine-tuning data generated by DeepSeek V3.2, Kimi K2, Qwen3-Coder-480B. Nvidia plans $26B over 5 years for open-weights. Key reason: Chinese open-weights models (DeepSeek trained on Huawei Ascend) threaten to pull developers away from Nvidia ecosystem.
