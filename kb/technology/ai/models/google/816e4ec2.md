# Google Nano Banana + Veo: Image and Video Generation Models with SigLIP Evaluation Pipeline

Google released Nano Banana, a new image generation model, alongside Veo (video generation), featured in the DeepLearning.AI course 'AI Agents for Image and Video Generation' (May 2026, co-developed with Google). The course teaches building agentic pipelines that combine generation with automated quality evaluation using: SigLIP (image-text similarity scoring) for evaluating generated images against prompts, LLM-based judges, and structured rubrics for scalable evaluation. The pipeline uses Gemini CLI to package generation + evaluation workflows into reusable agent skills. Practical applications covered: an image agent that converts brand guidelines into UI mockups, and a video agent that creates multi-scene explainers with synchronized audio and temporal consistency checks. Nano Banana represents Google's latest entry in the competitive image generation market.
