# OpenAI Codex expands from coding agent to universal desktop superapp

OpenAI's Codex (originally an answer to Claude Code for complex coding tasks) received a major update in early May 2026 expanding it to connect Slack, Google Drive, email, calendar, and everyday apps for general task automation. New 'Goal' feature lets users assign a task and Codex works until the goal is met. Key messaging from OpenAI: Sam Altman: 'Try it for non-coding computer work'; Greg Brockman: 'Codex is for everyone, for any task done with a computer.' Peter Steinberger (OpenClaw founder) was hired to lead this direction. Brockman confirmed in a GPT-5.5 briefing that the superapp rollout happens in stages. Note: Claude Cowork launched on January 12, 2026 — Codex is 'catching up.'
