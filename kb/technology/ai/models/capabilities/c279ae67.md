# Anthropic Doubles Claude's Context Token Limit: Design Token Expansion to Support Larger Codebases

Anthropic announced a doubling of Claude's design token (context window) capacity, enabling the model to process significantly larger codebases, documents, and multi-file projects in a single context. The expansion is particularly significant for software engineering use cases where full repository context is needed for accurate refactoring, dependency analysis, and code generation. The move keeps Claude competitive with models like Gemini 1.5 Pro and GPT-4o that have also expanded context windows substantially. Larger context also benefits agentic workflows where accumulated tool call history and intermediate state must remain in-context across long tasks.
