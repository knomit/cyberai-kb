# DeepSeek releases V4-Pro-0813 with aggressive pricing

DeepSeek rolled out DeepSeek-V4-Pro-0813 on its API and chat, priced at $0.435 per 1M input tokens and $0.87 per 1M output tokens. The model reportedly outcompetes Claude Opus 4.8 on the Terminal Bench 2.1, Cybergym, DeepSWE, and AutomationBench benchmarks. DeepSeek was second only to Anthropic in total tokens consumed in July.
