# DeepSeek-V4.1-Flash-1017 cuts KV cache to 890 bytes per token

DeepSeek-V4.1-Flash-1017 (Hugging Face repo) combines cross-layer KV cache reuse in Compressed Sparse Attention 2 with FP4 KV caching, reducing its global KV cache footprint to 890 bytes per token; its persistent KV cache is roughly 1/8 that of DeepSeek-V4-Flash. DeepSeek claims improvements across reasoning, coding, agentic tasks and visual benchmarks, with reduced task execution time and output length.
