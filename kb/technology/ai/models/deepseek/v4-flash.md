# DeepSeek V4-Flash: production release with speculative decoding, cheapest well-known model to run

DeepSeek released the production version of V4-Flash, featuring stronger agentic performance and an attached speculative decoding module for faster inference; the DeepSeek-V4-Flash API went live in public beta. Separately, research cited by Reuters (surfaced in TLDR AI, Aug 4, 2026) found V4-Flash to be by far the cheapest to run among well-known models, costing about 105 times less than Anthropic's Claude Fable 5.
