# DeepSeek released DeepSeek-V4-Pro-0813 and the open-source Harness v0.1 agent harness in August 2026

On Thursday August 13, 2026, DeepSeek launched two things together: Harness v0.1, an open-source agent harness released in developer preview under the MIT license, and DeepSeek-V4-Pro (shipped as DeepSeek-V4-Pro-0813), its latest flagship model built for agentic workloads.

Harness v0.1 positions DeepSeek as an open-source challenger to Anthropic's Claude Code and signals a deliberate push at the developer and enterprise audience.

DeepSeek-V4-Pro-0813 rolled out on DeepSeek's API and chat priced at $0.435 per 1M input tokens and $0.87 per 1M output tokens. It reportedly outcompetes Claude Opus 4.8 on the Terminal Bench 2.1, Cybergym, DeepSWE, and AutomationBench benchmarks. DeepSeek was second only to Anthropic in total tokens consumed in July 2026.
