# DeepSeek released Harness v0.1 and DeepSeek-V4-Pro for agentic workloads

On Thursday Aug 13, 2026, DeepSeek launched Harness v0.1, an open-source agent harness in developer preview under the MIT license, alongside DeepSeek-V4-Pro, its latest flagship model built for agentic workloads. The harness positions DeepSeek as an open-source challenger to Anthropic's Claude Code and signals a push at the developer/enterprise audience.
