# DeepSeek-V4.1-Flash cuts KV cache to ~890 bytes per token via an asymmetric encoder-decoder

DeepSeek released V4.1-Flash on 2026-09-10, the smallest model in a new architecture family, live on the DeepSeek API with native multimodal/visual understanding; V4-Flash and V4-Flash-Vision-Exp were retired. It uses an asymmetric Causal Encoder-Decoder (CED) design — a 20-layer causal encoder followed by a 20-layer decoder — with 552B total MoE parameters but only ~8B active for input and ~16B for output. The headline efficiency result is KV cache compression to roughly 890 bytes per token, about 1/4 the HBM and 1/8 the SSD of the previous generation. This specifically targets the dominant cost in agentic workloads: repeatedly processing very long inputs and holding their KV cache, which is why the reported gains concentrate on agentic benchmarks rather than general quality. Architecture and benchmark figures are DeepSeek-reported.
