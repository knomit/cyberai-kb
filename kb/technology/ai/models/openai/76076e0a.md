# OpenAI releases GPT-5.5 via recursive self-improvement

OpenAI released GPT-5.5 on April 24, 2026, just seven weeks after GPT-5.4. The model was built using itself and Codex (recursive self-improvement / RSI). Key improvements: better long-horizon task handling (planning, feedback, iterations, tool use), more intuitive problem-solving with less guidance, improved computer use across 44 occupations, multi-step scientific workflows and novel math insight generation. OpenAI reported zero latency impact despite capability gains. President Greg Brockman confirmed GPT-5.5 will power ChatGPT's upcoming 'superapp', which will transform Codex from a developer tool into a consumer app for workflow automation.
