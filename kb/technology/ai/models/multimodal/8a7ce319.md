# DeepSeek released V4-Flash-Vision-Exp, an experimental multimodal model rivaling Opus 4.8 on agent benchmarks

DeepSeek released DeepSeek V4-Flash-Vision-Exp, an experimental multimodal model that adds image understanding to its text capabilities. It nearly matches Anthropic's Opus 4.8 on agent tasks and is designed to work across different agent frameworks. Capabilities include describing images, extracting text from screenshots, analyzing diagrams, and handling multiple image formats. It is API-compatible with OpenAI's Chat Completions and Responses APIs and Anthropic's Messages endpoint.
