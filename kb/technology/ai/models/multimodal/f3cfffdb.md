# TypeSafe Jev 1.14.0 adds image support and a 'box' output type; multimodal worse than text

TypeSafe's Jev 1.14.0 adds image support, longer context, and a new 'box' type returning a single bounding box; multimodal support was also enabled for Jev 1.13.0. Both models perform worse on multimodal tasks than on pure text; decomposing questions into the simplest pieces helps a lot. The box type previews TypeSafe's exploration beyond simple decisions with System One Models.
