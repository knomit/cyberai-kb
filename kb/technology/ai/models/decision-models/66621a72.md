# Cloudflare open-sources Clef and Clef-flash decision models (Apache 2.0)

Cloudflare introduced Clef and Clef-flash, open-source 'decision models' (Apache 2.0, on Hugging Face, runnable locally) that classify and return typed answers with probabilities so agents can gather context, decide, act, or defer to a human; Jev-API compatible, alongside a new RL fine-tuning platform. Related: Kev (4 open models, 0.8B-27B, same API as TypeSafe's Jev, full 27B training corpus private), Perplexity pplx-decider-v1-27b (fine-tuned from a Qwen base), and Amazon Strands Decider 2B.
