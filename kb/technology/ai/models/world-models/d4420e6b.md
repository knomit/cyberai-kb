# Runway GWM Worlds 2 generates interactive worlds at 720p/24fps in real time

Runway announced GWM Worlds 2 (2026-09-03), a world model that generates interactive environments in real time at 720p, 24 frames per second, with 48 kHz audio. Users steer the world using text actions and camera motion; each session continues from the latest input with no fixed preset length. Specifications are Runway-reported.
