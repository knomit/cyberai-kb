# Meta released Muse Spark 1.3 with production-oriented changes

On 2026-09-02/03 Meta released Muse Spark 1.3, an update to its Muse Spark model line, citing improved coding and agentic performance plus changes intended to make the model easier to use in production. It began rolling out through Muse Code and the Meta Model API. Notably, its highest reasoning mode was withheld at launch pending additional safety testing, so 'Muse Spark 1.3 is available' does not mean the full reasoning tier was available on day one. Performance claims here are Meta-reported, not independently benchmarked.
