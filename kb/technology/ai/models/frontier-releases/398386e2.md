# OpenAI's GPT-6 Astra: first model rated "critical" for cyber capability, and an ARC-AGI-3 score that depends on the harness

OpenAI launched GPT-6 Astra, its flagship vision-language model, on 2026-09-03 (covered in The Batch 2026-09-11). It is the first model OpenAI has designated as meeting the "critical" cybersecurity level of its Preparedness Framework — OpenAI's description is that with the right tools and access it can find previously unknown security flaws and develop new exploits across many well-protected systems without step-by-step human guidance. The most advanced cyber abilities are restricted to selected defenders in the Daybreak program, and the launched model refuses to write proof-of-concept exploits.

Specification: text and images in (up to 1,050,000 tokens), text out (up to 128,000 tokens, 71.3 tokens/second). Knowledge cutoff 2026-04-30. Five reasoning levels (low, medium, high, xhigh, max), adjustable mid-conversation without invalidating cache; tool use including computer use, shell, code interpreter, web and file search; asynchronous tool calls that let it keep reasoning while a tool runs; mid-turn steering; compaction; reasoning retained between API calls; and in Codex an experimental, off-by-default mode where it writes searchable notes to itself instead of compacting. Price: $10/$1/$12.50/$50 per million input/cached input/cache write/output tokens, with requests above 272,000 input tokens charged 2x input and cache and 1.5x output; batch and flex at half price, fast mode at double. Architecture, parameter count and training data undisclosed. VP of research Aidan Clark says it was trained on more than 100,000 GPUs — OpenAI's largest run — and it is the first run where earlier OpenAI models played a key role in supervising training. It was trained on Model Spec examples applied to real situations and on attacks generated by GPT-Red, OpenAI's automated red-teaming agent.

The measurement that most needs care — ARC-AGI-3, interactive puzzle environments where an agent must discover each game's rules by exploring: under ARC Prize's provider-neutral standard harness, GPT-6 Astra at max reasoning solved 62.7% of the semi-private set at $26,098, versus a previous best of 30.2% by Claude Opus 5 at high reasoning. Under ARC Prize's Provider Adapter harness — which calls OpenAI's API with hidden reasoning preserved across requests and long histories compacted — the same model at high reasoning scored 99.9% at $18,817. Quoting "99.9% on ARC-AGI-3" without the harness qualifier is the foreseeable misreading; the honest summary is that two harnesses on the same benchmark differ by 37 points. Astra also used fewer actions than the median human tester on 96% of levels, 57.3% fewer actions per level. ARC Prize says this does not demonstrate AGI, noting its games are closed and deterministic.

Other independent results: second on Artificial Analysis' Intelligence Index v4.2 at max reasoning (55, $2.57 and 5.2 min/task), behind Claude Fable 5.1 with fallback (57, $6.12, 9.9 min) and ahead of Claude Opus 5 (54); tied for first on the v4.3 update (53, $3.26, 8.2 min). It leads four v4.2 components: GDP.pdf (33.2%), AA-Omniscience (44), GPQA Diamond (96.3%) and MMMU-Pro (87%). Third on Vals AI's Vals Index at max reasoning (66.61%, $19.09, 25 min/task) behind Claude Fable 5.1 (68.83%) and Claude Opus 5 (67.21%), while leading Vals components Code Migration (67.74%), BioMysteryBench (79.26%) and Terminal-Bench 2.1 (87.27%). First on Arena AI's WebDev leaderboard. OpenAI's own tests: 59.3% on Agents' Last Exam versus Claude Opus 5's 55.5% while using ~65% fewer tokens, and 72.6% on an offline OSWorld 2.0 subset at ~40 min/task versus GPT-5.6 Sol's 65.7% at 75 min.

Safeguards mechanics: classifiers review reasoning and actions on every tool-using call and can interrupt. In ChatGPT or Codex a flagged task pauses for user approval; via the API the request ends and cannot be resumed. The checks run alongside the model rather than ahead of it, and OpenAI warns an action may complete before it is flagged.

The generalizable point The Batch draws: per-token price is a poor guide to cost per task, and reasoning level is becoming one too. Astra's per-token price is 2.5x GPT-5.6 Sol's yet it completed Artificial Analysis' agentic coding tasks for about the same money by using a third as many tokens, and on ARC-AGI-3 higher reasoning levels cost *less* than lower ones because it solved games in fewer moves. Measure cost per task on your own setup.
