# Cisco releases Antares open-weight small language models for security

On July 21, 2026, Cisco unveiled Antares, a series of open-weight small language models (SLMs) purpose-built for source code vulnerability triage. Available on Hugging Face in 350M and 1B parameter sizes (a 3B version coming), Cisco says Antares outperforms closed and open models including Google Gemini/Gemma, GPT-OSS, and Alibaba Qwen on security tasks and performs on par with OpenAI's GPT-5.5 while being roughly 172x cheaper at the same tasks. The models run locally/on-premise, enabling inference in 'seconds rather than hours.'
