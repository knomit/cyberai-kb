# Ling-3.1-flash: 560B total / 25B active hybrid reasoning model with 1M context

inclusionAI released Ling-3.1-flash on Hugging Face: a native hybrid reasoning model with 560 billion total parameters, 25 billion active parameters per token, and a one-million-token context window, aimed at complex real-world tasks.
