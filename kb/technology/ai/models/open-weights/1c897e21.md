# Meta releases Muse Spark Open: 816B-param multimodal open-weight model

Meta released Muse Spark Open on 2026-10-15: natively multimodal, 816B total / 42B active parameters, 1M-token context, aimed at coding, agentic and long-horizon tasks. Meta says it is the first model of its size class able to run on two Apple M5 Ultra Mac Studios via MLX. Available via Baseten, Fireworks, Groq, Modal, Nebius, OpenRouter, Together AI; weights downloadable from Amazon, Google Cloud, Hugging Face, Microsoft. Per Deep View, Moonshot's Kimi K3 still beats it on Terminal-Bench 2.1 and DeepSWE 1.1.
