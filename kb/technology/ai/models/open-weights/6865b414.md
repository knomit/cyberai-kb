# NVIDIA Nemotron 3.5 Lightning: open 30B MoE model for agent workloads

NVIDIA released Nemotron 3.5 Lightning, an open 30-billion-parameter mixture-of-experts model with 3B active parameters, designed for low-latency, high-volume tasks in long-running AI agents; it can run on a single GPU or laptop. NVIDIA claims up to 4x faster output than comparable class models and ~30% faster agentic task completion than Qwen3.6-35B at matching accuracy. Paired with NVIDIA's new open-source NeMo Switchyard library — which routes each step of an agent workflow to whichever model fits best — it retains frontier-level task completion while costing roughly a third of running Opus 4.8 alone (per NVIDIA's own tests).
