# Cloudflare Clairic: 'extraction model' that outputs values with confidence scores instead of generating tokens

Cloudflare introduced Clairic, described as a new class of 'System One'-style extraction model. It extracts, computes, estimates and forecasts values from unstructured input and returns them directly without generating tokens, so it cannot produce mistyped answers or hallucinate in the same way LLMs do. It can still be wrong, but outputs carry confidence scores to help users decide when to trust or re-check.
