# NVIDIA releases Nemotron 3 Embed open embedding models; 8B ranks first on RTEB

NVIDIA released three open embedding models under the Nemotron 3 Embed family, targeting RAG, agentic retrieval, code search, and memory. The 8B model ranked first overall on RTEB (Retrieval Embedding Benchmark).
