# Google released Gemma 4 E2B optimized for the Pixel 10 TPU

Google announced Gemma 4 E2B for TPU, a model designed to run natively on the Pixel 10's TPU. It supports offline conversation, image identification, and on-device audio transcription, and lets users command core phone functions such as Wi-Fi or maps via private on-device voice or text.
