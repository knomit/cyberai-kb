# Apple 20B-parameter on-device model streams weights from flash, activating 1-4B parameters and ~2GB memory

TLDR AI (2026-10-26) summarizing an AIRealist analysis: Apple's 20-billion-parameter on-device model keeps most weights in flash storage and activates only 1-4 billion parameters per prompt. On an M3 Max Mac it used roughly 2GB of memory with significantly lower energy use than comparable open models, but weaker math performance.
