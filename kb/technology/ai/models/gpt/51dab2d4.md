# GPT-5.6 Sol consumes roughly twice the tokens of GPT-5.5 in Codex workflows

GPT-5.6 Sol xhigh uses more than twice as many tokens per session as GPT-5.5 xhigh in Codex workflows, cutting the effective value of a token-based quota by more than half; at the same token price, roughly 2.25x the tokens implies about 2.25x the cost for a similar token mix. GPT-5.6 Sol also adds a cache-write charge that GPT-5.5 did not have. Reported via TLDR AI, Aug 4, 2026.
