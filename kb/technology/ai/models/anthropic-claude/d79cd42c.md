# Anthropic released Claude Fable 5.1 and Mythos 5.1 on 2026-09-01

On Tuesday 2026-09-01 Anthropic announced Claude Fable 5.1 and Mythos 5.1, the latest versions of its most powerful model line. Fable 5.1 is generally available; Mythos 5.1 uses the same underlying model but with specialized access controls for advanced cybersecurity and life-sciences work and is available only through trusted-access programs. Anthropic claims Fable 5.1 sets a new standard for coding, knowledge work and long-running problem-solving, beating prior generations and OpenAI's GPT-5.6 Sol on those benchmarks. Early-access testers included Cognition, Rakuten, Red Hat, Block, Ramp and Canva.
