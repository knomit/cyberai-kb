# Bonsai 2 27B ships ternary weights at 1.76 effective bits for a 5.9GB footprint

Prism ML released Bonsai 2 27B, a ternary-weight model using {−1, 0, +1} weights with FP16 group-wise scaling, yielding 1.76 effective bits per weight and a total model footprint of 5.9GB — roughly 9x smaller than an equivalent uncompressed model. It supports a 262K-token context window and multimodal text-and-image input, and runs on NVIDIA GPUs via CUDA and on Apple devices via MLX through custom low-bit kernels. The release claims stronger reasoning, coding, vision, and agentic capability than prior Bonsai models. Operational consequence: the combination that matters is ternary weights AND FP16 group-wise scaling AND custom low-bit kernels — the footprint claim does not hold without the kernel support, so deployment requires CUDA or MLX specifically, not arbitrary inference runtimes.
