# PrismML announced Bonsai 27B, a 27B-class model running on a phone

PrismML announced Bonsai 27B, described as the first 27B-class model to run on a phone. It achieves this through 1-bit and ternary weights, shrinking model size to 3.9 GB (1-bit) and 5.9 GB (ternary). The model supports multi-step reasoning and tool use while fitting within modern smartphone device limits.
