# Cursor releases Composer 2.5 coding model; SpaceX holds $60B acquisition right

Cursor released Composer 2.5, its native agentic software-engineering model, based on Moonshot's open-weights Kimi K2.5 (mixture-of-experts, ~1.04T parameters / 32B active) with up to 200K-token input. It ranks third on the Artificial Analysis Coding Agent Index (behind Claude Opus 4.7 and GPT-5.5) but runs faster and far cheaper, and leads on Cursor's own CursorBench at default settings. It was trained via further pretraining on code plus reinforcement learning inside a simulated Cursor CLI harness. Per The Batch, SpaceX obtained (in April) the right to acquire Cursor for $60 billion (or pay $10 billion) as part of a partnership; Cursor will train future models on SpaceX hardware and from scratch.
