# Microsoft MAI-Code-1.1-Flash improves coding quality at a quarter of the cost

Microsoft released MAI-Code-1.1-Flash, which it says produces higher-quality code at 25% greater token efficiency and a quarter of the cost of its June predecessor, achieved by optimizing across hundreds of thousands of reinforcement-learning environments in GitHub Copilot. It shows a 22% improvement on Terminal-Bench 2.1 in GitHub Copilot CLI and a 15% improvement on .NET tasks, and is now available in GitHub Copilot.
