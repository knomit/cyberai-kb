# Z.ai releases GLM-5.2 open-weights agentic model

Z.ai released GLM-5.2, an open-weights large language model optimized for coding and autonomous agentic tasks. It is a mixture-of-experts transformer with 753 billion total parameters and 40 billion active per token, accepting up to 1 million input tokens and producing up to 128,000 output tokens at ~103 tokens/second. Weights are available under the MIT license on Hugging Face for commercial and noncommercial use; API pricing is $1.40/$0.26/$4.40 per million input/cached/output tokens. It expands context to 1M tokens (from GLM-5's 200,000) by modifying DeepSeek sparse attention and using a sparse attention indexer once every four layers, cutting per-token compute ~2.9x at 1M-token context.
