# Superwhisper's S1-mini is a 0.6B text normalizer reaching 94.8% token accuracy on ASR cleanup

Superwhisper released S1-mini, a 0.6B-parameter text normalizer for speech-to-text outputs that transforms raw ASR transcripts into clean written text at 94.8% token accuracy. It is optimized for English, runs comfortably on CPU, and requires a specific input format including a control line specifying styling, structure, and context settings.
