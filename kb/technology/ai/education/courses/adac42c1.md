# DeepLearning.AI: 'Build Interactive Agents with Generative UI' short course (CopilotKit, May 2026)

DeepLearning.AI launched a new intermediate short course 'Build Interactive Agents with Generative UI', taught by Atai Barkai (CEO, CopilotKit). Duration: 1h25m, 8 video lessons, 5 code examples. Currently free during the DeepLearning.AI platform beta. The course covers: (1) Generative UI Spectrum — Controlled (hand-crafted components like pie charts/flight cards the agent renders on demand), Declarative (A2UI spec, co-developed with Google, where agents assemble layouts from reusable building blocks), and Open-Ended (agent-created UIs via MCP Apps); (2) Connecting LangChain and Google ADK agents to a React frontend via CopilotKit + AG-UI protocol; (3) Building canvas apps where agent and user share live state. Prerequisites: React, Python, basic LLM/agent familiarity. Audience: fullstack devs, AI engineers, frontend builders shipping agent features.
