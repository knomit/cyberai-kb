# DeepLearning.AI + Oracle course: Agent Memory — Building Memory-Aware Agents (Mar 2026)

DeepLearning.AI launched a new short course with Oracle (March 18, 2026): 'Agent Memory: Building Memory-Aware Agents.' Core problem: AI agents lose all knowledge when session ends. The course teaches how to build a memory-first architecture with persistent memory stores, a Memory Manager that orchestrates read/write, semantic search for tool retrieval, and memory extraction/consolidation/write-back pipelines. Stack: Oracle AI Database, LangChain, LLM-powered pipelines. Transforms stateless agent into one that learns and improves over time. Instructors: Richmond Alake (Director of AI Developer Experience, Oracle) and Nacho Martínez (Data Science Advocate, Oracle). Note: Andrew Ng's letter that week also observed that 'the Product Management bottleneck, which is already acute, will get worse' as coding agents improve.
