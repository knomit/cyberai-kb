# Wiz: State of AI in the Cloud 2026 — key statistics

Wiz Research's second annual 'State of AI in the Cloud 2026' report (promoted via The Hacker News, May 27, 2026) found: (1) 81% of organizations use managed AI services; 90% run self-hosted models — AI is now core operational infrastructure. (2) 68% of organizations using self-hosted models ingest them via third-party software ('transitive AI'), creating inherited model risks and supply chain vulnerabilities without explicit deployment. (3) 80% of organizations use AI IDE extensions ('vibe coding' is now a day-one engineering reality). Roughly 1 in 5 organizations using AI coding platforms have systemic security weaknesses from insecure AI-generated defaults. (4) 57% of organizations deploy self-hosted AI agents; 80% have adopted Model Context Protocol (MCP) servers. These create often-overprivileged control planes that attackers can exploit for lateral movement.
