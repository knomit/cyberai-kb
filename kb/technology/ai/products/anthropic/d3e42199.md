# Anthropic Claude Code redesigned for parallel multi-agent workflows with View Modes and Routines

Anthropic redesigned Claude Code desktop on April 15, 2026. Focus: accommodating parallel agents and multi-threaded workflows. Key changes: (1) New sidebar managing multiple sessions with filtering by status/project/environment; (2) Drag-and-drop session rearranging; (3) Integrated terminal and file editor; (4) View Modes — Verbose/Normal/Summary (user chooses depth of process visibility); (5) New keyboard shortcuts including [⌘+/] or [Ctrl+/] for full shortcuts list; (6) Rebuilt for speed and reliability; (7) Full CLI plugin parity and SSH remote machine support. Also released in research preview: Claude Code Routines — automate sessions via API call, event trigger, or schedule. Week before: Claude Managed Agents and Advisor tool. Anthropic blog: 'You're not typing one prompt and waiting… The new app is built for how agentic coding actually feels now: many things in flight, and you in the orchestrator seat.'
