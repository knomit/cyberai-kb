# Anthropic's Project Parka turns meeting audio into runnable work for Claude agents

Project Parka is an Anthropic feature, Mac-first, that captures system and microphone audio, streams speaker-attributed transcripts, and creates runnable work items for Claude's agents — effectively turning a meeting into implementation prompts. As reported, it was not clear whether Claude starts actions automatically or waits for user approval.
