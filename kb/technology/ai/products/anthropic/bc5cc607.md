# Anthropic Opus 4.7 bridges gap to Mythos as Project Glasswing testbed

Anthropic released Claude Opus 4.7 on April 17, 2026. Key improvements over 4.6: better software engineering, substantially higher image resolution, more creative professional outputs, higher-quality documents/slides/designs, gains in instruction following/memory/multimodal support. Benchmarks show gains in agentic coding, multidisciplinary reasoning, tool/computer use, visual reasoning. Scored similarly on safety/alignment (deception, sycophancy). Price unchanged: $5/M input, $25/M output. Available in all Claude products, API, Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry. Box Head of AI Yashodha Bhavnani: 'significantly more with less — fewer tool calls, lower latency.' Anthropic positioned Opus 4.7 as (1) a bridge to Mythos and (2) a real-world testbed for Project Glasswing cybersecurity safeguards: 'What we learn from the real-world deployment of these safeguards will help us work towards our eventual goal of a broad release of Mythos-class models.'
