# Anthropic launched a Claude reflection dashboard

Per The Deep View, Anthropic launched a reflection dashboard in Claude's settings (claude.ai/settings/reflect) on July 9, 2026, summarizing usage patterns, key topics, and task types, with options like quiet hours and break nudges. It is in beta on Free, Pro, and Max plans for web and desktop, runs only when memory is on, and excludes incognito chats and health-integration content. The same day, Anthropic reset the 5-hour weekly rate limits for its Fable model.
