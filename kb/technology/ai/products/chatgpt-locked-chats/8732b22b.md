# ChatGPT Locked Chats: PIN/biometric-protected chats excluded from memory

On 2026-10-21 OpenAI launched Locked Chats in ChatGPT: chats moved into a protected space unlocked with a PIN in the browser (Face ID, Touch ID or device unlock on supported devices). New messages in locked chats do not update memory used by regular chats. Rolling out to Free, Go, Plus, Pro, Business, Enterprise and Edu. It differs from Temporary Chat, which cannot be revisited.
