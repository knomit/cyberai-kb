# OpenAI superapp to merge ChatGPT, Atlas browser, and Codex into unified agentic platform

OpenAI is developing a 'superapp' merging its three desktop products: (1) ChatGPT desktop — chat history, projects, custom GPTs; (2) Atlas web browser (launched Oct 2025, Chromium-based, multi-tab AI queries); (3) Codex — coding agent and general-purpose agent harness. OpenAI president Greg Brockman told the Big Technology Podcast: 'Over the next couple months, we should have shipped the complete vision… it's going to come in pieces.' Codex is the starting point, positioned as 'a general agent harness that knows how to use tools.' Combined product would bring multi-tab browsing + agentic automation to OpenAI's 900M users — similar to 'OpenClaw in the mainstream.' Microsoft exec confirmed exploring 'OpenClaw in enterprise context.' OpenAI also acquired Hiro Finance (personal finance, founded 2024) in the same week, signaling financial management as a superapp use case.
