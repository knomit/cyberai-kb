# OpenAI's agent harness (open-source) powers both Codex and ChatGPT Work

In an exclusive interview with The Deep View, OpenAI engineers described the agent 'harness' as the technology underneath both Codex and ChatGPT Work — the layer that manages context, connects plugins/tools, executes actions, and keeps the model on task. Notably, OpenAI's Codex agent harness is open-source, unlike Anthropic's Claude Code harness. Joe Gershenson, OpenAI's lead for harness engineering, said 'the harness is how the model interacts with the world.' ChatGPT Work is positioned as 'Codex for the masses,' aimed at the roughly 990 million ChatGPT users who don't use Codex.
