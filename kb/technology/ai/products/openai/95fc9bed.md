# OpenAI's early-May 2026 'superapp' direction: merge ChatGPT desktop, the Atlas browser and Codex into one agentic platform, with Codex explicitly repositioned for non-coding computer work

MERGED from two records of the same early-May 2026 announcement window, both resting principally on Greg Brockman's public remarks. Each carried details the other omitted; both are preserved. Confidence is LOWERED from the 0.95 each input carried, because both were single-source newsletter/podcast reporting of a stated plan, not of a shipped product.

## THE PLAN
OpenAI is developing a 'SUPERAPP' merging its three desktop products:
1. CHATGPT DESKTOP — chat history, projects, custom GPTs.
2. ATLAS WEB BROWSER — launched October 2025, Chromium-based, multi-tab AI queries.
3. CODEX — coding agent and general-purpose agent harness.
Greg Brockman told the Big Technology Podcast: 'Over the next couple months, we should have shipped the complete vision… IT'S GOING TO COME IN PIECES.' Codex is the STARTING POINT, positioned as 'a general agent harness that knows how to use tools.' Brockman separately confirmed in a GPT-5.5 briefing that the superapp rollout happens IN STAGES.

## THE CODEX EXPANSION THAT STARTED IT
Codex — originally an answer to Claude Code for complex coding tasks — received a major update in EARLY MAY 2026 expanding it to connect SLACK, GOOGLE DRIVE, EMAIL, CALENDAR and everyday apps for general task automation. A new 'GOAL' feature lets users assign a task and Codex works UNTIL THE GOAL IS MET.

## THE MESSAGING
- Sam Altman: 'TRY IT FOR NON-CODING COMPUTER WORK.'
- Greg Brockman: 'CODEX IS FOR EVERYONE, FOR ANY TASK DONE WITH A COMPUTER.'

## PERSONNEL AND ADJACENT MOVES
PETER STEINBERGER, OpenClaw founder, was hired to lead this direction. OpenAI also acquired HIRO FINANCE (personal finance, founded 2024) in the same week, signalling financial management as a superapp use case.

## SCALE AND COMPETITIVE FRAMING
The combined product would bring multi-tab browsing plus agentic automation to OpenAI's ~900 MILLION users — characterised in coverage as 'OpenClaw in the mainstream'. A Microsoft executive confirmed exploring 'OpenClaw in enterprise context'. Note the competitive ordering: CLAUDE COWORK LAUNCHED ON 12 JANUARY 2026, so Codex is described as CATCHING UP rather than leading here.

## WHAT THIS DOES NOT MEAN
- This records a STATED PLAN AND A FEATURE EXPANSION, not a shipped superapp. 'Over the next couple months' is Brockman's estimate.
- The ~900 million user figure is OpenAI's own and is a ChatGPT figure, not a Codex or superapp figure.
- SUBSEQUENT DEVELOPMENT THAT CHANGES THE PICTURE: kb/technology/ai/products/openai/atlas/0ac6e0ad.md records that OpenAI SHUT DOWN THE ATLAS BROWSER (reported July 2026), folding its agentic browsing features into the ChatGPT desktop app. So the three-way merge described here did not happen as three products converging; one of the three was retired into another. Do not cite this record as a description of what OpenAI shipped.
- Both inputs were single-source and carried 0.95 confidence, which overstated a plan-stage claim.
