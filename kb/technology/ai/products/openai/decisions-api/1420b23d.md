# OpenAI Decisions API (GPT-6 Luna based) generally available at $0.10/M input tokens, no output charge, rivaling TypeSafe Jev

On Thursday (Oct 22, 2026) OpenAI made Decisions API generally available (previously public beta): built on GPT-6 Luna, priced at $0.10 per million input tokens, $0.01 per million cached input tokens, no charge for output tokens (still over twice Jev's cost). It produces software-actionable outputs rather than human-readable text. OpenAI says internal agents decide up to 10x faster than Luna via the Responses API (TechCrunch: ~3 s down to ~100 ms). TypeSafe's Jev uses a non-language model trained with 'Reinforcement Learning for Calibrated Decisions', reports 70-500 ms end-to-end latency, and TypeSafe raised $870M at a $7.5B valuation led by Andreessen Horowitz. Signals an enterprise pivot from frontier LLMs to cheap decision-specialized models.
