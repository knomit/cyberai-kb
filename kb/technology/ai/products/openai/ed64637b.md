# OpenAI Codex expands to computer use, memory, 111 plugins, and scheduled future tasks

OpenAI announced major Codex upgrades on April 17, 2026. Codex now has 3M+ weekly developer users. New capabilities: (1) Computer use — runs desktop apps in background on macOS, enabling parallel agents without disrupting other apps; (2) In-app browser — natively works with the web; (3) gpt-image-1.5 integration for image generation/editing; (4) 111 new Plugins combining skills, app integrations, and MCP servers; (5) SSH connections to remote devboxes (alpha); (6) Sidebar with PDF/spreadsheet/slides/doc preview; (7) Memory feature (preview) remembering preferences and context across conversations; (8) Scheduled future work — Codex can schedule tasks across days/weeks autonomously; (9) Suggestions for where to pick up previous projects. Computer use currently macOS only. Codex App Lead Andrew Ambrosino: 'Teach Codex to work across a much larger surface area instead of just call and response with some plugins.'
