# OpenAI platform updates: MCP Events, Sign in with ChatGPT, Decisions API

OpenAI docs: MCP Events lets ChatGPT subscribe to MCP server updates via webhook delivery and callback verification from the draft MCP Events spec; polling, streaming and the draft's gap/terminated control notifications are unsupported. Sign in with ChatGPT lets authenticated ChatGPT users sign in to partner apps, available globally; initial partners Airtable, GitLab, HubSpot, Notion, Supabase, Vercel. Decisions API (GPT-6 Luna) is in limited preview for classification/routing/next-action choice with text and image context, broad release planned within days.
