# OpenAI Codex reached 10M monthly users; harness optimizations cut token usage

The Deep View reported that OpenAI's Codex coding agent has grown to 10 million monthly users (against OpenAI's roughly 1 billion monthly users). Following optimization of the agent harness, inference layer, and API stack, OpenAI reported: GPT-5.6 Sol with max reasoning outperforms Claude Fable 5 on the Artificial Analysis Coding Agent Index while using 54% fewer output tokens; GPT-5.6 Terra performs on par with GPT-5.5 on intelligence benchmarks at half the price; and GPT-5.5 Luna is OpenAI's fastest model and costs 80% less than Sol. The push responds to an enterprise backlash against runaway agent token costs.
