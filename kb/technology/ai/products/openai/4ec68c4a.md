# OpenAI launches Meetings plugin (note-taker) in ChatGPT

OpenAI launched a Meetings plugin in the new ChatGPT Space tab that records meetings, generates a transcript and summary with action items using ChatGPT's personal context. Per The Deep View's test, transcripts lack speaker labels and audio cannot be replayed, so it substitutes for Granola more than Otter.ai.
