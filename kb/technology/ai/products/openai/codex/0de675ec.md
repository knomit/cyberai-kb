# OpenAI is folding Codex into ChatGPT to reach non-coders

OpenAI is collapsing the wall between ChatGPT and Codex, putting all of Codex's agent capabilities inside ChatGPT so users no longer toggle between apps, and opening it beyond software developers. Alex Embiricos (head of enterprise product) framed this as a second phase: turning useful agents into capabilities for everyone, with the same Codex features available on computer and phone within ChatGPT. OpenAI also launched six role-specific plugins targeting creative production, sales, and public-equity investing. Practical non-coder uses demonstrated include drafting/sending messages via connected email or Slack, calendar briefings via a plugin, and scheduled daily automations (e.g., an 8 AM meeting-and-inbox summary). Codex's main rival in this space is Anthropic's Claude Code.
