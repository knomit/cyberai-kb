# Cursor launched Cursor Router for cost-efficient model routing

Cursor released Cursor Router, an intelligent model router that selects the appropriate model per task, claiming frontier-quality results at roughly 60% lower cost. Early-access customers reported no drop in quality and lower cost per commit versus routing all requests to Opus 4.8. It is available across Teams and Enterprise plans, with admin controls to enable it per team and allow or block specific models.
