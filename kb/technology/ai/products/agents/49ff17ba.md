# Perplexity Computer - 19-model orchestration agent for multi-hour complex workflows

Perplexity launched Perplexity Computer (perplexity.ai/computer), a general-purpose digital worker that orchestrates 19 AI models (open-source + proprietary). Model assignments at launch: Claude Opus 4.6 (orchestration + coding), Gemini (deep research), Nano Banana (images), Veo 3.1 (video), Grok (speed/lightweight tasks), ChatGPT 5.2 (long-context recall + wide search). Capabilities: tools, files, personal context, deep web research, agentic web access, coding, file creation; runs in secure development sandbox; can run for hours or months. Availability: Perplexity Max ($200/month) immediately, rolling to Pro ($20/month) and Enterprise; web-only (not in app). Per-token billing introduced for consumers: Max users get 10K tokens + 20K launch bonus. Internal Perplexity usage examples: engineering docs published rapidly, 4K-row spreadsheet built overnight (normally 1 week), websites/dashboards/apps/visualizations. Key differentiation: outcome-driven orchestration across best-in-class specialist models vs single-model approach (vs Claude Code/OpenClaw).
