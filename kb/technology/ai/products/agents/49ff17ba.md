# Perplexity Computer: 19-model orchestration agent — launch through enterprise expansion

Perplexity launched Perplexity Computer (perplexity.ai/computer), a general-purpose digital worker orchestrating 19 AI models. Model assignments: Claude Opus 4.6 (orchestration + coding), Gemini (deep research), Nano Banana (images), Veo 3.1 (video), Grok (speed/lightweight tasks), ChatGPT 5.2 (long-context recall + wide search). Runs for hours or months in a secure sandbox with tools, files, personal context, deep web research, agentic web access, coding, and file creation. Originally Perplexity Max ($200/month), later expanded to Pro ($20/month) and Enterprise. Enterprise expansion (Apr 2026): 50+ prebuilt workflow templates (shareable, schedulable, asynchronous), Databricks and Snowflake connectors, 1Password integration (credentials stay private from AI models), Computer for Financial Services with Carbon Arc/Daloopa/Morningstar/PitchBook licenses. Available via Microsoft Teams/Marketplace and as a native Excel side panel (beta). Claims $2.8B in labor-equivalent work since launch; $1.6M in first four internal Slack weeks. Key differentiator: outcome-driven orchestration across best-in-class specialist models vs. single-model approach (cf. Claude Code/OpenClaw).
