# OpenAI Codex Gets Mobile Management via ChatGPT App, HIPAA Enterprise Support (May 2026)

OpenAI announced mobile management capabilities for its Codex coding agent in May 2026, allowing users to monitor and control long-running agent sessions from the ChatGPT iOS and Android apps.

Mobile capabilities added:
- View all running agent tasks
- Review outputs and see screenshots
- See terminal output in real-time
- Approve commands
- Change models mid-session
- Start new tasks

Enterprise/team upgrades:
- Remote SSH access
- Hooks (event-driven automation)
- Programmatic access tokens for business/enterprise
- HIPAA-compliant Codex for eligible ChatGPT Enterprise workspaces

Context: Codex reached 4 million weekly active users. Peter Steinberger (founder of OpenClaw, the pioneering local agent with text-message control) has been working at OpenAI for several months helping the Codex team. The mobile move signals OpenAI's trajectory toward a superapp merging Codex, ChatGPT, and the Atlas web browser.

Competitive context: Claude Code/Cowork was stymied by Anthropic's uptime issues stemming from rapid growth. The mobile-first agentic control capability goes beyond what any rival currently offers, including Perplexity Personal Computer.
