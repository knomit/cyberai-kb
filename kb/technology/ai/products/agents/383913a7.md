# NemoClaw + OpenClaw ecosystem: Nvidia enters personal AI agent market at GTC 2026

At GTC 2026 (Mar 18, 2026), Jensen Huang announced NemoClaw — Nvidia's addition to the OpenClaw agent ecosystem. NemoClaw integrates Nvidia's Nemotron open-source model family into OpenClaw 'self-evolving' autonomous AI agents. Key components: (1) OpenShell: open-source tech stack with policy-based guardrails for privacy and security controls. (2) Agent toolkit to optimize OpenClaw commands. OpenClaw has rapidly become the most-starred project on GitHub (Huang claimed 'most popular open-source project in history' — by star count only; Linux/Git/Apache are far more deployed). Vera Rubin platform announced: 7-chip, 5-computer rack 'AI factory' built to scale agentic AI; includes Groq 3 LPU (chip designed specifically for fast LLM inference); available H2 2026. Also at GTC: Nemotron 3 Super (120B parameter model, one of most open in the world). Nemotron Coalition announced: Perplexity, Cursor, Thinking Machines Lab, Mistral AI, Black Forest Labs, LangChain, Reflection AI, Sarvam as inaugural members.
