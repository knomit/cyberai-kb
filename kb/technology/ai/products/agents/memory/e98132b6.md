# Claude Managed Agents: 'Dreaming' as Scheduled Memory Consolidation Process (May 2026)

Anthropic's Claude Managed Agents now include a capability called 'dreaming' — a scheduled memory process that runs asynchronously to consolidate and organize agent memory. This is a first-party implementation of the concept of scheduled knowledge distillation at the agent infrastructure level. The feature enables agents to process and structure accumulated context without being in an active reasoning session. Directly analogous to the post-session distillation pass concept for knowledge accumulation systems: Anthropic themselves are building the harvest-and-consolidate pattern into their managed agent offering. Source: The New Stack coverage of Anthropic Managed Agents announcement.
