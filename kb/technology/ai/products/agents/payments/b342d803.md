# Amazon Bedrock AgentCore Payments: AI Agents Can Now Autonomously Pay for Resources via USDC

Amazon Web Services launched Bedrock AgentCore Payments — a set of features enabling AI agents to autonomously access and pay for the resources they consume, including web content, APIs, MCP servers, and other agents. Payment infrastructure is built on Coinbase (USDC) and Stripe. This is the first major cloud provider to build native payment primitives into the agentic layer, enabling fully autonomous agent operation without human-in-loop for resource acquisition. Structural implication: agents can now compose multi-agent pipelines and pay downstream agents and services without human authorization per transaction. Introduces new attack surface (unauthorized agent spend) and new market dynamics (agents as economic actors).
