# Anthropic Launches Claude Managed Agents: Hosted Agentic Workflows with Built-In Orchestration

Anthropic launched Claude Managed Agents, a product that provides hosted, managed agentic workflow infrastructure directly on the Anthropic platform. Claude Managed Agents allows enterprises to deploy long-running agentic tasks without managing their own orchestration infrastructure — Anthropic handles agent lifecycle, tool routing, state persistence, and safety guardrails. The launch positions Anthropic as a full-stack agentic platform rather than just a model API provider, competing directly with OpenAI's Codex HIPAA-compliant managed offering and emerging agent orchestration platforms like LangChain Cloud and Vertex AI Agents.
