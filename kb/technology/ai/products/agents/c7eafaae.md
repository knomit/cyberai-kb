# Amazon Quick desktop agent launches with enterprise-grade integrations

Amazon launched a desktop app for Amazon Quick, its agentic work assistant, integrating natively with Microsoft 365, Google Workspace, Salesforce, and Zoom. Key capabilities: deep memory (context between sessions), proactive intelligence (runs in background, flags unanswered messages, pending approvals, Salesforce deal updates), action-taking (edit docs, draft emails/Slack, update Jira, reply to requests), and file creation (presentations, spreadsheets, dashboards). Free tier available — no AWS account required; login via Google, Apple, Amazon, or GitHub. Already trusted by Southwest Airlines, BMW, and the NFL. Amazon also expanded Amazon Connect with pre-built enterprise agents for hiring, supply chain, healthcare, and customer service.
