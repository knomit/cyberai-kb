# Slack launches 30+ AI features: meeting notes, Operator mode, MCP client, native CRM

Slack (Salesforce) announced 30+ new AI features in late March 2026: (1) Automatic meeting transcription and summary in Slack huddles/calls, (2) 'Operator mode' — deploy custom AI agents in channels that can take actions (book meetings, create tickets, update records), (3) MCP client integration enabling Slack to call external MCP servers and bring tool results into channels, (4) Native lightweight CRM built into Slack DMs with contact enrichment via Salesforce Data Cloud, (5) AI-powered channel digest that summarizes threads since last visit. CEO Denise Dresser framed Slack as 'the operating system for work AI.'
