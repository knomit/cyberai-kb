# Box Agent GA: enterprise document AI with governance controls

Box launched Box Agent into general availability (GA) in late March 2026. Box Agent enables users to deploy AI agents that can autonomously read, analyze, extract, and act on documents stored in Box. Key capabilities: multi-document reasoning across up to 500 files in a single query, structured data extraction to spreadsheets/databases, automated workflow triggers (e.g., 'when contract uploaded, extract key dates and notify legal team'), native integration with Salesforce, ServiceNow, Okta. Enterprise governance: all AI actions logged to Box Shield audit trail, PII redaction layer, admin can whitelist which AI models agents can call. Pricing: included in Box Enterprise Plus tier.
