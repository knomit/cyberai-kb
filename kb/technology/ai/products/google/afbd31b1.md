# Gemini Notebook API in early-access Public Preview

Google's Gemini Notebook API is a REST interface (plus MCP server) to create/manage notebooks and sources from web pages, YouTube videos, text and Markdown. Early-access Public Preview; only personal Google accounts supported, Workspace accounts not yet.
