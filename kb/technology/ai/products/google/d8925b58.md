# Google launches Gemini Enterprise as end-to-end agentic platform

Google announced Gemini Enterprise at Google Cloud Next 2026 as an end-to-end agentic platform built on an evolution of Vertex AI. Key components: Gemini Enterprise Agent Platform (with updated Agent Dev Kit, Agent Runtime, Memory Bank, Memory Profiles, Agent Identity, Agent Gateway), Gemini Enterprise app for team agent collaboration, Agent Designer (no-code natural language or visual interface), support for BYO-MCP (Bring Your Own Model Context Protocol) for third-party tool integration, and an Agent Gallery from Google Cloud Marketplace.
