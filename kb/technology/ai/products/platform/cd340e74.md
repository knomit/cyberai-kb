# Claude Import Memory - paste preferences and context from other AI providers

Anthropic launched Claude Import Memory, allowing users to copy-paste anything into Claude's memory system — including preferences, projects, and context imported from other AI providers (e.g., ChatGPT custom instructions). This lowers switching cost from competitor AI platforms and allows Claude to build a persistent model of the user across sessions.
