# Claude adds inline visual explanations: interactive charts and diagrams in real-time within chat

Anthropic updated Claude (March 2026) to generate visuals in real time inline within responses: custom charts, diagrams, and other visualizations. Design: functions like 'Claude drawing on a whiteboard' — as a teacher would to explain something. Visuals are temporary and can change or disappear as a conversation evolves. Use cases: step-by-step origami instructions, interactive periodic table (clickable), topic diagrams. Claude decides when to create a visual, but users can also prompt it. Available on all plan types including free. Similar to Gemini 3's November 2025 launch of interactive tools and simulations. Educational implication: AI visuals shift the concern from 'cheating tool' to 'deeper learning enabler.'
