# Claude Cowork Projects: Local Folder Storage, Vendor Interoperability; Sketch Tool Planned

Anthropic launched Projects feature for Claude Cowork desktop app (March 2026): creates separate workspaces with tasks, instructions, and files stored locally on user's computer. Advantages: no re-uploading between sessions, no context-switching, full control over files, vendor interoperability (local storage allows re-uploading same personalization to other AI tools). Project creation options: start fresh, import from existing chat project, or use existing local folder. Sketch tool also planned per X post: users input a quick sketch to explain desired task rather than describing in words. Strategy: Anthropic laser-focused on enterprise clients, constantly shipping features that deepen AI into knowledge work.
