# Anthropic Claude Managed Agents: built-in memory beta — exportable files, agent-to-agent sharing, 97% error reduction at Rakuten

Anthropic launched built-in memory for Claude Managed Agents in beta (April 2026), closing a key enterprise agent gap. Key features: (1) Memory stored in exportable files manageable via API — enterprise-friendly; (2) Agents can share accumulated context with each other (if permitted by operator), improving effectiveness over time; (3) Early adopters: Netflix reduced manual prompt updates by carrying context across sessions; Ando (Slack competitor) retains organizational context for customers; Rakuten reduced first-pass errors by 97% for long-running task-based agents. Context: Claude Managed Agents 'pairs an agent harness tuned for performance with production infrastructure' in the cloud at Claude's token costs. The memory feature makes agents self-improving within a deployment without human intervention to re-explain context.
