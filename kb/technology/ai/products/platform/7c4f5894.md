# Anthropic acquires Vercept to improve Claude computer use capabilities

Anthropic acquired Vercept, a company specializing in computer use capabilities, to improve Claude's ability to operate computers autonomously. This represents a strategic investment in agentic computer control, competing with OpenAI's computer-use features in GPT-5.4.
