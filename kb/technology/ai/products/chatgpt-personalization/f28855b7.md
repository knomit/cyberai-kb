# ChatGPT personality design: presets, memory, custom instructions — future is naturally adaptive (OpenAI, 2026)

OpenAI PM Laurentia Romaniuk (Deep View, May 26 2026) details ChatGPT personalization: users choose preset traits (Friendly, Candid, Cynical), set nickname, occupation, custom instructions, and toggle memory for cross-conversation context. Foundation model is the same for everyone; personalization is a layer. Default goal: 'broadly useful and adaptable' for as many people as possible. Challenge: balancing warmth and clarity without being deferential or verbose — small wording changes elicit strong reactions. Future direction: 'naturally adaptive' that requires little configuration while keeping transparency and user control. Goal: 'AI that feels genuinely helpful without compromising reliability, trustworthiness, or user agency.' Precedent: Custom Instructions launched 2023. OpenAI faced backlash when retiring GPT-4o (users preferred its warm tone).
