# Mistral Workflows: production-grade agentic orchestration built on Temporal

Mistral launched Workflows in public preview in Studio, an orchestration layer for enterprises to run AI-powered processes in production. Key architecture: developers write workflows in Python, publish to Le Chat so anyone in the org can trigger them; built on Temporal's durable execution engine (same infrastructure as Netflix, Stripe, Salesforce). Features: step tracking and auditing, fault tolerance, durability, pause-for-human-approval mid-execution without losing progress, hybrid deterministic+agentic design (rule-based parts with agentic tools injected only when needed). Deployment: supports hybrid workflows, customer VPC, or Mistral infrastructure. Use cases already deployed: cargo release automation, document compliance checking, customer support triage.
