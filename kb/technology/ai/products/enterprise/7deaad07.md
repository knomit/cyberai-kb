# Pigment Modeler Agent - enterprise planning via natural language with MCP integration

Pigment (6-year-old enterprise performance management platform, ~$100M ARR, doubled ARR for 3 consecutive years) launched Modeler Agent: AI agent that generates production-ready enterprise planning applications from natural language in minutes vs months. Built natively with guardrails (role-based permissions, governance, enterprise-grade security, real-time computation on billions of data points). MCP-exposed API: developers can interact with Pigment's modeling engine directly from Cursor or Claude Code. Key clients: ServiceNow, Unilever, Siemens. Notably, Anthropic itself is a Pigment customer — cited as evidence against 'AI agents will replace all SaaS' narrative. Carta cut model build times from 1 week to 2 days. 54% of new customers migrating from legacy vendors. Ben Previeux (Head of Product and AI Strategy): 'turning vibe coding into something enterprises can trust.' Positions Pigment as enterprise back end that AI coding tools should build on.
