# Microsoft launches MAI-Cyber-1-Flash multi-agent vulnerability model

The Deep View reported (Jul 27, 2026) that Microsoft introduced MAI-Cyber-1-Flash, a multi-agent tool for identifying and remediating vulnerabilities, claiming powerful cyber capabilities at roughly half the cost of leading models. It is integrated with MDASH, Microsoft's agentic bug-hunting system, is designed to handle ~90% of tasks (deferring the hardest work to heavier models), and was benchmarked against rivals on CyberGym. Microsoft also launched 'Perception,' an agentic security system for continuous monitoring and patching. Quotes attributed to Microsoft AI CEO Mustafa Suleyman and EVP Hayete Gallot.
