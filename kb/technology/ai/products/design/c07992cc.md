# Google Stitch 'vibe design': AI-native canvas for UI design with MCP server (Mar 2026)

Google launched the redesigned Stitch in beta (March 18, 2026) — introducing 'vibe design' for AI-native UI/UX creation. Originally launched May 2025, Google Labs Dec 2025; redesign adds: AI-native infinite canvas (Figma-like), Design Agent (reasons across project evolution), Agent Manager (parallel tasks + progress tracking), DESIGN.md (exportable/importable design rules for cross-tool use), voice capabilities. Stitch MCP server + SDK enables integration into other design and coding tools. Free via Google Labs. The Deep View designer Lucas Crespo: 'Feels closer to downloading a Figma UI kit or starting from a hyper-custom template — useful for a first draft, but not a substitute for knowing what to do with it if you have a high bar as a designer.' Notable: centralized vs. decentralized AI tension at GTC captured by Illia Polosukhin (Near co-founder, transformer co-inventor at Google): user-owned AI keeps data separate from models, agents as secure OS; Near's IronClaw = secure OpenClaw variant.
