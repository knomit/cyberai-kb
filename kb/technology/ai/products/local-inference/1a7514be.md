# Perplexity Portable Computer reached Windows RTX PCs

Perplexity's Portable Computer became available on Windows PCs with NVIDIA RTX hardware, enabling agentic AI tasks to run locally on consumer GPUs rather than in the cloud. This is a platform-reach expansion for the product — it broadens local-first execution from the original workstation-class hardware to mainstream Windows RTX machines, which changes who can run it, not what it does.
