# Anthropic merged Claude chat and Claude Cowork memory into one system, on by default

Anthropic merged the memory systems of Claude and Claude Cowork so both surfaces remember the same conversations. The feature is on by default. Claude now adds topics to memory while the user is still conversing, and everything remembered is stored as a list of files under 'Topics' in memory settings, where users can read, edit, or delete each one individually.
