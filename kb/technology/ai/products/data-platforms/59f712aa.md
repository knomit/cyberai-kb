# Snowflake positions against SaaSpocalypse: data platform as AI app substrate

Snowflake CEO Sridhar Ramaswamy gave keynote in late March 2026 explicitly naming the 'SaaSpocalypse' — the displacement of SaaS applications by AI agents that perform the same tasks without requiring a dedicated app. Snowflake's strategic counter-positioning: become the data substrate that AI agents query regardless of which agent framework or LLM is used. New announcements: Snowflake Cortex Agents (GA), native MCP server support for Snowflake data (agents can call Snowflake via MCP), Arctic LLM fine-tuned on enterprise SQL, partnership with Anthropic (Claude as default reasoning model in Cortex). Ramaswamy: 'We don't care which agent wins. We care that all agents need data.'
