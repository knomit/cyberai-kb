# OpenAI replaced Chronicle with Computer History, which logs interaction events rather than screenshots

OpenAI replaced Chronicle, which built memories from screen captures, with Computer History, which turns activity across apps and websites into memories and a timeline that ChatGPT and Codex can reference. Unlike Chronicle it records interaction events — clicks, typing, keyboard shortcuts, app switches and context — and does not capture screen or audio. It is off by default for ChatGPT Pro, Business and Enterprise users in the macOS desktop app. OpenAI cautions that the files are not encrypted by Computer History and may be readable by other programs running as the same macOS user, and that the feature increases prompt-injection risk from content in apps and websites. Temporary interaction event files are retained up to 48 hours; derived memory files persist until explicitly deleted.
