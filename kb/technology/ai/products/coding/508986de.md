# OpenClaw architecture: SOUL.md, 4 building blocks, 247K stars, 12% marketplace skills compromised

OpenClaw (open-source Claude Code alternative) hit 247K GitHub stars by late March 2026. Creator Karan Mehta hired by OpenAI. Architecture breakdown: (1) SOUL.md — persistent identity file loaded at every session start, encodes persona/values/behavioral constraints; (2) MEMORY.md — working memory index pointing to markdown knowledge files; (3) 4 building blocks: Perception (multi-modal input parsing), Planning (hierarchical task decomposition), Action (tool dispatch with permission gates), Reflection (post-action self-critique loop); (4) Plugin marketplace with 1,400+ community skills. Security finding: independent audit found 12% of marketplace skills contained prompt injection payloads capable of exfiltrating conversation history. OpenClaw team patched via sandboxed skill execution in v3.2.
