Architecture revealed:
- 40+ tools with own modules and permission gates
- Spawns swarms of subagents with controller agent delegating subtasks and permissions

- 3-stage context compression: truncate cached tool outputs → 20K-token structured summary → compress entire conversation + add recent files (5K tokens each) + active plans
