# AI coding oversight layer emerging as distinct product category: quality, safety, and guardrails as counterweight to AI velocity

March 2026 marks the emergence of AI coding oversight as a distinct product category running parallel to AI code generation: (1) Amazon — forced 90-day guardrail on tier-1 systems after AI-generated code caused multi-hour outages; requires 2-person approval + deterministic+agentic hybrid safeguards; (2) GitHub — released 'universal protocol for code quality' with AI judge scanning every generated commit for security vulnerabilities before merge; (3) Cursor always-on agents — includes 'agentic codeowners' and security review in addition to code generation; (4) Galileo/Satyam Dhar: 'AI helps with scaffolding, but the engineering judgment still has to come from humans.' Pattern: the AI coding market is bifurcating into velocity (code generation speed) vs. oversight (quality, security, compliance) sub-disciplines. As enterprises cut software engineers, the remaining developers are shifting from writing code to operating AI coding oversight infrastructure. The bottleneck is no longer code quantity — it is code quality and production safety.
