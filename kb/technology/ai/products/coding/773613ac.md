# Amazon AI coding mishap: tier-1 system outages cost millions, trigger 90-day guardrail

Amazon experienced a series of outages tied to AI-generated code (including from its own AI assistant Amazon Q) starting in Q3 2025. The latest outage occurred in early March 2026, taking down the company's website and shopping app for several hours, costing millions in lost orders. Response: (1) 90-day safety guardrail on code written for 'tier-1 systems' (those directly facing consumers); (2) Developers must document changes more stringently + get approval from 2 additional staff members before making changes; (3) Developing hybrid safeguards combining agentic and deterministic (rules-based) guardrails. Expert commentary: Satyam Dhar (staff software engineer, Galileo; former Amazon + Adobe): 'AI helps with scaffolding, but the engineering judgment still has to come from humans.' 'That’s where things get dangerous' — AI creates code that looks production-ready before being pressure-tested. Context: major tech companies (Atlassian, Oracle, Block, Amazon) cutting software engineers as AI adoption grows. Lesson: speed unlocked by AI coding can be 'the enemy of quality' and changes the risk profile enterprises must manage.
