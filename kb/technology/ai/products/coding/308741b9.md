# GitHub Repository Intelligence: institutional memory and expertise layer for AI coding agents

GitHub is building 'Repository Intelligence' — an indexed layer above code repositories that gives AI agents institutional memory and expertise for a codebase. What it indexes: all commits, pull requests, issues, design decisions, prompts used, and quality outcomes. Key capabilities: (1) Mid-term and long-term memory for agents working on a codebase; (2) Graph of work for software development — agents can query the full history; (3) Answers questions like 'why did we migrate to this library then migrate away?', 'what decisions led to this architecture?', 'what prompts produced the best quality output?'; (4) New team members or agents can onboard immediately with full institutional context. Mario Rodriguez: 'Repo intelligence is that institutional memory plus expertise at any point in time.' Platform-agnostic: the intelligence layer adds value regardless of which coding tool (Cursor, Claude Code, Copilot) an agent uses. All the world's code lives on GitHub — the data advantage is structural.
