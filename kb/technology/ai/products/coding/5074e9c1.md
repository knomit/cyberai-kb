# Claude Code most-used AI coding tool at GTC 2026 + coding → all knowledge work transformation

The Deep View straw poll at GTC 2026 (March 2026): Claude Code was the most-used AI coding tool, mentioned by more than 3/4 of people surveyed regardless of technical level; next were Codex and Cursor; most multi-tool users combine Claude Code with another tool. Independent Ramp data (March 2026): Anthropic captures 73%+ of enterprise spending among first-time AI buyers. GTC panel on AI and jobs (Nemotron Coalition): Michael Truell (Cursor CEO): 'What started working in coding last year is going to work in all of these other domains this year.' Aravind Srinivas (Perplexity CEO): model trained for coding 'is suddenly able to do all kinds of knowledge work.' Misha Laskin (ReflectionAI CEO): coding/enterprise automation are the 'first generation' of problems; future problems become a matter of allocating economic resources vs. scientific barriers. Jensen Huang to packed theater: 'Almost all work can be specified as code.' Kari Briski (Nvidia VP): 'You're more of an architect now, rather than just a typer.'
