# GitHub targets 1 billion developers by 2030 via natural language and mobile-first vibe coding

GitHub CPO Mario Rodriguez articulated the company's north star: 1 billion developers by 2030 (10% of world population), up from 180M users currently (1 new user joins per second). Strategy: redefine what a 'developer' means using natural language — making software creation accessible to people who cannot write traditional code. Mobile as a key channel: a billion developers cannot all use Macs and PCs, but everyone has a phone; GitHub mobile app enables creating and publishing apps via an agent. Analogy: 'I know how to cook, but I didn’t open a Michelin-starred restaurant' — expertise barriers should not define who can build software. Context: Claude Code is gaining significant buzz extending beyond tech industry; vibe coding is the consumer-facing narrative. GitHub's MCP-layer strategy: repository intelligence provides added value above all individual coding assistants.
