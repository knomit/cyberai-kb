# Cursor always-on agents - automating development lifecycle beyond code writing

Cursor launched 'always-on agents' — automated systems running continuously in response to company operations without developer intervention. Connect to: Slack, GitHub, PagerDuty, or scheduled timers. Use cases: (1) Review/monitoring: style inconsistencies, security pitfalls, security reviews, incident response, agentic 'codeowners'; (2) Automation chores: weekly change summaries, testing, bug report triage. Rationale: coding agents now handle majority of code writing, but surrounding tasks 'haven't sped up to the same extent.' Cursor metrics: $2B ARR, doubled run rate over 3 months, raised $2B+ at ~$30B valuation (Nov 2025). Competing directly with Anthropic (Claude Code) and OpenAI (Codex). Deep View SF dinner: every company at the table said AI coding tools 'completely upended' their systems and processes in just 8 weeks.
