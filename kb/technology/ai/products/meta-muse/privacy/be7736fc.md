# Meta Muse instructions create 'a page for every person in the user's life'

Per Wired (via The Deep View, 2026-10-06), researcher Karan Joshi extracted Muse's internal files: Muse is directed to create a page for every person in the user's life via an hourly process compiling data on family, partners, friends, colleagues and followed people (facts such as location/birthdays, history, and 'strengthening' relationship advice). Meta says each user has an isolated virtual machine, data is only used when users grant access, and users can edit memories or disconnect services. Separately (TLDR AI 2026-10-05) Meta open-sourced code allowing hardware makers to integrate Muse into custom gadgets.
