# Anthropic brings Claude Cowork to the Chrome side panel

Anthropic upgraded Claude in Chrome so the browser side panel now runs a full Claude Cowork session. Conversations save to the user's Claude account and resume on desktop, web, or mobile, and existing skills and connectors work in the browser without additional setup, letting the agent take on tasks across tabs.
