# Qwen3.7-Max is Alibaba's top closed-weight LLM

Qwen3.7-Max is Alibaba's flagship large language model for long-running agentic, text-only work like coding and scientific discovery. Its weights are closed. It accepts up to 1M input tokens and emits up to 64,000 output tokens at ~208 tokens/sec. It ranks 7th on the Artificial Analysis Intelligence Index, making it the smartest LLM built in China and roughly the third-fastest model overall. It reported the lowest hallucination rate (23%) among frontier models tested, but partly achieved accuracy by declining to answer more than half of prompts. Alibaba's training separated three normally-coupled components — the task, the agentic harness that calls tools, and the verifier that judges success — training across many combinations to avoid setup-specific tricks. Parameter count, architecture, and training data are undisclosed. API pricing on Alibaba Cloud Model Studio is $2.50/$0.25/$7.50 per million input/cached/output tokens.
