# Anthropic Acquires Stainless: SDK Generation Automation for Claude API Ecosystem

Anthropic acquired Stainless, a startup specializing in automated SDK generation from OpenAPI specifications. The acquisition is strategically aimed at reducing friction for developers integrating the Claude API — Stainless tooling can auto-generate idiomatic client libraries across multiple languages from a single API spec. This follows the broader pattern of AI labs acquiring developer tooling companies to deepen ecosystem lock-in at the integration layer. Stainless had been used by several major API companies to accelerate SDK maintenance. The acquisition signals Anthropic's intent to invest in developer experience as a competitive differentiator.
