# Mistral Agentic Search replaces one-shot retrieval with a five-operation navigation loop

Mistral released Agentic Search, which replaces one-shot document retrieval with an iterative loop. The model is given five operations — search, open, navigate, read, and grep — so it can inspect long documents, follow references, and verify an answer rather than accepting the first retrieved chunks.

In Mistral's own tests, the loop raised FinanceBench correctness from 26.7% to 86% and reduced tail latency. A different harness moved the same model another 10.5 percentage points. Caveat: all reported measurements are vendor-run.
