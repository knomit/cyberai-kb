# Long-Horizon Terminal-Bench evaluates sustained LLM agent terminal work

Long-Horizon Terminal-Bench (LHTB) is a benchmark evaluating whether LLM agents can sustain productive work across hundreds of terminal interactions. It comprises 46 stateful tasks that use hidden verifiers which rebuild and inspect final artifacts rather than trusting an agent's self-reported progress.
