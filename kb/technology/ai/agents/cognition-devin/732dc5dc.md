# Cognition's Devin Fusion two-agent harness matches frontier coding-agent scores at 36-39% lower cost

Cognition released SWE-2, a coding model fine-tuned via reinforcement learning from Moonshot AI's 2.8-trillion-parameter mixture-of-experts model Kimi K3 (the reward function subtracts an attempt's money/time cost from whether it succeeded, letting Cognition train all reasoning levels in one run rather than a separate expert per level as Kimi K3's makers did). Alongside it, Cognition made Devin Fusion -- a harness that runs two AI agents in one session -- available beyond its cloud service, in Devin CLI and Devin Desktop (previously announced in June 2026 for Devin Cloud only, where it drove 88% of merged PRs among Cognition's internal users over the summer). In Devin Fusion, a capable/expensive 'lead' model (e.g. Claude Fable 5.1) resolves ambiguity, plans, delegates tasks with constraints/success criteria, and reviews work (reclaiming a task if the sidekick stumbles), while a cheaper 'sidekick' model (SWE-2) executes most of the work; the two agents exchange only briefs, results, and feedback rather than full conversation history, preserving each agent's own prompt cache. In the cloud version, lightweight classifiers can swap which model plays which role mid-session during context-compaction events, when the cache is discarded anyway.

INDEPENDENT BENCHMARK (Artificial Analysis, Coding Agent Index v1.5 -- an average of software-engineering, command-line, and repo-understanding tasks): with Claude Fable 5.1 as lead (xhigh reasoning) and SWE-2 as sidekick (medium reasoning), Devin Fusion scored 62, matching Claude Code running Claude Fable 5.1 alone at max reasoning with fallback (also 62), while costing $7.90 vs $12.40 per task (36% less) in similar time (35.8 vs 34.8 minutes). With GPT-6 Astra as lead, Devin Fusion scored 59 versus Codex-with-Astra's 62, but cost 39% less ($4.54 vs $7.47/task). On Vals AI's Code Migration test, Devin Fusion with Claude Fable 5.1 (57.3% at $42.00/task) beat Claude Code alone (54.6% at $70.97/task), but with GPT-6 Astra as lead (61.3% at $35.51/task) it trailed Codex-with-Astra alone (67.7% at $44.36/task). Devin Fusion with Claude Fable 5.1 as lead consumed 70% more tokens and took nearly 3x as many turns as Claude Code alone, yet still cost less per task overall -- so a cheaper per-token sidekick model does not automatically mean lower total cost; SWE-2 appears unusually efficient as a sidekick specifically.

CONTEXT: Sakana AI released a competing multi-model orchestrator design, Fugu Max/Fugu Ultra v2, the same day Fusion left Devin Cloud. Fugu uses a low-cost dispatcher to split tasks and route each subtask to whichever of several pooled models fits, rather than fixing one lead+sidekick pair for a session -- a more decomposed alternative to Fusion's fixed two-model design.
