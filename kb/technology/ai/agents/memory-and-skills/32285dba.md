# WikiSkill co-evolves agent skills with a persistent knowledge wiki

Google introduced WikiSkill, a framework in which reusable agent skills are co-evolved alongside a persistent wiki that consolidates knowledge from prior experience — an approach to giving agents durable, accumulating learning across episodes rather than per-task context only.
