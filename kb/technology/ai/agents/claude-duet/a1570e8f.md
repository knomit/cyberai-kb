# Anthropic launches Claude Duet, a proactive always-on agent on Opus 5.5 (research preview, waitlist)

On 2026-10-21 Anthropic announced Claude Duet, a proactive agent built on Claude Opus 5.5 that monitors connected apps, sends a morning brief, keeps working when the user steps away, and asks approval before acting on the user's behalf. Research preview via waitlist for US Pro and Max subscribers. It reuses the user's Claude memory, skills and connected apps (6,000+ Claude Marketplace plug-ins such as Gmail, Slack, QuickBooks, Stripe). Safety: never sees passwords or sign-in tokens, defends against prompt injection, uses an auto-mode classifier plus a dedicated classifier against sensitive information leaks. Competes with OpenAI's Dots (DevDay, late Sept 2026) and Meta's Muse.
