# Cloudflare launches Kitesurf, an agent-first browser on Workers

Cloudflare introduced Kitesurf, a lightweight agent-first browser designed for AI agents that runs inside V8 isolates on Cloudflare Workers, providing a browsing environment optimized for automated agents rather than human users.
