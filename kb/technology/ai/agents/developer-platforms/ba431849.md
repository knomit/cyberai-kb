# Cursor cloud agents can now run on customer-managed machine pools

Cursor announced (2026-09-03) that its cloud agents can execute on dynamically scheduled pools of machines inside a customer's own private network. Agents are still started and managed from Cursor's control plane; only the execution substrate moves. This lets agents sit next to internal services and source control, use custom hardware, or run OS and build pipelines that are impractical to package as a standard Cloud Agent image. It is not a fully self-hosted Cursor — orchestration remains with Cursor.
