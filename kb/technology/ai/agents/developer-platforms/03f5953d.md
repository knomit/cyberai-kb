# OpenAI's Agents API productizes the Codex harness as a managed service

OpenAI launched the Agents API in public beta on 2026-09-10, exposing the same agent harness and execution infrastructure that powers Codex. It manages context (including automatic compaction), tool routing and MCP servers, subagent orchestration, approvals, tracing, recovery and run state, plus persistent long-running sessions, files, and code execution in either an OpenAI-hosted sandbox or a developer-selected compute environment. There is no separate fee for the Agents API — developers pay only for tokens and tools consumed. The structural significance is that the harness, previously the differentiating layer each agent builder wrote themselves, becomes a bought component; the split OpenAI draws is harness-as-control-plane versus sandbox-as-execution-plane.
