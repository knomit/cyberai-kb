# Vercel releases Agent Plugins 1.0.0 open standard

Vercel introduced Agent Plugins 1.0.0, an open standard for packaging reusable AI Agent Skills and MCP (Model Context Protocol) servers into distributable plugins, simplifying how agent capabilities are shared and installed.
