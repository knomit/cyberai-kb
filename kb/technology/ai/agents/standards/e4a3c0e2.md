# Agent Behavior is an open standard for specifying AI agent conduct

Agent Behavior is an open standard for defining and evaluating how an AI agent should behave across a whole trajectory. Each behavior spec is a Markdown file describing recurring conduct that makes the agent reliable, giving reviewers, rubrics, scorers, and evals something concrete to measure against.
