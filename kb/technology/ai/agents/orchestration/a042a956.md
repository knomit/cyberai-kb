# Google's AX is a declarative orchestrator running autonomous agent workloads at cluster scale on Agent Substrate

AX is a high-throughput, declarative orchestrator for running large volumes of autonomous agent workloads in a cluster. Users declare an agentic task with workspace and gateway specifications; AX then sandboxes it, wires up its workspace, fences its network, and runs it at scale. It runs on top of Agent Substrate and its interaction model is described as similar to Kubernetes. The declarative model means isolation (sandbox, workspace, network fence) is part of the task SPECIFICATION rather than something the agent code arranges for itself — which is the reason it can be enforced uniformly across workloads.
