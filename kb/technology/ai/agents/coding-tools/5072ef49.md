# Kiro Crew: persistent, self-improving development workspace

Kiro Crew is a persistent workspace for development work that self-improves and continues beyond a single session. It can run locally or remotely on personal hardware; developers can start work from a desktop app, web dashboard, or CLI and continue via tools like Slack and Discord. It can run multistep tasks and recurring scheduled jobs and monitor systems until intervention is needed.
