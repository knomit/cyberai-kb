# Google releases Mantis skills toolkit for AI security review harnesses

Google released 'Mantis', a decoupled, sequential, security-focused set of Skills for use with coding agents to build security review harnesses. It is designed as a flexible, adaptable foundation rather than rigid instructions; Google recommends using AI to iterate on the skills, augmenting with internal docs/coding standards, and calibrating risk to the environment.
