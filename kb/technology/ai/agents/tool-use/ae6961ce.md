# HYSET: tool-set selection raises ToolBench task resolution to 69.9% vs 61.8%

HYSET (Shanghai Jiao Tong / HK PolyU) scores candidate tool sets by pairwise tool compatibility plus whole-set relevance to the query, rather than ranking tools independently. On ToolBench: Recall@5 88.6% vs ToolGen 81.4%; agent resolved 69.9% of tasks (human evaluators) vs 61.8% with ToolLLaMA-Retriever. No change to the underlying agent required.
