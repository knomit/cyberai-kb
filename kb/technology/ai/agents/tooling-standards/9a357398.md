# Anthropic added AGENTS.md support to Claude Code, adopting a spec originated by OpenAI

Anthropic added support for the AGENTS.md instruction file format to Claude Code, reported 2026-09-18. AGENTS.md is a markdown instruction spec that originated with OpenAI, so this is a direct interoperability concession: a repository can carry one agent-instruction file that multiple vendors' coding agents read. The practical consequence for repo owners is that agent instructions no longer need to be duplicated per vendor. It does NOT mean CLAUDE.md is deprecated or that the two formats are interchangeable in precedence — support was added alongside, and precedence between them is a Claude Code implementation detail to check rather than assume.
