# Notion's Skills API lets teams co-edit agent instructions and distribute them via GitHub sync or Vercel

Notion launched a Skills API that lets teams collaboratively edit agent instructions in one place and distribute them to other agents through GitHub sync or Vercel's skills installer. Operational consequence: this treats agent instructions as a shared, versioned artifact with a distribution channel rather than per-agent configuration — the notable move is that the instruction set becomes portable across agent vendors, not locked to Notion's own agent.
