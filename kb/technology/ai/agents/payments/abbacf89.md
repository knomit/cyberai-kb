# Cloudflare introduces programmable Wallets for AI agents

Cloudflare launched Cloudflare Wallets, a system giving AI agents stable identities and controlled access to payments for APIs, MCP tools, and online content. Virtual Wallets support spending limits, allow lists, and transaction caps intended to make agentic commerce safer.
