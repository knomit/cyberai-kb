# GUI-Owl 1.5: 2B-parameter model operating Android apps via accessibility service

GUI-Owl 1.5 is a 2-billion-parameter screen model that reads an Android screen through the accessibility service and taps and types in other apps, i.e. on-device computer use (Opposable write-up).
