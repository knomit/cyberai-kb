# Microsoft's practices for shipping thousands of production AI agents

Microsoft described the infrastructure and mechanisms it uses to operate AI agents at scale across Foundry and its Copilot products. Key practices include treating retrieval as a sub-agent, assigning each agent distinct identities and workspaces, and using rubric-based evaluations with automated improvement loops.
