# Amazon Kiro-trace separates change proposal from deterministic verification

Amazon unveiled Kiro-trace (2026-10-20), an internal tracing system that mines Kiro coding-agent runs for mistakes or wasted effort, proposes changes one at a time, keeps a change only if a separate deterministic check passes, then sends it to a human reviewer. Origin: one wrong tool description in the file-read/search tool caused 61,000+ errors. In week one it opened eight changes, seven shipped; one raised long-task ability from 82% to 92%. Design principle: the component proposing a change never judges whether it worked. Results are vendor-reported.
