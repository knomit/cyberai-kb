# Google's RRSI regularizes recursive self-improvement of agent harnesses to reduce benchmark overfitting

Google published RRSI (Regularized Recursive Self-Improvement), a method for agent-harness self-improvement. Premise: an AI agent's capability is largely determined by its harness (prompts, control flow, configuration, context management, tools, skills, memory, sub-agents). Naively evolving the harness against a fixed evolve set causes it to memorize the training tasks, so large in-distribution gains shrink or vanish out of distribution.

Mechanism: RRSI keeps the harness edit space open and instead regularizes the search trajectory through it, constraining HOW the search moves rather than WHAT the harness may contain, favoring changes that transfer to new tasks.

Reported result (Google's own evaluation): across eight benchmarks it improved out-of-distribution performance while using fewer policy tokens.

WHAT THIS DOES NOT MEAN: RRSI does not restrict the set of permissible harness contents; the regularization is on the search path. The eight-benchmark result is the authors' own reported evaluation, not an independent replication.
