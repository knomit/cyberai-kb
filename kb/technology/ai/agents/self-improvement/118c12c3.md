# Google Research Harness²: agents improve prompts, tools, memory and orchestration without weight changes

Google Research's open-source Harness² (GitHub google-research/harness2) lets agents iteratively improve their own harness (prompts, tools, memory, orchestration) without changing model weights. It refines the harness per task and carries evidence-backed lessons forward to improve future tasks. It is a recursive-self-improvement approach at the harness level, not model-weight training.
