# Google put Agent Anomaly Detection into private preview on the Gemini Enterprise Agent Platform

Google announced Agent Anomaly Detection in Private Preview on the Gemini Enterprise Agent Platform. It monitors AI agent behavior for anomalies, using the agents' logs and traces to flag suspicious activity. It is telemetry-based detection after the fact, not a preventive control — flagging depends on the agent's actions appearing in logs and traces, so behavior outside that telemetry is not covered.
