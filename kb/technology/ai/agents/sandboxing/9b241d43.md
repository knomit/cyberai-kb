# Microsoft Quicksand: async Python API for QEMU VM sandboxes for AI agents

Quicksand (github.com/microsoft/quicksand) is an async Python API to launch, control and snapshot QEMU VMs, focused on sandboxing AI agents. Ships prebuilt Ubuntu and Alpine Linux VMs, supports x86_64 and ARM64 on macOS, Linux and Windows, and needs neither root nor Docker.
