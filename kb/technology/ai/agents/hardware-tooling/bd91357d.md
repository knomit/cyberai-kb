# Google Accelerator Agents use Gemini to port PyTorch to JAX and tune TPU kernels

Google released Accelerator Agents, a Gemini-powered toolkit helping developers migrate PyTorch workloads to JAX and optimize custom kernels for Google Cloud TPUs. It contains MaxCode for model conversion and MaxKernel for writing, porting, profiling and debugging Pallas kernels. Strategically this attacks the porting friction that keeps workloads on CUDA, complementing Google's move to sell TPUv7 Ironwood externally.
