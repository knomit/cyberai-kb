# LM Studio launches Bionic, an AI agent for open models

LM Studio launched Bionic, an AI agent for coding, research, and document management built around open models, with local and cloud options for privacy and cost control. It supports offline voice transcription via Mistral AI's Voxtral, inspects codebases and solves issues with models like GLM 5.2, uses sandbox environments for security, and includes native web search integration.
