# Anthropic launches Claude Tag, embedding Claude into Slack as a teammate

On June 2026 Anthropic unveiled Claude Tag, a system that embeds its flagship Claude model into Slack so it can 'join as a team member.' Users grant it access to channels, tools, or codebases and delegate tasks by tagging Claude. It is 'multiplayer' (visible to everyone in a channel, can pick up where others left off), builds and retains context from the channels it is in, supports 'ambient' proactive notifications, and works asynchronously (including scheduling tasks for itself). It launched for Slack Enterprise and Team customers with plans to expand to other work platforms. Anthropic frames it as an evolution of Claude Code and a digital 'colleague' rather than a tool.
