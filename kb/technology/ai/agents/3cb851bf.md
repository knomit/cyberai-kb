# Mid-2026 AI theme: agentic coding harnesses, ubiquitous coding assistants, and RSI framing

A cluster of June 2026 developments points to agentic coding and 'harness engineering' (the software wrapping an LLM that drives the next-action loop) as the dominant AI theme of the period. Andrew Ng/DeepLearning.AI released OpenCoworker, an open-source desktop-agent harness; Cursor shipped Composer 2.5, a coding model fine-tuned inside its own CLI harness (rejecting the model-vs-harness dichotomy); Anthropic reported ~80% of its code is now Claude-authored and framed the trajectory as recursive self-improvement (RSI), reviving a global-pause debate; and Wiz's 2026 SDLC Security Report found AI coding assistants present in 70%+ of environments (with GitHub Actions in ~45-50%). The throughline: LLM-driven agents are moving from chat into doing real engineering work, which simultaneously multiplies developer productivity and expands the software supply-chain / developer-tooling attack surface.
