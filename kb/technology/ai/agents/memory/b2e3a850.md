# Databricks MemCurrent persistent agent memory layer

On 2026-10-20 Databricks unveiled MemCurrent, a memory architecture for agents that retains knowledge across sessions, with two memory types: episodic (raw conversation history) and derived (patterns, preferences, workflows). On Databricks' internal benchmark of 114 enterprise tasks, task completion was 22.3% with no memory, 35.8% episodic-only, 66.1% derived-only, and 68.4% with both. Databricks also reports 26% faster completion, 31% fewer tokens, and parity with giving the agent all past conversations using 12x fewer tokens on three public benchmarks, outperforming OpenClaw, Mem0 and PropMem. It is an architecture integrated into Genie, plus Agent Bricks Memory (beta) for custom agents, running in Lakebase. Figures are vendor-reported from internal benchmarks.
