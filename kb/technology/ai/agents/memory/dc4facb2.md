# Anthropic research: how agent memory is built, including idle-time 'dreaming'

Anthropic published research (components of agent memory) on how AI agents can build effective long-term memory by capturing experiences during interactions and reorganizing them during idle periods in a process called 'dreaming', and how different memory components contribute to organizing and retaining useful information.
