# Persistent agent memory reached vertical enterprise products by Aug 2026, not just horizontal agent platforms

The persistent-memory battleground identified across horizontal agent platforms through H1 2026 (Anthropic's Claude Managed Agents with exportable API-manageable memory, agent-to-agent context sharing and scheduled asynchronous 'dreaming' consolidation; Nous Research's Hermes Agent with auto-written SKILL.md files, a background 'Curator' that archives skills unused 90+ days or merges related ones, two-tier deduped memory and persistent goal tracking via a judge model; OpenClaw's SOUL.md identity plus MEMORY.md working-memory index; Amazon Quick's cross-session 'deep memory'; Anthropic's Claude Import Memory lowering switching cost) extended into domain-specific enterprise products in August 2026: Harvey released Harvey II, whose legal AI agents start new work carrying context, memory and preferences from prior tasks to reduce repetitive setup. Reading: the harvest-and-consolidate loop (act, extract, dedupe/merge, write back) is propagating from agent frameworks into vertical SaaS, where accumulated client/matter context is a stronger lock-in surface than in horizontal tools. WHAT THIS DOES NOT MEAN: Harvey has published no comparative performance figures for the memory feature; this is one vertical datapoint, not evidence that the pattern is general across verticals.
