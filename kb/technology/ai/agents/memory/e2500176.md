# Proactive memory agent improves long-horizon agent benchmarks

A research approach uses a separate memory agent that tracks important state and selectively reminds an action agent when relevant information risks being lost, improving pass rates on Terminal-Bench 2.0 and tau2-Bench without modifying the underlying action model.
