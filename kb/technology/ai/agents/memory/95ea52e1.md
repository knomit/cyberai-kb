# LangChain releases OpenWiki Brains proactive memory for agents

LangChain's OpenWiki Brains (version 0.1.0) provides proactive memory for AI agents, creating a general-purpose 'Personal Brain' via connectors to diverse information repositories and maintaining local wikis so agents get consistent context without manual updates.
