# Hypothesis: a cross-vendor agent-memory interchange standard will emerge, making memory portability the next competitive axis

Prediction (forward-looking): As persistent, self-consolidating memory becomes the primary differentiator and lock-in mechanism for AI agents (see synthesis 144c448b), competition will move from merely HAVING memory to MOVING it. A portable agent-memory interchange standard — analogous to what MCP did for tool access — will be publicly proposed and/or adopted by at least one major AI vendor, and vendors will increasingly compete on memory import/export and interoperability rather than just on memory presence. Mechanism: memory creates switching costs (already visible in Anthropic's Claude Import Memory, which exists specifically to lower switching cost FROM rivals, and in Claude Managed Agents storing memory in exportable API-managed files); once memory is the locus of lock-in, both challengers (who want to lower switching costs inbound) and standards bodies/enterprises (who want to avoid single-vendor capture) will push toward a portable format. Settlement criterion (falsifiable): by 2027-06-30, observe whether any major vendor (e.g. Anthropic, OpenAI, Google, AWS, Microsoft) or a recognized standards effort has publicly proposed or adopted a cross-vendor agent-memory interchange format/standard beyond ad-hoc copy-paste import. If none exists by that date, the hypothesis is weakened/false; emergence of such a standard corroborates it. Load-bearing evidence gap: standards announcements and vendor interop/export features over H2 2026 – H1 2027.
