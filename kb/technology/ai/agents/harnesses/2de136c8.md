# Ramp's Laminar managed agents platform and Vercel durable-harness

Ramp built Laminar, an in-house agent harness (secure conversation history, session compaction, tool-calling interfaces, message queuing/steering, subagents, multiplayer chat, observability); v1 took six weeks with a small team and code generated entirely by agents. Separately, Vercel's durable-harness lets agent harnesses (Pi, OpenCode, Codex, Claude Code) run durably on Vercel or self-hosted Postgres, surviving mid-turn crashes and browser disconnects by resuming from a log without repeating finished work.
