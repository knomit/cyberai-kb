# Jev decision models cut Qwen agent LLM calls by 29.6%

A community report on 360 SOP-Bench cases: offloading step-completion checks and bounded decisions to 'Jev' decision models reduced Qwen agent LLM calls by 29.6%, estimated API cost by 26.6% and latency by 19.7%. Self-reported, single benchmark.
