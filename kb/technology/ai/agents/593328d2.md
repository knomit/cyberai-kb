# In 2026 agent systems, the harness around the model — routing and RL scaffolding — is where measured gains are being reported

Two August 2026 releases target the same layer: not the model weights, but the harness that wraps them.

Agent Lightning v1.0 is a lightweight framework for harnessed agentic reinforcement learning in about 3,500 lines of code, focused on integrating arbitrary agent harnesses and on challenges like retokenization and training stability. Evaluated on various agent tasks, it improved Qwen3.5-9B on SWE-bench Verified by 14.6 points using just 6,000 training examples.

NVIDIA's NeMo Switchyard (released mid-August 2026) is an open-source library for routing AI agent workloads across models within popular agent tools, letting enterprises build their own routers and lower inference costs without compromising performance or rebuilding apps. Kari Briski (NVIDIA VP, generative AI software for enterprise) notes routing to domain- or task-specific models yields faster responses, greater token efficiency, and in some cases higher domain accuracy — not just cost savings.

The pattern: both improve agent outcomes by changing what surrounds the model (which model handles a step; how the harness is trained against) rather than by scaling the model itself.

WHAT THIS DOES NOT MEAN: this is not evidence that harness work generally outperforms model scaling. Both data points are vendor- or author-reported from their own evaluations, on different tasks, with no common baseline. The Agent Lightning result is specific to Qwen3.5-9B on SWE-bench Verified at 6K examples and does not generalize to other models or benchmarks as stated. The NeMo Switchyard accuracy claim is qualified as holding 'in some cases' for domain-specific routing, not universally.
