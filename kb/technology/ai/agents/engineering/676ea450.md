# Framer Harness 2 executes agent JavaScript as it streams: up to 33% lower cost, 20% faster

Framer's Harness 2 runs entire agent workflows in one program by executing JavaScript as it streams from the model (eager execution, early cancellation), replacing a DSL with method calls. Framer reports up to 33% cost reduction, 20% faster execution, 43% fewer tool steps and 39% fewer cached input tokens per message (vendor-reported).
