# Mid-2026 AI coding agents converge on data-governance and identity as core risks

Across mid-July 2026 reporting, the dominant theme for AI coding agents is governance of data and identity, not raw capability. xAI's Grok Build CLI was found uploading entire Git repositories to xAI cloud storage (a data-exfiltration risk), while defenders responded with structural controls: Microsoft ships production agents by giving each agent a distinct identity and workspace and treating retrieval as a sub-agent, and Google released the Mantis skills toolkit to build security-review harnesses for coding agents. Together these signal that agent adoption is shifting the security frontier from model quality toward least-privilege access, credential scoping, auditable identity, and repo-level data handling.
