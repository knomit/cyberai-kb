# Hark launches Handoff, a computer-use agent

AI startup Hark unveiled its first product, Hark Handoff, a computer-use agent that navigates the open web on a user's behalf. It spins up a dedicated virtual computer (its own browser, file system, and terminal) per request and can log in and act with users' saved addresses, payment methods, and history. Signups opened with broader availability planned for later in August 2026.
