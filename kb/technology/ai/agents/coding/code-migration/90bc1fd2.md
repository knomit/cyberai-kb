# Anthropic's six-step process for large-scale code migrations with Claude Code

Anthropic describes a six-step process for running large-scale code migrations with Claude Code: creating a rulebook, analyzing dependencies, and stress-testing translation rules, then deploying multiple agents to translate, review, and fix code iteratively. It emphasizes adversarial reviewers and mechanical verification as the keys to efficient migration.
