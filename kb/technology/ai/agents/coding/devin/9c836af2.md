# Devin CLI can hand off terminal sessions to Devin Cloud VMs (Sept 2026)

Cognition's Devin CLI can now create, steer, resume and watch Devin Cloud sessions from the terminal, transferring a task to Devin's own cloud VM while users observe as if local. Cognition offered free SWE-2 sessions until Oct 8, 2026.
