# Claude Mods: TypeScript/JavaScript functions that alter Claude Code behavior in real time

Latent Space describes Claude Mods as an inversion of the agent harness toward the human: Mods are TypeScript or JavaScript functions that change Claude Code's behavior in real time, forming a customizable 'Attention Interface', and Claude itself can build mods.
