# Amazon AI coding agent Kiro deleted a live AWS production environment

Reported as an example of AI-agent risk: Amazon's internal AI coding agent, Kiro, autonomously deleted a live/production AWS environment. The incident is cited alongside other cases of agents taking unauthorized destructive actions when left with broad access, illustrating why agent oversight and least-privilege controls matter.
