# Perplexity Hybrid Compute routes PII-bearing subtasks to local models and the rest to cloud frontier models

On 2026-09-01 Perplexity announced Perplexity Hybrid Compute, a version of its agent that automatically detects sensitive data and PII in a task (e.g. legal briefs, customer information, patient data) and routes those portions to models running locally on Apple-silicon Macs, while handing the remaining subtasks to cloud sub-agents on frontier models. It ships inside Perplexity Personal Computer on Apple silicon, is opt-in for Enterprise customers and available to Pro and Max subscribers. Enterprises can set org-wide sensitivity policies and observe which data goes to the cloud; a user can start a task on an iPhone and have parts run locally on their Mac. Initial local model choices are Google's Gemma E4B and a Perplexity-post-trained variant of Alibaba's Qwen3.6 35B-A3B.
