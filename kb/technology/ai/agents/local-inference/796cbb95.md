# Perplexity and NVIDIA launched Portable Computer, a fully local agent running on DGX Spark

On 2026-08-25 Perplexity announced Portable Computer, a version of its agentic Computer platform that runs entirely on hardware the user already owns, with no token billing. Every task starts on-device by default and the system asks permission before sending any individual step to a cloud model. It runs on NVIDIA's DGX Spark (128GB unified memory, up to ~1 petaflop, models up to 200B parameters, fine-tuning up to 70B) and initially ships a post-trained Qwen 3.8 27B variant called PPLX 27B, with NVIDIA Nemotron 3.5 Lightning planned. Availability at launch: Pro, Max, Enterprise Pro and Enterprise Max subscribers on Linux, with Windows support slated for September 2026; running the agent requires an RTX GPU with at least 24GB VRAM. DGX Spark-class machines cost roughly $4,000–$5,000. Perplexity's Nate Kupp framed the product as removing setup friction rather than adding raw capability.
