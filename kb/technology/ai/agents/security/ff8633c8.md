# Linux Foundation announces Agent Name Service (ANS) for AI agents

At the Confidential Computing Summit in San Francisco, the Linux Foundation announced the Agent Name Service (ANS), which gives every AI agent a tamper-proof identifier (akin to a serial number) for tracking and registration, functioning similarly to how DNS operates for internet servers. Summit consensus was that AI agents need hardware-enforced, cryptographic identities traceable to the chip level. Apple's Ivan Krstic discussed using Private Cloud Compute to power the new Siri unveiled at WWDC 2026.
