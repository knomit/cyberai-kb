# Vercel Connect replaces long-lived agent API tokens with runtime-issued, task-scoped credentials

Vercel Connect issues credentials at runtime that are scoped to individual tasks and expire automatically, replacing long-lived API tokens as the way AI agents authenticate to third-party services. Its generally available release added more than 100 connectors along with a unified integration model and production governance controls. The stated problem it addresses is 'credential sprawl' — agents accumulating broad, long-lived secrets.
