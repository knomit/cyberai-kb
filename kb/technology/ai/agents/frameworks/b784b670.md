# LangChain's Managed Deep Agents 0.8 adds user-owned credentials, memory, and Slack file transfer

LangChain's Managed Deep Agents (which combines the Deep Agents harness with production infrastructure for running agents) released version 0.8, adding support for user-owned credentials, user-level memory, HTTP channels, and file transfer in Slack, plus a pre-built web-search tool powered by Parallel.
