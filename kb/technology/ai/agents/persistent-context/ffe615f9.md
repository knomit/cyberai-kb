# Grok Build added memory for conventions, decisions and project facts

xAI added memory to Grok Build, storing conventions, decisions, and project facts so later sessions benefit from earlier ones. The stored categories are specific — conventions, decisions, and project facts — rather than general conversation history, which is what makes it a project-scoped knowledge store rather than a chat transcript.
