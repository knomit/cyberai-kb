# Flex lets a model write and execute its own code in a sandbox

Flex (by cmpnd.ai) uses model coding ability to rewrite not just a program's instructions but its actual code, then executes the generated source inside a sandboxed interpreter, producing cheaper and faster programs by optimizing both the prompt and the code.
