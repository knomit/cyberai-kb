# VISTA agent harness: persistent frame memory reaches 100 RHAE on ARC-AGI-3

MIT's VISTA (MIT license) stores all input frames and provides tools to retrieve/zoom frames, past actions and notes. With Claude Opus 5.0 it scored 100 RHAE on ARC-AGI-3 (GPT-5.6 Sol: 99; without frame storage: 70); on GameWorld GPT-5.6 Sol completed 63.3% of tasks vs 55.3% for first-time humans and 40% for the native harness.
