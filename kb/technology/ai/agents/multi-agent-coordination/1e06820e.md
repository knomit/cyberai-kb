# Agora uses an append-only Git DAG as shared memory for autonomous research agents

Agora is an open-source system letting autonomous research agents share findings through an append-only Git directed acyclic graph, where hypotheses, results, verifications, and reports each become reproducible commits. Operational consequence: the design choice is that agent coordination state is stored in version control rather than a database or message bus, which buys reproducibility and provenance at the cost of write throughput — appropriate for research workflows where auditability matters more than latency.
