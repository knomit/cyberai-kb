# Hermes Agent: open-source AI agent challenging OpenClaw with self-improving skills

Hermes Agent (launched Feb 2026 by Nous Research, NYC) moved ahead of OpenClaw on OpenRouter's daily token consumption leaderboard by May 2026. Key differentiators vs OpenClaw: (1) Auto-skill creation — when it solves a long/complex problem, it writes a SKILL.md automatically; a background 'Curator' archives skills unused for 90+ days or merges related ones. (2) Two-tier memory — user preferences file + workflows/lessons file; checks for duplicates before writing; merges when file grows too large. Also maintains a conversation database for search. Supports external memory providers like Honcho. (3) Persistent goal tracking — judge model evaluates whether goal was completed after each response; continues until done or max turns hit. Runs locally or in the cloud, supports many LLMs, integrates with ~20 messaging services, works via Agent Communication Protocol (ACP) with IDEs. Skills Hub is currently much smaller than OpenClaw's crowd-sourced library.
