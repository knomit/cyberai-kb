# LangSmith Connections splits agent credentials into agent-owned and user-owned

LangChain shipped LangSmith Connections, a credential management system for managed deep agents distinguishing two identity modes: agent-owned (shared) secrets for tasks like web search where one credential serves all callers, and user-owned OAuth credentials letting an agent act AS a specific user when filing tickets or touching that user's data. The security consequence is that per-caller identity preserves the downstream system's own authorization checks and audit trail, which a single shared service account destroys.
