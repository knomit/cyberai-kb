# Anthropic's Project Parka turns meeting audio into runnable work for Claude agents

Project Parka is a Mac-first Anthropic feature that captures system and microphone audio, streams speaker-attributed transcripts, and converts meeting content into runnable work items / implementation prompts for Claude's agents. As of the 2026-08-21 report it was unclear whether Claude starts the resulting actions automatically or waits for user approval.
