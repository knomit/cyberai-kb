# Andrew Ng's three loops for building 0-to-1 products with coding agents

In The Batch (June 26, 2026), Andrew Ng described three nested loops for AI-assisted product building amid the 'loop engineering' buzzphrase (popularized via Boris Cherny, Claude Code's creator, and Peter Steinberger, OpenClaw's creator). (1) The agentic coding loop runs in minutes: the agent writes, tests, and iterates code against a spec/evals autonomously. (2) The developer feedback loop runs over tens of minutes to hours: a human reviews the product and steers the agent, increasingly making higher-level product decisions as agents self-test. (3) The external feedback loop runs over hours to weeks: real-user feedback (alpha testers, A/B tests) refines the developer's product vision. Ng frames the human role as a 'context advantage' rather than 'taste'.
