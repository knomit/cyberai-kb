# Liquid AI built a production BPE tokenizer trainer with autonomous coding agents, identifying three reliability ingredients

Liquid AI used autonomous coding agents to build 'toktoktok', a production BPE tokenizer trainer requiring both ML and systems expertise. The experiment identified three key ingredients for reliable long-running agent workflows: concrete specifications, multi-domain tasks, and external verification.
