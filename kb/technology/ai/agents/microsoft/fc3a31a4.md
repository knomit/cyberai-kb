# Microsoft Copilot harness now available through Microsoft Foundry

Microsoft announced on 2026-10-28 that the Microsoft Copilot harness, which powers Copilot Code, Copilot Studio, the GitHub Copilot app, CLI and VS Code, is available through Microsoft Foundry as a managed way to build agents that reason, use tools and complete long-running tasks, designed to work across model families.
