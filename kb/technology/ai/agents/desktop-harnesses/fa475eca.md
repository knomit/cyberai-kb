# DeepLearning.AI releases OpenCoworker, an open-source desktop-agent harness

In The Batch (June 12, 2026), Andrew Ng announced OpenCoworker, a free, open-source desktop-agent harness from DeepLearning.AI, built by extending the aisuite library (with collaborators Rohit Prsad and Devika Verma). It lets an LLM drive an agentic loop with tools for file access, web search/fetch, and messaging integration. It runs on the user's own API key (OpenAI, Anthropic, Google, etc.) or a local model via Ollama, and stores memory locally — positioned as a privacy-respecting alternative to commercial desktop agents whose data-retention policies Ng distrusts. Some integrations (e.g. email) remain hard to set up; the project invites community contributions.
