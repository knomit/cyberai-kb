# Claude platform adds OpenTelemetry tracing for agents (Managed Agents, Messages API, SDKs)

Anthropic announced (reported 2026-10-15) that OpenTelemetry traces can be sent from Claude Managed Agents, the Messages API and Claude SDKs to any OTel tool that accepts a standard OTLP endpoint. Traces follow the OpenTelemetry GenAI semantic conventions, so data from Claude and other providers works in the same dashboards. Intended uses: debugging agents, improving agents with production data, and tracking usage across an organization.
