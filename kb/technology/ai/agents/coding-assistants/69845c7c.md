# xAI's Grok Build: terminal-based coding agent

Grok Build (xai-org/grok-build) is a terminal-based coding agent that can inspect codebases, edit files, run shell commands, search the web, and manage long-running tasks. It supports interactive use, headless scripting and CI, and editor integration via the Agent Client Protocol.
