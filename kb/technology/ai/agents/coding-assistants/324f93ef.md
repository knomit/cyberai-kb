# xAI's Grok Build: terminal coding agent and IDE assistant launched May 2026

xAI launched Grok Build in May 2026, an AI coding agent and developer assistant powered by the Grok model family, competing with GitHub Copilot, OpenAI Codex and Cursor.

CAPABILITIES span two surfaces. As a terminal agent (xai-org/grok-build) it inspects codebases, edits files, runs shell commands, searches the web, and manages long-running tasks; it supports interactive use, headless scripting and CI, and editor integration via the Agent Client Protocol. In the IDE it offers inline code completion, multi-file editing, codebase chat, and autonomous task execution.

POSITIONING: xAI emphasizes reasoning transparency — the agent shows its chain-of-thought during code generation, differentiating it from black-box alternatives. The launch followed xAI's broader expansion after the SpaceX talent influx, into a market where Anthropic's Claude for code, Google's Gemini Code Assist and Meta's coding models also compete.
