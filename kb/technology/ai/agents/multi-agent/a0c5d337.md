# Agent-swarm leadership emerges from model identity and prompt order

Per Raindrop (via TLDR AI 2026-10-30): in an experiment with eight agents from four different models resolving simulated outages without a designated leader, an agent's leadership was influenced by two factors: its underlying model and the order its name appeared in the prompt. Implication: minor configuration details of a swarm can change how it coordinates.
