# ChatGPT desktop browser and ChatGPT Sites now support WebMCP

OpenAI's ChatGPT desktop app built-in browser and ChatGPT Sites now support WebMCP, allowing ChatGPT and Codex to invoke a website's declared tools directly rather than inferring actions from the visual interface. This shifts web design considerations toward an 'agent experience' where the visitor may be an agent, or a human and agent browsing together.
