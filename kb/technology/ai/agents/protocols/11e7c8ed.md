# Personal Agent Protocol: open standard from Meta and Sierra

The Personal Agent Protocol is an open standard being developed by Meta and Sierra with partners to handle authentication for consumers' personal AI agents, let consumers set agent access, and let companies set limits and gain visibility into agent actions via sites, APIs or company agents (per TLDR AI, Oct 7 2026).
