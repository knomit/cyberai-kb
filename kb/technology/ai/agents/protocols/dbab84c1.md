# Agent Client Protocol v2 draft published

A v2 draft of the Agent Client Protocol (ACP)—which standardizes communication between code editors and coding agents by exposing methods and notifications each side can call—is now available for feedback. v2 aims to add flexibility and consolidate common patterns learned over the prior year.
