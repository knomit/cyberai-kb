# Gemini Agent details: Workspace integration, Claude model routing, agent sandbox

Gemini Agent works across Gmail, Drive, Docs, Slides, Sheets, Chat and Calendar and connects to Teams, Slack, Git and Jira. Cost controls include multi-model orchestration, routing to Gemini and Anthropic's Claude models, and token spending caps. Each agent gets a traceable identity, admin-approved fine-grained permissions, auditing, and runs in an Agent Sandbox with its own network boundary.
