# hip-agent implements an agent harness in ~200 lines by delegating to OS primitives

hip-agent is a minimal agent harness whose design principle is to reuse existing operating-system and protocol primitives instead of building harness machinery: configuration is environment variables, actions are shell commands, and a subagent is a child process. The core loop is roughly 200 lines of Python plus a module for the Codex API. It is a counterpoint to heavyweight harness architectures — the claim is that most harness complexity is reinvention of things the OS already provides.
