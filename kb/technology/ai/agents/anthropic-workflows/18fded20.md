# Anthropic dynamic workflows let Claude write the orchestration program for multi-agent tasks

Per Latent Space, Anthropic's dynamic workflows let Claude write the program that coordinates several agents. An Oct 12 demo assigned stock tickers to separate agents and reviewed findings before a report; presenters said it found more detail but cost much more than one agent. Developers can set a session spending limit, but the running model does not know that budget.
