# Vercel releases AI SDK 7 with new execution loop and telemetry

Vercel released AI SDK 7, introducing a zero-overhead execution loop that simplifies how frontend frameworks handle multi-step tool calls and streaming agentic UI states, plus a unified telemetry layer that hooks into serverless compute runtimes to trace token usage, model choices, and tool-execution latency.
