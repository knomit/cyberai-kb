# Microsoft Build 2026: MAI reasoning model, autopilot agents, MDASH bug hunter, ASSERT safety tool

At Microsoft Build 2026 (San Francisco), CEO Satya Nadella announced a sweeping set of AI products targeting every layer of the enterprise AI stack. Agent products: (1) 'Autopilots' — long-running enterprise-grade agents with connectors, context, memory, personality and name, built on OpenClaw; first autopilot is Microsoft Scout (personal agent for meeting prep, scheduling, routine tasks). (2) Microsoft IQ (enterprise knowledge + intelligence system for agents, now GA). (3) WebIQ (real-time web search platform for agents). Model releases: MAI-Thinking-1 (first Microsoft reasoning model, 35B parameters, 128K context, optimized to lower token costs for agentic workloads); MAI-Image-2.5; MAI-Transcribe-1.5; MAI-Voice-2; MAI-Code-1 (ultra-efficient, tuned for GitHub). Safety/governance: ASSERT (open-source AI safety evaluation automation); Agent Control Specification (open-source standard to regulate agent controls); Codename MDASH (agentic bug-hunting system); Frontier Tuning (applies reinforcement learning within compliance policies to let agents learn organizational rules). Copilot 'superapp' announced, combining coding, chat, and Copilot Cowork agent. Copilot also redesigned across Microsoft 365.
