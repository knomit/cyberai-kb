# Claude Opus 4.8 launch: honesty focus, agentic improvements, $965B valuation (May 29 2026)

Anthropic launched Claude Opus 4.8 on May 29, 2026 alongside a $65B Series H funding round at a $965B valuation — surpassing OpenAI. Key improvements over Opus 4.7: (1) Honesty/calibration: more likely to flag uncertainty, less likely to make unsupported claims; 4x less likely to miss code flaws it wrote. Early testers (Shopify, Genspark, Cursor, Databricks) found it 'more reliable and sharper in agentic tasks.' (2) Dynamic workflows (research preview): Claude Code can plan work and run hundreds of parallel subagents in a single session. (3) Effort control: users choose how much effort Claude puts into a response; defaults to high effort. (4) Messages API: now accepts system entries inside the messages array to update instructions mid-task without breaking the prompt cache. Anthropic also announced an upcoming 'new class of models with even higher intelligence than Opus' — likely referring to Mythos — planned for release in coming weeks.
