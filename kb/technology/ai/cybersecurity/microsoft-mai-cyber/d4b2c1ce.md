# Microsoft launches MAI-Cyber-1-Flash inside MDASH

Microsoft launched MAI-Cyber-1-Flash, its first cybersecurity-specific model, inside MDASH (a multi-model vulnerability identification and remediation harness). MDASH running MAI-Cyber-1-Flash with GPT-5.4 scored 95.95% on CyberGym while costing about 50% less than Microsoft's prior best combination (GPT-5.4, GPT-5.4 mini, GPT-5.3 Codex). MAI-Cyber-1-Flash is designed to handle up to 90% of MDASH tasks with GPT-5.4 reserved for the hardest 10%; it is available only inside MDASH via an Azure AI Foundry private preview, not as a standalone public model.
