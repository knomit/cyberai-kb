# DeepSeek launches Search and Fetch APIs for agents and RAG

DeepSeek's Search API finds web pages for a query and returns structured results; the Fetch API retrieves a single page and returns its content as Markdown. Both are raw JSON APIs using the same bearer authentication as the DeepSeek API, aimed at agents and RAG applications needing live web content.
