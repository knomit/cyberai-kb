# Claude API version 2026-10-21 is the first official API version since 2023

Anthropic released Claude API version 2026-10-21, its first official version release since 2023-06-10 (which is not deprecated). Anthropic plans more frequent versions so developers can handle breaking changes before a new model requires them. New major versions of the Anthropic SDKs and CLI default to the new API; a migration guide exists. Misreading to avoid: the old 2023-06-10 version still works.
