# NVIDIA ENPIRE applies coding-agent self-improvement loops to physical robots

NVIDIA researchers developed ENPIRE, a harness framework that lets physical robots run the same autonomous experiment-and-execution loop as AI coding agents. It has four core modules including an Environment module (EN) for automatic reset and verification and a Policy Improvement module; a scaffold supervises robots much as coding agents supervise code. In tests (e.g., using a cutter to cut a zip tie, inserting GPUs into a motherboard), GPT-5.5 within Codex and Opus 4.7 within Claude Code traded off for best performance while Kimi-2.6 lagged, and larger numbers of agents (e.g., 8) reached higher-scoring solutions sooner, with multi-agent setups sometimes beating single-agent ones. Reported in Import AI 463.
