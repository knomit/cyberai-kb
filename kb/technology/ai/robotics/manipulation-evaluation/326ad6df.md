# GPT-6 Astra's robotic manipulation success drops sharply with task precision

In a robotic-manipulation test using YAM arms under an Inspect Robots agent policy, GPT-6 Astra placed a block in a bowl in 19 of 20 trials but completed a puzzle-piece insertion task in only 2 of 20. Frontier reasoning capability does not transfer to fine physical manipulation.
