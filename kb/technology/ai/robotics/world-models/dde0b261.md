# MBZUAI PAN Arcadia: real-time interactive world model prioritizing responsiveness over fidelity

MBZUAI's Institute of Foundation Models (IFM) released PAN Arcadia, a research preview of a real-time interactive world model. Unlike most world models optimized for visual coherence in fixed clips, PAN Arcadia responds to user input as it happens — a user steers an agent through a scene with keyboard controls and the model continuously generates the surrounding environment. Sessions capped at 30 seconds; user image uploads planned for future. Trained on footage with strong intentional motion (city walks, synthetic data with clear objectives) to learn how scenes change, not just how they look. Does not model fine-grained motor control or joint physics — operates at cause/effect/navigation/decision-making level. MBZUAI is also developing K2 Think, a reasoning model, with the thesis that world models and reasoning models must evolve together: reasoning model handles planning, world model provides environment for testing decisions. Even simple hand-drawn images can be turned into navigable environments.
