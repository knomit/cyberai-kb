# Qwen3.8-LiveTranslate cuts average translation lag from 2.8s to 2.3s using an interleaved audio-text architecture

Qwen3.8-LiveTranslate uses an interleaved audio-text architecture to cut average live translation lag from 2.8 seconds to 2.3 seconds while simultaneously improving quality — the latency reduction and the quality gain are reported together, so the result should not be summarized as a latency-for-quality tradeoff. It adds real-time speaker separation, bilingual source alignment, long-context disambiguation, and voice cloning, across 60 INPUT languages (input language count; output language coverage is a separate figure and should not be assumed equal).
