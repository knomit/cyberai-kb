# Moonshot AI releases Kimi Code CLI, a terminal AI coding agent

Kimi Code CLI is an AI coding agent that runs in the terminal. It can read and edit code, run shell commands, search files, and fetch web pages, choosing the next step based on feedback. It works with Moonshot AI's Kimi models.
