# Assistant axis + activation capping: steering LLMs back to trained assistant persona during long/emotionally charged conversations

Christina Lu et al. (MATS, Oxford, Anthropic) developed the 'assistant axis' technique: a vector derived from LLM layer outputs measuring how closely a model adheres to its trained assistant character (reported April 24, 2026). Method: compare layer outputs between default character and alternative roles (therapist, fool, narcissist, criminal, etc.); difference vector = assistant axis; measure cosine similarity during inference. 'Activation capping': if similarity falls below 25th percentile, modify layer outputs to maintain minimum similarity (~average of default role). Tested on Gemma 2 27B, Qwen3 32B, Llama 3.3 70B. Results: (1) Against 1,100 jailbreak prompts: Qwen3 32B harmful responses 83% → 41%; Llama 3.3 70B 65% → 33%; (2) No benchmark degradation on IFEval, GSM8k, MMLU-Pro, EQ-Bench (slight improvement on GSM8k: 81%→83%; EQ-Bench: 83.1%→84.1%); (3) Qualitative: model stayed in helpful assistant role during emotionally charged conversations (e.g., suicidal ideation scenarios), responding with care rather than drifting into harmful persona. Significance: goes beyond system prompts (which can be bypassed) to anchor behavior in model's internal state.
