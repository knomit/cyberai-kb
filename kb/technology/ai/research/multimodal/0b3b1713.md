# Apple AToken: unified 4D tokenizer for images, videos, and 3D objects

Apple researchers Jiasen Lu, Liangchen Song et al. trained AToken — a single tokenizer and encoder for images, videos, and 3D objects, analogous to LLMs' single tokenizer for all text types. Key innovation: 4D coordinate system (t, x, y, z) maps all three media types into a shared token space; images at t=z=0 (2D), videos add time dimension (t,x,y), 3D objects use (x,y,z) with t=0. Architecture: SigLIP2 encoder (400M params) + decoder of same size; 4D Rotary Position Embeddings. Training: three-stage (images → videos → 3D), with contrastive loss to align visual embeddings to text. Results: ImageNet 82.2% (vs SigLIP2 standalone 83.4%); rFID 0.21 for image generation (vs FLUX.1 dev 0.18); 3D reconstruction 28.28 PSNR (vs Trellis-SLAT 26.97). Benefit: knowledge transfers across modalities — improvements in one domain generalize. Particularly relevant for robotics that need 3D/video data synthesis.
