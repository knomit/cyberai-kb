# Z.ai Single-rollout Asynchronous Optimization RL method

Per TLDR AI, Z.ai's Stable Asynchronous RL introduces Single-rollout Asynchronous Optimization, which replaces GRPO-style grouped sampling with one rollout per prompt for reinforcement learning training.
