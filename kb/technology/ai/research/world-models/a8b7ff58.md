# WorldTUI: 360M-parameter model fine-tuned to simulate a terminal

WorldTUI is a 360M-parameter model fine-tuned to act as a terminal: it predicts how the screen changes for each key press with no shell or file system behind it. It can create files, run vim and tmux, play snake, usually remember commands, repair mistakes and decode screen rows in parallel. Browser demo available.
