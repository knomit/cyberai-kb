# MIT Recursive Language Models: External REPL Context for 11M+ Token Document Reasoning

MIT researchers (Alex L. Zhang, Tim Kraska, Omar Khattab) developed Recursive Language Models (RLMs) that process documents larger than context windows by managing context as an external Python variable in a REPL environment. How it works: Model writes Python code to fetch relevant chunks, spawns submodels for subtasks, aggregates results. Tested with Qwen3-8B (32K ctx), GPT-5 (400K ctx), Qwen3-Coder-480B (256K ctx). Results: RLM-GPT-5: 91.3% on BrowseComp+ vs GPT-5 unable to answer (context limit). RLM-GPT-5 on OOLONG-PAIRS: 58% at 32K tokens (vs GPT-5 ~0%). Maintains ~50% at 1M tokens. Total document size tested up to 11M tokens. RLM-Qwen3-8B: 14% vs 0% for base Qwen3-8B. Outperforms retrieval augmentation and summarization approaches. Implications: Blueprint for agents that reason coherently over far more tokens than their context window permits.
