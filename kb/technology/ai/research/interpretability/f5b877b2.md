# Qwenputer: deterministic RISC-V CPU running inside Qwen3.5 using GDN layers as RAM

Qwenputer is a developer project in which a fully functioning, deterministic RISC-V CPU runs inside Qwen3.5, using the model's Gated DeltaNet layers as RAM. It runs arithmetic and C and MicroPython code without an external runtime or tools, and includes an experimental in-model file storage.
