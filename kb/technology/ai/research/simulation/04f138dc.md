# Google Persona Generators use AlphaEvolve evolutionary algorithm to generate maximally diverse synthetic user cohorts

Google researchers Davide Paglieri, Logan Cross, et al. published Persona Generators research in April 2026. Method: uses AlphaEvolve (evolutionary algorithm) to generate code that produces 25 maximally diverse LLM personas per questionnaire. Setup: Gemini 2.5 Pro generates 30 questionnaires on varied topics (health care, financial literacy, conspiracy theories) with diversity axes (risk tolerance, institutional trust, etc.); AlphaEvolve iteratively optimizes persona-generation code over 500 iterations to maximize 6 diversity metrics; Gemma 3-27B-IT (with Concordia library) simulates each persona's questionnaire responses. Results: covers 82% of possible response space vs 76% for Nemotron Personas (US demographics-based) and 46% for Concordia memory generator. Application: product management research, user testing, and navigating the PM bottleneck — using synthetic personas to decide what to build when you can build fast.
