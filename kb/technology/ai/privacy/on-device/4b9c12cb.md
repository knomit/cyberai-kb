# Google's planned Private AI Compute keeps cross-device AI memory encrypted, unreadable even by Google

Google says its planned Private AI Compute memory feature will let AI assistants recall context across devices while keeping data encrypted in cloud storage with keys stored on the user's own devices; a protected enclave decrypts the data only while actively answering a request, so Google itself cannot read the stored memory.
