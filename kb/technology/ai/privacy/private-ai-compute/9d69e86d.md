# Google/DeepMind plan encrypted cross-device memory for Private AI Compute, with keys held only on user devices

Google (via Google DeepMind; reported by THN 2026-09-28) announced a PLANNED persistent memory layer for Private AI Compute that lets AI assistants recall context across a user's devices. User information is kept in dedicated encrypted cloud storage while the decryption keys are held only on the user's own devices; a protected enclave decrypts the data only while actively answering a request. Google states this makes the stored memory inaccessible even to Google.

WHAT THIS DOES NOT MEAN: this is an announced plan, not a shipped feature. The 'unreadable even by Google' property is Google's own claim about the design, not an independent audit; and data is decrypted inside the enclave while a request is being served, so it is not encrypted at every moment of use.
