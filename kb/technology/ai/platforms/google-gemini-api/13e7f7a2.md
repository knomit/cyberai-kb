# Google expands Managed Agents in Gemini API

Google announced new capabilities for Managed Agents in the Gemini API: background (asynchronous) execution, remote MCP server integration, custom function calling, and credential refresh across interactions. Users call a single endpoint while Gemini handles reasoning, code execution, package installation, file management, and web access inside an isolated cloud sandbox, turning managed agents into asynchronous workers in real development environments. Reported in TLDR AI, July 8 2026.
