# A gray market gives Chinese developers discounted access to restricted US LLMs

A ChinaTalk think-tank report describes a network of API proxy servers, account farms, verification platforms, token resellers, and identity brokers that lets developers in mainland China access US models (OpenAI, Anthropic Claude, Google Gemini, Midjourney) that are otherwise unavailable there — reportedly buying Claude tokens for as little as 10% of typical market price. Tactics include aggregating Anthropic free credits, reselling unused quotas, exploiting education/corporate discounts, and using stolen credit cards. Requests for higher-tier models may be silently routed to cheaper, inferior models: CISPA Helmholtz Center found proxy 'Gemini-2.5' scored 37% on MedQA versus 83.82% via Google's official API. Proxies also harvest and resell user request logs, which make useful training data. The report is based largely on interviews and circumstantial evidence and is not fully independently verified.
