# DeepSeek building abstraction layer to run on Huawei Ascend as well as Nvidia

DeepSeek plans to rebuild the software ecosystem around Nvidia-style hardware so Chinese chips are easier to use for frontier training, creating an abstraction layer between models and GPU hardware that could sit over Nvidia GPUs or Huawei Ascend chips. If it works, the cost of moving AI workloads from Nvidia to Chinese hardware could fall significantly. Plan, not shipped result.
