# Ramp Router routes LLM traffic via Thompson sampling and EWMA

Ramp built 'Ramp Router', which learns provider failure rates through exponentially weighted moving averages (EWMA) and latency distributions through Thompson sampling, then routes to the cheapest model meeting reliability/latency targets — online learning for cost-efficient LLM routing.
