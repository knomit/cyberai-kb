# Nvidia PAIR routes local inference across multiple PCs on a home network

Announced at IFA 2026 on 2026-09-03, Nvidia Personal AI Router (PAIR) is a free, open-source tool that coordinates a household's PCs to run local AI together. Nvidia says PAIR automatically discovers compatible PCs on the local network and routes independent inference requests to whichever system has available capacity, bypassing the bottleneck that occurs when multiple agents or tasks queue on a single GPU. Note the constraint: PAIR distributes independent requests across machines — it is load balancing, not splitting one model or one inference across multiple GPUs.
