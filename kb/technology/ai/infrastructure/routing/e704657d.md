# OpenRouter launches next-generation Auto Router and Auto Code router

OpenRouter launched a new Auto Router (claimed up to 4x better than the old router) and Auto Code, a router specialized for coding. Both choose models by weighing eleven factors per request combined with live pricing, provider health and cache status, and support user governance policies.
