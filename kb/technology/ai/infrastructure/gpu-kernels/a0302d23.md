# Cursor open-sources Mixture-of-Kittens MoE megakernel

Cursor's Mixture-of-Kittens (MoK) is an open-source optimized Mixture-of-Experts (MoE) megakernel that improves efficiency on NVL72 GPUs, boosting performance for models like Composer by addressing computation and communication bottlenecks.
