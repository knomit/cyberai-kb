# Model routing is a systems-optimization problem, not model selection

IBM Research argues that LLM model routing systems face challenges well beyond choosing the best model per task, becoming complex systems-optimization problems. Factors such as caching, workload interactions, and serving infrastructure impact cost and latency often more than base model pricing or perceived task difficulty. Effective routing must optimize across multiple axes to find an optimal operating point for the whole system rather than the best model for an isolated task.
