# Z.ai used a GLM-5.3 agent to build GLM-5.3-Flash's serving stack on 100,000+ Chinese accelerators in under two weeks

Z.ai reported that a GLM-5.3-powered Infra Agent helped build the production serving stack for GLM-5.3-Flash across more than 100,000 Chinese-made accelerators in under two weeks. Dense feedback loops, kernel-level fixes, and system-level optimization tripled throughput. Z.ai states humans remained responsible for objectives and risk decisions while the agent performed the engineering work. Operational consequence: this is a concrete data point for partial recursive self-improvement in infrastructure rather than model training — the model improved the system that serves the model, not the model's own weights. Note what this does NOT mean: tripled throughput is relative to Z.ai's own prior stack, not a cross-vendor comparison, and the domestic-accelerator context means the result may not transfer to NVIDIA-based stacks.
