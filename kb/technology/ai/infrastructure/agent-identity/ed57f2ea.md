# Linux Foundation announces Agent Name Service (ANS) at Confidential Computing Summit

At the Confidential Computing Summit in San Francisco (organized by The Linux Foundation), leaders from Google, Microsoft, AMD, Intel and others pushed for decentralized, 'sovereign' AI rooted in hardware-based confidential computing. The Linux Foundation announced the Agent Name Service (ANS), intended to give every enterprise AI agent a verified identity and tamper-proof audit trail — described as analogous to DNS for the internet. Opaque CEO Aaron Fulkerson, the event emcee, argued enterprises 'should never have to pay for AI with our data.'
