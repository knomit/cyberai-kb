# OpenAI + AWS: Stateful Runtime for Agents on Bedrock + Full Model Availability (Mar 2026)

OpenAI and Amazon announced a 'stateful runtime environment' for AI agents on Amazon Bedrock (launch within months of Mar 2026), with OpenAI models also made available directly via AWS Bedrock — ending Microsoft's effective exclusivity on OpenAI distribution.

Key deal terms:
- Amazon invested $15B + up to $35B contingent (or if OpenAI IPOs before 2029)
- Total $110B round also included Nvidia and SoftBank, valuing OpenAI at $730B
- AWS is exclusive third-party cloud for OpenAI Frontier (agent platform)
- OpenAI committed to 2GW of Trainium processing ($100B expansion of prior $38B agreement over 8 years)
- OpenAI models (GPT series) now available via AWS Bedrock for enterprise customers

Stateful vs stateless legal distinction:
- Microsoft retains exclusive right to OpenAI's stateless APIs
- The runtime environment is not a stateless API, so it goes to AWS
- Azure hosts stateless API calls arising from the Amazon collaboration

Stateful runtime manages: agent working memory, tool connections, user permissions, multi-step workflow state. Integrates with Amazon Bedrock AgentCore.

Broader context: dissolution of early AI era's tight cloud partnerships — Microsoft stake now 27%, 20% of revenue but no first refusal on cloud. Anthropic similarly multi-cloud (AWS + Google Cloud + Azure). Note: Andrew Ng is an Amazon board member.
