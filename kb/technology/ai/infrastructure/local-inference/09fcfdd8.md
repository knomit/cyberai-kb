# Cost of running SOTA LLMs locally (2026)

Per jamesob's guide to running state-of-the-art LLMs locally, a roughly $2,000 hardware budget can run Qwen models plus good local speech-to-text, while about $40,000 buys a machine capable of running almost-Opus-level models locally within Docker containers.
