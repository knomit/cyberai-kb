# Google's Agent Substrate agent-sandbox runtime became available on GKE

Google announced Agent Substrate is available on Google Kubernetes Engine (GKE). Agent Substrate is an open-source, secure-by-default agent execution runtime engineered to run millions of sandboxes at 10x higher density than standard container runtimes, delivering sub-500ms resume operations at over 500 suspend/resume activations per second, with native zero-trust kernel and network isolation. Portability and optimization are separate claims that must not be collapsed: Agent Substrate runs on ANY Kubernetes infrastructure, and is OPTIMIZED FOR GKE — availability on GKE does not make it GKE-only.
