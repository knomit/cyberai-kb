# PyTorch releases Miles stack for large-scale LLM RL post-training

PyTorch published 'Miles', a PyTorch-native stack for large-scale LLM reinforcement-learning post-training, designed to make frontier-scale LLM RL easier to build, reproduce and operate while keeping the core trainer small enough to customize.
