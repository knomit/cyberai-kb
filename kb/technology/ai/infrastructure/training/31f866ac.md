# Tencent details ARGUS tracing system used on 10,000+ GPU training cluster

Tencent released details on ARGUS, described as a low-overhead, fine-grained, always-on tracing and real-time analysis system for large-scale AI training workloads. It spans three software layers (a Python scheduling/data-prep layer, a framework orchestration layer, and a GPU runtime layer for kernel execution). Tencent deployed ARGUS on a production cluster of over 10,000 GPUs for more than six months and demonstrated it via five real-world case studies diagnosing issues such as compute stragglers, communication link degradation, and pipeline bubble amplification.
