# Keenable emerged from stealth claiming a 100B+ document web index built for AI agents

Keenable, backed by Accel, emerged from stealth with a claimed index of more than 100 billion documents and an API it says is already used by unnamed AI labs, plus a planned query language for combining evidence across sources. The pitch is a web index and query layer purpose-built for AI agents rather than human search. The document-count and lab-adoption claims are the company's own and were not independently verified in the reporting.
