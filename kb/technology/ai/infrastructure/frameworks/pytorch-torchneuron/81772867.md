# TorchNeuron: open-source native PyTorch backend for AWS Trainium (public beta, Apache 2.0)

TorchNeuron is a native PyTorch backend for AWS Trainium, supporting eager execution for research and debugging and using existing PyTorch model code and tools. Released as public beta under Apache 2.0.
