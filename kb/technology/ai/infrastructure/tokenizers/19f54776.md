# Gigatoken high-speed tokenizer

Gigatoken is a tokenizer for language modeling that supports a wide range of CPU hardware and nearly all commonly used tokenizers. It can be used via its own API or in a compatibility mode with Hugging Face Tokenizers or Tiktoken, and is reported to be roughly 1,000 times faster than Hugging Face's tokenizers, tokenizing text at gigabytes per second.
