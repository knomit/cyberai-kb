# Replit made Intelligent Model Routing the default, cutting cost 65% at equal quality

Replit launched Intelligent Model Routing as the default for all accounts, matching tasks to the model best suited for them to balance quality, speed, and cost. Replit reports the same output quality as its previous Max Mode (top-tier paid setting using frontier models) at 65% lower cost. Free-tier users are notified before escalation to higher-cost models and can override; paid users can still select models manually; enterprise administrators can define an approved model set the router must choose from.
