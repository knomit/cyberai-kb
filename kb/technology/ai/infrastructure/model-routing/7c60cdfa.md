# Replit made Intelligent Model Routing the default, claiming Max Mode quality at 65% lower cost

On 2026-08-27 Replit launched Intelligent Model Routing as the default across all accounts on its AI coding platform. The system matches each task to the model best suited to it, trading off quality, speed and cost. Replit reported the routed system delivers the same output quality as its previous Max Mode — the top-tier paid setting that always used frontier models — at 65% lower cost. Control is preserved differently per tier: Free Mode always routes and cannot manually select a model, but users are notified before work escalates to higher-powered models that incur usage costs and can override; Core and Pro users can still select models manually; enterprise administrators can define an approved model set per workspace, and routing chooses only from within that set. The 65% figure is Replit's own reported comparison against its prior Max Mode, NOT an independently benchmarked claim about routing in general.
