# Snowflake adds dynamic model routing to Cortex AI Gateway, claiming up to 3x token efficiency

Snowflake unveiled dynamic model routing within its Cortex AI Gateway and its AI products Snowflake CoCo and Snowflake CoWork. Model routing matches AI models to task complexity, using lighter, cheaper models for most jobs and reserving frontier models for when they are needed, and lets enterprises avoid rebuilding agents or apps for different models. In internal evaluations, agents using dynamic model routing to build a dbt pipeline saw up to 3x greater token efficiency than a frontier-model-only path without compromising quality; in another test, engineers completed the same number of pull requests with 25% greater token efficiency. Baris Gultekin is Snowflake's VP of AI.
