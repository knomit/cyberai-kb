# NVIDIA released NeMo Switchyard, an open-source model-routing library for agent workloads

NVIDIA released NeMo Switchyard in mid-August 2026, an open-source library for smart routing of AI agent workloads across models within popular agent tools. It lets enterprises build routers meeting their own needs, lowering inference costs without compromising performance or requiring apps to be rebuilt. Kari Briski, NVIDIA's VP of generative AI software for enterprise, noted routing to domain- or task-specific models yields faster responses, greater token efficiency, and in some cases higher domain accuracy — not just cost savings.
