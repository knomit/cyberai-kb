# OpenAI expands ChatGPT Voice to mobile 'on-the-go' agentic work

On September 23, 2026, OpenAI released ChatGPT Voice 'on-the-go', extending its GPT-Live voice model to the web and mobile experiences of ChatGPT Work and Codex. Pro/Plus users can use Voice in ChatGPT Work on mobile to create docs, decks and spreadsheets, work with connected plugins, draft emails, create sites, and talk to Slack; Free/Go users can use Voice in the base chatbot to interact with connected plugins/apps. Voice and text models are linked so conversations can switch seamlessly between the two modes. The release follows OpenAI's GPT-6 Sol and Luna model launch a day earlier, priced cheaper than Anthropic's comparable models.
