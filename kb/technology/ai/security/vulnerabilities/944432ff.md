# GitHub CVE-2026-3854 (CVSS 8.7): RCE via single 'git push', 'most severe SaaS vulnerability ever found'

Wiz Research disclosed CVE-2026-3854 (CVSS 8.7) in GitHub.com and GitHub Enterprise Server. An authenticated user can obtain remote code execution via a single 'git push' command. On GitHub.com: RCE on shared storage nodes. On GitHub Enterprise Server: full server compromise, unauthorized access to all hosted repositories and internal secrets. Microsoft patched within 6 days of responsible disclosure. Wiz: 'Exploitation could expose the codebases of nearly all of the world's biggest enterprises, making this one of the most severe SaaS vulnerabilities ever found.'
