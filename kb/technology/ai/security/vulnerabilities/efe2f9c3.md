# LiteLLM CVE-2026-42208 SQL injection exploited within 36 hours of disclosure

A critical SQL injection vulnerability (CVE-2026-42208) in BerriAI's LiteLLM Python package was exploited in the wild within 36 hours of public disclosure. LiteLLM is a widely used AI inference proxy/abstraction library used in production AI systems. The 36-hour exploitation window illustrates how rapidly attackers are targeting AI infrastructure tooling once vulnerabilities are published.
