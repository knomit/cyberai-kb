# GitHub CVE-2026-3854: critical RCE via single git push on GitHub.com and Enterprise Server

Cybersecurity researchers disclosed a critical RCE vulnerability (CVE-2026-3854) affecting GitHub.com and GitHub Enterprise Server. An authenticated user can obtain remote code execution with a single git push. Severity: critical. This affects the primary platform for AI code repositories, CI/CD pipelines, and GitHub Copilot integrations.
