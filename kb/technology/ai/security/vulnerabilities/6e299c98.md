# Gemini CLI CVSS 10 RCE patched: npm package and GitHub Actions workflow both vulnerable

Google fixed a maximum severity (CVSS 10) remote code execution vulnerability in Gemini CLI — specifically in the '@google/gemini-cli' npm package AND the 'google-github-actions/run-gemini-cli' GitHub Actions workflow. Attackers could exploit this to execute arbitrary code. The dual-surface nature (npm package + CI/CD workflow) is notable: a supply chain attack on either surface could compromise developer pipelines. Corroborates existing synthesis on AI adoption creating structural security debt (dc28a59e).
