# Hugging Face LeRobot: critical unpatched unauthenticated RCE in open-source robotics platform

Cybersecurity researchers disclosed a critical, unpatched security flaw in LeRobot, Hugging Face's open-source robotics platform (nearly 24,000 GitHub stars), enabling unauthenticated remote code execution. The vulnerability is unpatched as of disclosure. LeRobot is a significant platform in the physical AI/robotics ecosystem — an unpatched critical RCE in a widely used robotics platform represents serious supply chain risk for physical AI deployments.
