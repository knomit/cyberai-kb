# Microsoft Open-Sources RAMPART and Clarity: Agent Red-Teaming Tools for Continuous Security Testing

Microsoft's AI red team released two open-source agentic security tools in May 2026:

**RAMPART**: An open-source framework that embeds AI red-teaming techniques into the development workflow. Enables teams to continuously test agent behavior under common and adversarial circumstances throughout the development cycle — not as a one-time assessment.

**Clarity**: A complementary reasoning tool that helps engineers and product teams pressure-test ideas and assumptions before code is written, identifying potential risks at the design stage.

Rationale (per Ram Shankar Siva Kumar, founder of Microsoft AI red team): (1) Scale red-teaming practices industry-wide; (2) Make incidents reproducible and verify mitigation techniques; (3) Enable engineers to think through 'why' before 'how.' Quote: 'That shift from generate text to do things in the world changes the safety equation entirely, because an agent that can act can also potentially act in ways nobody intended.'

Open-sourcing strategy: Microsoft gains differentiation in the AI security ecosystem — a market where it can stand out as it doesn't lead on frontier models. By open-sourcing, defense techniques can spread industry-wide faster than proprietary tools. Positions alongside Anthropic's Mythos/Glasswing and OpenAI's Daybreak as the major labs' AI security response.
