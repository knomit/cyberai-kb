# SecureForge automatically optimizes system prompts to make LLMs generate less insecure code

Houjun Liu, Lisa Einstein, John Jang, and colleagues at Stanford introduced SecureForge, a method that automatically optimizes an LLM's developer system prompt to reduce security flaws in generated Python code. It uses the top 25 MITRE Common Weakness Enumeration (CWE) items to generate benign coding requests likely to yield vulnerable output, detects vulnerabilities with the Semgrep static analyzer, and optimizes the system prompt with the GEPA genetic algorithm (iteratively proposing improved prompts via GPT-5.4 until no meaningful gains). Across all LLMs tested, SecureForge produced programs with security flaws 11.8% of the time on average, versus 20.1% when simply asking for secure code and listing issues to avoid. For GPT-5.4: 10.1% vs 15.8%; GPT-5.4 Mini: 12.4% vs 21.4%; GPT-5.4 Nano: 15.6% vs 22.1%. Limitation: it only optimizes the developer system prompt against known vulnerability classes, so effectiveness against unknown ones is unproven. Freely available for commercial and noncommercial use.
