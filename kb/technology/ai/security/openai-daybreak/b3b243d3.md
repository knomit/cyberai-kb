# OpenAI expands Project Daybreak with GPT-5.5-Cyber for defenders

On Monday (June 2026), OpenAI released an improved GPT-5.5-Cyber model to trusted defenders under its Project Daybreak initiative (announced the prior month), calling it its 'strongest model yet for finding and helping patch software vulnerabilities' and able to sustain deeper analysis across large codebases, validate issues in a controlled environment, and develop/test patches. Alongside it, OpenAI shipped a Codex Security plugin update, a partner program for broader org access, and a 'patch the planet' initiative to find and fix vulnerabilities in popular open-source projects.
