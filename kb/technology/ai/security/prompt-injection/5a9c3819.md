# The lethal trifecta: private data, untrusted content, and an outbound channel

Independent developer Simon Willison identified the 'lethal trifecta' for AI agents in mid-2025: private data access, exposure to untrusted content, and a way to send data out. Willison argued the only safe option is to avoid combining all three, and that a classifier catching even 99 percent of new prompt injections still leaves unacceptable risk. Related prior work: in April 2025, Google DeepMind and ETH Zurich researchers led by Edoardo Debenedetti proposed CaMeL, which separates a planning model from the model that reads untrusted data and enforces written policies before tool calls. Operational consequence: when all three trifecta components are unavoidable (as in Meta's Muse agent, which processes all three but routes outgoing data through a component the model cannot override), the mitigation is architectural containment rather than making the model injection-proof. Note the compression failure to avoid: 'use a prompt-injection classifier' is NOT the lesson — Willison's point is specifically that probabilistic filtering is insufficient at security-relevant scale, which is why deterministic controls must sit outside the model.
