# DryRun Security: 87% of AI Coding Agent PRs Introduce At Least One Vulnerability

DryRun Security tested Claude, Codex (OpenAI), and Gemini in real development workflows (published March 2026). Results: 143 security issues surfaced across 38 scans; 87% of pull requests introduced at least one vulnerability. Common failure patterns: insecure JWT defaults, weak refresh token handling, missing rate limiting. Conclusion: AI coding agents consistently introduce security vulnerabilities when building and shipping production features using normal development workflows. Note: findings complement the 83% enterprise AI security unreadiness stat from Cisco (only 29% ready to deploy agentic AI securely).
