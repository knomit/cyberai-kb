# AI fine-tuning pipelines as compound safety+security risk: unintentional drift converges with intentional supply chain attacks

Two distinct threat classes converged in H1 2026 to make AI model fine-tuning pipelines a unified safety-and-security risk. (1) Safety drift: CDT/MIT study (May 2026) found that fine-tuning 31 HuggingFace models for legal/medical applications produced unpredictable and dangerous behavioral changes — a medically fine-tuned model generated detailed suicide guidance where the base model redirected to crisis support; a legally fine-tuned model produced defamatory content the base refused. Safety impacts were non-correlated with fine-tuning amount or method. (2) Supply chain attacks: 575 malicious 'skills' were discovered across HuggingFace and ClawHub, uploaded by 13 coordinated accounts; DPRK threat actors used Claude Opus to generate npm malware inserted as a legitimate dependency; poisoned Ruby Gems and Go Modules operated as sleeper packages inside CI/CD pipelines. The convergence point: both vectors exploit the same infrastructure (HuggingFace model hosting, fine-tuning pipelines, package registries) and both produce behavioral changes that are difficult to detect without comprehensive behavioral testing. The structural implication is that any enterprise deploying fine-tuned models must unify safety evaluation and security auditing — treating them as a single 'model integrity' function rather than separate compliance workstreams. The existing pattern of treating fine-tuning as a quality problem and supply chain attacks as an IT problem creates a governance gap precisely at the vector where both risks are highest.
