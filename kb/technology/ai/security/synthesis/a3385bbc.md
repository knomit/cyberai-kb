# AI workspaces are emerging as dedicated high-value exfiltration targets as power-user data density increases

Two independent data points in May 2026 together surface a non-obvious risk: (1) LayerX 2026 data shows that top 5% of enterprise AI users generate 12x more conversations and 9x deeper prompt chains than average, and interact across multiple AI platforms — concentrating sensitive data exposure in a small population using predictable AI tool paths. (2) The Malware-Slop npm package (mouse5212-super-formatter) explicitly targeted Anthropic Claude's workspace directory at /mnt/user-data/ — the location where Claude stores uploads and outputs — recursively exfiltrating all files to a threat actor-controlled GitHub repo. The convergence: AI tools create persistent, identifiable, high-density data stores (uploaded documents, conversation outputs, processed files) in known filesystem paths. As AI adoption deepens among power users, these workspace directories become a predictable and high-value target for credential and data theft — a risk category not yet covered by traditional DLP or endpoint controls designed before agentic AI workloads existed.
