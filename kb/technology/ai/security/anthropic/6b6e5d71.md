# Anthropic's Project Glasswing (Claude Mythos) found 10,000+ high-severity vulnerabilities

Anthropic revealed that Project Glasswing (using Claude Mythos AI) has uncovered more than 10,000 high- or critical-severity vulnerabilities across systemically important open-source software since the initiative launched last month. Of these: 6,202 are high/critical across 1,000+ open-source projects; 1,726 are confirmed true positives; 1,094 are high/critical-severity; 97 have been patched upstream; 88 advisories issued.
