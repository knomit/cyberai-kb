# Microsoft Entra ID 'Agent ID Administrator' role enables privilege escalation and identity takeover

An administrative role in Microsoft Entra ID designed for AI agents — 'Agent ID Administrator' — could enable privilege escalation and identity takeover attacks, according to Silverfort researchers. The role grants excessive permissions that can be abused to take over service principals. This highlights a new attack surface: AI agent identity roles in enterprise identity platforms are being created faster than their security implications are understood.
