# SAP npm packages compromised in credential-stealing supply chain attack

SAP-related npm packages were compromised in a supply chain attack campaign designed to steal credentials. Flagged by Aikido Security, Onapsis, and OX Security. Attackers embedded credential-stealing malware in widely used SAP ecosystem npm packages, targeting enterprise developers and SAP administrators.
