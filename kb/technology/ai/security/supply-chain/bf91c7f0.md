# DPRK AI-assisted npm malware: Claude Opus used to insert malicious package as dependency

Cybersecurity researchers discovered a new wave of DPRK attacks using AI-inserted npm malware, fake firms, and RATs. A malicious npm package was inserted as a dependency into a project by Anthropic's Claude Opus LLM. The package '@val...' contained malicious code. This represents a novel attack vector: using AI coding tools to unknowingly introduce malicious dependencies, shifting the trust model for AI-assisted development. Raises significant questions about AI code assistants as supply chain risk amplifiers.
