# LLMs are becoming both offensive and defensive tools in software/cryptographic security

Two mid-2026 results (The Batch issue-365) show LLMs cutting both ways in security. Offensively/defensively for discovery: Anthropic's Claude Mythos Preview, under human steering in a multi-agent harness, found a genuine weakness in the HAWK post-quantum signature scheme (lowering HAWK-512 key-recovery cost from 2^150 to <=2^108, though still infeasible absolutely), leading its designers to withdraw it from NIST's competition; the AES result applied only to a weakened 7-round variant, not production AES-128. For prevention: Stanford's SecureForge automatically optimizes an LLM's developer system prompt (via MITRE CWE + Semgrep + the GEPA genetic algorithm) to cut insecure-code generation from ~20.1% to ~11.8% on average. CAVEATS preserved: the crypto attack used no fundamentally new math and cost ~60 hours/~$100K; SecureForge only guards known vulnerability classes via the developer system prompt, so unknown-class coverage is unproven. Both remain narrow, evidenced results — not general claims that LLMs 'solve' security.
