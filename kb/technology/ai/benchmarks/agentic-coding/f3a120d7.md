# New agentic SWE benchmarks: DeepSWE, ProgramBench, ITBench-AA

Three new benchmarks are emerging to replace the saturated SWE-bench family for agentic software-engineering evaluation. DeepSWE (by Datacurve) tests feature implementation with 113 human-vetted problems in 5 languages drawn from private code bases to avoid contamination, requiring ~5.5x more lines of code than SWE-Bench Pro; GPT-5.5 (xhigh reasoning) leads at 70%, Claude Opus 4.8 at 58%, Gemini 3 Flash at 5%. Artificial Analysis replaced SWE-Bench Pro with DeepSWE in its indices. ProgramBench (Meta, Stanford, Harvard) tests turning 200 ideas into functional programs without human oversight; no model passes all tests, and at the 95% bar Claude Opus 4.7 reproduced only 3%. ITBench-AA (IBM + Artificial Analysis) tests root-cause diagnosis across 59 human-written real-world incidents; Claude Opus 4.7 (max reasoning) led with 46.7% full recall, GPT-5.5 at 45.8%.
