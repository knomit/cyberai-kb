# Epoch AI and METR release MirrorCode long-horizon coding benchmark

Epoch AI and METR released MirrorCode, a benchmark measuring how well AI systems reimplement software programs from CLI (input-output) access alone, without source code or web access. Claude Opus 4.7 solved one task in 14 hours for $251 of inference that Epoch/METR estimate would take a human 2-17 weeks. Leading models from a year earlier scored ~30%. Across 25 target programs, 17/25 had at least one perfect-scoring run and 4 more scored >99%; 8/25 were never solved to 100%. The hardest target was 'ruff', a Python linter/formatter. The release includes a scaffold and 22 of 25 target programs (132 task instances across six languages).
