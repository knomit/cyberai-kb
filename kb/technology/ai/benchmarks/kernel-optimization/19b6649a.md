# Fable wrote the first genuine megakernel submitted to KernelBench-Mega

Import AI 464 (2026-07-06) reports that Fable produced what a KernelBench-Mega maintainer and the official leaderboard describe as the first genuine — and fastest — megakernel submitted to the benchmark. Fable achieved an 18.71x speedup writing CUDA on an RTX PRO 6000 Blackwell versus an optimized PyTorch baseline. Comparison points: Claude Opus 4.8 14.4x (Triton), GLM-5.2 11.14x (Triton), GPT-5.5 4.34x (Triton). Notably, torch.profiler showed exactly ONE cooperative kernel launch per decoded token, whereas every other high-scoring entry decomposed the problem into 4–14 separate kernel launches per token. Significance framing: autonomous kernel design is a fundamental input task for AI R&D, so KernelBench-Mega is a signal of progress toward recursive self-improvement.
