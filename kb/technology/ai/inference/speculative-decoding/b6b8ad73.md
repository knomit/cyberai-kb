# Speculative decoding: free compute at small batch, wasteful at high throughput

A small draft model proposes a token sequence and the big model verifies it in one parallel forward pass, accepting tokens it would have generated. When batch size is smaller than the optimal token count, this uses 'free' compute to finish sequences faster; at high throughput it can waste compute that could be used moving memory.
