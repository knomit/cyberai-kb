# Nvidia's NeMo Switchyard cut agentic task cost to a third by routing steps across models

Nvidia released Nemotron 3.5 Lightning (Artificial Analysis measured ~302 output tokens/second across providers with 7.5s time to first token; Nvidia claims up to 4x faster output than class peers and 30% faster agentic task completion). Alongside it Nvidia released NeMo Switchyard, an open-source routing library that sends each step of an agentic workflow to whichever available model best fits that step's speed, quality, or cost needs. Nvidia reports routing through Switchyard cut task-completion cost to about one third of running every step on Claude Opus 4.8 alone.
