# llm-d: Kubernetes-native distributed LLM inference stack

llm-d is a Kubernetes-native stack for distributed LLM inference that runs vLLM, SGLang and others across clusters, with tested deployment recipes for production patterns, supporting GPUs, TPUs, XPUs, CPUs and emerging NPUs.
