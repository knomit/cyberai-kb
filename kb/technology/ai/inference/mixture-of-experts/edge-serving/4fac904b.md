# FreeToken serves 20+ MoE models on consumer hardware, including a 753B GLM model on one workstation GPU

FreeToken is an edge-native mixture-of-experts serving system that continuously remaps experts, model state, CPU/GPU work, and agent state reuse to the bandwidth and memory actually available on a personal machine. The authors report support for more than 20 MoE models, ranging from 35B-parameter models on an 8GB laptop GPU up to a 753B-parameter GLM model on a single workstation GPU.
