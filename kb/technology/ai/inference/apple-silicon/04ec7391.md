# Perplexity published an Apple-silicon on-device inference engine writeup ('Lily')

A post on Perplexity's blog hub describes an inference engine referred to as Lily that optimizes on-device LLM inference for Apple silicon, exploiting unified memory and specialized hardware to outperform MLX-LM on prefill and decode throughput.
