# Model values differ across Claude versions, which may propagate into generated art

The Deep View reports that an Anthropic study found Claude's expressed values vary by model version and generation, with some versions leaning more toward warmth and others more toward rigor. The newsletter's inference is that such value differences are not neutral for generative art: a 'warmer' model rendering a mother-and-child prompt would add nurturing sweetness, while a more literal model would produce a flatter, more generic depiction — meaning aesthetic and emotional content can be an artifact of model selection rather than authorial intent. NOTE: the newsletter did not link the underlying Anthropic report, so the specific finding is unverified against a primary source.
