# camelAI migrated its agent to a Cloudflare Durable Object and open-sourced its codebase

camelAI moved its agent off virtual machines onto a Cloudflare Durable Object, with a file system living in SQLite and R2, and having the agent write JavaScript instead of bash. The team cited the cost of giving every user an always-on machine with attached disk as the reason for moving off VMs. camelAI's codebase was recently open-sourced.
