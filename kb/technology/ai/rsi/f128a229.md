# 2026 pattern: automated AI R&D and RSI via optimization harnesses outside the base LLM

By mid-2026 multiple teams pursued improving AI capability through optimization/agent harnesses that sit OUTSIDE a frozen base LLM rather than retraining the base model. Poetiq (ex-DeepMind founders Ian Fischer and Shumeet Baluja) builds 'self-optimizing optimizers' — harnesses that improve themselves on narrowly-scoped tasks — and kept the RSI tech internal-only citing danger. Intology's 'Locus' turns LLMs into autonomous ML researchers and set a PostTrainBench SOTA (44.7% with Opus 5 vs 34.1% bare), beating the human baseline on PostTrainBench+ (51.6% with >4000 H100 hours). Both illustrate that large capability gains on AI-R&D tasks can come from better external harnesses/tooling around existing models, not only from bigger base models. Note the differing scopes: Poetiq's claim is about a private RSI product and benchmarking tool (Augur); Intology's is a specific externally-verified benchmark result.
