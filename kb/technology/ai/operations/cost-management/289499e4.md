# Token reduction tools do not reliably reduce AI costs

PointFive ran the same prompt across 2,908 Claude Code sessions with and without token-reduction tooling and found that in some cases token compression increased costs by nearly 50%, undermining the common vendor claim that cutting tokens cuts spend.
