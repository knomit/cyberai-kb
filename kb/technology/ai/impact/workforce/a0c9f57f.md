# Andrew Ng: Coding agents accelerate software work unevenly — frontend most, research least (April 2026)

Andrew Ng's DeepLearning.AI letter (April 24, 2026) on coding agent impact hierarchy: frontend > backend > infrastructure > research. (1) Frontend (most accelerated): agents fluent in TypeScript/JavaScript/React/Angular; browser-based feedback loop lets agents close-iterate on implementations; dramatic speed-up even without polished design skills; (2) Backend (less): requires more human steering for corner cases, security flaws, subtle bugs; backend bugs have non-intuitive downstream effects (e.g., corrupted database); skilled developers still significantly outperform inexperienced coding-agent users; (3) Infrastructure (much less): LLM knowledge limited re: infrastructure tradeoffs; agents can help with testing/experimentation but not critical infra decisions; finding infra bugs requires deep expertise; (4) Research (least): non-coding work dominates (hypothesis formation, experiment interpretation); coding agents speed up code writing and experiment orchestration but not the research itself. Practical implication: Ng now asks frontend teams to ship dramatically faster than a year ago, but expectations for research teams are largely unchanged.
