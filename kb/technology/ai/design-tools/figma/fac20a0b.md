# Figma Config 2026 adds AI and team collaboration tools

At Figma Config 2026 in San Francisco, Figma (CEO Dylan Field) released tools to build a full-stack design platform: Code Layers (work with repositories and sync design and production code), Motion and Shader tools (animations and 3D effects), Figma Weave (bringing 20+ AI tools into Figma as reusable building blocks), and agent skills to automate repetitive tasks.
