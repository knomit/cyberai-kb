# Google's ToolGrad generates tool-use training data answer-first, letting a 12B model match Gemini 2.5 Pro on BFCL

ToolGrad (Google, presented at ACL 2026) inverts the standard tool-use dataset pipeline: instead of inventing a user query and running a depth-first-search agent to find a working API path, it first constructs a verified API workflow, then writes the matching user query and response in a single LLM step. It adapts TextGrad's 'textual gradients' to dataset generation via four modules — API Proposer, parallel API Executors, API Selector (the gradient signal), and LLM Updater. Using ToolBench's 16k+ real-world APIs it achieves almost a 100% data-generation pass rate at lower cost with longer-horizon chains. Gemma-3 models fine-tuned on just 500 generated examples (ToolGrad-500) improved at every size; ToolGrad-12B scored 83.1 on the Berkeley Function Calling Leaderboard, versus gemini-2.5-pro 83.2, claude-4.5 Opus 82.8 and gpt-5 74.4 — and beat its own teacher model, gemini-2.5-flash-lite, which generated the data.
