# Miles v0.1 is an open system from LMSYS for production-scale RL post-training of agents

Miles v0.1, released by LMSYS on Aug 18, 2026, is an open system for improving AI agents via reinforcement learning after initial training. It packages rollout, sandboxing, asynchronous training, replay, model-update, and multi-hardware components so many agent copies can attempt tasks in isolated environments, be scored, feed results back into training, and receive updated weights without stopping the pipeline.
