# DAPO is a fully open-sourced large-scale LLM RL system reaching 50 points on AIME 2024 from Qwen2.5-32B base

DAPO is a system for large-scale reinforcement learning on LLMs, developed by ByteDance Seed and Tsinghua SIA. It reports 50 points on AIME 2024 starting from the Qwen2.5-32B BASE model (not an instruct or already-RL-tuned checkpoint), and is fully open-sourced including algorithm details, dataset, and infrastructure. The full-stack release — algorithm AND dataset AND infrastructure together — is what makes the result reproducible; an RL result released with only one of the three is not comparable to this.
