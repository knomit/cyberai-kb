# Perplexity trains its Computer agent on real sessions via rejection-sampling fine-tuning plus hint-guided self-distillation

Perplexity described combining rejection sampling fine-tuning (learning from successful sessions) with hint-guided self-distillation (learning from user-corrected failures) so its Computer model learns from real-world tool use.
