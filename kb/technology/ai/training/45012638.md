# Small amounts of verifiable, machine-readable scaffolding let agents exceed strong baselines — with a ceiling set by the scaffolding's source

Two independent August 2026 systems share an architectural pattern: rather than scaling the model, they package a modest amount of structured, EXECUTABLE, verifiable scaffolding that a coding or reasoning agent can read, invoke, and compose, and this alone moves the agent past strong expert baselines.

INSTANCES:
- Hawkeye (kb/technology/ai/systems/gpu-kernel-optimization/e16b230e.md) packages hardware knowledge as a taxonomy of unit tests, each pairing a HUMAN-AUTHORED solution kernel with the profiling metric that verifies the optimization, wrapped as a callable function with a short usage guide. SCOPE QUALIFIERS carried from the source: evaluated specifically on porting PyTorch workloads across NVIDIA Ampere, Hopper, Blackwell and AMD MI350, across BF16, FP8, NVFP4, MXFP4. On ESTABLISHED workloads it matches or exceeds torch.compile in both BF16 and low precision, including formats PyTorch cannot natively run — 'matches or exceeds', not uniformly beats. The headline 18.9x geomean speedup applies specifically to EMERGING attention variants versus expert-authored Triton kernels from the Flash Linear Attention library; on Linear Attention it reaches 1.22x on Blackwell and 1.00x on MI350, i.e. parity on MI350.
- SPADE (kb/technology/ai/training/synthetic-data-and-environments/b478d58d.md) has an LLM alternate between an Environment Designer writing long-horizon training environments as executable Python with a Gym-style interface, and a Reasoning Agent trained in them, with the Designer rewarded by 'hint-based regret' — the gap in agent return with versus without a privileged hint. SCOPE QUALIFIERS carried from the source: tested on three Qwen3 backbones tuned via GRPO for 400 rollouts of 25 environments; the +8.1-over-base and +5.3-over-strongest-fixed-environment-baseline figures are specifically the 30B-A3B game-suite average of 58.3.

THE COMMON MECHANISM: both convert domain knowledge into artifacts that EXECUTE and therefore VERIFY — a unit test with a profiling metric, an environment with a computable return. Verifiability is what lets test-time compute or RL scale against them; Hawkeye's authors note scaling test-time compute with it produces the most performant kernels.

THE SHARED CEILING — do not drop this: SPADE's authors state explicitly that the method cannot bootstrap models substantially beyond the imaginative capabilities of the base model used for environment generation. Hawkeye's scaffolding is likewise human-authored. So the pattern is elicitation and transfer of existing knowledge into a form agents can exploit, NOT open-ended self-improvement.

WHAT THIS DOES NOT MEAN: it does not mean scaffolding substitutes for model capability in general, and it does not mean these gains generalize outside the evaluated hardware, precisions, backbones, and task suites listed above. Both original facts are retained in full alongside this synthesis.
