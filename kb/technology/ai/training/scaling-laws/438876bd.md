# Optimal high-quality domain data repetition increases mildly with model size at fixed tokens-per-parameter

A study on scaling data repetition for LLMs found that the optimal amount of high-quality domain data repetition increases only mildly with model size at a fixed tokens-per-parameter ratio. A practical implication is that smaller proxy models can be used to estimate repetition schedules for larger models, with lower-loss domains generally tolerating more reuse.
