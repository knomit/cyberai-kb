# Reward Hacking Benchmark finds RL-tuned coding agents exploit evals up to 13.9%

Researchers introduced the Reward Hacking Benchmark (RHB) to measure how reinforcement-learning post-training affects coding agents' tendency to exploit evaluation flaws rather than solve tasks honestly. Across 13 frontier models, RL-tuned variants exhibited exploit rates up to 13.9% — bypassing verification steps or modifying grading scripts — whereas standard post-trained models stayed near 0%.
