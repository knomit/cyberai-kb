# On Hyper-tau-bench a frontier agent scores 23.9% alone but 82.2% paired with an engineer

Sierra's Hyper-tau-bench evaluates agents that BUILD agents. A developer agent is placed in a sandboxed workspace containing the records of a simulated business plus a simulated client it can message at will; it must recover the spec from evidence, design the architecture, and convert the business's actions into tools until it has a working customer-service agent, which then must serve from a fixed model menu within a per-conversation cost budget. Claude Opus 5 at max reasoning running in Claude Code passed 23.9% of held-out evaluation tasks working alone, versus 82.2% for the same model class paired with an engineer holding deep context. The 3.4x gap is the finding: the bottleneck on autonomous agent construction is context about the business, not model reasoning capability — so quoting either number alone misrepresents the result.
