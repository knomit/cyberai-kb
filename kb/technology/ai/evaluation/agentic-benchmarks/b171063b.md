# Agents building agents perform 3.4x better with an in-context engineer

On Sierra's Hyper-tau-bench, which evaluates agents that build agents, Claude Opus 5 at max reasoning running in Claude Code alone passed 23.9% of held-out tasks, versus 82.2% when paired with an engineer who had deep context. The gap is a measure of how much of agent-building performance is currently supplied by human context rather than model capability.
