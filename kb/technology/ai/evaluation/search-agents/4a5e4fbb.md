# Exa ATLAS benchmark: search agents miss significant golden answers

ATLAS is a benchmark for search agents on real-world, non-memorized, multi-domain web search tasks with a cost-effective grading process. Even high-effort agents miss significant golden answers, indicating large room for improvement.
