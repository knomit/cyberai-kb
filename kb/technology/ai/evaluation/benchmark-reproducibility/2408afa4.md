# A shared benchmark name identifies a dataset family, not a measurement procedure

A September 2026 analysis ('The two MMLU scores') demonstrates that two evaluation runs sharing the same provider, model family, metric identifier, unit AND benchmark name can still produce different scores. The divergence comes from runners, graders and dataset splits — components the benchmark label does not pin down. The operational rule: an 'mmlu' label identifies a dataset family only, so comparing two reported MMLU numbers from different sources is invalid unless the harness, grader and split are also matched. This generalizes beyond MMLU and is the same failure mode behind the GPT-6 Astra ARC-AGI-3 62.7%-vs-99.9% harness discrepancy.
