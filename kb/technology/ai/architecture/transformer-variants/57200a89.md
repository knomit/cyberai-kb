# GPT-6 Astra's looped transformer trades memory footprint for inference cost

Sebastian Raschka's 2026-09 analysis describes OpenAI's GPT-6 Astra as a looped transformer: it reuses the same transformer-block layers multiple times, increasing effective depth and capacity without adding parameters. The trade-off is that storage and RAM needed to host the model stay flat while inference cost rises, because each embedded token must traverse more layer passes. Raschka's explicit caveat: the looping is a small architectural tweak and is NOT the reason Astra performs well — attributing Astra's quality to looped layers is the foreseeable misreading.
