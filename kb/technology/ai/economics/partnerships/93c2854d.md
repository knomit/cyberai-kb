# OpenAI-Microsoft partnership amended: non-exclusive cloud deal, AGI clause removed

OpenAI and Microsoft amended their partnership agreement, granting OpenAI greater independence. Key changes: (1) OpenAI can now offer products on any cloud provider — Microsoft remains primary partner and products ship first on Azure unless Microsoft declines; (2) Microsoft's IP license for OpenAI models/products is now non-exclusive through 2032; (3) Microsoft no longer pays OpenAI a revenue share, while OpenAI continues paying Microsoft at the same percentage through 2030 subject to a total cap; (4) AGI clause removed — previously Microsoft retained exclusivity until OpenAI created AGI, verified by an independent expert panel. OpenAI revenue chief Denise Dresser cited in an internal memo that the Microsoft partnership 'limited our ability to meet enterprises where they are' including on AWS Bedrock. Clears path for IPO by demonstrating diversified revenue.
