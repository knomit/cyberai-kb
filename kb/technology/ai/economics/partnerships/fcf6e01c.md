# OpenAI models now available on AWS Bedrock

Amazon and OpenAI struck a deal making OpenAI models available via AWS Bedrock. This follows the OpenAI-Microsoft partnership amendment that made the Azure relationship non-exclusive. OpenAI can now distribute through multiple cloud providers simultaneously.
