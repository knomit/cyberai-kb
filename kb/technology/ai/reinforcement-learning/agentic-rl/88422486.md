# Agent Lightning v1.0 improves Qwen3.5-9B on SWE-bench Verified by 14.6 points with 6K examples

Agent Lightning v1.0 is a lightweight framework for harnessed agentic reinforcement learning, implemented in about 3,500 lines of code. It focuses on integrating arbitrary agent harnesses, enabling exploration of challenges such as retokenization and training stability. Evaluated on various agent tasks, it improved Qwen3.5-9B's performance on SWE-bench Verified by 14.6 points using just 6,000 training examples.
