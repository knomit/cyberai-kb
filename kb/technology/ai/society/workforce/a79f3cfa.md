# MCP Security State of Agentic Integrations Survey: 70% Credential Leak Concerns, 56% Enterprise Search Gaps

Survey of hundreds of AI leaders building agentic integrations (Merge, March 2026): 70% worry about credential leaks and malicious MCP servers. 56% say MCP doesn't support enterprise search well. 51% report ambiguous tool definitions causing incorrect tool calls. Most teams building AI agents plan to adopt MCP in 2026, but serious security concerns remain. This extends the existing MCP adoption picture: within-ecosystem adoption is strong (Cursor, Pigment, Claude Code, Google Stitch, Mistral Forge) but enterprise security readiness for MCP is not yet there.
