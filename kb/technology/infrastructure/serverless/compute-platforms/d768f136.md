# Vercel Fluid is a unified compute layer absorbing burst capacity above a trillion requests per month

Vercel described Fluid, a unified compute layer that dynamically configures infrastructure per workload and absorbs burst capacity. Vercel says it already powers builds, sandboxes and functions at volumes exceeding one trillion requests per month.
