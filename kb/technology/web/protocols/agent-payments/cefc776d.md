# x402 protocol lets a website price page access per-crawl and collect payment from AI agents

A developer documented setting a per-page price (one cent) for AI agent access to their website using the x402 protocol, which advertises a price before an agent reads the page; if the agent wants access, it pays. The developer reported that testing showed the mechanism works end to end — including Claude paying — but that no real payments had been received yet. The relevance is to content owners too small to negotiate direct licensing deals with AI companies: x402 offers a machine-negotiated alternative to bilateral licensing.
