# Google launches Pixel 11 with agentic AI features, reframes Android as an 'intelligence system'

At its Made by Google event in New York, Google unveiled the Pixel 11 family, positioning it as an AI-first smartphone. Standout AI features: a Rambler voice keyboard built into Gboard for fast dictation; a Magic Capture photo mode (a third capture mode that records a scene and auto-produces high-resolution stills, useful for freezing motion); and multi-step agentic tasks executed in a sandboxed environment that prompts the user for approval before final actions like purchases, messages, or calendar events. Executives framed Android as 'no longer an operating system' but an 'intelligence system that gets things done for you.'
