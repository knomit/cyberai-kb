# Nvidia RTX Spark brings 1-petaflop local AI hardware to Windows PCs

At IFA 2026 on Thursday 2026-09-03, Nvidia unveiled RTX Spark, arriving in October 2026 in Windows PCs from Lenovo and Acer. Specs: a 1 petaflop RTX Blackwell GPU, up to 128GB unified memory, and a 20-core Grace CPU, which Nvidia says lets Windows PCs run always-on AI agents locally. Nvidia also simplified local model setup for three agent apps: Perplexity Portable Computer (RTX GPUs with at least 24GB VRAM, Linux or Windows), Hermes Agent (one-click local model setup across RTX and DGX on Windows and Linux, coming soon), and OpenClaw (Nvidia worked with Microsoft so the OpenClaw Windows app configures an optimized local model on any RTX GPU with at least 24GB VRAM). The strategic read is that Mac had been the default platform for local AI — evidenced by Mac mini and Mac Studio shortages and AI features shipping on Mac first — and RTX Spark gives users an alternative outside Apple's ecosystem. The petaflop figure is Nvidia's spec sheet, not a measured inference throughput on any particular model.
