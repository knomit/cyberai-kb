# Systolic arrays handle over 95% of modern AI-chip compute

Systolic arrays account for more than 95% of compute on modern AI chips. They work by moving matrix data locally between processing elements, which reduces memory traffic. Larger arrays improve peak throughput but are harder to saturate, so compiler scheduling often determines whether a chip reaches useful utilization in practice.
