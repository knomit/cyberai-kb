# Nvidia RTX Spark PCs bring petaflop-class local AI to Windows

Nvidia unveiled RTX Spark PCs from Lenovo and Acer, arriving October 2026, pairing a 1-petaflop RTX Blackwell GPU with 128GB unified memory and a 20-core Grace CPU to run local AI agents on Windows. Nvidia also released the free open-source NVIDIA Personal AI Router (PAIR) to coordinate local AI workloads across household PCs.
