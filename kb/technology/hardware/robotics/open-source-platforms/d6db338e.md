# Hugging Face released Microduck, a $399 open-source RL robot

In August 2026 Hugging Face unveiled Microduck, a $399 open-source robot that learns new behaviors via reinforcement learning. Its form factor resembles Nvidia's "Blue" research robot (itself inspired by Star Wars' BD-1), and it strengthens Hugging Face's robotics position alongside Nvidia's Jetson, Isaac, and Omniverse stack.
