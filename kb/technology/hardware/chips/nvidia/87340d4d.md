# Nvidia unveils Vera CPU for agentic AI at Computex 2026

At Computex 2026 (announced June 1, 2026), Nvidia positioned itself as a full-stack AI company. Its new Vera CPU is purpose-built for agentic workloads (tool use, code writing, data processing) and claimed to complete these tasks 1.8x faster than traditional x86 CPUs; early customers include OpenAI, Anthropic, CoreWeave, Lambda, Dell, HPE, and Lenovo. Nvidia also launched the DSX software platform for AI factories (DSX MaxLPS for power/cooling efficiency, DSX OS), a DGX Station for Windows able to run models up to 1 trillion parameters locally, Cosmos 3 world model, and reported Vera Rubin reaching full production with ~10x higher agent throughput than Grace Blackwell.
