# 404 Media reported OpenAI staff read user ChatGPT conversations to train models

404 Media published reporting on an effort it calls Project Lily, in which OpenAI workers read users' ChatGPT conversations as part of model training. The claim is about human review of real user chat content, which bears on privacy expectations for consumer chatbot use — users who assume their conversations are seen only by a model may be mistaken.
