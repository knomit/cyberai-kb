# Cisco Model Provenance Kit: open-source AI model origin verification tool

Cisco released Model Provenance Kit, an open-source tool to verify the origin of third-party AI models. Uses both metadata and learned model parameters (described as a 'unique genome') to assess whether models share a common origin and identify signs of modification. Addresses the risk of tampered or counterfeit AI models being deployed in production. Cisco: 'Much like a DNA test reveals biological origins, the Model Provenance Kit examines... the actual learned parameters of a model.'
