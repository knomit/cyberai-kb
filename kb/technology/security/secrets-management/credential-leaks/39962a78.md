# Truffle Security found 768 leaked corporate AWS keys with full admin rights, most never rotated

Truffle Security verified 64,024 unique AWS key pairs across 431,875 public findings spanning git history, Hugging Face datasets, Docker images, package registries, and CI logs, surfacing publicly between August 2022 and August 2026. Of these, 10,616 came with complete credentials. Per Truffle Security, 88% still authenticate, and 768 of the live ones belong to a company and carry full control of its AWS account — 526 root keys plus 242 IAM users holding AdministratorAccess. The median live leaked key is five years old and has never been rotated.
