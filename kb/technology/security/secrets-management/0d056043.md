# Leaked API keys function as durable, unrotated, full-privilege access — not as passwords

Two August 2026 findings independently show that the practical risk of a leaked programmatic credential is not 'someone can log in' but 'someone holds standing, full-privilege, money-moving or infrastructure-controlling access that nobody revokes'.

EVIDENCE:
- Stripe merchant keys (kb/technology/security/data-breaches/api-key-leaks/4e82e587.md): a dataset published on a data-trading forum on AUGUST 18, 2026 contained live Stripe API keys for 659 merchant accounts plus roughly 35 GB of customer and payment data pulled from them. Ransomnews's framing is the key point: a Stripe secret key is NOT a dashboard password but full programmatic access — read every customer record, create charges, issue refunds, and change where payouts are sent. SCOPE QUALIFIER: the claim that 519 of the accounts could both take money in and move it out rests on THE COLLECTOR'S OWN RECORD, not independent verification.
- Leaked AWS keys (kb/technology/security/secrets-management/credential-leaks/39962a78.md): Truffle Security verified 64,024 unique AWS key pairs across 431,875 public findings spanning git history, Hugging Face datasets, Docker images, package registries, and CI logs, surfacing publicly between August 2022 and August 2026. Of these, 10,616 came with COMPLETE credentials; 88% still authenticate. SCOPE QUALIFIER: the 768 figure is specifically the subset of LIVE keys that belong to a company AND carry full control of its AWS account — 526 root keys plus 242 IAM users holding AdministratorAccess — not 768 out of all 64,024. The median live leaked key is five years old and has never been rotated.

THE COMMON MECHANISM: (1) the credential grants programmatic, often administrative, capability rather than session access; (2) it leaks through channels outside the security perimeter — public repos, forums, build artifacts, datasets, CI logs; (3) nothing expires it, so exposure persists for years. Truffle's five-year median age and 88% still-authenticating rate quantify the third point directly.

PRACTICAL IMPLICATION: automatic rotation and short credential lifetimes address the durability problem that detection alone does not; scanning finds a key, but only expiry ends the exposure.

WHAT THIS DOES NOT MEAN: neither finding establishes that the leaked credentials were actually abused — both describe exposure and capability, not confirmed fraud or intrusion. Both original facts are retained in full alongside this synthesis.
