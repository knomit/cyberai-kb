# Open-weight GLM 5.3 can turn published Firefox security fixes into exploits before users patch

Per Epoch AI (via TLDR AI 2026-10-30): GLM 5.3 can identify and exploit vulnerabilities in recent Firefox versions using security fixes that are published but not yet shipped to users; widely available open-weight models can do much or all of this autonomously. Open-source projects are especially exposed because patches are public; the threat is expected to worsen as open-weight cyber capability improves.
