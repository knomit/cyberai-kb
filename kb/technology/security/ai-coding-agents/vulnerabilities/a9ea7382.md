# AI security-scanning agents can be tricked into running malicious code

As reported by The Hacker News (Jul 9, 2026), a proof-of-concept showed that AI coding agents asked to scan open-source code for vulnerabilities can be manipulated into executing the attacker's code on the reviewer's own machine instead of merely analyzing it.
