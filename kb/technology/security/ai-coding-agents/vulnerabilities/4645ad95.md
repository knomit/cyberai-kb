# Wiz 'GhostApproval' symlink flaws in six AI coding assistants

As reported by The Hacker News (Jul 9, 2026), Wiz researchers found 'GhostApproval' symlink-related flaws affecting six popular AI coding assistants. A booby-trapped repository can get the assistant to request permission to edit a harmless-looking file while a symlink causes code to execute, quietly taking control of a developer's computer.
