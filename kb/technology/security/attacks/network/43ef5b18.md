# NatJack: new attack class hijacks TCP sessions and spoofs DNS via NAT manipulation

Security researcher Malcolm Stagg disclosed a new attack class called NatJack that manipulates network address translation (NAT) connection state to hijack active TCP sessions and spoof DNS responses. Reported August 2026.
