# Malware can abuse Windows Hello for Business keys for persistent Entra ID access

Entra ID researcher Dirk-jan Mollema demonstrated that malware already running in a signed-in Windows session can silently use the victim's Windows Hello for Business key to authenticate to Microsoft Entra ID, granting persistent access. Reported by The Hacker News, Aug 7, 2026.
