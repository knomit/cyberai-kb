# REF8801: fake Web3 'Apex Accelerator' spreads malware via npm and hijacks AI agent traffic

Elastic Security Labs tracks REF8801, a fake Web3 VC accelerator (Apex Accelerator) using malicious npm packages for Windows and macOS, luring victims with free Claude/Gemini credits, coding tools and security audits. It delivered infostealers/backdoors, repackaged a legitimate coding agent to route model requests via attacker services, and produced fabricated audit findings.
