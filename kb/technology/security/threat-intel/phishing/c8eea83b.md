# Microsoft dismantles Yam Store (Storm-3119) phishing-kit marketplace: 1B+ messages, 75,000+ orgs

Microsoft took down Yam Store (aka Storm-3119), which sold phishing kits CoGUI, Haozi and Iron Man System tied to over 1 billion malicious messages to 75,000+ organizations. Kits featured geofencing, fake CAPTCHA gates and IP block/allowlists; Yam Store also acted as an initial access broker.
