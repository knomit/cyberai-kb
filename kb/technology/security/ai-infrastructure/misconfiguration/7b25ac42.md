# Wiz found 294 of 3,074 internet-facing LiteLLM gateways accepted the documentation's example admin key sk-1234

LiteLLM is an open-source AI gateway that sits between a company's applications and the model providers it pays for; its master key is the gateway's administrator credential, and anyone holding it can read every model provider API key stored on the server. Wiz Research scanned internet-facing LiteLLM servers in February 2026 and found that 294 of 3,074 gateways - nearly one in ten - accepted sk-1234, the example key printed in LiteLLM's own setup guide. In 191 of those 294 no key was set at all, so they would have accepted any value. In Wiz's tests, holding the admin key also reached the cloud IAM credentials of the machine the gateway ran on, turning an AI-gateway exposure into cloud account compromise. As of September 9, 2026 LiteLLM's setup guide still used sk-1234 as its example, above a comment telling operators to replace it with a long random value before any real use.
