# Kali365 phishing kit weaponizes Microsoft device-code authentication

The Kali365 phishing kit targets US organizations by abusing legitimate Microsoft authentication: it uses attacker-controlled device codes that victims approve on Microsoft's real authentication page, turning a legitimate Microsoft login into a gateway to corporate data.
