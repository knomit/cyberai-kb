# Apple iCloud Private Relay can leak real IP via WebKit proxy bypasses

Researchers Talal Haj Bakry and Tommy Mysk disclosed that Apple's iCloud Private Relay can expose a user's real IP address. Private Relay (introduced with iOS 15, part of iCloud+) uses a dual-hop architecture routing Safari traffic through two relays. The leak stems from three WebKit features: DNS prefetching, WebAuthn Related Origin Requests, and WebTransport. Because WebKit is the mandatory browser engine for Safari and all third-party iOS/iPadOS browsers (Chrome, Edge, Firefox, Brave, etc.), the bypass affects those browsers too.
