# OpenAI Codex memories reported to exfiltrate local-provider chat content

A public issue filed against OpenAI Codex reports that its 'memories' feature exfiltrates chat content originating from local model providers back to OpenAI without notifying the user — a privacy concern for developers routing work through local models.
