# FROST Attack: SSD Timing Side-Channel Reveals Visited Sites and Open Apps

Researchers demonstrated the FROST attack, a browser-based side-channel that uses JavaScript and SSD access-timing measurements to infer which websites a user has recently visited and which desktop apps are currently open. The attack requires no native code, no browser extension, and no special permissions — a purely web-accessible fingerprinting vector. The technique exploits timing differences in SSD access patterns caused by OS-level caching.
