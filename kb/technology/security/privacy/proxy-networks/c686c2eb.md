# Bright Data SDK turns consumer apps and smart TVs into web-scraping proxy nodes

A researcher reverse-engineered an iOS SDK embedded by Bright Data in free consumer apps, documenting how it turns devices — including always-on smart TVs — into exit nodes that relay web-scraping traffic for a data broker. This quietly conscripts consumer hardware into a residential-proxy network. Reported June 6–8, 2026.
