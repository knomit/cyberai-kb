# METR lost ~$600K in AI credits after an agent dashboard leaked its API key

METR (Model Evaluation and Threat Research), the non-profit that evaluates frontier AI models on long-horizon agentic tasks, disclosed two 2026 security incidents. In March 2026 a researcher's 'vibe-coded' agent orchestration dashboard on a personal EC2 instance had a fail-open authentication bug that silently disabled Google auth, exposing it to the public internet for several days. The attacker prompted the agent directly to reveal its model-provider API key, added an SSH key for persistence, and burned API credits on public models over three weeks — roughly $600,000 worth, though the provider had granted them free. Detection was slow because METR routinely consumes high token volumes and had no spend caps. METR suspects the attacker found the instance by scanning certificate-transparency logs for recently registered sites with LLM/agent keywords, hunting for exposed provider keys.
