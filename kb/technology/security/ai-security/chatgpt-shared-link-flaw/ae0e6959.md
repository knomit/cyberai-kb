# Shared ChatGPT link could run attacker code in victim session (Parameter, fixed by OpenAI)

Security firm Parameter showed a malicious ChatGPT public share link could run attacker code in the logged-in session of anyone who opened it, enabling reading of private conversations. Reported via OpenAI's bug bounty on Oct 18, 2026; fixed eight days later and rated P1. The victim needed no install or sign-in via the attacker: in the most reliable variant they clicked ChatGPT's Preview button once; a later variant auto-opened Preview so opening the link sufficed. Shared links can be delivered by email, chat, support ticket or social post. It is fixed; this does not imply ongoing exposure.
