# GhostSplice splits malicious instructions across MCP channels to defeat coding-assistant guardrails

GhostSplice is an attack technique against AI coding assistants in which a malicious request is fragmented across separate channels — an MCP tool description, a tool result, and a sampling message — each benign in isolation. Because all tool channels, files and user chat pour into a single undifferentiated block of assistant memory with no marking of provenance, the assistant stitches the fragments back into one instruction. ASSET Group describes this as cross-channel trust fragmentation: the attacker never needs any individual piece of content to look dangerous.
