# Infostealer malware is hijacking Claude login sessions to drain usage

Anthropic warned that a bad actor used infostealer malware to hijack Claude login sessions and drain victims' usage allowances — an account-resource-theft pattern analogous to stolen API keys, but operating on browser session credentials rather than issued keys. Reported August 31, 2026.
