# Early Aug 2026: converging attacks on OT/cellular infrastructure and AI agent supply chains

Security disclosures around 2026-08-08 to 08-11 cluster into two converging themes. (1) Operational-technology and cellular/IoT attack surfaces: attackers shut a steam turbine at a Polish CHP plant by pivoting over a misconfigured private APN cellular network (CERT Polska, Dec 2025 incident); researchers showed a malicious SIM card can execute code inside cellular modems in EV chargers, industrial routers and telematics units; and Gunra ransomware breached critical infrastructure via Schneider Electric PowerLogic (CVE-2024-5559) and Fortinet (CVE-2025-24472) flaws. (2) AI-agent supply-chain risk: malicious MCP servers can split instructions across tool descriptions and results to make AI coding agents exfiltrate secrets, and DPRK IT-worker infiltration used AI-processed (Gemini/SynthID) fake identities to gain insider access. The shared lesson is that machine-to-machine trust boundaries — cellular APNs, USB PnP, MCP tool channels, hiring pipelines — are increasingly the exploited perimeter.
