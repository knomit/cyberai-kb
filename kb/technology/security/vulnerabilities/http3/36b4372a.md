# FoxIO QPACK flaws: unauthenticated HTTP/3 DoS with up to 4,000x memory amplification

FoxIO disclosed QPACK (HTTP/3 header compression) flaws that let an unauthenticated remote attacker crash many HTTP/3 servers over a single connection via headers that expand to thousands of times their size (up to 4,000-fold) in memory; denial of service only, no evidence of code execution or data theft, no known attacks in the wild. FoxIO found the same flaw class in 7 of 10 HTTP/3 stacks tested. Fixes exist for quic-go, Cloudflare quiche, lsquic and Wireshark; Bun, the h3 Rust library and aioquic were unpatched at disclosure. PoC code is public.
