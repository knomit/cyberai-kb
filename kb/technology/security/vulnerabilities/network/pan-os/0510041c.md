# PAN-OS CVE-2026-0322 authenticated management-interface RCE under active exploitation

Palo Alto Networks patched CVE-2026-0322 (CVSS 8.6) on 2026-10-14, a remote code execution flaw in the PAN-OS management interface that lets an authenticated attacker with network access run arbitrary code as root on the firewall. It affects PA-Series and VM-Series firewalls and Panorama (virtual and M-Series); Cloud NGFW and Prisma Access are not affected. No special configuration is needed to exploit it, and it is under active exploitation. Mitigation beyond patching: restrict management-interface access to trusted internal IPs/jump hosts. It does NOT mean unauthenticated internet attackers can exploit it directly; authentication plus network reach to the management interface is required.
