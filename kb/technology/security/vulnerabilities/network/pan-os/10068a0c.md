# CVE-2026-0257: PAN-OS GlobalProtect authentication bypass actively exploited (CVSS 7.8)

Palo Alto Networks confirmed CVE-2026-0257 (CVSS 7.8) is under active exploitation. The vulnerability is an authentication bypass in PAN-OS and Prisma Access that allows threat actors to establish VPN connections. Specifically affects firewalls with GlobalProtect portal or gateway configured when authentication override cookies are enabled and a specific certificate configuration exists. Belgium's CCB also flagged CVE-2026-41089 (Windows Netlogon stack-based buffer overflow, active exploitation, patched in May 2026 Patch Tuesday) during the same period.
