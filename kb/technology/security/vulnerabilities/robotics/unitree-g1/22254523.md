# Unitree G1 EDU humanoid robot: two root RCE chains, one over Bluetooth LE

Security researcher Olivier Laflamme disclosed on August 27, 2026 two independent root remote code execution chains affecting the Unitree G1 EDU humanoid robot, tracked as CVE-2026-76639 and CVE-2026-76640. The first is a network-adjacent path through the chat_go and bashrunner components; the second begins from Bluetooth Low Energy proximity and can reach root on the robot's Locomotion PC. No fixed firmware release has been verified in accessible Unitree guidance, leaving G1 EDU owners without a confirmed remediation target for either vulnerability. Unitree patched the cloud account-to-robot ownership check in July 2026, so as of the August 27 disclosure the cloud-assisted route requires an account already bound to the target G1 or possession of the relevant key material.
