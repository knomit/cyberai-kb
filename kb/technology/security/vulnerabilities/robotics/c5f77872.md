# Reachy Mini robot: five chained vulnerabilities allow root and motor control

JFrog disclosed five chained vulnerabilities in Reachy Mini (Pollen Robotics / Hugging Face open-source robot) allowing attacker code execution, persistent root via passwordless sudo and motor control; a variant works via a malicious web page visited by the operator.
