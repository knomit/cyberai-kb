# Drupal Core SQL injection CVE-2026-9082 under active exploitation

CVE-2026-9082 (CVSS 6.5), a critical SQL injection flaw in Drupal Core, came under active exploitation within days of public disclosure. Imperva observed 15,000+ attack attempts targeting ~6,000 individual sites across 65 countries.
