# Unpatched XRING flaw in XQUIC crashes HTTP/3 servers

Per The Hacker News, a single wrong variable on one line in XQUIC (Alibaba's QUIC and HTTP/3 library), dubbed the XRING flaw, lets any remote client crash the server with a short burst of legitimate traffic. There is no patch. The flaw was reported by a FoxIO researcher.
