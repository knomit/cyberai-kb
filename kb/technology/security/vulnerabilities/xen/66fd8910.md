# Xen XSA-523: grant-copy flaws let a guest VM read/write other VMs' memory incl. dom0

Xen advisory XSA-523 (Nov 3, 2026), CVE-2026-102703 and CVE-2026-102704: two flaws in grant copy let a malicious guest VM read and write memory of other VMs on the host, including dom0. All Xen versions from 4.6 onward are affected (4.5 and earlier are not). Patches are available; no known mitigation. Credited: Anthropic found the flaws using its Claude model; Stephan Lipp of Ada Logics validated; CodeAnt AI independently reported the same issue.
