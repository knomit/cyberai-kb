# Six 'Proto6' vulnerabilities in protobuf.js expose Node.js apps to RCE and DoS

Cyera researchers (Assaf Morag) disclosed six vulnerabilities, codenamed Proto6, in protobuf.js, the JavaScript/TypeScript implementation of Protocol Buffers. A single malicious protobuf schema, descriptor, or crafted payload could trigger crashes, runtime corruption, or code execution, enabling RCE and DoS. Affected: Node.js apps using protobuf.js, Google Cloud client libraries, messaging frameworks like Baileys, and CI/CD pipelines.
