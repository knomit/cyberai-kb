# Claude Dispatch hijack: malicious extension on claude.ai can drive Claude Desktop

Forever Security showed a browser extension able to run scripts on claude.ai could make Claude Desktop execute commands via the Dispatch feature, because Dispatch accepted an ordinary signed-in claude.ai session. Researchers say Anthropic told them Oct 13 Dispatch would be retired by end of October, but the help page did not mention retirement and the flaw was still exploitable at publication. Lesson: agents that run local commands inherit browser-extension risk.
