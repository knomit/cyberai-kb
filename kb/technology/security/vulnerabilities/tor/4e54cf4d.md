# GoBalance flaw lets attackers recover Tor keys and hijack .onion addresses

Searchlight Cyber disclosed (2026-10-08) a GoBalance bug: it passed only the first 32 of a Tor private key's 64 bytes to the signer when signing descriptors, letting anyone derive the secret key controlling a site's .onion address from public information and take over the address (redirecting visitors to an attacker copy). It does not give access to the site's servers, database or user data.
