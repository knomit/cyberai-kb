# cPanel CVE-2026-41940: auth bypass targeting SE Asian governments, Mirai + 'Sorry' ransomware deployed

A critical flaw in cPanel and WebHost Manager (WHM) tracked as CVE-2026-41940 is under active exploitation targeting government/military entities in Southeast Asia and MSPs/hosting providers in the Philippines. Exploitation consequences include: authentication bypass giving remote attackers elevated control, complete website and backup wipe, deployment of Mirai botnet variants, and a ransomware strain called 'Sorry.' Represents targeted weaponization of common web hosting infrastructure.
