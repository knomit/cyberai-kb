# Three Fortinet FortiSandbox flaws exploited in the wild (June 2026)

In mid-June 2026, threat intelligence firm Defused Cyber reported active exploitation of three Fortinet FortiSandbox vulnerabilities, all rated CVSS 9.1: CVE-2026-39813 (path traversal in the FortiSandbox JRPC API allowing authentication bypass via crafted HTTP requests) and CVE-2026-39808 (OS command injection), both patched by Fortinet in April 2026; and CVE-2026-25089 (OS command injection affecting FortiSandbox, FortiSandbox Cloud, and FortiSandbox PaaS web UI), which Fortinet fixed only the week before the report.
