# Cisco patches actively exploited Catalyst SD-WAN Manager flaw CVE-2026-20262

Cisco released updates for CVE-2026-20262 (CVSS 6.5), a medium-severity flaw in the web UI of Cisco Catalyst SD-WAN Manager (formerly SD-WAN vManage) that is under active exploitation. Inadequate validation of user-supplied input during file upload lets an authenticated, remote attacker create or overwrite any file on the underlying OS via crafted HTTP requests, which can be weaponized to escalate to root. Successful exploitation requires the attacker to already hold valid credentials with at least write access.
