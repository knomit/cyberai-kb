# Critical MLflow SSRF and FUXA authentication-bypass flaws under active exploitation

watchTowr and VulnCheck independently reported malicious scanning and exploitation of two critical flaws. CVE-2026-64849 (CVSS 9.3) is an unauthenticated Server-Side Request Forgery in MLflow that lets an attacker who can reach the Tracking Server issue HTTP requests to arbitrary internal cloud metadata endpoints and extract sensitive data, affecting versions below 3.15.0. CVE-2026-25895 (CVSS 9.5) is a missing-authentication plus path-traversal flaw in FUXA, the open-source web-based SCADA/HMI software for OT and industrial automation, allowing an unauthenticated remote attacker to write arbitrary files and achieve remote code execution, affecting versions up to and including 1.2.9.
