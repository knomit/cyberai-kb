# CISA added actively exploited Ray flaw CVE-2025-62593 to KEV catalog

On 2026-08-17 CISA added CVE-2025-62593 (CVSS 9.4) in Ray, the open-source Python-native distributed computing framework for AI/ML workloads, to its Known Exploited Vulnerabilities catalog, citing evidence of active exploitation. The flaw enables remote code execution via web browsers (Firefox, Safari) using a DNS rebinding attack, rooted in the Ray team's longstanding decision not to implement authentication on critical endpoints such as /api/jobs and /api/job_agent/jobs/. A developer running Ray who visits a malicious website or is served a malicious ad can have arbitrary shell code executed; the attack can be extended to network-adjacent Ray instances inside private corporate networks by using the browser as a confused deputy. Fixed in Ray 2.52.0. Oligo researcher Avi Lumelsky and Jonathan Leitschuh were credited. A BitSight report from March 2026 found the RondoDox DDoS botnet incorporated the vulnerability two days before its 2025-11-26 public disclosure. Oligo also reports unpatched Ray instances with NVIDIA GPUs being turned into a self-replicating cryptomining botnet in a campaign dubbed ShadowRay 2.0. FCEB agencies must remediate by 2026-08-20.
