# Mass exploitation of unauthenticated file upload RCE in Super Forms and Elementor Pro

Wordfence reported blocking more than 440,000 exploit attempts against two critical unauthenticated file-upload remote code execution flaws in WordPress plugins, under active exploitation into September 2026. CVE-2026-14894 (CVSS 9.8) is missing file type validation in Super Forms – Drag & Drop Form Builder, affecting all versions through 6.3.313 (roughly 13,000 active installs), letting unauthenticated attackers upload arbitrary files including executable PHP; fixed in 6.3.314. CVE-2026-32475 in Elementor Pro (reported CVSS 9.0–9.8 depending on source, so treat the exact score as unsettled), deployed on more than six million sites, allows the same unauthenticated arbitrary-file-upload-to-RCE path; fixed in 4.2.2. Wordfence counted over 250,000 attempts against CVE-2026-14894 and over 190,000 against CVE-2026-32475, with activity beginning July 14, 2026 and peaking above 40,000 requests on August 18, 2026. Successful exploitation allows PHP web-shell upload and full site takeover.
