# Next.js patched two critical unauthenticated RCE flaws in AVIF handling and Windows path traversal

Vercel released patches on August 25, 2026 for two critical-severity Next.js vulnerabilities, both allowing unauthenticated remote code execution. CVE-2026-75604 (CVSS 9.0) is a Windows path traversal affecting applications using both the Pages Router and App Router without Cache Components when the server uses a Windows filesystem; Linux and macOS deployments are unaffected and there is no known workaround, so Windows-hosted applications must upgrade. It affects Next.js 13.4 through 15.5.23 and 16.0 through 16.3.2. The second is a heap buffer overflow in libheif (GHSA-g89c-p67h-r497) reachable because Next.js uses the sharp image processing package, which relies on libheif to parse AVIF files — tracked for Next.js as GHSA-2xp9-vwfh-vxw4 (CVSS v4 9.5) and triggerable when Next.js processes an attacker-controlled AVIF image. All libheif versions through v1.23.1 are affected. Fixes shipped in Next.js 15.5.24 (Maintenance LTS) and 16.3.3 (Active LTS). Applications hosted on Vercel are protected and need no upgrade. Researchers evolutionstorm and B0RI were credited with the Windows disclosure.
