# Next.js patched two critical unauthenticated RCE vulnerabilities in August 2026

Vercel released patches for two critical-severity Next.js vulnerabilities that allow unauthenticated remote code execution: one exploitable via specially crafted AVIF image files, and a Windows path traversal tracked as CVE-2026-75604 (CVSS 9.0). The path traversal affects applications using both the Pages Router and App Router without Cache Components when the server runs on a Windows filesystem; Linux and macOS deployments are unaffected. Vercel says there is no known workaround for affected Windows-hosted applications. Fixes shipped August 25, 2026 in Next.js 15.5.24 (Maintenance LTS) and 16.3.3 (Active LTS).
