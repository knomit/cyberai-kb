# Next.js out-of-band patch fixes two critical RCE flaws (Oct 14, 2026)

Next.js shipped an out-of-band security update on 2026-10-14 fixing two unauthenticated remote-code-execution flaws, each rated critical by Vercel at CVSS 9.5, plus a high-severity denial-of-service flaw. One RCE is in React Server Components ('use cache', affecting Next.js 16.0.0 through 16.4.0, App Router apps with Cache Components enabled where a use cache function returns more than one typed array; GHSA-673q-mjm6-r5xr); the other is in librsvg, used via the sharp package for SVG image handling. Fixed in Next.js 16.4.1 and 15.5.28 (current Active and Maintenance LTS). Action: upgrade; the use-cache bug requires the specific configuration described. Distinct from earlier Next.js RCE advisories (AVIF/path traversal; ImageResponse SVG).
