# Rails Active Storage + ImageMagick flaw (CVSS 9.8) allows arbitrary file write

Disclosed 2026-11-04 by the Rails project: a critical flaw (GHSA-f3w6-w445-fwh9, no CVE yet, CVSS 9.8/10) in Active Storage lets an unauthenticated attacker write arbitrary files on the server via a crafted upload, when the app processes uploads with ImageMagick. Apps using Active Storage's Disk service could also let an attacker read any file the app can read (e.g. secret_key_base, credentials), enabling RCE or lateral movement. Fixed in Rails 8.1.4.1 and 8.0.5.2. Action: upgrade. Distinct from the earlier CVE-2026-66066 Active Storage flaw (not verified to be the same issue).
