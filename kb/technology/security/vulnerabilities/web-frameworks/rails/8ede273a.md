# Critical Rails Active Storage flaw CVE-2026-66066 allows unauthenticated arbitrary file read

Ruby on Rails patched a critical Active Storage vulnerability, CVE-2026-66066 (CVSS 9.5), that lets unauthenticated attackers read arbitrary files from application servers via crafted image uploads when libvips is used as the image processor. It can expose secrets such as secret_key_base, master key, database passwords, cloud storage credentials and API tokens, potentially enabling remote code execution or lateral movement. A prerequisite is that the server accepts image uploads from untrusted users.
