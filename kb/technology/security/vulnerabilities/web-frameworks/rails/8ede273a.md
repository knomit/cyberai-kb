# Critical Rails Active Storage flaw CVE-2026-66066 enables unauthenticated file read

Ruby on Rails patched a critical Active Storage vulnerability (CVE-2026-66066, CVSS 9.5) that lets unauthenticated attackers read arbitrary files from application servers via crafted image uploads, exposing secrets like secret_key_base, the Rails master key, DB passwords, cloud credentials and API tokens — potentially enabling RCE or lateral movement. Affected: Rails 7.0.0–7.2.3.1, 8.0.0–8.0.5, 8.1.0–8.1.3 (and 6.x only when Active Storage uses Vips). Exploitation requires libvips image processing and accepting uploads from untrusted users. Fixed in 7.2.3.2, 8.0.5.1, 8.1.3.1; operators should rotate all readable secrets and require libvips 8.13+.
