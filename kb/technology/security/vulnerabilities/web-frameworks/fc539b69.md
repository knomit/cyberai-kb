# Public Telerik UI padding-oracle exploit chain works only on non-default configs

TantoSec published a working exploit chain, with write-up, ready-to-run tool and two payloads, turning an AES-CBC padding oracle in Telerik UI for ASP.NET AJAX into unauthenticated remote code execution — the first complete public attack path for this chain. The entry point is CVE-2026-13182: the control encrypts client-side state with AES-CBC and no integrity check, so the server responds differently depending on whether tampered decrypted bytes have valid padding or merely fail to parse as JSON. Exploitation requires two preconditions that a default installation does not meet, both of which must hold: a page must render a RadAsyncUpload control whose server-side handler reads the upload result, AND the application must be configured with an explicit, non-default encryption key for the control. Progress Software fixed the chain in version 2026.2.708 (2026 Q2 SP1) on July 8, 2026 and published the CVEs and advisory on July 22, 2026. There are no confirmed reports of exploitation in the wild.
