# PoC for Microsoft Defender 'RoguePlanet' zero-day grants SYSTEM on patched Windows

An anonymous researcher (Chaotic Eclipse / Nightmare-Eclipse, via GitHub account 'MSNightmare') released a proof-of-concept exploit for a Microsoft Defender zero-day named RoguePlanet. It is a race-condition exploit (hit-or-miss, but 100% success on some machines) that yields a SYSTEM-level shell. It was tested working on Windows 11 and 10 with the June 2026 Patch Tuesday updates installed (i.e., up-to-date systems), though it does not work on Windows Server.
