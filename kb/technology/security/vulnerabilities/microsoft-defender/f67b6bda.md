# Microsoft confirms Defender 'RoguePlanet' zero-day CVE-2026-50656

Microsoft confirmed a zero-day in the Microsoft Malware Protection Engine in Microsoft Defender, publicly known as 'RoguePlanet' and assigned CVE-2026-50656 (CVSS 7.8), an elevation-of-privilege flaw. A researcher using the handle 'Chaotic Eclipse' (aka Nightmare-Eclipse) released the exploit ~a week earlier, describing it as a race condition that yields a shell with SYSTEM-level privileges. Microsoft said a security update is in development.
