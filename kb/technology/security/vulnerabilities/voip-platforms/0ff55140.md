# Switchvox CVE-2026-9586 exploited in the wild since 2026-08-30 for credential-free RCE

CVE-2026-9586 is a critical flaw in Sangoma Switchvox SMB Edition 8.3 (104997) that lets an unauthenticated attacker execute arbitrary code as the PostgreSQL superuser. It permits arbitrary database operations — dumping database contents, modifying user records, escalating to Switchvox web administrator — and code execution on the server including invoking reverse shells. Horizon3.ai reported it as one of 12 distinct Switchvox vulnerabilities disclosed to Sangoma in April 2026, and observed valid exploitation attempts in the wild beginning 2026-08-30. Security Risk Advisors (SRA) Labs independently found and reported the same flaw in May 2026. Roughly 4,000 instances are exposed to the internet, most in the U.S.
