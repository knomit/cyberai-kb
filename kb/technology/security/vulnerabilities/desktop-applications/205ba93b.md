# CVE-2026-51990: UNC3569 chained Sogou Input Method weaknesses for a one-click GRAYRABBIT backdoor install

Gen Digital published research on 2026-09-10/11 describing how China-linked espionage group UNC3569 exploited Tencent's Sogou Input Method for Windows — one of the most widely used tools for typing Chinese characters — to install a backdoor from a single crafted link, ending with the attacker able to do anything the logged-in user could.

The one-click remote code execution chains three separate weaknesses: unvalidated command-line argument injection in the sgbiz: custom protocol handler, unrestricted URL navigation in a CEF-based webview, and a severely outdated, unsandboxed Chromium engine with important web-security protections disabled. Because Sogou bundled Chromium version 80, the chain can also leverage CVE-2021-38003, a V8 type confusion flaw affecting Chrome versions before 95.0.4638.69.

Gen reported the issue to Tencent on 2026-04-09; Tencent replied the next day and confirmed on 2026-04-21 that a fix was complete and would reach all users by automatic update in version 16.3.0.3498. The issue is tracked as CVE-2026-51990.

The payload is GRAYRABBIT, a small first-stage implant the group has used for years, providing a remote command shell, bidirectional file transfer, and on-demand loading of additional modules. Google Threat Intelligence has tracked UNC3569 since 2021, ties it to China's hacker-for-hire scene, and says it targets government, education, technology and finance mostly in East and Southeast Asia.
