# A one-click Sogou Input Method exploit chains three weaknesses to deploy the GRAYRABBIT backdoor

Gen Digital reported that threat actors linked to China-aligned espionage group UNC3569 exploited CVE-2026-51990 in Tencent's Sogou Input Method for Windows to deploy the GRAYRABBIT backdoor. The one-click remote code execution chains three separate weaknesses: unvalidated command-line argument injection in the sgbiz: custom protocol handler, unrestricted URL navigation in a CEF-based webview, and a severely outdated, unsandboxed Chromium engine. Because Sogou bundled Chromium version 80, the chain can also leverage CVE-2021-38003, a V8 type confusion flaw affecting Chrome versions before 95.0.4638.69. Tencent fixed the flaw in April 2026.
