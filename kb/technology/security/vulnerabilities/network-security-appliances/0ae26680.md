# Check Point patched an actively exploited SmartConsole flaw enabling full admin access

Check Point released security updates addressing multiple vulnerabilities in its Security Management and Multi-Domain Security Management (MDSM) products, including a critical flaw under active exploitation that could allow full administrative access via SmartConsole.
