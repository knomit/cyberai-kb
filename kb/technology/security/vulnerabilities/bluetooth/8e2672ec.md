# Apple patched Beats Studio Buds eavesdropping flaw CVE-2025-20701

Apple released Beats Firmware Update 1B211 to patch CVE-2025-20701 (CVSS 8.8), a high-severity incorrect-authorization flaw in the Airoha Bluetooth audio SDK affecting Beats Studio Buds. The flaw lets an attacker within Bluetooth range pair without user consent and listen through the microphone of a device that is not yet paired but actively seeking pair requests, enabling remote privilege escalation with no user interaction. Details first emerged in June 2025 from ERNW GmbH researchers Dennis Heinze and Frieder Steinmetz.
