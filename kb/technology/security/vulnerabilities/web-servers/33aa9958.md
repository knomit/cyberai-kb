# NGINX 1.30.6 / 1.31.7 fix five flaws incl. possible RCE and TLS client-cert bypass

NGINX released 1.30.6 and 1.31.7 on 2026-10-14 fixing five vulnerabilities, one present in every release since May 2005. Three memory bugs could crash a worker or possibly allow code execution (F5 scores CVSS v4.0 9.2; NGINX rates all five medium), each needing specific configuration. A fourth (8.3) allows forging a TLS session that may bypass client-certificate checks (non-deterministic); a fifth (6.9) lets an HTTP/3 client smuggle extra bytes to a backend. None in CISA KEV as of 2026-10-15; no attacks reported.
