# LiteSpeed Enterprise pre-6.3.7 flaw allows shared-hosting tenant to gain root

cPanel published an advisory on September 14, 2026 warning that a critical vulnerability in LiteSpeed Web Server Enterprise before version 6.3.7 lets a low-privilege website user on a shared-hosting server gain root access to the whole machine, and thereby read or alter other customers' sites. The flaw bypasses the isolation controls that separate hosting accounts, including CloudLinux's CageFS (which normally gives each account a restricted view of the filesystem). LiteSpeed published the fixed 6.3.7 release on September 11, 2026; neither cPanel's advisory nor LiteSpeed's release notes describe the mechanism. Shared-hosting operators should treat tenant isolation as void until patched.
