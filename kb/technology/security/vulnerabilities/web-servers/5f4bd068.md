# F5 patched two critical NGINX Open Source RCE flaws (CVE-2026-42530, CVE-2026-42055)

F5 released security updates for two critical NGINX Open Source flaws, both CVSS v4 9.2, that allow remote unauthenticated code execution. CVE-2026-42530 is a use-after-free in the ngx_http_v3_module triggered via a crafted HTTP/3 session when the HTTP/3 QUIC module reopens a QPACK encoder stream (exploitable on systems with ASLR disabled or bypassed). CVE-2026-42055 is a heap-based buffer overflow in the ngx_http_proxy_v2_module and ngx_http_grpc_module, triggered when proxy_http_version 2 or grpc_pass directives proxy HTTP/2 traffic.
