# CVE-2026-4020: Gravity SMTP WordPress plugin info-disclosure flaw

Gravity SMTP, a WordPress plugin installed on roughly 100,000 sites, has a medium-severity information-disclosure vulnerability tracked as CVE-2026-4020 (CVSS 5.3) that threat actors are actively exploiting. Per Wordfence, the plugin registers a REST API endpoint at /wp-json/gravitysmtp/v1/tests/mock-data whose permission_callback unconditionally returns true, letting any unauthenticated visitor access it. Appending the ?page=gravitysmtp-settings parameter causes the endpoint to return ~365 KB of JSON containing the full System Report, exposing configuration data, API keys, secrets, and OAuth tokens for the plugin's email integrations.
