# Two unauthenticated auth-bypass flaws in miniOrange SAML SSO WordPress plugin under active attack

Attackers are exploiting two unauthenticated authentication bypasses in the Xecurify miniOrange SAML 2.0 Single Sign On WordPress plugin, disclosed by Patchstack: CVE-2026-61979 (CVSS 8.1, signature algorithm confusion, fixed in Standard edition 17.0.5) and CVE-2026-15981 (CVSS 9.8, acceptance of malformed signatures as valid, fixed in 17.0.6). The root cause of CVE-2026-15981 is that mo_saml_validate_signature() performs a loose boolean check on the tri-state integer returned by PHP's openssl_verify(), so the error return value of -1 evaluates as truthy and is treated as successful verification. An attacker can submit a crafted SAMLResponse with an attacker-controlled NameID and a deliberately malformed signature to get wp_set_auth_cookie() called for any account, including administrators. DigitalOcean's security team discovered the issue after spotting an anomalous WordPress admin session attempt from outside its trusted network.
