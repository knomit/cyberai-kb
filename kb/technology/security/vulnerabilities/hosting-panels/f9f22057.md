# cPanel EmailTrack SQL injection escalates to root

cPanel patched CVE-2026-67401, a SQL injection in the EmailTrack feature affecting every supported cPanel/WHM version, allowing an authenticated account with mail-related privileges to write files and escalate to root code execution. Advisory published September 8, 2026. On shared hosting this crosses the tenant boundary: one account's mail privilege reaches the whole server.
