# Critical nginx flaw CVE-2026-42533 can crash workers and may allow RCE

F5 shipped fixes for a critical nginx flaw, CVE-2026-42533, that lets a remote, unauthenticated attacker trigger a heap buffer overflow in the worker process with crafted HTTP requests, potentially enabling remote code execution. It was patched on July 15, 2026.
