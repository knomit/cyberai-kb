# worse_query iOS sandbox escape lets apps read other apps' data on iOS 26 and 27; no fix confirmed

Researcher 'forcequit' published worse_query on GitHub (2026-11-08), a sandbox escape letting an app with an App Group container read other apps' data containers on iOS 26 and 27. Binance warned seed phrases, keys and credentials could be exposed and advised deleting sideloaded/untrusted apps and updating. Apple's iOS 27.2.1 and 26.7.3 notes do not mention it. No attacks reported. Tools like WQ Files, sideloaded via AltStore/SideStore, build on it; unknown whether App Store apps could use it.
