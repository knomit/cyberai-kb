# CISA adds ownCloud CVE-2023-49105 to KEV after Philippine nuclear research body targeted

On August 27, 2026, CISA added ownCloud flaw CVE-2023-49105 (CVSS 9.8) to its Known Exploited Vulnerabilities catalog, following reports that a Chinese-speaking threat actor weaponized it against a nuclear research body in the Philippines. The vulnerability is a WebDAV API authentication bypass (via pre-signed URLs) allowing an attacker to access, modify or delete any file without authentication if the victim's username is known and no signing key is configured — the default configuration. Disclosed by ownCloud in November 2023, it affects ownCloud core versions 10.6.0 through 10.13.0 and was fixed in 10.13.1. The KEV addition followed Hunt.io research identifying an open directory on host 31.58.209[.]241 staging custom Python scripts and open-source offensive security tooling.
