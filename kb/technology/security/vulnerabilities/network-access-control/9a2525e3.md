# Cisco ISE CVE-2026-76460 (CVSS 10.0) is an actively exploited unauthenticated API auth bypass

Cisco warned of a maximum-severity flaw in Identity Services Engine (ISE) under ACTIVE exploitation, tracked as CVE-2026-76460 with a CVSS score of 10.0. Cisco's description: 'This vulnerability is due to insufficient authentication control on an API endpoint. An attacker could exploit this vulnerability by sending a crafted request to an affected API endpoint. A successful exploit could allow the attacker to gain unauthorized access to the affected device by bypassing the web-based management interface.' All three conditions hold together: the attacker needs no authentication, needs no local access (remote), and only needs to reach one API endpoint. Because ISE is the policy decision point for network access, a bypass here is not one device compromised — it is control of who gets onto the network. Patch on emergency timelines and do not defer on the assumption that the management interface is internal-only.
