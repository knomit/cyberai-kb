# Cisco ISE zero-day CVE-2026-76460 (CVSS 10.0) under active exploitation

Cisco disclosed CVE-2026-76460, a CVSS 10.0 authentication-bypass flaw in Cisco Identity Services Engine (ISE) and the ISE Passive Identity Connector (ISE-PIC), and stated it is aware of active exploitation in the wild. The root cause is insufficient authentication control on an API endpoint: an unauthenticated remote attacker sending a crafted request to that endpoint can bypass the web-based management interface and gain unauthorized device access. The flaw affects ISE and ISE-PIC REGARDLESS of device configuration — there is no configuration that makes an unpatched instance safe, and no workaround was offered. Fixed releases are 3.1 Patch 12, 3.2 Patch 11, 3.3 Patch 12, 3.4 Patch 7, and 3.5 Patch 4; every one of those component versions must be matched, because patching to a lower patch level on the correct minor branch does not remediate. Operational consequence: patch affected ISE deployments immediately rather than relying on network placement or hardening. This does NOT mean only internet-exposed ISE instances are at risk — the condition is the unpatched version, not the exposure.
