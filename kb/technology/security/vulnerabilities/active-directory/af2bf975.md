# Certighost PoC (CVE-2026-54121) lets low-privileged AD users impersonate a Domain Controller

A proof-of-concept was released for CVE-2026-54121 ('Certighost'), a critical privilege-elevation flaw in Active Directory Certificate Services (AD CS) allowing any authenticated domain user (no admin rights or user interaction) to obtain a certificate impersonating a Domain Controller, then run DCSync to extract the krbtgt secret—a precursor to Golden Ticket domain compromise. Microsoft patched it earlier in July 2026. Researchers H0j3n and Aniq Fakhrul published a working exploit on July 24.
