# Plex patched undisclosed flaws following prior admin-token exposure

Plex patched multiple undisclosed flaws in Plex Media Server 1.43.3 and Plex Desktop 1.115.0, following a prior high-severity authentication bug (CVE-2025-34158, CVSS 8.5) that exposed owner admin tokens via the /myplex/account endpoint.
