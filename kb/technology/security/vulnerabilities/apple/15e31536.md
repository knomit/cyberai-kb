# Apple patches CoreGraphics zero-day CVE-2026-86950, exploited in targeted attacks

Apple patched CVE-2026-86950, an out-of-bounds write in CoreGraphics (arbitrary code execution via crafted file) in older iOS, iPadOS and macOS versions; possibly exploited in extremely sophisticated attacks against targeted individuals on versions before iOS 27. Discovered by Meta Product Security. Apple gave no details on victims or timeline.
