# macOS Screen Sharing's legacy VNC path produced a 2026 vulnerability cluster spanning pre- and post-auth root compromise

Across mid-2026 Apple patched a cluster of defects concentrated in one component — the macOS Screen Sharing Server and its legacy VNC authentication path — collectively covering both unauthenticated entry and post-authentication privilege abuse, all reported by researcher Alfredo Pesoli of Bynario. macOS Tahoe 26.6 (late July 2026) fixed CVE-2026-43779 (CVSS 9.8, logic issue letting an app intercept network connections intended for another process), CVE-2026-43777 (CVSS 7.5, remote DoS) and CVE-2026-43760 (CVSS 8.6, access issue exposing user-sensitive data). An emergency update on August 6, 2026 (macOS Tahoe 26.6.1, Sequoia 15.7.9, Sonoma 14.8.9) then fixed CVE-2026-65400 (CVSS 9.8), an authentication issue 'addressed with improved state management' letting an attacker already on the network authenticate to the built-in remote desktop service without valid credentials.

The two ends of the cluster carry different preconditions and must not be conflated. CVE-2026-65400 requires only network adjacency and no credentials, and is the one confirmed exploited in the wild: NCSC-NL reported abuse across multiple systems with port 5900 exposed to the internet, where attackers obtained root and installed a Monero cryptocurrency miner. CVE-2026-43760 is post-authentication and requires all of: Screen Sharing or Remote Management enabled, the 'VNC viewers may control screen with password' option configured, and the attacker already possessing that VNC password; under those conditions the legacy path turns a file-copy operation into protected file disclosure, arbitrary root file creation, and remote root command execution.

The pattern for defenders: an internet-exposed port 5900 is the single highest-value control point, since it is the precondition shared by the observed exploitation, and a legacy compatibility authentication path retained inside a modern component was the common root of both the pre-auth bypass and the post-auth root escalation. WHAT THIS DOES NOT MEAN: only CVE-2026-65400 has reported in-the-wild exploitation — the Tahoe 26.6 bugs, including the root-RCE chain, are not documented as exploited, and no details are available on the timing, scale, whether CVE-2026-65400 was a zero-day, or whether the observed activity went beyond cryptomining.
