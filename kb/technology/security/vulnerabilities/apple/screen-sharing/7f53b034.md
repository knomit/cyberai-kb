# macOS Tahoe 26.6 patched a cluster of Screen Sharing Server bugs enabling root RCE via legacy VNC path

Alongside CVE-2026-65400, Apple patched a related series of Screen Sharing Server bugs in macOS Tahoe 26.6: CVE-2026-43779 (CVSS 9.8, logic issue allowing an app to intercept network connections intended for another process), CVE-2026-43777 (CVSS 7.5, remote denial-of-service), and CVE-2026-43760 (CVSS 8.6, access issue exposing user-sensitive data). Researcher Alfredo Pesoli described CVE-2026-43760 as a post-authentication bug requiring Screen Sharing or Remote Management enabled with 'VNC viewers may control screen with password' and possession of the VNC password. A legacy Screen Sharing authentication path turns a file-copy operation into protected file disclosure, arbitrary root file creation, and remote root command execution.
