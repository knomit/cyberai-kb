# Debian 12 shipped libheif 1.19.7 months after the CVE-2026-32882 fix landed in libheif 1.22.0

The libheif flaw tracked as CVE-2026-32882 was fixed upstream in libheif 1.22.0, released in May 2026. When Hacktron researchers examined OpenAI's Discourse forum in July 2026, the forum's server image — built on Debian 12 — still shipped the old, unpatched libheif 1.19.7, because Debian had not yet incorporated the upstream fix into its packaged version even though both the fix and the CVE were already public. Two conditions combined to create the exposure and both matter: the distribution's packaged version lagged upstream, AND the deployed server image had not been rebuilt. Operational consequence for self-hosted Discourse operators: rebuild on the latest server image to pick up the patched libheif, because a web-interface update alone may not replace the old library. Fixed self-hosted Discourse releases are 2026.7.0, 2026.6.1, 2026.5.2, and 2026.1.6; Discourse-hosted sites were already patched. This does NOT mean that a public upstream fix implies your distribution's package or your running image carries it — 'CVE is fixed upstream' and 'my deployment is patched' are independent claims and must be checked separately.
