# One-click VS Code attack steals full GitHub OAuth token with read/write access to all private repos

Security researcher Ammar Askar disclosed a one-click attack via GitHub.dev (GitHub's web-based VS Code editor) that steals a user's GitHub OAuth token. The token has full access to all repos the victim has access to — not scoped to a single repo. Attack mechanism: a malicious link exploits the message-passing mechanism between the main VS Code window and webviews (which render Markdown previews and Jupyter notebooks). Malicious JavaScript runs inside an untrusted webview and simulates keypresses in the main editor window, triggering Ctrl+Shift+P to open the Command Palette, installing an attacker-controlled VS Code extension that extracts the GitHub OAuth token being POSTed to GitHub.dev and queries the GitHub API to enumerate all private repositories.
