# Zyxel GS1900 zero-day CVE-2026-107441 exploited against ~1,000 switches by Kapibala

Zyxel fixed CVE-2026-107441 (CVSS 8.8), an out-of-bounds write in GS1900 series switches allowing a LAN-based unauthenticated attacker to potentially run OS commands via a crafted HTTP request. Attributed to Chinese-speaking actor Kapibala (aka Red Heron), it compromised nearly 1,000 devices worldwide, stealing configs and credentials, deploying the JITTERLY backdoor and the SIXZUT rootkit.
