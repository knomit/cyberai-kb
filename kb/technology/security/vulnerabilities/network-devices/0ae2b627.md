# Zyxel GS1900 earlier patch (2.90 Patch 2) does not block zero-day root command execution; fixed in Patch 3

Binarly found GS1900 switches patched with firmware 2.90 Patch 2 (for CVE-2026-7273, June 16 advisory) remain exploitable by unauthenticated command execution via the web management interface. Zyxel's 2.90 Patch 3 (posted Oct 23 2026) fixes the separately tracked CVE-2026-107441 for 10 GS1900 models. GreyNoise reported data taken from 996 GS1900 switches around Aug 17.
