# Next.js CVE-2026-94545 (CVSS 9.5): ImageResponse SVG injection can yield server code execution; fixed only in 16.3.6

CVE-2026-94545 affects Next.js 16.2.0 through 16.3.5 when ImageResponse runs on the Node.js runtime (the default); the Edge ImageResponse and Next.js 15 are not affected. ImageResponse uses Vercel's Satori to build SVG, and certain values reached Satori's SVG output unescaped, so apps that pass attacker-controlled values into SVG content, attributes or styles can be driven to server code execution. Vercel rates it critical (CVSS 9.5). Fix: upgrade to Next.js 16.3.6 (the only patched version); interim workaround: keep attacker-controlled values out of Node.js ImageResponse SVG content/attributes/styles. No public exploit or attacks reported as of Sept 23, 2026.
