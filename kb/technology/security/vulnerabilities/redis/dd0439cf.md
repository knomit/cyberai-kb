# Redis shipped seven security releases after AI agents found RCE zero-days

Redis shipped seven security releases on July 23, 2026 after researchers published authenticated remote-code-execution proof-of-concepts affecting stock Redis 6.2.22, 7.4.9, 8.6.4, and 8.8.0. All four exploit chains require the RESTORE command; the Streams-based chains also require EVAL. Researchers said Kimi K3 AI agents discovered the zero-days and built the RCE exploit. Reported by The Hacker News.
