# Windows Paint RCE CVE-2026-83844 fixed only via Microsoft Store update (build 11.2609.401.0)

A remote code execution flaw in Windows Paint, CVE-2026-83844, is fixed in Paint build 11.2609.401.0 available through the Microsoft Store. Paint receives this fix only via Store update, not Windows Update, so systems relying solely on Windows Update remain unpatched.
