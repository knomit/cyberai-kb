# Windows Paint RCE CVE-2026-83844 fixed only via Microsoft Store update

CVE-2026-83844 is an out-of-bounds-read RCE in Windows Paint (CVSS 8.1, rated Important; published Oct 13, not known exploited then). The fix ships only via a Microsoft Store update of Paint, not Windows Update; fixed build is 11.2609.401.0. Earlier in the week the Store still offered build 11.2605.81.0 (unfixed) in six countries per RFF's Brian Vitko. Patch compliance must verify the Store app version.
