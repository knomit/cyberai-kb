# ServiceNow patched three CVSS 10.0 flaws exploitable without authentication

ServiceNow published an advisory on August 27, 2026 patching four flaws in the ServiceNow AI Platform, three rated CVSS 10.0 and exploitable in certain circumstances by an unauthenticated attacker: CVE-2026-18885 (code injection in the GraphQL Composite Data API allowing arbitrary code execution and access to or modification of instance data), CVE-2026-18886 (improper access control in the system configuration image upload processor allowing creation or modification of instance data and privilege escalation), and CVE-2026-74820 (SQL injection reached through a dynamic schema ORDER BY clause allowing arbitrary SQL against the underlying database). A fourth, CVE-2026-6876 (CVSS 8.7), is a Now Platform sandbox escape allowing unauthenticated code execution. The three maximum-severity flaws share the vector CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H — network-reachable, low complexity, no privileges, no user interaction, high impact to both the vulnerable component and connected systems. ServiceNow updated hosted instances itself; self-hosted customers must apply the fixes. The advisory follows CVE-2026-6875, a pre-authentication sandbox escape in the same platform reported by Searchlight Cyber on April 1, 2026.
