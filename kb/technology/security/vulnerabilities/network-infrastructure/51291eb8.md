# Cisco Nexus 9000 critical unauthenticated root RCE CVE-2026-20212

Cisco patched CVE-2026-20212 (CVSS 9.8), an unauthenticated remote root code execution flaw affecting 10 Silicon One-based Nexus 9000 switches via exposed TCP ports 43210 and 43211. No active exploitation was known as of the September 2, 2026 disclosure.
