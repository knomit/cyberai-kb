# Cisco zero-days: Catalyst SD-WAN Manager and Unified CM under threat

Cisco warned that CVE-2026-20245 (CVSS 7.8) in Catalyst SD-WAN Manager is under active exploitation with no patch available, while CVE-2026-20230 in Unified Communications Manager — letting an unauthenticated network attacker write files and escalate to root — was patched as public proof-of-concept exploit code emerged. Reported June 5–6, 2026. CISA also added an actively exploited SolarWinds Serv-U DoS flaw to its Known Exploited Vulnerabilities (KEV) catalog.
