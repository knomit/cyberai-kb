# Plex2Shell: four Plex Media Server CVEs chained, exploited in the wild, all added to CISA KEV

CVE-2026-96652, -96654, -96655 and -96656 in Plex Media Server are chained as Plex2Shell to deliver crypto miners and proxy software; CISA added all four to the Known Exploited Vulnerabilities catalog.
