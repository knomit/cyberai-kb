# Cisco Secure FMC flaws CVE-2026-20079 and CVE-2026-20316 exploited by three clusters, including Qilin ransomware

Cisco disclosed that three distinct threat clusters, spanning ransomware and state-sponsored activity, exploited two recently patched Secure Firewall Management Center (FMC) vulnerabilities. CVE-2026-20079 (CVSS 10.0) is an authentication bypass in the FMC web interface letting an unauthenticated remote attacker execute script files on the device and obtain root. CVE-2026-20316 (CVSS 5.3) lets an unauthenticated remote attacker log in with a low-privilege account and reach sensitive data. The ransomware operation tracked as UAT-11988 used CVE-2026-20316 for initial access, then conducted a living-off-the-land campaign with FMC's own built-in tooling: environment reconnaissance, tunneling tools for persistent network access, credential collection, building a target list of endpoints, terminating security tools, and finally deploying Qilin ransomware on selected systems. Cisco urged customers to apply the already-released hotfixes for both CVEs and said it intended to ship a broader hardening release for additional internally found vulnerabilities the following week.
