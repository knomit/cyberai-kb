# Cisco Unified CM SSRF flaw CVE-2026-20230 exploited

Threat actors began exploiting CVE-2026-20230 (CVSS 8.6), a critical improper-input-validation flaw in Cisco Unified Communications Manager (Unified CM) and Unified CM Session Management Edition that enables unauthenticated remote server-side request forgery (SSRF). Per Cisco's advisory, a crafted HTTP request could let an attacker write files to the underlying OS and later elevate to root. Defused Cyber reported observing active exploitation, which followed public release of a proof-of-concept exposing a file-write path to root.
