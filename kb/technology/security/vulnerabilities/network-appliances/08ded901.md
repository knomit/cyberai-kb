# CVE-2026-8452: Citrix NetScaler heap overflow silently patched, then exploited

Citrix silently addressed a heap overflow vulnerability in NetScaler in updates released at the end of June 2026, likely corresponding to CVE-2026-8452, described as a memory overflow leading to unpredictable behavior or denial-of-service when configured as a Gateway or AAA virtual server. watchTowr showed it can be turned into code execution dropping a PHP web shell that survives NetScaler packet engine respawns and runs commands as root. Defused Cyber observed in-the-wild exploitation two calendar days after details became public.
