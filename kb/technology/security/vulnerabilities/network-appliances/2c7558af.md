# Check Point patched two CVSS 9.8 VPN certificate-handling flaws allowing unauthenticated RCE (CVE-2026-85102/85103)

Check Point disclosed and patched two critical flaws, both scored CVSS 9.8, in how its firewall and management products handle VPN certificates. Check Point discovered both itself. CVE-2026-85102 is a failure to properly validate certificate trust during VPN negotiation, through which an unauthenticated remote attacker may be able to run code on the Security Gateway. CVE-2026-85103 is a heap-based buffer overflow that occurs while decoding the ASN.1 structure of a VPN certificate, through which an unauthenticated remote attacker may be able to run code on Quantum Security Management and Quantum Security Gateway systems. Check Point framed both as exploitable only under unspecified conditions. Two remediation routes exist: customers on Check Point Live Patch are protected automatically as the rollout, which began September 9, 2026, reaches them; everyone else must install the latest Jumbo Hotfix for their deployed version once available. As of September 9, 2026 Check Point said it had seen no evidence of exploitation in the wild. Note this is a SEPARATE incident from CVE-2026-91843, the pre-authentication stack overflow in the Security Management Server login process disclosed 16 September 2026 — same vendor, same CVSS score, different component and different fix.
