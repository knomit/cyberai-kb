# CVE-2026-16232: Check Point SmartConsole authentication bypass under active exploitation

CVE-2026-16232 (CVSS 9.3) is an authentication bypass in the SmartConsole login process of Check Point Security Management Server and Multi-Domain Security Management Server (MDS). An unauthenticated remote attacker can obtain an application login token and use it to log in through SmartConsole with full administrator privileges, then modify security policy or configuration. Exploitation requires network access to the Management Server and a configuration that does not restrict Trusted Clients. The flaw has come under active exploitation in the wild; Rapid7 released public proof-of-concept technical details.
