# StyleSmuggler Magento zero-day CVE-2026-75650 rated CVSS 10.0

Sansec disclosed "StyleSmuggler," a template-injection zero-day in Magento Open Source and Adobe Commerce affecting the 2.4.4 through 2.4.9 branches, exploited in the wild from September 4, 2026 for unauthenticated code execution. Attackers deployed a Rust backdoor (variants named fc-cache and chronyd, calling out to C2 99.84.67[.]186) and a PHP web shell for persistence. Adobe subsequently patched it as CVE-2026-75650 (CVSS 10.0).
