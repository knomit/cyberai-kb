# StyleSmuggler Magento zero-day CVE-2026-75650 exploited to backdoor stores

Sansec disclosed CVE-2026-75650 (CVSS 10.0), codenamed StyleSmuggler, an unauthenticated remote code execution flaw in Magento Open Source and Adobe Commerce. The flaw abuses Magento's template system via PHP code injection while generating a 'Payment Transaction Failed Reminder' email, executing attacker code on the store server with no login. Every version from 2.4.4 through 2.4.9 is affected; one confirmed victim ran 2.4.6-p15 with Adobe's July and August 2026 security updates applied, i.e. fully patched to the then-current level. Sansec confirmed in-the-wild exploitation from September 4, 2026, several days before Adobe shipped an emergency hotfix on September 7; as of September 7 Adobe had not published its own CVE, advisory, or workaround. Observed payloads include a Rust-based Linux backdoor that disguises its command-and-control traffic as NTP server replies, and, in separate attacks, a PHP web shell capable of running arbitrary PHP.
