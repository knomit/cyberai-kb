# GreatXML exploit bypasses Windows BitLocker via recovery-partition XML files

Researcher 'Chaotic Eclipse' (aka Nightmare-Eclipse / MSNightmare) released GreatXML, a Windows BitLocker bypass, a day after publishing a Microsoft Defender exploit (reported Jun 12, 2026). The attack places an unattend.xml and a Recovery/WindowsRE/ReAgent.xml file at the root of the recovery partition, then reboots into the Windows Recovery Environment (WinRE) by holding Shift while clicking Restart. The researcher said using Windows Defender Offline Scan makes a machine automatically vulnerable, calling it an accidental discovery that took about 4 hours to find.
