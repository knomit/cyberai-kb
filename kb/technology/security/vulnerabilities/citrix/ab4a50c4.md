# Citrix NetScaler CVE-2026-88771 and CVE-2026-88772 actively exploited; CISA patch deadline

Citrix confirmed on 2026-09-27 that two critical NetScaler ADC / Gateway flaws were exploited before a fix was public: CVE-2026-88771 (CVSS v4 9.5; improper input validation, unauthenticated arbitrary command execution; affects ALL NetScaler ADC and Gateway deployments, no extra feature required) and CVE-2026-88772 (CVSS v4 9.5; memory overflow leading to RCE or DoS; requires DTLS, on by default for VPN virtual servers, so a Gateway is affected unless DTLS was explicitly disabled). Citrix fixed both plus six other flaws; the bulletin lists no workaround and no indicators of compromise, and did not say whether these are the two unpatched RCEs watchTowr described the day before. CISA added both to KEV on Sunday 2026-09-27 and urged federal agencies to patch by the following Wednesday. Builds 14.1-73.32 / 13.1-63.21 (which fixed the August auth bypass CVE-2026-19490) are inside the affected range. Consequence: patch immediately; no mitigation short of the fix.
