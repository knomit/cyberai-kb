# Citrix patches six NetScaler ADC/Gateway vulnerabilities

Citrix released updates for multiple NetScaler ADC and NetScaler Gateway flaws enabling arbitrary file read or denial-of-service. Disclosed CVEs include CVE-2026-8451, CVE-2026-8452 and CVE-2026-8655 (each CVSS 8.8) and CVE-2026-10816 (CVSS 7.7), affecting configurations such as SAML IdP, Gateway/AAA virtual server, and DNS resolver deployments.
