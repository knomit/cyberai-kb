# CVE-2026-112816: CVSS 10.0 LXD/MicroCloud flaw allows trusted-client impersonation without private key

CVE-2026-112816 (CVSS 10.0) in Canonical LXD and MicroCloud lets an attacker with network access to the HTTPS API and a trusted client's public certificate authenticate as that client without its private key (mutual TLS trust store flaw); if the client is privileged, root on the host is possible. Canonical released fixed versions of both products.
