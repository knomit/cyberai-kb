# CISA warns of actively exploited Lantronix EDS5000 flaw CVE-2025-67038

CISA warned of active exploitation of CVE-2025-67038 (CVSS 9.8), a critical code-injection flaw in Lantronix EDS5000 Series devices, urging Federal Civilian Executive Branch agencies to apply fixes by June 26, 2026. Per the CVE description, the HTTP RPC module runs a shell command to write logs on failed authentication, concatenating the username into the command without sanitization, allowing attackers to inject arbitrary OS commands (executed as root) via the username parameter. The flaw was disclosed by Forescout Research Vedere Labs in April 2026.
