# Cisco patched nine Crosswork and Secure Workload flaws, five rated CVSS 10.0

In August 2026 Cisco published security updates for Crosswork platforms and Secure Workload Software as part of a continued internal security review. Four flaws affect Crosswork Data Gateway, Crosswork Network Controller and Crosswork Planning regardless of configuration: CVE-2026-20030 (SQL injection, CVSS 10.0), CVE-2026-20357 (missing authentication for critical function, CVSS 10.0), CVE-2026-20358 (external control of file system, CVSS 10.0) and CVE-2026-20359 (insufficiently protected credentials, CVSS 9.9). They affect Crosswork release 7.2.1 and earlier and are fixed in 7.2.1-SP. Five further flaws affect Cisco Secure Workload (SaaS and on-premises): CVE-2026-20231 (injection, CVSS 9.9), CVE-2026-20315 (improper access control, CVSS 10.0), CVE-2026-20317 (improper authentication, CVSS 10.0), CVE-2026-20318 (improper input validation/path traversal, CVSS 9.6) and CVE-2026-20319 (memory buffer issues, CVSS 7.5). This followed roughly two weeks after Cisco resolved 12 bugs in Catalyst SD-WAN and IOS XE from the same review, and came in the same month Cisco warned that CVE-2026-20349 (CVSS 8.6) in Secure Firewall ASA and FTD Software was being exploited in the wild.
