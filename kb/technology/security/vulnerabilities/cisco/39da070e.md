# Cisco SD-WAN Manager CVE-2026-76504 critical auth bypass exploited as zero-day

Cisco advised on 2026-09-30 that attackers are exploiting CVE-2026-76504 (CVSS 9.8), an authentication bypass in Cisco Catalyst SD-WAN Manager's API login session handling (mishandled URI encoding), giving remote unauthenticated attackers admin-privileged API access. Fixed releases exist; no workaround. Internet-exposed Managers are at immediate risk; the default admin user holds the netadmin role permitting all device operations. Distinct from earlier SD-WAN Manager CVEs (CVE-2026-20245, CVE-2026-20262).
