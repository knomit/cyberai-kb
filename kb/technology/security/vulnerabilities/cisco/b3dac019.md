# Cisco CVSS 10.0 flaw CVE-2026-20223 in Secure Workload allows unauthenticated data access

CVE-2026-20223 (CVSS 10.0) is a maximum-severity flaw in Cisco Secure Workload. Arises from insufficient validation/authentication on REST API endpoints. An unauthenticated remote attacker can read sensitive data and make config changes across tenant boundaries with Site Admin privileges. Cisco has patched it.
