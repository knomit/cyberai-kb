# Cisco Unified CM flaw CVE-2026-20230 actively exploited via unvetted PoC

CVE-2026-20230 (CVSS 8.6) is an improper-input-validation/SSRF flaw in Cisco Unified Communications Manager (Unified CM) and Unified CM Session Management Edition. An unauthenticated remote attacker sending a crafted HTTP request can write files to the underlying OS and later elevate to root. Cisco disclosed it earlier in June 2026; Defused Cyber reported active exploitation from a single source using an unvetted public proof-of-concept (PoC).
