# Cisco ASA/FTD SSL VPN DoS flaw CVE-2026-76418 (CVSS 8.6) exploited in the wild

Cisco patched CVE-2026-76418 (CVSS 8.6) in Secure Firewall ASA and FTD software, which Cisco says has been exploited in the wild. A logic error when secondary authentication is configured on a tunnel group in the Remote Access SSL VPN service lets an unauthenticated remote attacker send a crafted request to make the device reload, causing denial of service. Advisory published Wednesday 2026-10-28. It causes DoS, not code execution.
