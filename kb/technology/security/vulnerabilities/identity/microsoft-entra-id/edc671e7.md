# Microsoft Entra ID CVE-2026-69836 (CVSS 10.0) was a deserialization RCE that Microsoft later confirmed was NOT exploited in the wild

On Thursday 2026-08-20 Microsoft disclosed CVE-2026-69836, a maximum-severity (CVSS 10.0) remote code execution vulnerability in Entra ID (formerly Azure Active Directory / Azure AD), Microsoft's cloud identity and access management service. The root cause is deserialization of untrusted data, allowing an unauthorized attacker to execute code over a network.

Microsoft's original bulletin marked the "Exploited" field in the Exploitability Assessment table as "Yes." On 2026-08-21, after The Hacker News contacted the company, Microsoft corrected that status to "No" and stated the vulnerability was not exploited in the wild. This is an important correction: initial reporting (including THN's own Daily Updates newsletter for that day) described it as exploited in the wild.

Microsoft said the issue was fully mitigated on its side and that no customer action is required. Microsoft credited principal security engineer Robert Fitzpatrick with discovery and reporting.
