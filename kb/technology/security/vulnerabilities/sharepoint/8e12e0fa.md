# SharePoint auth-bypass CVE-2026-55040 exploited after Rapid7 PoC release

CVE-2026-55040 (CVSS 9.1) is a critical security-feature-bypass in Microsoft SharePoint stemming from weak authentication that allows impersonation, enabling an attacker to disclose files and modify data (but not affect availability). Microsoft patched it in the July 2026 Patch Tuesday updates. Per Defused Cyber, threat actors began exploiting it in the wild after Rapid7 released a proof-of-concept exploit. It is the fifth SharePoint vulnerability exploited in 2026.
