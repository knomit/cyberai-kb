# SharePoint RCE CVE-2026-50522 under active exploitation

CVE-2026-50522 (CVSS 9.8), a critical deserialization-of-untrusted-data flaw in Microsoft Office SharePoint Server, came under active exploitation after a public proof-of-concept, per watchTowr. It allows a network attacker authenticated as at least a Site Owner to write and execute arbitrary code remotely. Microsoft patched it in the July 2026 Patch Tuesday update and credited DEVCORE researcher 'splitline' with discovery. It is the third SharePoint Server flaw from that update to be exploited.
