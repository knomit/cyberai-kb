# SharePoint RCE CVE-2026-45659 added to CISA KEV after active exploitation

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) added a high-severity remote code execution flaw in Microsoft SharePoint Server, tracked as CVE-2026-45659, to its Known Exploited Vulnerabilities (KEV) catalog on Wednesday, citing evidence of active exploitation in the wild. Reported by The Hacker News, July 2, 2026.
