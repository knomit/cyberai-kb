# CISA adds exploited SharePoint RCE zero-day CVE-2026-58644 (CVSS 9.8) to KEV

CISA added a newly patched Microsoft SharePoint Server flaw, CVE-2026-58644 (CVSS 9.8), to its Known Exploited Vulnerabilities catalog, requiring Federal Civilian Executive Branch agencies to patch by July 19, 2026. It is a critical deserialization-of-untrusted-data vulnerability allowing an unauthorized attacker to execute arbitrary code.
