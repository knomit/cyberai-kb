# Gogs CVSS 9.4 RCE: authenticated user executes code via malicious branch name in rebase merge (no CVE)

A critical RCE vulnerability (CVSS 9.4, no CVE identifier) was disclosed in Gogs, a popular open-source self-hosted Git service. Researcher: Jonah Burgess (Rapid7). The flaw: 'git rebase' accepts a --exec flag as a shell command executed after each commit replay. An authenticated user can create a pull request with a malicious branch name that injects the --exec flag into git rebase during the 'Rebase before merging' merge operation. This does NOT require admin privileges or interaction from other users. To exploit on any default-configured instance, all an attacker needs is to create an account and a repository — rebase merging is enabled by a single toggle in repository settings, and the owner is automatically the account creator. 'The entire exploit chain can be operated without interaction from any other user.' In an alternative scenario, any user with write access to a repo where rebase merging is already enabled can exploit directly. Rapid7 published a PoC video demo.
