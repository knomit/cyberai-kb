# Chrome 157 patches eighth actively exploited zero-day of 2026, CVE-2026-125350

Google on 2026-11-09 patched nine Chrome vulnerabilities incl. CVE-2026-125350, a use-after-free in the XML component exploited in the wild (reported 2026-11-06 by an anonymous researcher). Fixed in Chrome 157.0.8103.50/.51 (Windows/macOS) and .50 (Linux). Eighth exploited Chrome zero-day in 2026. Chromium-based browsers should apply fixes when available.
