# Chrome V8 type confusion zero-day CVE-2026-85046 exploited in the wild

Google shipped a Chrome stable-channel update on September 3, 2026 fixing 12 vulnerabilities, one of which, CVE-2026-85046 (CVSS 8.8, high severity), was already under active exploitation in the wild. It is a type confusion bug in V8, Chrome's JavaScript and WebAssembly engine, letting a remote attacker execute arbitrary code inside the Chrome sandbox via a crafted HTML page. Fixed in Chrome 152.0.7977.82/.83 for Windows and macOS and 152.0.7977.82 for Linux. Reported by researcher Salvatore Gulizia (Serotav) on August 4, 2026. CISA added the flaw to its Known Exploited Vulnerabilities catalog within hours of the advisory, with a September 18, 2026 remediation deadline for federal civilian agencies. This was the sixth Chrome zero-day Google fixed in 2026.
