# CVE-2026-87491: actively exploited Chrome V8 out-of-bounds write patched in Chrome 153

CVE-2026-87491 is an out-of-bounds write (CWE-787) in V8, Chrome's JavaScript and WebAssembly engine, reported by Jihyeon Jeong of Seoul National University. A remote attacker can execute arbitrary code inside the browser sandbox by delivering a crafted HTML page — the flaw does not by itself break out of the sandbox. Google classified it as medium severity but NVD-style scoring puts it at CVSS 8.8. Google stated it is aware an exploit exists in the wild. It was fixed in Chrome 153, shipped September 8, 2026: builds 153.0.8010.36 on Linux and 153.0.8010.36/.37 on Windows and macOS. It was the seventh actively exploited Chrome zero-day of 2026 and the second in under five days.
