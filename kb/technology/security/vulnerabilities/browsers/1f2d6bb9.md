# July 2026 browser and vendor patches: Firefox critical flaws with public exploit code

Mozilla released Firefox 152.0.6 fixing two critical vulnerabilities for which exploit code was publicly published (though no in-the-wild attacks were known at disclosure): CVE-2026-15718, an invalid pointer in the JavaScript/WebAssembly component, and CVE-2026-15719, a site-isolation flaw in the DOM Navigation component. Concurrently, Google shipped fixes for 15 Chrome security flaws, including two critical use-after-free bugs in Ozone (CVE-2026-15764 and CVE-2026-15765) — Ozone being the cross-platform abstraction layer Chrome uses to interact with display servers and windowing systems on Linux, ChromeOS, and Fuchsia. Adobe and VMware also issued fixes in the same window.
