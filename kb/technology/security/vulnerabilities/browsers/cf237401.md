# Zero-click Opera GX flaw allowed silent data theft

Researchers found a zero-click flaw in Opera GX (the gaming-focused Opera browser) that let a malicious website silently install a GX Mod add-on and exfiltrate data from pages the victim visits; a proof-of-concept reconstructed a signed-in user's full Gmail address from a single visit with no click. Opera patched it in Opera GX version 130.0.5847.89, found no evidence of exploitation in the wild, assigned no CVE, rated it P1 (top severity), and paid the maximum $5,000 bug-bounty award.
