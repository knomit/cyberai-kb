# Chrome V8 Zero-Day CVE-2026-11645 Actively Exploited (CVSS 8.8)

Google patched CVE-2026-11645, a high-severity V8 JavaScript engine zero-day (CVSS 8.8) in Chrome, as part of a 74-vulnerability release on June 9, 2026. The flaw is under active exploitation in the wild. V8 zero-days with active exploitation are a recurring pattern; this is the second Chrome zero-day in active exploitation in 2026.
