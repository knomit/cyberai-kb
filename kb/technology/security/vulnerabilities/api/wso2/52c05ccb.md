# CVE-2026-5430: WSO2 API Manager JWT signature bypass actively exploited for admin account takeover

watchTowr found active in-the-wild exploitation of CVE-2026-5430 (CVSS 9.8), an improper cryptographic signature verification / path traversal flaw in WSO2 API Manager allowing unrestricted file upload leading to remote code execution and JWT authentication bypass. Per WSO2's May 2026 advisory, JWT authentication can be bypassed when a token is signed using an unsupported algorithm, enabling unauthorized access up to full administrative account takeover. Affected products include WSO2 API Manager 4.1.0 through 4.6.0, WSO2 API Control Plane 4.5.0/4.6.0, WSO2 Traffic Manager 4.5.0/4.6.0 and WSO2 Universal Gateway 4.5.0/4.6.0. Hacktron Team was credited with discovery. watchTowr reported seeing exploitation attempts (including forged JWT tokens) against its honeypots since at least September 13, 2026. Note the gap between the May 2026 advisory and September 2026 exploitation — unpatched deployments are the exposure.

UPDATE: On Thursday September 24, 2026, CISA formally added CVE-2026-5430 to its Known Exploited Vulnerabilities (KEV) catalog based on evidence of active exploitation. In the same action, CISA also added CVE-2026-71362 (CVSS 9.1), an incorrect authorization vulnerability in Adobe Commerce and Magento allowing an attacker to gain elevated access to sensitive resources without user interaction.
