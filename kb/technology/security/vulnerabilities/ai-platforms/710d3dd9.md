# Xint: OpenAI compaction feature leaked hidden reasoning, fixed Oct 23

Security firm Xint showed OpenAI's compaction feature (shrinks long conversations) could be abused to extract a reasoning model's hidden reasoning in plain text, bypassing protections OpenAI added in August against reasoning theft. Tested on gpt-5.6-sol with researchers' own math/algorithm puzzles; Xint did not claim it exposed another user's reasoning. OpenAI confirmed and fixed it on October 23, 2026.
