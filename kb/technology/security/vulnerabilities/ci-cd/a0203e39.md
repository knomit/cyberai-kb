# Claude Code and Gemini CLI flaws let a GitHub issue reach CI workflow secrets

The Hacker News (Aug 7, 2026) reported that a GitHub issue opened by an account with no repository privileges was enough to execute code on the CI runners behind Anthropic's (Claude Code) and Google's (Gemini CLI) own coding-agent repositories; on OpenAI's repository it was enough to hijack the next workflow, exposing CI workflow secrets.
