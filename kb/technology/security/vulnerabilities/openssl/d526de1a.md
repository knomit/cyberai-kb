# OpenSSL CVE-2026-84782: DTLS resend flaw leaks heap memory unencrypted (Sep 29, 2026)

OpenSSL released fixes on 2026-09-29 for a High-severity DTLS flaw, CVE-2026-84782. When a resend starts while a larger handshake message is stuck part-way through being sent on a DTLS connection, the library can leak heap memory to the peer unencrypted or crash from a buffer overrun. Affected lines: 4.0, 3.6, 3.5, 3.4, 3.0, 1.1.1, 1.0.2. Fixed in 4.0.3, 3.6.5, 3.5.9, 3.4.8 (public); 3.0.23, 1.1.1zj, 1.0.2zs are premium-support only. OpenSSL reported no known exploits at disclosure. Action: patch software using DTLS (e.g. WebRTC data channels, UDP-based call encryption). Does not affect plain TLS-over-TCP-only use.
