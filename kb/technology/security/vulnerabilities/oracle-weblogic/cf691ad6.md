# CVE-2026-21962: max-severity Oracle WebLogic/HTTP Server flaw added to CISA KEV

CISA added CVE-2026-21962 (CVSS 10.0) to its Known Exploited Vulnerabilities catalog on Monday 2026-08-24, citing active exploitation. The flaw is an improper access control vulnerability in Oracle HTTP Server and the Oracle WebLogic Server Proxy Plug-in that lets an unauthenticated attacker with HTTP network access read, create, delete, or modify critical data. Oracle patched it in January 2026, but GreyNoise and CloudSEK have reported exploitation attempts since. In February 2026 a single IP (193.24.123.42) was seen probing it alongside Ivanti EPMM, GNU InetUtils and GLPI flaws; CloudSEK honeypots later captured attacks combining it with older WebLogic RCEs (CVE-2020-14882/14883, CVE-2020-2551, CVE-2017-10271). FCEB agencies must remediate under BOD 26-04.
