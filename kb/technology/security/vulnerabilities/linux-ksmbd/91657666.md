# Two CVSS 9.0 Linux KSMBD RCE flaws disclosed publicly before mainline fix

Trend Micro ZDI rated two KSMBD (Linux kernel SMB server) RCE flaws 9.0, disclosed on public mailing lists with no mainline kernel fix yet. ZDI-CAN-33774 is a pre-authentication race exposing any server running KSMBD on port 445. ZDI-CAN-33549 is an integer underflow in the SMB Direct path requiring an RDMA-capable interface (hardware or rxe), a writable KSMBD share and a client negotiating SMB Direct. Only systems running KSMBD are affected.
