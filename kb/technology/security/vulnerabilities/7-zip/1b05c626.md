# 7-Zip flaw CVE-2026-14266 allows code execution when extracting crafted XZ archives

A new 7-Zip vulnerability, CVE-2026-14266, is a heap-based buffer overflow in how the archiver processes XZ chunked data. Opening a crafted XZ archive in 7-Zip could let an attacker run code on the machine. The flaw was reported via Trend Micro's Zero Day Initiative.
