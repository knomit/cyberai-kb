# CVE-2026-12957: Amazon Q Developer ran malicious repo code via MCP config files

CVE-2026-12957 (CVSS 8.5), reported by Wiz Research and patched by Amazon, was a high-severity flaw in Amazon Q Developer (Amazon's AI coding assistant) in how it handled Model Context Protocol (MCP) servers. Amazon Q automatically read an MCP configuration file (.amazonq/mcp.json) from an opened workspace and launched the servers it defined, executing commands on the developer's machine. Those processes inherited the developer's full environment — AWS keys, cloud CLI tokens, API secrets, and SSH agent sockets — so a single malicious config file dropped in a repository could take a victim from 'git clone' to full cloud-credential compromise after the developer trusted the workspace.
