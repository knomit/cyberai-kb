# CVE-2026-85706: GitLab CVSS 10.0 unauthenticated arbitrary file read probed within hours of disclosure

CVE-2026-85706 is a path traversal issue in GitLab's repository commits API, scored CVSS 10.0, caused by improper path confinement combined with missing authentication enforcement in that API. Under certain conditions an unauthenticated user can read arbitrary files from the GitLab server, including log files and GitLab-specific configuration files, yielding credentials, secrets and other sensitive information. Affected are GitLab Community Edition and Enterprise Edition from 18.7 up to but not including 19.1.8, 19.2.6 and 19.3.2. GitLab disclosed and patched it on September 10, 2026; exposure management firm watchTowr observed in-the-wild probing beginning 06:00 UTC on September 11, 2026 - within hours of disclosure. The same release also patched CVE-2026-87719, a critical insecure deserialization bug in GitLab EE scored 9.9.
