# GitLab CVSS 10.0 path traversal probed within hours of disclosure

GitLab patched CVE-2026-85706 (CVSS 10.0), a path traversal in the repository commits API allowing unauthenticated arbitrary file read, affecting CE/EE versions 18.7 through 19.1.7, 19.2 through 19.2.5 and 19.3 through 19.3.1 (fixed in 19.1.8, 19.2.6 and 19.3.2). watchTowr observed active in-the-wild probing from 06:00 UTC on September 11, 2026, within hours of disclosure — the window between advisory and exploitation is now measured in hours, not days.
