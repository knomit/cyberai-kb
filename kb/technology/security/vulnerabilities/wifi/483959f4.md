# Unpatched Broadcom WPS flaw enables over-the-air root code execution on routers (no CVE yet)

Quentin Kaiser disclosed Oct 16, 2026 a flaw in Broadcom's WPS implementation (mishandled reassembly of fragmented setup messages) letting an attacker in radio range run code as root without the Wi-Fi password or pairing. Demonstrated on gateways from three Belgian ISPs. No CVE assigned and no fix deployed as of reporting.
