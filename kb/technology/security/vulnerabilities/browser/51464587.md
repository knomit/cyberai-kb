# CVE-2026-10702: Firefox JIT flaw enables drive-by code execution, also hit Tor Browser

Nebula Security disclosed CVE-2026-10702, a Firefox JIT vulnerability that gives arbitrary code execution inside the browser's renderer process and can be triggered simply by visiting a malicious webpage with no additional user interaction. Mozilla rated it High and fixed it in Firefox 151.0.3. Every Tor Browser release incorporating a vulnerable Firefox version was affected. On its own the bug runs only inside the sandboxed content process; Nebula used it as the first stage of 'IonStack,' a browser-to-kernel exploit chain demonstrated on an ARM64 device running Android 17. Nebula Security CEO Eten Zou provided details to The Hacker News.
