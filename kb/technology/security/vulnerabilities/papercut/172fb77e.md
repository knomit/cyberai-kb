# PaperCut auth bypass and RCE chained in sustained education-sector campaign

Attackers chained PaperCut NG/MF flaws CVE-2026-81578 (authentication bypass) and CVE-2026-82078 (remote code execution) to steal credentials and create privileged accounts, per Arctic Wolf, targeting K-12 schools and universities across the US and Europe. A suspected Russian-speaking actor used AI to build the exploits and compromised 440+ instances across the US, UK, France, Spain, Canada, Belgium, Portugal, Australia, Germany and Switzerland from IP 45.142.193[.]132. PaperCut subsequently released maintenance versions 26.0.5, 25.0.13 and 24.1.10 superseding three emergency patches.
