# Varonis discloses CoSnitch: three Microsoft Copilot Personal flaws enabling one-click data exfiltration

Varonis Threat Labs disclosed three vulnerabilities in Microsoft Copilot Personal, collectively named CoSnitch and tracked as CVE-2026-24301, that could allow a single click on a crafted link to silently pull data from connected apps and other information available in the victim's Copilot session. The chain turns in part on an undocumented URL parameter that the assistant itself surfaced during testing; researchers reached it by repeatedly asking Copilot why a prompt could not be made to run without user interaction. The research names Copilot Personal (the consumer assistant at copilot.microsoft.com) and does not state that Microsoft 365 Copilot was affected. Varonis reported the issue to Microsoft in December 2025; patches shipped 2026-08-18. No evidence of in-the-wild exploitation was found.
