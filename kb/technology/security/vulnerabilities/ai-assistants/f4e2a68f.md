# Atlassian Rovo AI assistant vulnerable to prompt-injection data exfiltration

Attacker-controlled instructions can trick Atlassian's Rovo AI assistant into collecting Jira or Confluence data that a signed-in user can access and sending it to an external attacker-controlled server. Two separate security firms independently discovered the behavior. Reported August 2026.
