# Critical ServiceNow AI Platform flaw CVE-2026-6875 exploited in the wild

Threat intelligence firm Defused Cyber reported in-the-wild exploitation of CVE-2026-6875 (CVSS 9.5), a sandbox-escape vulnerability in the ServiceNow AI Platform that allows an unauthenticated user to run arbitrary code. ServiceNow released patches throughout June 2026. Searchlight Cyber (which disclosed additional technical detail) reported the issue on April 1, 2026, and said it enables complete compromise of the ServiceNow instance and all connected proxy servers.
