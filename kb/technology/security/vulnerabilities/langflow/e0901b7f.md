# Langflow critical authenticated RCE (CVSS 9.9) exploited in 1,423 honeypot attempts

Previdian reported active exploitation of a critical Langflow flaw (CVE-2026-105740, CVSS 9.9) affecting versions prior to 1.9.0. Any authenticated Langflow user can achieve RCE by adding an MCP server with the 'stdio' transport: the user-supplied command field is passed to bash -c "exec {command}" with no validation, allowlisting or sandboxing, and executes when the server list is fetched. Langflow is an open-source AI/agentic-workflow builder whose parent DataStax was acquired by IBM in Feb 2025. Fix: upgrade to 1.9.0 or later. Pattern: MCP stdio server configs are an arbitrary-command surface.
