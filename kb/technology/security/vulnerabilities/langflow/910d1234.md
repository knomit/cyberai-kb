# Langflow 1.0.0-1.12.8 has two unauthenticated critical flaws (CVE-2026-93680, CVE-2026-110186); fix is 1.13.0

IBM's bulletin (Oct 28, 2026) lists Langflow flaws CVE-2026-93680 (CVSS 9.8, improper authentication, no account needed) and CVE-2026-110186 (9.8, arbitrary code via code generation, no account needed), plus CVE-2026-110193 (8.8, low-privileged account). All releases 1.0.0 through 1.12.8 are affected; only fix is 1.13.0. Not in CISA KEV as of Oct 30 update, though six other Langflow flaws are.
