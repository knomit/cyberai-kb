# Langflow path traversal CVE-2026-5027 under active exploitation

CVE-2026-5027 (CVSS 8.8) is a path traversal flaw in Langflow, an open-source low-code platform for building AI applications. The POST /api/v2/files endpoint does not sanitize the multipart 'filename' parameter, allowing an attacker to write files to arbitrary filesystem locations via '../' sequences, enabling unauthenticated RCE. Discovered by Tenable (disclosed March 27, 2026 after three contact attempts to maintainers) and reported under active exploitation in the wild by VulnCheck. Reported unpatched as of June 2026.
