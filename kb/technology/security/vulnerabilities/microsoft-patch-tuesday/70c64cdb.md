# Microsoft Patch Tuesday Oct 2026: record 1,413 flaws patched, one exploited Windows Shell bug

On Tuesday 2026-10-13 Microsoft shipped patches for a record 1,413 vulnerabilities, including 1,102 in Windows, and one flaw (Windows Shell) it said is under active exploitation. Operational consequence: prioritize applying this update, especially for the exploited Windows Shell bug.
