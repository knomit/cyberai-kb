# Broadcom patches three critical VMware flaws (auth bypass, RCE, VM escape)

Broadcom released updates for VMware ESX, vCenter, Workstation and Fusion, including three critical flaws: CVE-2026-59309 (CVSS 9.8), an authentication bypass in vCenter; CVE-2026-59310 (CVSS 9.8), a directory-traversal in vCenter allowing arbitrary code execution; and CVE-2026-47876, a VM escape where an attacker with local admin inside a VM using the VMXNET3 adapter can execute code on the ESX host. Broadcom found no evidence of in-the-wild exploitation but said there are no workarounds and flagged the updates as an emergency change.
