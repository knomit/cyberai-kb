# Linux KVM 'Januscape' flaw (CVE-2026-53359) enables guest-to-host VM escape

The Hacker News reported a 16-year-old use-after-free bug in Linux's KVM hypervisor, dubbed 'Januscape' and tracked as CVE-2026-53359. It can be triggered from a guest virtual machine to corrupt the shadow-page state of the host kernel, allowing a guest VM to escape to the host on both Intel and AMD x86 systems.
