# CVE-2026-60004: Gitea RCE via attacker-controlled Git hook, fixed in 1.27.1

CVE-2026-60004 (CVSS 9.8) is a remote code execution flaw in the self-hosted Git platform Gitea. A user with ordinary repository write access can turn attacker-controlled patch content into a live Git hook and run shell commands as the Gitea service account. It affects Gitea versions 1.17 and later before 1.27.1 and is fixed in 1.27.1. Because Gitea enables registration by default, an outside visitor can create an account and repository on an unchanged installation and exploit the bug without pre-existing credentials; disabling open registration mitigates. Gitea Cloud instances were auto-upgraded (July 27); the July 28 advisory includes public PoC code but does not report in-the-wild exploitation.
