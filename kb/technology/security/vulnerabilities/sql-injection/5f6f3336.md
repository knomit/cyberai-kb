# 'khunt' toolkit compiles Java inside Oracle to gain fileless SYSTEM access

Huntress documented a post-exploitation toolkit it tracks as 'khunt' used to turn Oracle SQL injection into Windows SYSTEM-level code execution without writing an executable to disk. Attackers exploited a SQL injection flaw in a public-facing web app (an autocomplete search field passed unvalidated input over a JDBC connection whose account could create Java objects), fed Java source code to the database, let Oracle compile it into stored schema objects, and ran commands from inside the database engine. Huntress investigated after credential-theft detections fired on July 27, 2026. No Oracle patch closes the application flaw or the account privilege issue.
