# N-able N-central 'Able2Shell': 33 zero-days with PoCs disclosed; hosted N-central taken offline

Researcher Sean Bales publicly disclosed over 30 N-central vulnerabilities (Able2Shell) with PoCs, tested on N-central Appliance 2026.4.0.31: credential disclosure, file write, traversal, XSS, XXE, RCE, including root command execution. N-able took Hosted N-central offline (Americas/APAC/Europe) and urged on-prem customers to shut down servers pending a hotfix. watchTowr observed exploitation attempts against honeypots overnight.
