# N-able N-central CVE-2026-86218 needed a fourth hotfix in five weeks

N-able shipped its fourth N-central hotfix in five weeks for CVE-2026-86218, a static code injection weakness (CWE-96) carrying a CVSS 4.0 score of 10.0 that permits remote code execution on the N-central server with no authentication and no user interaction. Every on-premises build below 2026.3.1.14 is affected, including servers that had applied Hotfix 3 only a day earlier; the fixed build shipped as 2026.3 Hotfix 4 in the early hours of September 6, 2026 UTC. N-able's own communications conflict on exploitation: its incident notice says the flaw has been exploited in the wild while its release notes call that unconfirmed. Because N-central is an MSP remote monitoring and management platform, an exposed instance gives an attacker a foothold into every downstream endpoint the MSP manages through it, not just the server itself.
