# Fastjson 1.x RCE exploited in the wild with no patch available

Security firms ThreatBook and Imperva report attackers are targeting a critical remote code execution flaw in Fastjson 1.x, Alibaba's JSON library for Java. In affected Spring Boot applications, a malicious JSON request can execute code without authentication; no patch was available at the time of reporting.
