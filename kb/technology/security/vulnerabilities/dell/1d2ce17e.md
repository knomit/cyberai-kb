# Dell Container Storage Modules critical flaws incl. two CVSS 10.0

Dell patched multiple critical flaws in Container Storage Modules (CSM): CVE-2026-63688 (CVSS 10.0, missing authentication in csm-authorization-storage gRPC server, exposes storage backend admin credentials for all registered arrays to unauthenticated remote attackers); CVE-2026-63692 (CVSS 10.0, missing authentication in authorization proxy and tenant service, enables admin-level privileges); CVE-2026-67269 (CVSS 9.9, improper privilege management in ContainerStorageModule Custom Resource reconciler, exploitable by low-privilege remote attacker; headline indicates root on Kubernetes nodes). Apply Dell's security updates.
