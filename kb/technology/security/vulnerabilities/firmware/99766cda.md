# EDK II 16-year-old UEFI flaw allows pre-boot code execution during network boot

Per The Hacker News (2026-10-28): a critical 16-year-old flaw in EDK II (open-source UEFI firmware base) lets an unauthenticated attacker hang the boot or, with firmware-build-specific work, run code before Secure Boot loads, but only while the machine is network-booting and the attacker can reach it (Red Hat and SUSE rate it adjacent-network exploitable). TianoCore published an advisory. Does NOT mean machines are remotely exploitable when not network-booting.
