# Binarly discloses six new U-Boot bootloader vulnerabilities

Firmware security firm Binarly found six new vulnerabilities in U-Boot, the bootloader used in devices ranging from home routers and smart cameras to data-center server management chips. Four bugs can crash a device; two allow an attacker who inserts a malicious image before the bootloader to run arbitrary code before software authenticity is verified. All six are triggered while U-Boot reads an untrusted image (such as a FIT package) before checking its signature, undermining the chain of trust for everything loaded afterward.
