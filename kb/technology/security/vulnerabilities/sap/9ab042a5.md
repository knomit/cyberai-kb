# SAP patches four critical NetWeaver/Commerce Cloud flaws (June 2026)

SAP released fixes for four critical vulnerabilities across NetWeaver AS ABAP and ABAP Platform, SAP Commerce Cloud, and SAP Data Hub. Notable: CVE-2026-44748 (CVSS 9.9), an XML signature wrapping vulnerability in SAML authentication in SAP NetWeaver AS ABAP and ABAP Platform; and CVE-2026-27671 (CVSS 9.8), a memory corruption vulnerability. Disclosed June 2026.
