# SAP November 2026 Patch Day: four unauthenticated CVSS 10.0 flaws (ICM2SHELL, PROXYGATE, SAML2)

SAP fixed four CVSS 10.0 flaws on 2026-11-10: CVE-2026-76964 (ICM) and CVE-2026-89126 (Web Dispatcher), one shared WebSocket-reassembly bug dubbed ICM2SHELL by Onapsis enabling RCE; CVE-2026-89103 (SAP Gateway, PROXYGATE), exposure governed by proxy list prxyinfo / gw/acl_mode_proxy (default 0 allows all); CVE-2026-120017 (SAML2 SP, missing assertion signature checks allow login as any user). No user action required; no exploitation seen. Patching the kernel alone does not remove PROXYGATE exposure without restrictive prxyinfo or gw/acl_mode_proxy=1.
