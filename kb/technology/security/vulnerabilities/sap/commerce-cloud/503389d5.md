# CVE-2026-58231: maximum-severity SAP Commerce Cloud RCE under active exploitation attempts

CVE-2026-58231 is a CVSS 10.0 vulnerability in SAP Commerce Cloud caused by insufficient authorization checks and input validation. Per CVE.org, it lets an unauthenticated attacker abuse a default authentication client and submit specially crafted input to functions lacking sufficient validation, potentially enabling arbitrary code execution and compromise of internal components. Threat intelligence firm Defused Cyber reported exploitation attempts hitting its honeypots roughly three days after the patch was released, with no public proof-of-concept available at the time. SAP security vendor Onapsis advises patching to fixed Commerce Cloud release levels and rebuilding/redeploying, with a temporary workaround of configuring an IP Filter Set to restrict access to the vulnerable endpoint.
