# WordPress Core RCE (4.7-7.1.3) exploited ~63,000 times in 24h after Oct 28 patch

A high-severity (CVSS 8.1) unauthenticated RCE with no CVE affects WordPress Core 4.7 through 7.1.3; patches were released Oct 28, 2026 and exploitation attempts (~63,000 in 24h) followed quickly. Wordfence: predictable, web-accessible staging paths during full-package core upgrades let attackers execute code, but only in a narrow window while WordPress unpacks a complete core update. Update WordPress core to the patched release.
