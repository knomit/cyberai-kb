# WordPress pre-auth XSS in login screen can chain to PHP code execution

WordPress fixed a pre-authentication reflected cross-site scripting (XSS) flaw in its login screen that affected every version of the CMS. Researchers at pwn.ai demonstrated how the flaw could be chained into PHP code execution. Users are urged to patch. Reported August 2026.
