# Drupal Commerce Core CVE-2026-118539 actively exploited; PHP2Shell tracking

Per The Hacker News (Oct 30, 2026): Drupal warned that missing authorization CVE-2026-118539 in Commerce Core (0.0.0-2.41 and 3.0.0-3.3.13) is actively exploited; fix is 3.3.13 or 8.x-2.41. Separately PHP flaws CVE-2026-109618/109619 (CVSS 9.2, 'PHP2Shell') see exploitation attempts; Wiz says organizations significantly affected fell to 52.1% as of Oct 25 because public PoCs are unreliable across PHP builds.
