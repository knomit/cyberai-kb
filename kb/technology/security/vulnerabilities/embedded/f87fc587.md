# GoAhead web server ignores CRL for revoked client certificates in OpenSSL mutual-TLS builds

Per The Hacker News (2026-10-28): GoAhead loaded a certificate revocation list but never enabled revocation checking, so revoked client certificates could authenticate in builds using the OpenSSL backend with mutual TLS and a configured CRL (not default builds). Fixed in GoAhead 6.1.1 (released to device makers Aug 2, public Oct 12, 2026). Found by Sebastien Fery of FoxIO; EmbedThis says GoAhead runs in hundreds of millions of devices.
