# Thermo Fisher patched DNA-analysis flaw CVE-2026-17583 enabling file tampering

Thermo Fisher Scientific patched a flaw (CVE-2026-17583) in select Applied Biosystems human identification software that could allow data files to be altered before the analysis software loads them, potentially making DNA file tampering nearly undetectable. The vendor issued a security bulletin dated July 31, 2026.
