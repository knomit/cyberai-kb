# NASA AIT-GUI flaw chain (GHSA-p9r8-2q67-fp86, CVSS 9.4) allows unauthenticated spacecraft commands

Cycode disclosed a chain of flaws in AIT-GUI, the browser-based operator console for NASA/JPL's open-source AMMOS Instrument Toolkit, allowing an unauthenticated attacker to issue arbitrary commands to the software's spacecraft and instrument command bus. The chain is tracked as GHSA-p9r8-2q67-fp86 and rated 9.4 on CVSS v3.1. It affects AIT-GUI versions 2.5.1 and earlier; version 2.5.2 is listed as the fixed release. The advisory was published August 13, 2026, and states that no CVE has been assigned. AMMOS Instrument Toolkit is a framework for building ground data systems that send commands to instruments and spacecraft and process returning telemetry.
