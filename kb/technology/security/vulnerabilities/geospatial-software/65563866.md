# GeoNetwork chained CVE-2026-63219 + CVE-2026-58400 gives unauthenticated RCE on geoportal backends

Two GeoNetwork flaws chain to unauthenticated remote code execution on the open-source geospatial metadata catalog. CVE-2026-63219 (CVSS 8.6) is a missing authorization check on the formatter upload endpoint, letting an anonymous user write arbitrary .xsl or .zip formatter files. CVE-2026-58400 (CVSS 9.1) is an unsafe Saxon XSLT processor configuration used to render formatters, so a loaded stylesheet can call java.lang.Runtime.exec() or ProcessBuilder and run OS commands as the GeoNetwork process user. The second flaw alone is scored as requiring high privileges; chaining removes that precondition because the upload is reachable without authentication. Attack flow: upload a malicious formatter, then issue a GET to a public record to trigger execution. Fixed in 4.4.12 and 4.2.17 (released 2026-07-08; advisories published 2026-08-31); all 4.4.x ≤ 4.4.11 and 4.2.x ≤ 4.2.16 are affected, and the chain is reachable from version 4.0.6 when the formatter endpoint was refactored and the authorization line dropped.
