# GeoServer SQL injection RCE was exploited within hours of disclosure

GeoServer patched a critical SQL injection vulnerability leading to remote code execution in versions 3.0.1, 2.28.5 and 2.27.6. No CVE identifier had been assigned at the time of reporting. watchTowr observed active exploitation within hours of public disclosure, with hundreds of attempts from a small pool of IP addresses. Maintainers said the flaw had been responsibly disclosed and was scheduled for the regular release cycle when details became public.
