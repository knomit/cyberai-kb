# Arista VeloCloud CVE-2026-16812 exploited

A maximum-severity flaw, CVE-2026-16812 (CVSS 10.0), an OS command injection in on-premises Arista VeloCloud Orchestrator (VCO), is under active exploitation in the wild. Per Arista's advisory, it lets a remote attacker access privileged internal functionality and compromise the VCO host and managed data; the functionality was intended for internal use only. Arista says the issue is already addressed in hosted and dedicated deployments.
