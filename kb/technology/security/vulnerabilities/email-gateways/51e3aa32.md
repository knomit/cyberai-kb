# CVE-2026-76461: Cisco Secure Email Gateway AsyncOS RCE exploited in the wild

Cisco disclosed on Monday September 14, 2026 that CVE-2026-76461, a critical flaw (CVSS 9.8) in AsyncOS Software for Cisco Secure Email Gateway, is under active exploitation in the wild. The root cause is insufficient validation in the email parsing logic: an unauthenticated remote attacker can send a crafted email containing malicious SQL statements through an affected device, causing arbitrary SQL execution that escalates to arbitrary command execution with root privileges on the underlying OS. Both physical and virtual Secure Email Gateway appliances are affected regardless of device configuration. Operators should treat any internet-reachable Secure Email Gateway as exposed and patch immediately; no configuration hardening mitigates it. This is a distinct product and CVE from the Cisco Nexus 9000 Silicon One issue (CVE-2026-20212).
