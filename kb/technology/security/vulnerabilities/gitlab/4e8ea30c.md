# Alpine Linux GitLab targeted via CVE-2026-97229 (CVSS 10.0) after upgrade failed to fix Ruby

Alpine Linux said on 2026-10-28 that an attacker tried to exploit CVE-2026-97229 (CVSS 10.0), a GitLab flaw allowing code execution via a crafted regular expression in a CI configuration, on its own GitLab server a week after the fix. No evidence it worked, but Alpine rebuilt the server and reset all passwords. GitLab's fix is patches to the Ruby it ships in its packages and images; Alpine's image used standard Ruby, so upgrading to GitLab 19.3.6 on 22 October did not fix it. Anyone running GitLab on their own Ruby also needs Ruby 3.3.13, 3.4.12, 4.0.9 or later: upgrading GitLab alone is not enough.
