# GitLab CVE-2026-110264: CVSS 10.0 unauthenticated RCE affecting all versions back to 7.0

GitLab released fixes on 2026-10-21 for CVE-2026-110264 (CVSS 10.0), which under unspecified conditions lets an unauthenticated user run arbitrary code on a self-managed server via an integer overflow while compiling a specially crafted regular expression. It affects every version back to 7.0 (2014). Administrators who patched on October 12 are NOT safe: that update covered only 19.2 and later and the new fixed versions sit one patch higher. As reported, no exploitation was known and it was not in CISA's KEV catalog. Action: upgrade self-managed instances to the new fixed patch release. (Distinct from the earlier GitLab path-traversal fact.)
