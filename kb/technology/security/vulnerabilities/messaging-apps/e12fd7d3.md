# Telegram Desktop HTML export injected script via unescaped inline-keyboard button text

ExPatch researchers Denis Rostilov and Aleksander Rostilov disclosed on September 12, 2026 that Telegram Desktop's chat-to-HTML export wrote bot inline-keyboard button text into the page without HTML escaping, while correctly escaping message text, sender names and other fields. A bot could place a script tag in a button's label padded with invisible characters so the button appeared empty in the client; the script executed only when a user opened the exported HTML in a browser, and could exfiltrate every message in the export to an attacker server or rewrite the page. The bot need not be in the target chat: a message whose only buttons are web links retains them when forwarded, so any member forwarding it carries the payload into a group, where it can sit in history for months before being exported. Reported to Telegram June 3, 2026 (two days after discovery); Telegram shipped a fix in July 2026, but the fix does not sanitize HTML exports produced by earlier versions — updating the app does not make pre-July export files safe to open.
