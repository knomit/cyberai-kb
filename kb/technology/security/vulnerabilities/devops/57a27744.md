# GitLab RCE PoC published for flaw patched six weeks earlier

Security researchers at depthfirst published working exploit code on July 24, 2026 for a GitLab flaw that GitLab had patched six weeks earlier on June 10. The exploit runs commands as the 'git' user on self-managed GitLab 18.11.3 servers meeting certain conditions.
