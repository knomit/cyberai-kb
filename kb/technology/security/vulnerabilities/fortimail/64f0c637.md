# FortiMail CVE-2026-104286 path traversal exploited; added to CISA KEV

CISA added Fortinet FortiMail flaw CVE-2026-104286 (CVSS 9.8) to its Known Exploited Vulnerabilities catalog on Thursday 2026-10-01 after reports of active exploitation. It is a path traversal (CWE-22) plus NULL byte neutralization (CWE-158) bug letting unauthenticated attackers write arbitrary files via crafted HTTP/HTTPS requests. Affected: FortiMail 8.0.0-8.0.1 (fix in upcoming 8.0.2+) and 7.6.0-7.6.6 (fix in upcoming 7.6.7+), plus 7.4.x per advisory. Patches were announced as upcoming at time of reporting.
