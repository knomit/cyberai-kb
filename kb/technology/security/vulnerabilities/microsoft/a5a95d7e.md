# Microsoft August 2026 Patch Tuesday: 398 flaws, Windows kernel zero-day exploited by Lazarus

Microsoft's August 2026 Patch Tuesday fixed 398 flaws. The only one flagged under active exploitation is CVE-2026-68820 (CVSS 7.0), a race-condition privilege-escalation bug in a core Windows kernel driver handling network socket operations, allowing local escalation to SYSTEM. Check Point Research says the Lazarus group used the zero-day in its Operation Dream Job campaign. Four other flaws in the release are exploitable with no account, password, or click, affecting Windows DNS Server and Windows Deployment Services among others.
