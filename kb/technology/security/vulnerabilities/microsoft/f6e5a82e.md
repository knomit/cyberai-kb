# BitLocker bypass YellowKey CVE-2026-45585 — Microsoft released mitigation

YellowKey (CVE-2026-45585, CVSS 6.8) is a BitLocker security feature bypass zero-day affecting Windows 11 (versions 24H2, 25H2, 26H1), Windows Server 2025. An attacker with physical access can bypass BitLocker Device Encryption to access encrypted data. Microsoft released a mitigation following public disclosure.
