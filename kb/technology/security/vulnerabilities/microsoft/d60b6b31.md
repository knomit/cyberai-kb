# Two Microsoft Defender zero-days actively exploited — CVE-2026-41091 and CVE-2026-45498

Microsoft disclosed two actively exploited Defender vulnerabilities: CVE-2026-41091 (privilege escalation to SYSTEM privileges) and CVE-2026-45498 (denial-of-service). These overlap with RedSun and UnDefend zero-days previously disclosed by Chaotic Eclipse (aka Nightmare-Eclipse).
