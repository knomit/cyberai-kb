# Microsoft's July 2026 Patch Tuesday fixed a record 622 CVEs including two exploited zero-days

Microsoft shipped its largest Patch Tuesday on record on 2026-07-14, covering 622 of its own CVEs by Security Update Guide count — more than triple June 2026's previous high of around 200. Two fixes address flaws already under active exploitation, both elevation-of-privilege bugs in identity and collaboration infrastructure rather than headline RCEs: CVE-2026-56164 in on-premises SharePoint Server (CVSS 5.3), which lets an unauthenticated attacker escalate privileges over the network with no user interaction (credited to Mandiant incident responders and Google's FLARE team), and CVE-2026-56155 in Active Directory Federation Services (CVSS 7.8), which lets an already-authenticated attacker elevate privileges locally via weak access controls (credited to Microsoft's own DART unit). CISA added both to its Known Exploited Vulnerabilities catalog, mandating that Federal Civilian Executive Branch agencies remediate by July 17 and July 28, 2026 respectively. Microsoft's advisory notes that enabling AMSI in Full Mode blunts the SharePoint attack. Rapid7's Adam Barnett observed that 'after years of relative stability, the Patch Tuesday process has experienced significant turbulence so far in 2026.'
