# CVE-2026-42897: actively exploited Outlook Web Access XSS on on-premise Exchange, used to plant the OWAReaper implant

CVE-2026-42897 (CVSS 8.1) is a cross-site scripting flaw in Microsoft Outlook Web Access, present in on-premise versions of Exchange Server. Microsoft disclosed it as a vulnerability already under active exploitation in the wild. It is triggered via a crafted email and requires no user interaction beyond receiving the message.

Exploitation: Russian threat actors — previously tied to a Zimbra zero-day — began exploiting the flaw on July 22, 2026, targeting US and European government, telecommunications, financial, hospitality and aerospace entities. The attack deploys OWAReaper, a previously unknown JavaScript browser-based implant that provides persistent webmail access. OWAReaper's persistence lives server-side: it survives credential rotation and full device re-imaging, and requires deliberate removal from the Exchange server. It abuses Outlook add-ins holding ReadWriteMailbox permission to steal OAuth tokens, and grants Owner-level permissions to the Default user on every mail folder.

Context: this continues the pattern of Exchange Server as a high-value, persistently exploited attack surface, consistent with Mandiant's M-Trends finding that exploits increasingly precede patches.
