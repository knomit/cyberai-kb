# SharePoint Server 2016 and 2019 reached end of extended support on July 14, 2026 with no paid ESU option

July 14, 2026 — the same day Microsoft disclosed the actively exploited SharePoint Server zero-day CVE-2026-56164 — was also the end of extended support for SharePoint Server 2016 and 2019. Unlike Windows Server or SQL Server, neither SharePoint version has a paid Extended Security Update (ESU) program to fall back on, leaving self-hosted operators of those versions without a vendor patching path. SharePoint has been a persistent attacker target since the ToolShell exploit chain tore through unpatched servers in 2025.
