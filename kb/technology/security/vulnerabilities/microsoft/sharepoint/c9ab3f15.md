# CVE-2026-58644: exploited SharePoint Server RCE added to CISA KEV

On 16 July 2026 CISA added CVE-2026-58644 to its Known Exploited Vulnerabilities catalog, requiring US Federal Civilian Executive Branch agencies to remediate by 19 July 2026. It is a critical (CVSS 9.8) deserialization-of-untrusted-data flaw in Microsoft SharePoint Server allowing remote arbitrary code execution. Microsoft's advisory notes an attacker authenticated as at least a Site Owner could write and execute arbitrary code remotely; the flaw is exploitable over the internet with low attack complexity (no significant prior knowledge of the system needed, and repeatable payload success).
