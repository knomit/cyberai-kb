# Public PoC released for critical libssh2 flaw CVE-2026-55200

A public proof-of-concept was released for CVE-2026-55200, a critical client-side flaw in libssh2 in which a malicious or compromised SSH server can trigger memory corruption on a connecting client, with possible code execution. No credentials are required.
