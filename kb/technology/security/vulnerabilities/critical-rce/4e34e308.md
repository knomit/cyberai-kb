# Critical Splunk Enterprise flaw CVE-2026-20253 allows unauthenticated RCE

Splunk (part of Cisco) released updates for CVE-2026-20253 (CVSS 9.8) in Splunk Enterprise. In versions below 10.2.4 and 10.0.7, an unauthenticated user could create or truncate arbitrary files via a PostgreSQL sidecar service endpoint that lacked authentication controls, enabling unauthenticated file operations and remote code execution. Fixed in 10.0.7 and 10.2.4; version 10.4 is not affected. Reported by The Hacker News, June 15, 2026.
