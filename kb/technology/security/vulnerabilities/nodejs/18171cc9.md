# Node.js 2026-10-21 security release fixes Brotli decoder RCE across supported lines

Node.js released security updates on 2026-10-21 for 22.x, 24.x and 26.x fixing 10 flaws; the most serious is a remote-code-execution bug in the bundled Brotli decompression code, reachable via node:zlib or fetch() on Brotli-compressed responses. Fixed versions: 22.23.4, 24.22.1, 26.12.1. Node.js 20.x and earlier are end-of-life and will not be patched, so must move to a supported line.
