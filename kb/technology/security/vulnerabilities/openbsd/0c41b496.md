# OpenBSD 7.9 root exploit chains 37-year-old shmat integer overflow with refcount UAF

Per The Hacker News (Oct 2026): Calif published a writeup and full PoC for a local privilege escalation to root on OpenBSD 7.9, chaining a ~37-year-old integer overflow in shmat(4) with a reference-counting use-after-free, bypassing KARL, SMAP and SMEP. Fixes: errata 018 (Sept 14, shipped as a reliability fix, also backported to 7.8) for the overflow and errata 026 (Sept 30, security fix) for the UAF; both available via syspatch on all architectures. Consequence: apply both errata; the overflow fix alone was not labeled a security fix.
