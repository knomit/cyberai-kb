# Gravity SMTP WordPress plugin flaw (CVE-2026-4020) actively exploited

Attackers are actively exploiting CVE-2026-4020 (CVSS 5.3), a medium-severity information-disclosure flaw in the Gravity SMTP WordPress plugin, installed on roughly 100,000 sites. Per Wordfence, a REST API endpoint at /wp-json/gravitysmtp/v1/tests/mock-data has a permission_callback that unconditionally returns true, letting unauthenticated visitors access it; appending ?page=gravitysmtp-settings populates internal connector data, exposing configuration data, API keys, secrets, and OAuth tokens for the plugin's email integrations.
