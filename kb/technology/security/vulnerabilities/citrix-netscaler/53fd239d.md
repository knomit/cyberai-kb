# CVE-2026-88779: NetScaler ADC/Gateway memory overflow exploited as zero-day (SAML SP/IdP precondition)

Citrix patched CVE-2026-88779 (CVSS 8.7), a memory overflow in NetScaler ADC and NetScaler Gateway exploited in targeted zero-day attacks; it can cause denial-of-service. Only customer-managed deployments configured as a SAML service provider (SP) or SAML identity provider (IdP) are exploitable. Action: check config for SAML SP/IdP entries and apply Citrix updates (CTX697174). Distinct from the earlier CVE-2026-88771/88772 NetScaler issues.
