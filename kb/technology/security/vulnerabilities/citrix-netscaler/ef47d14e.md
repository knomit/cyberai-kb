# Citrix NetScaler CVE-2026-88772 (CVSS 9.5) DTLS pre-auth overflow actively exploited

CVE-2026-88772 is a critical (CVSS 9.5) memory overflow in DTLS handshake handling in the NetScaler Packet Processing Engine (NSPPE) of Citrix NetScaler ADC and Gateway, reported as actively exploited in the wild. NetScaler trusts the declared fragment_length in the DTLS handshake header while processing a larger claimed message size, so crafted records can write ~174 KB into a 35,840-byte scratch buffer, giving pre-auth shellcode execution with root privileges. watchTowr published technical details (researcher Sina Kheirkhah) and a proof-of-concept repo; CISA tracks it as exploited. Action: patch NetScaler; public PoC lowers exploitation barrier. Complements the existing exploitation/CISA-deadline fact with the technical mechanism.
