# AnyPwn: public exploit for pre-auth AnyDesk Linux RCE giving root; fixed silently in 8.0.3

A full working exploit named AnyPwn, released on GitHub 2026-10-08, targets a heap buffer overflow in AnyDesk's session protocol on Linux for pre-authentication remote code execution as root before any connection is approved. AnyDesk patched it in version 8.0.3 in June 2026, but the changelog said only 'fixed a bug that could lead to a crash'; no CVE or security advisory. The exploit works only over direct TCP connections on port 7070 and is probabilistic (needs a target object adjacent to the overflowed buffer, otherwise the service crashes). Action: update AnyDesk Linux to at least 8.0.3; latest is 8.1.0. Does not affect already-patched versions.
