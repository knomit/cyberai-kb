# Linux CVE-2026-31431 'Copy Fail': local privilege escalation to root on major distributions

A high-severity Linux local privilege escalation (LPE) vulnerability, tracked as CVE-2026-31431 (dubbed 'Copy Fail'), was disclosed, allowing an unprivileged local user to obtain root access on major Linux distributions. Corroborates pattern of infrastructure-level vulnerabilities that could affect AI workloads running on Linux servers.
