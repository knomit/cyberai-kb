# cPanel CVE-2026-58048 lets authenticated users run SQL as database root

cPanel patched CVE-2026-58048 (CVSS 4.0 score 9.4), a critical flaw allowing an authenticated hosting customer with access to the MySQL/MariaDB feature to execute arbitrary SQL in the database's root context, crossing the privilege boundary between a cPanel account and the server's administrative database identity. The vendor warned this 'may extend to operating-system-level compromise' depending on OS and DB engine configuration. It affects all supported versions of cPanel & WHM and WP Squared, and was fixed in builds 11.110.0.137, 11.118.0.71, 11.126.0.78, 11.134.0.48, 11.136.0.32, and 138.1.6 (WP Squared). Reported by The Hacker News, Aug 4, 2026.
