# CVE-2026-65400: macOS Screen Sharing auth bypass exploited to install Monero miners

CVE-2026-65400 (CVSS 9.8) is a critical authentication flaw in the macOS Screen Sharing component that lets a network-adjacent attacker authenticate to the built-in remote desktop service without valid credentials. It was fixed in an emergency update across macOS Tahoe 26.6.1, Sequoia 15.7.9 and Sonoma 14.8.9. NCSC-NL reported active abuse across multiple systems with port 5900 exposed to the internet, in which attackers gained root and placed a Monero cryptocurrency miner.
