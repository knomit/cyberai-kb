# Cloudflare fixed a container-isolation flaw exposing other customers' leftover disk data

A flaw in Cloudflare Containers (and Cloudflare Sandboxes, which runs on Containers and is used to run untrusted code including AI-agent-written code) let a paying customer read data left behind on shared servers by other customers' earlier containers -- not from any live workload, and an attacker could not choose whose data they received. The issue stemmed from how each container's disk was provisioned on shared infrastructure that Cloudflare, not the customer, assigns. It was reported to Cloudflare's bug bounty program on September 4, 2026 by researcher Oren Yomtov of security firm Accomplish; Cloudflare has fixed it across its service and says customers need to take no action.
