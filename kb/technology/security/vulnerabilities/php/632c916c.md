# PHP2Shell: two critical PHP RCE flaws, emergency release Oct 21 2026

PHP announced an out-of-cycle security release at 14:00 UTC on 2026-10-21 for two critical flaws rated CVSS v4.0 9.2, dubbed PHP2Shell; watchTowr says both allow remote code execution. Only supported branches 8.2-8.5 get fixes; no exploitation reported at the time of writing. A leak claimed CVSS 10.0, all versions since PHP 5 and disclosure Oct 22; identifiers circulating are CVE-2026-109618 and CVE-2026-109619, but PHP's notice names neither and the PHP 5-onward scope is unconfirmed by an official advisory. THN noted a single INI setting passed around as a workaround is not sufficient alone. Confirm affected/fixed versions in the official advisory.
