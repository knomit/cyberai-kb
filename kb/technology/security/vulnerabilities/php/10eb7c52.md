# PHP advisory CVE-2026-115560: second unpatched RCE risk after PHP2Shell fixes

On 2026-10-23 PHP published an informational advisory for CVE-2026-115560, a separate code-execution risk affecting only web applications configured in an unusual way (involving session upload progress); PHP considers it unlikely and issues no emergency fix, recommending disabling the session upload progress feature until a fix ships in the next routine release. It is NOT fixed by the Oct 21 emergency releases (PHP 8.5.12, 8.4.27, 8.3.36, 8.2.35) that patched the critical PHP2Shell flaws CVE-2026-109618 and CVE-2026-109619. Patching to those versions does not remove this risk.
