# PHP rebuilt Windows packages for Brotli flaw CVE-2026-111497

PHP rebuilt its official Windows packages (8.5.12-1, 8.4.27-1, 8.3.36-1, 8.2.35-1) to fix CVE-2026-111497, a memory-corruption/potential code execution flaw in the bundled Brotli library; the packages now include Brotli 1.2.1. It is reachable through the cURL extension only when automatic HTTP response decompression is enabled (off by default in cURL, but apps/HTTP client libraries can enable it). This is the second Windows security update in five days, following Oct 21 releases fixing two PHP2Shell remote code execution flaws; those fixes remain.
