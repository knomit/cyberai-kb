# CVE-2026-21589: critical (9.3) Atlassian Data Center unauthenticated file read across 8 products

Atlassian disclosed CVE-2026-21589 on 2026-10-05, rated 9.3, affecting 8 self-hosted Data Center products: an unauthenticated attacker can read specific files in a product's web application root directory but must already know the exact file name and path (cannot list the directory). Cloud products are already patched. Atlassian advises taking unpatched instances offline if possible, especially internet-reachable ones. Does NOT allow arbitrary directory listing.
