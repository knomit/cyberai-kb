# Atlassian Data Center CVE-2026-21589 (CVSS 9.3) exploited within two hours

CVE-2026-21589 is an unauthenticated arbitrary file access flaw (CVSS 9.3) in Bitbucket, Confluence, Jira Service Management, Jira Software, Bamboo and Crowd Data Center, Crucible and Fisheye; exploitation needs the exact file name/path and cannot list directories. Atlassian Cloud is patched; fixed DC versions released (e.g. Confluence DC 9.2.26/10.2.19). Mitigations: remove from public internet, WAF rule, block via Tomcat RewriteValve, urlrewrite.xml rule for Bitbucket. Previdian saw 15 exploitation attempts from 3 IPs (Japan, US) within two hours of public details.
