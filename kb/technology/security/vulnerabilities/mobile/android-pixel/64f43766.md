# CVE-2026-58704: Pixel Cellular Modem privilege escalation under limited targeted exploitation

Google disclosed in a September 2026 advisory that CVE-2026-58704, a high-severity privilege escalation flaw (CVSS 8.0) in the Pixel Cellular Modem, may be under limited, targeted exploitation in the wild. Per NIST NVD, the bug is a permission bypass caused by a logic error that permits remote (proximal/adjacent) escalation of privilege with no additional execution privileges and no user interaction. Google did not name the threat actor or describe the attacks. The same September 2026 Pixel update addressed 109 other security flaws.
