# Pillow CVE-2026-112900: OS command execution via EPS/Ghostscript, fixed in 13.0.0

Pillow (Python image library, ~436M downloads/month per OX Security) CVE-2026-112900: opening EPS images passes the file name to Ghostscript without validation, so an attacker-chosen name can be interpreted as instructions and run commands. Fixed in Pillow 13.0.0 (released October 16, 2026). Exposure includes upload forms, thumbnail tools, PDF pipelines and ML projects. Action: upgrade to 13.0.0+.
