# CVE-2026-8037: Progress Kemp LoadMaster pre-auth root RCE (CVSS 9.8)

CVE-2026-8037 is a critical (CVSS 9.8) flaw in Progress Kemp LoadMaster allowing an unauthenticated attacker to run arbitrary commands as root via a crafted API request when the API is enabled. It affects GA v7.2.63.1 and older and LTSF v7.2.54.17 and older; fixed in GA v7.2.63.2 and LTSF v7.2.54.18. The bug is in the escape_quotes() input-sanitization function. Reported via ZDI on April 15, 2026; advisory published June 4; watchTowr Labs published a technical exploit write-up on June 29, 2026. No in-the-wild exploitation reported.
