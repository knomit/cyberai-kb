# CVE-2026-67401: cPanel EmailTrack SQL injection gives a mail-privileged account root code execution

CVE-2026-67401 is a SQL injection in the EmailTrack mail delivery report of cPanel/WHM that chains to arbitrary file write and then code execution as root. An authenticated hosting account holder with mail-related privileges can create files of their choosing anywhere on the server and from there run code as root, collapsing the tenant-isolation boundary that shared hosting depends on — mail privileges are among the most widely granted permissions on a shared host, included even in cheap reseller plans. cPanel published the advisory on September 8, 2026 and says every supported version of cPanel and WHM is affected; the CVE record published September 9, 2026 scores it 9.9. Fixed builds are 11.110.0.143, 11.134.0.55, 11.136.0.39, 11.138.0.4, and WP Squared 11.138.1.9.
