# LMCache unauthenticated RCE CVE-2026-105192 (CVSS 9.8), no fixed version

JFrog disclosed on 2026-10-07 a critical RCE, CVE-2026-105192 (CVSS 9.8), in LMCache (open-source KV cache that accelerates LLM servers such as vLLM). It affects versions 0.3.9 through 0.5.5 in multiprocess mode, where the cache runs as a standalone server reached over ZeroMQ; a single network message can run commands as the LMCache process user. Remote exploitation requires the operator to bind the server to a routable address (default is localhost). No fixed version was available at disclosure; mitigation is keeping it bound to localhost/not network-exposed.
