# LiteLLM CVE-2026-42271 Added to CISA KEV: Unauthenticated RCE Under Active Exploitation

CISA added CVE-2026-42271, a high-severity flaw in BerriAI LiteLLM, to its Known Exploited Vulnerabilities (KEV) catalog due to active exploitation. The vulnerability chains to unauthenticated remote code execution. LiteLLM is a widely-deployed open-source proxy/SDK used to route requests across multiple LLM providers, making it a high-value target in AI-powered enterprise infrastructure.
