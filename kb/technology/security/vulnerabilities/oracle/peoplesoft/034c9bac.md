# ShinyHunters exploits Oracle PeopleSoft zero-day CVE-2026-35273 (CVSS 9.8)

The ShinyHunters extortion crew (tracked by Google Mandiant as UNC6240) exploited CVE-2026-35273, an unauthenticated remote code execution flaw in Oracle PeopleSoft Enterprise PeopleTools rated CVSS 9.8, between May 27 and June 9, 2026. Oracle did not publish its advisory until June 10, 2026, so it was a zero-day throughout the campaign, which hit universities hardest. The bug requires no login or user interaction—only HTTP network access—and sits in the Updates Environment Management component; exposure stems from an internet-reachable Environment Management Hub. Update (Sept 2026): Mandiant reported a renewed wave of mass exploitation by the same UNC6240/ShinyHunters-linked activity targeting multiple sectors globally (beyond the original academic-sector focus). The group updated its exploit to bypass web application firewall (WAF) rules that had been blocking earlier attack attempts, and is now deploying web shells after gaining access. Consequence: WAF rules alone are no longer sufficient mitigation; patching/upgrading remains necessary even for organizations that added WAF blocking after the original disclosure.
