# ShinyHunters exploits Oracle PeopleSoft zero-day CVE-2026-35273 (CVSS 9.8)

The ShinyHunters extortion crew (tracked by Google Mandiant as UNC6240) exploited CVE-2026-35273, an unauthenticated remote code execution flaw in Oracle PeopleSoft Enterprise PeopleTools rated CVSS 9.8, between May 27 and June 9, 2026. Oracle did not publish its advisory until June 10, 2026, so it was a zero-day throughout the campaign, which hit universities hardest. The bug requires no login or user interaction—only HTTP network access—and sits in the Updates Environment Management component; exposure stems from an internet-reachable Environment Management Hub.
