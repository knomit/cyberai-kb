# Tailscale 1.104.4 patches SSH server privilege flaws

Per The Hacker News (2026-10-28 digest summary): Tailscale released version 1.104.4 to fix flaws in its built-in SSH server that could let an attacker reach services and files on other servers that only root should access. Operators should update to 1.104.4 or later. Based on the digest excerpt only; full article not read.
