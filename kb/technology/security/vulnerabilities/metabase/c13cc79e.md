# Metabase zero-day (CVSS 10.0) exploited in the wild for unauthenticated SQL injection

A maximum-severity zero-day (CVSS 10.0, no CVE assigned) in the Metabase business-intelligence software was exploited in the wild. It lets an unauthenticated remote attacker inject arbitrary SQL into the Metabase application database, gaining administrator access, which enables changing configuration, stealing stored credentials for connected databases, and reading/exporting any accessible data. Framework was among the affected companies.
