# Metabase zero-day (CVSS 10.0, no CVE assigned) exploited in the wild for unauthenticated SQL injection to admin access

Metabase warned in August 2026 that a maximum-severity flaw (CVSS 10.0) in its business-intelligence and data-visualization software was exploited in the wild as a zero-day. NO CVE WAS ASSIGNED.

MECHANISM: an unauthenticated remote attacker can inject arbitrary SQL into the Metabase application database, thereby gaining administrator access without authentication.

CONSEQUENCES once administrator access is obtained: changing configuration, stealing stored credentials for connected databases, and reading or exporting any accessible data. The stored-credential exposure is the part that extends the blast radius beyond Metabase itself — a BI tool holds connection credentials for every database it reports on.

Framework was among the affected companies.
