# Two unpatched Kaltura mwEmbed deserialization flaws allow unauthenticated file read and RCE

CERT/CC disclosed CVE-2026-19913 (arbitrary file read) and CVE-2026-19912 (remote code execution) in Kaltura's mwEmbed HTML5 player library, also distributed as html5lib. Both stem from the same unsafe PHP deserialization in the mwEmbedLoader.php endpoint: the ServiceUrl parameter is used as the backend API target, and KalturaClientBase fetches whatever that URL returns and passes it to unserialize() without validating source, scheme, or content. Neither flaw requires authentication or a Kaltura session token; network access to the endpoint is the only precondition. No patch was available at disclosure and CERT/CC said it was 'unable to reach Kaltura to coordinate these vulnerabilities.' Because the endpoint is also exposed on Kaltura's shared multi-tenant CDN infrastructure, CERT/CC says every tenant on those hosts is affected, not just self-hosted customers. Mitigation advised: restrict or disable external access to the endpoint and enforce a strict allow-list for ServiceUrl. As of 2026-08-25 neither CVE appeared in CISA's KEV catalog and no exploitation had been reported.
