# Unpatched GeoServer zero-day SQL injection under active exploitation

A newly disclosed zero-day in the open-source GeoServer software — an SQL injection vulnerability that had not yet been assigned a CVE identifier — is seeing active exploitation attempts and can lead to remote code execution (RCE), according to watchTowr (reported by The Hacker News, Aug 14, 2026).
