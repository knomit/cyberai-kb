# ChatGPhish: ChatGPT Markdown trust exploited for prompt injection phishing via web summaries

Cybersecurity researchers disclosed a vulnerability in OpenAI ChatGPT that leverages the AI assistant's implicit trust in Markdown links and images to trigger prompt injections, turning ChatGPT's web summary feature into a phishing surface. The attack is called ChatGPhish. When ChatGPT summarizes a web page, it renders Markdown content from the page — including attacker-controlled Markdown links and images — and the AI implicitly trusts these, enabling prompt injection attacks that can redirect users to malicious sites or exfiltrate information.
