# Critical Zimbra Classic Web Client stored XSS enables code execution

Zimbra urged customers to patch a critical stored cross-site scripting (XSS) vulnerability in its Classic Web Client. A specially crafted email, when opened, could run malicious scripts in the victim's session, potentially exposing mailbox information, session data, or account settings. As of the July 2026 disclosure it had not yet been assigned a CVE identifier.
