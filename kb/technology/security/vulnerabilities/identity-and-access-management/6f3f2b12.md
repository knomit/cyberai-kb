# Critical Keycloak flaw CVE-2026-18963 (CVSS 9.1) allows unauthenticated account takeover via password reset

Red Hat and the Keycloak project patched a critical flaw in the open-source identity and access management server that lets an unauthenticated remote attacker take over any user account by forcing a password reset. CVE-2026-18963 is rated 9.1 CVSS by Red Hat (the CNA for the flaw) and classified as CWE-640, weak password recovery mechanism for a forgotten password. The root cause is improper state validation within the reset-credentials authentication flow. Upstream Keycloak users should update to version 26.7.2, released August 19, 2026; Red Hat build of Keycloak customers should apply updates shipped for 26.4.15 and 26.6.6. As of August 24, 2026 there was no evidence of exploitation and no verified public exploit.
