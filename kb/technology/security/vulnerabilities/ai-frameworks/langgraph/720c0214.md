# LangGraph SQLi-to-RCE vulnerability chain (CVE-2025-67644, CVE-2026-28277)

Check Point disclosed three now-patched flaws in LangGraph, LangChain's open-source framework for stateful multi-agent AI applications. The chain can yield remote code execution on self-hosted servers. CVE-2025-67644 (CVSS 7.3) is a SQL injection in LangGraph's SQLite checkpoint implementation that lets attackers manipulate queries via metadata filter keys (affects langgraph-checkpoint-sqlite before 3.0.1). CVE-2026-28277 (CVSS 6.8) is an unsafe msgpack deserialization flaw. Disclosed via THN edition Jun 12, 2026.
