# APT flaw CVE-2026-109518 lets MitM swap verified packages and run code as root

Debian, Ubuntu and APT developers published advisories Nov 4 2026: an attacker who can modify package downloads can swap a checked package for their own, running code as root. Requires APT retrying failed downloads, default from Debian 12 and Ubuntu 22.04 onward; older releases (Debian 11, Ubuntu 20.04) are not exposed by default but may be if scripts set Acquire::Retries. Debian released fixed APT; Ubuntu/Ubuntu Pro updates rolling out.
