# LibreOffice/OpenOffice spreadsheet code-exec flaws without macro warning (Java enabled)

A malicious spreadsheet can run attacker code on open in LibreOffice and Apache OpenOffice with no macro-style warning, only when Java support is enabled; PoC only, no known in-the-wild use. LibreOffice fixed CVE-2026-63277 on 2026-10-05 (upgrade to 26.2.5 or 26.8.0). Apache OpenOffice CVE-2026-59265 is unfixed in all versions through 4.1.16; fix expected in 4.1.17.
