# CIFSwitch: Linux LPE (since 2007) via logic flaw in CIFS client and cifs-utils; patch May 19 2026

A newly disclosed Linux local privilege escalation (LPE) vulnerability dubbed CIFSwitch allows low-privileged users to gain root access by abusing a logic flaw between the Linux kernel Common Internet File System (CIFS) client and the userspace helper package cifs-utils. Discovered by SpaceX security engineer Asim Viladi Oglu Manizada. The kernel-side bug has been present since 2007 (~19 years). A patch was pushed to mainline Linux on May 19, 2026.
