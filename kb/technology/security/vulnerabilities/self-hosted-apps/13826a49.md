# Nextcloud servers backdoored with web shells via Collabora Built-in CODE Server app flaw

Attackers exploited a critical flaw in the optional Nextcloud app 'Collabora Online - Built-in CODE Server' to plant web shells on Nextcloud servers; three administrators reported the issue on GitHub. Only Nextcloud instances with that optional app installed are affected, not Nextcloud core in general. Details beyond the newsletter excerpt were not captured.
