# Android Framework flaw CVE-2025-48595 under active exploitation

Google's June 2026 Android security update patched 124 vulnerabilities, including CVE-2025-48595 (CVSS 8.4), a high-severity privilege-escalation flaw in the Framework component requiring no user interaction. Google indicated it may be under limited, targeted exploitation. It affects Android 14, 15, 16, and 16 QPR2.
