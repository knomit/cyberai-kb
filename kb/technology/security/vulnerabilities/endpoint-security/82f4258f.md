# FalconFlank PoC claims unpatched local privilege escalation in CrowdStrike Falcon

Researcher Chaotic Eclipse (also known as INFINITE NIGHTMARE, MSNightmare, Nightmare-Eclipse) publicly released FalconFlank, a proof-of-concept privilege escalation exploit against the CrowdStrike Falcon sensor on Windows. The claimed attack path abuses Falcon's Microsoft Office suspicious-macro removal remediation, which runs with elevated privileges and is alleged to handle attacker-controlled files unsafely, letting a lower-privileged local user get the security agent to act on their behalf; the C++ PoC exercises named pipes, reparse points, and DLL operations. As of September 3, 2026 CrowdStrike had not confirmed the flaw, assigned a CVE, issued a CVSS score, or shipped a fix; CrowdStrike advised customers to disable the 'Microsoft Office File Suspicious Macro Removal' Windows policy setting and said the Cloud Anti-malware for Microsoft Office Files settings still provide protection. Because this is a vendor-unconfirmed researcher claim, treat the technical details as unverified.
