# runZero discloses seven vulnerabilities in FatFs filesystem library

Security firm runZero disclosed seven vulnerabilities in FatFs, a small filesystem library that reads/writes FAT and exFAT formats on USB drives and SD cards. FatFs ships in firmware for security cameras, drones, industrial controllers, and hardware crypto wallets running real-time operating systems. On worst-affected systems, an attacker with a booby-trapped USB drive, SD card, or update file can corrupt memory and run code. Because many embedded devices lack memory protections, runZero says 'any physical access leads to a jailbreak.'
