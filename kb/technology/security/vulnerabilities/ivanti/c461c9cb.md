# Ivanti Sentry critical RCE CVE-2026-10520 and auth bypass CVE-2026-10523

Ivanti patched two critical flaws in Ivanti Sentry (formerly MobileIron Sentry): CVE-2026-10520 (CVSS 10.0), an OS command injection allowing remote unauthenticated root-level RCE via the /mics/api/v2/sentry/mics-config/handleMessage endpoint (detailed by watchTowr Labs); and CVE-2026-10523 (CVSS 9.9), an authentication bypass letting an unauthenticated attacker create arbitrary admin accounts. Fixed in R10.5.2, R10.6.2, and R10.7.1. Disclosed June 2026.
