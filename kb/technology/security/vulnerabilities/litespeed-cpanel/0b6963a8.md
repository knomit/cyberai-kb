# CISA adds LiteSpeed cPanel plugin flaw CVE-2026-54420 to KEV catalog

CISA added CVE-2026-54420 (CVSS 8.5), a privilege-escalation flaw in the LiteSpeed cPanel plugin, to its Known Exploited Vulnerabilities (KEV) catalog, setting a June 18, 2026 remediation deadline for Federal Civilian Executive Branch agencies. The LiteSpeed cPanel plugin before 2.4.8 (distributed in LiteSpeed WHM PlugIn before 5.3.2.0) mishandles symlinks supplied by a user with FTP or web-shell access on shared hosting servers running CloudLinux/CageFS, allowing escalation to root. The exact in-the-wild exploitation method was not publicly known at disclosure.
