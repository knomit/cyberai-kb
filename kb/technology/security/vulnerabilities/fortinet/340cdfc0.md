# FortiSandbox command injection CVE-2026-25089 (CVSS 9.1)

Fortinet patched CVE-2026-25089 (CVSS 9.1), an OS command injection (CWE-78) in the FortiSandbox, FortiSandbox Cloud, and FortiSandbox PaaS web UI. An unauthenticated attacker can execute unauthorized commands via specially crafted HTTP requests. Affected: FortiSandbox 5.0.0–5.0.5 (fix 5.0.6+), 4.4.0–4.4.8 (fix 4.4.9+), and Cloud/PaaS 5.0.4–5.0.5 (fix 5.0.6+). Disclosed June 2026.
