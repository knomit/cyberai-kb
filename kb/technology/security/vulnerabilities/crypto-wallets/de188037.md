# 'Ill Bloom' wallet flaw drains over $5M in crypto

Per The Hacker News, security firm Coinspect disclosed a cryptocurrency wallet flaw it calls 'Ill Bloom' that attackers are already exploiting to drain over $5 million. The flaw lies in how some wallet software generated its recovery phrase (seed words).
