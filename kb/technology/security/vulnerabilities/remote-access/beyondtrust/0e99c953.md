# BeyondTrust patches two critical auth-bypass flaws in Remote Support and PRA

BeyondTrust released updates addressing two critical security flaws affecting its Remote Support (RS) and Privileged Remote Access (PRA) products which, if exploited, could allow unauthenticated attackers to gain access, according to The Hacker News.
