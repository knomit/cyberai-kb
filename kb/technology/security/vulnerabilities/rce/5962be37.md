# Bing Images SVG flaw ran commands as SYSTEM on Microsoft servers

A crafted SVG submitted to Bing's image search ran commands as NT AUTHORITY\SYSTEM on Microsoft's production image-processing workers, and as root on the Linux machines in the same fleet. The finding was reproduced in testing by security firm XBOW. Reported by The Hacker News, July 2026.
