# AI-assisted Linux kernel root exploit CVE-2026-53264

STAR Labs published a Linux kernel exploit for CVE-2026-53264 (CVSS 7.8), a use-after-free race in the kernel's network traffic-control (tc) subsystem, granting local privilege escalation to root on CentOS Stream 9. Researcher Lee Jia Jie said AI helped find the bug and speed up exploit development. It requires unprivileged user namespaces and CONFIG_NET_ACT_GACT/CONFIG_NET_CLS_FLOWER; the upstream fix landed June 1, 2026 and was backported to stable branches. This is local priv-esc, not remote code execution.
