# Pattern: 2026 Linux LPEs poison cached file-backed binary memory to gain root without touching disk

Two distinct Linux kernel local privilege-escalation vulnerabilities disclosed in June 2026 — 'pedit COW' (CVE-2026-46331, an act_pedit out-of-bounds write) and 'DirtyClone' (CVE-2026-43503, in the DirtyFrag family, via cloned network packets) — share a common exploitation pattern reminiscent of the original Dirty COW: corrupt shared/file-backed page-cache memory to overwrite the in-memory copy of a setuid-root binary such as /bin/su, then run the altered image as root. Because the on-disk file is never modified, file-integrity checks pass while the attacker already holds root. Both abuse the kernel networking/traffic-control subsystems and had public working exploits within days of disclosure, indicating page-cache/COW poisoning of privileged binaries is a recurring, high-reliability LPE technique defenders should expect.
