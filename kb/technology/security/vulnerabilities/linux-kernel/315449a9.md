# AI-found Linux vhost flaw (CVE-2026-74580, 'Vghost') gives local root, conditional VM escape

A flaw in Linux's vhost subsystem lets a local user read and write kernel memory at will and become root across nearly a decade of kernel versions; in one virtualization setup it lets an untrusted VM break out to the host. Found by AI. Tracked as CVE-2026-74580 per third-party coverage. The guest-to-host escape is conditional on the virtualization setup, not universal.
