# CVE-2026-89775: ARM64 KVM nested-virt flaw gives guests read-write host memory access

CVE-2026-89775 is a Linux kernel KVM flaw on ARM64 that leaves freed host memory exposed to a guest VM, allowing the guest to read and write host kernel memory and escape to run code on the host. Exploitation requires BOTH ARM64 hardware with Armv8.4 FEAT_NV2 AND nested virtualization enabled (off by default; an experimental boot-time mode). Fixed in Linux 6.18.51, 7.2.5 and 7.3-rc1. Red Hat lists its RHEL 10 kernel as affected and RHEL 6-9 as not affected. Where any user can open /dev/kvm (the RHEL default), a local user could build a guest and use the bug to gain root.
