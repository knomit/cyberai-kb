# PwnEscape (CVE-2026-99999): Linux kernel networking flaw lets guest VMs read host memory

PwnEscape, CVE-2026-99999, is a critical Linux kernel networking-code flaw letting code inside a VM send crafted packets to read host memory, crash the host, and run code on it. Paulos Yibelo of pwn.ai demonstrated it against Vercel's live cloud sandboxes (Vercel confirmed); found in a Vercel security challenge, reported privately; no sign of in-the-wild exploitation. The bug is in the kernel, not any cloud's configuration, so it hits the shared isolation layer providers use.
