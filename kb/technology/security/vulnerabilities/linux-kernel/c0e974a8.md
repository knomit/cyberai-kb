# Bad Epoll (CVE-2026-46242) Linux kernel privilege escalation flaw

A Linux kernel use-after-free flaw named Bad Epoll (CVE-2026-46242) lets an unprivileged local user gain root. It affects Linux desktops, servers, and Android, and a fix has been released. The bug is in the epoll subsystem where two parts of the kernel try to clean up the same internal object concurrently, corrupting kernel memory. It was found by researcher Jaeyoung Chung, who built a working exploit; notably the flaw sits in the same region of kernel code where Anthropic's AI model 'Mythos' had recently found a different bug but missed this one.
