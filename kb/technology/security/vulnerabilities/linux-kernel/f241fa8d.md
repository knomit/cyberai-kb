# Linux kernel TCP race flaw CVE-2026-98432 (CVSS 9.8) lacks Ubuntu/RHEL fixes

Per The Hacker News (Oct 29-30, 2026): CVE-2026-98432 is a use-after-free race in IPv4 TCP connection setup (introduced in Linux 4.4; IPv6 unaffected), rated 9.8 by the kernel CVE team while Red Hat, Amazon, Oracle and SUSE score it 5.9-8.1. Anthropic said Oct 27 its AI model wrote an exploit giving unauthenticated remote root on servers with an MPTCP listener (Go 1.24+ requests MPTCP by default on listening sockets). As of Oct 29 Debian, Oracle Linux, SUSE (some) and Amazon Linux shipped fixes; Ubuntu and RHEL had not.
