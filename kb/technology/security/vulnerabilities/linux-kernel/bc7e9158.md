# GhostLock (CVE-2026-43499) 15-year-old Linux kernel root flaw

Nebula Security disclosed GhostLock (CVE-2026-43499), a Linux kernel privilege-escalation flaw present by default in essentially every mainstream distribution since 2011. Any logged-in local user can gain full root using ordinary threading calls — no special permissions, settings, or network access. Nebula built a working exploit that is 97% reliable and also escapes containers, published the exploit code, and received a $92,337 award through Google's kernelCTF bug-bounty program. No in-the-wild exploitation was known at disclosure; patching is the priority.
