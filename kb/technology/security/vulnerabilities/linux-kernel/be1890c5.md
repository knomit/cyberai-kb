# OVSwrap Linux kernel flaw enables local privilege escalation to root

A memory-corruption flaw (OVSwrap) in the Linux kernel's Open vSwitch datapath gives ordinary local users a path to root on a broad set of default-configured distributions. A public exploit ships with pre-built records for reliable exploitation.
