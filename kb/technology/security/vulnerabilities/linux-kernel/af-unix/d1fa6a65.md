# CVE-2026-80521: AF_UNIX GC use-after-free enables container escape to host root; Ubuntu LTS unpatched with public exploit

CVE-2026-80521 (CVSS 7.8) is a use-after-free in the Linux kernel's AF_UNIX socket garbage collector that DepthFirst showed (Sept 22, 2026) can escape a container and gain host root. Fixed upstream Aug 6, 2026, but Ubuntu had not shipped patches for 26.04, 24.04 or 22.04 LTS (including AWS/Azure/GCP kernel packages for 24.04/22.04). DepthFirst released exploit code targeting Ubuntu 26.04. The exploit uses ordinary syscalls containers are allowed, so namespaces, cgroups and seccomp do not stop it. No workaround published; not on CISA KEV and no confirmed attacks at the time.
