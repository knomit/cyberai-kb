# CVE-2026-46331 'pedit COW': Linux kernel privilege escalation via cached-binary poisoning

CVE-2026-46331, nicknamed 'pedit COW', is an out-of-bounds write in the Linux kernel's traffic-control packet-editing action (act_pedit) that corrupts shared page-cache memory and lets a local unprivileged user gain root. Red Hat rates it 'important'. A public working exploit appeared within a day of the CVE assignment on June 16, 2026. The exploit never writes to disk: it poisons the in-memory cached copy of a setuid-root binary (/bin/su), injects a payload, and runs the altered image as root, so file-integrity checks stay clean. Exploitation requires act_pedit to be loadable and unprivileged user namespaces enabled (granting namespace-local CAP_NET_ADMIN); both conditions were present on tested RHEL and Debian systems.
