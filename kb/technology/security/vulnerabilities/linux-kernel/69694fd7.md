# 18-year-old Linux SCTP use-after-free enables root and container escape

The Hacker News (Aug 7, 2026) reported a use-after-free vulnerability in the Linux kernel's SCTP networking code that has existed since ~2008. It can be exploited by a local user to gain full root on the host, and Tencent researchers demonstrated using it to escape a container and reach the underlying machine.
