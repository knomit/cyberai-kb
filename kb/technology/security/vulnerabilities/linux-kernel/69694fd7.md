# 18-year-old Linux SCTP use-after-free enables root and container escape

A use-after-free bug in Linux's SCTP networking code, present since roughly 2008, can be exploited to gain full root on a host. Tencent researchers reported using it to escape a container and reach the underlying machine. Reported August 2026.
