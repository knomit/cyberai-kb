# RefluXFS (CVE-2026-64600): 9-year-old Linux XFS flaw gives local root on default RHEL

RefluXFS, a Linux kernel flaw disclosed on July 22, 2026 and tracked as CVE-2026-64600, lets an unprivileged local user overwrite root-owned files on an XFS filesystem and gain persistent root access. The bug is roughly nine years old. Qualys reported that default Red Hat Enterprise Linux (RHEL) installations are affected.
