# FreeIPA CVE-2026-76578 chained with 389-ds flaw yields anonymous admin Kerberos credentials

Red Hat tracks CVE-2026-76578 (CVSS 9.8, critical) in FreeIPA, which lets a client that has never authenticated create a Kerberos identity of its own choosing in the directory and end up in the administrators group. The attack requires chaining two things together: FreeIPA's overly permissive self-service OTP token access-control rule, AND CVE-2026-76560 (CVSS 7.5) in 389 Directory Server, where an anonymous client can satisfy an ownership check when the owner field is empty. Researchers reproduced the attack against a default FreeIPA deployment and obtained reusable administrator Kerberos credentials; in SID-enabled environments PAC-bearing tickets may also be obtainable, expanding access to HTTP and Dogtag services. RHEL 7, 8, 9 and 10 IPA/IdM components are affected. The FreeIPA project fixed its side in version 4.13.4; the 389 Directory Server side is a separate fix, so patching FreeIPA alone does not address CVE-2026-76560.
