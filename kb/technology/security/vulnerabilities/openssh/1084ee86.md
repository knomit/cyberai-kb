# OpenSSH SSHole (CVE-2026-123158): password-less account login on musl without PAM

CVE-2026-123158 (CVSS 8.1, 'SSHole') affects OpenSSH on Linux using the musl C library with PAM disabled, including Alpine Linux's default OpenSSH server config. An unauthenticated attacker can send an oversized password to sign in to accounts configured without usable passwords. Found by Ozgun Kultekin; fixed in OpenSSH 10.6p2; root cause traces to a 2016 username-enumeration patch (CVE-2016-6210). Previdian reports exploitation attempts within hours of disclosure, including root on a honeypot. Affects only the musl + PAM-disabled combination, not all OpenSSH installs.
