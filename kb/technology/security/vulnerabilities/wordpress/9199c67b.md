# Bricksforge WordPress plugin CVE-2026-85097 (CVSS 10.0) unauthenticated RCE exploited

CVE-2026-85097 (CVSS 10.0) in the Bricksforge WordPress plugin lets unauthenticated attackers upload and execute arbitrary PHP, giving RCE. Affects versions up to and including 3.1.8.9; fixed in 3.1.8.10. Patchstack detected exploitation on 2026-10-07 21:47 UTC. Root cause per Patchstack: MIME type is validated at first upload but, on later form submission, the plugin trusts client-supplied file metadata. Consequence: update to 3.1.8.10 or later.
