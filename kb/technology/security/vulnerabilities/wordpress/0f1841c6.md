# CVE-2026-93485 'Comment2Shell': WordPress core stored XSS via anonymous comment escalates to RCE through admin session

WordPress fixed CVE-2026-93485 ('Comment2Shell', Patchstack CVSS 7.1) on Sept 17, 2026 in version 7.1.1. An anonymous comment could plant a hidden script that runs when a logged-in administrator views the page, leading to server code execution. Root cause: comments are sanitized when saved but reformatted when displayed, and the flaw sat in the gap between those steps. Affects sites using block themes (default since Twenty Twenty-Two) and some classic themes that use the same formatting step (e.g., Twenty Twenty-One). WordPress said exploitation is 'subject to comment approval', but the researcher described bypasses of the approval hold, so moderation is NOT a reliable mitigation. No known exploitation and not on CISA KEV as of Sept 22, 2026.
