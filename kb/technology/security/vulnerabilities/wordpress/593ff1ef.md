# Elementor CSRF flaw: attacker-controlled query string bypasses Editor Events auth check

The Elementor Website Builder WordPress plugin had an unassigned-CVE CSRF vulnerability in its Editor Events module: because the module skipped CSRF protection for requests whose signed content includes the full request URI (including the query string), and the query string is written by whoever composes the link, an attacker could craft a link that, once clicked by a logged-in admin, forges requests across the entire REST API surface of the site (both WordPress core routes and plugin routes) with no other prerequisite (e.g. no JavaScript execution needed). Only Elementor Pro releases from 4.3.0 onward (which ship the Editor Events proxy) are affected; it was fixed in version 4.3.2 following responsible disclosure via Patchstack.
