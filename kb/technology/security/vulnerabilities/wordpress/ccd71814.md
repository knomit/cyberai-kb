# WordPress CVE-2026-119977: installing the core-update fix can expose sites via wp-content/upgrade

Picus Security researcher Umut Bayram found that WordPress sites can still be attacked while installing the fix for the actively exploited CVE-2026-119977 (affects WordPress 4.7 through 7.1.3). During a core update with a complete package, WordPress unpacks a copy of the new version, including the installer, into a temporary folder in wp-content/upgrade, using the site's old unpatched code; an unauthenticated attacker who learns the folder name and reaches the installer before it is deleted can run code on the server. Recommended mitigation: block web access to wp-content/upgrade before updating. CISA added the flaw to its known-exploited list (per the article). Does not mean already-patched sites are exposed.
