# wp2shell: pre-authenticated RCE in WordPress Core disclosed by Searchlight Cyber

Searchlight Cyber disclosed 'wp2shell,' a pre-authenticated remote code execution vulnerability in WordPress Core that can be exploited anonymously on a standard WordPress installation without requiring any plugins or special conditions. It is a combination of CVEs; as of July 18, 2026 the flaws carry CVE IDs, the full mechanism has been published, and a working proof-of-concept is public.
