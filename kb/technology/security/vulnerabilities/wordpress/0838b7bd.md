# Elementor Pro CVE-2026-32475 (CVSS 9.0) enables unauthenticated RCE via double file-part upload

Patchstack disclosed a critical unrestricted file upload vulnerability in the Elementor Pro WordPress plugin, tracked as CVE-2026-32475 with a CVSS score of 9.0. The flaw is in the Forms module's File Upload field, where the extension check and the file-move step run in two separate loops with different handling of empty file entries. By submitting two file parts for the same field, an unauthenticated attacker skips the extension blocklist entirely and writes a PHP file into a public directory, turning a restricted upload field into an unauthenticated remote code execution primitive.
