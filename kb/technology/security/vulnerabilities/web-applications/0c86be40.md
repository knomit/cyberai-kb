# CVE-2026-14863: FileRun thumbnail extractor command injection

VulnCheck disclosed CVE-2026-14863 (CVSS 8.7), an OS command injection flaw in FileRun leading to remote code execution. FileRun's thumbnail extractors build shell commands by pasting the uploaded file path into a double-quoted string passed to exec(), and the filename sanitizer permits $(), so a file named $(payload).mp4 executes its payload when a thumbnail is generated. Any authenticated user with upload permission gets code execution, and where a public file request weblink exists, anyone knowing its token can too. Affected versions up to and including 2026.2.0; fixed in 2026.2.1.
