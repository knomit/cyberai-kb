# Critical Gitea flaw allows unauthenticated file reads via Org-Mode markup

A critical flaw in Gitea, the self-hosted Git platform, lets an unauthenticated attacker read any file the service account can access, using crafted Org-Mode markup in a public repository. It affects versions 1.22.1 through 1.27.0 and requires no login or repository write access.
