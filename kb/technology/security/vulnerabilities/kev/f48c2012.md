# CISA adds Collabora Online CODE Server (CVE-2026-110447) and Arista VeloCloud Orchestrator (CVE-2026-114625) to KEV

CISA added two actively exploited critical flaws to its Known Exploited Vulnerabilities catalog: CVE-2026-110447 (CVSS 9.2), OS command injection in Collabora Online Built-in CODE Server (richdocumentscode) when used in Nextcloud, allowing RCE via proxy.php when the CODE local document server isn't running (fixed September 2026 in 26.4.303); and CVE-2026-114625 (CVSS 9.9), SQL injection in on-premise Arista VeloCloud Orchestrator allowing access to privileged internal functions (fixed October 2026). Reported by The Hacker News 2026-10-24.
