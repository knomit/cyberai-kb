# Check Point patches actively exploited SmartConsole auth-bypass CVE-2026-16232

Check Point released updates for its Security Management and Multi-Domain Management products, including CVE-2026-16232 (CVSS 9.3), an authentication bypass in the SmartConsole login process that lets an unauthenticated remote attacker obtain an application login token and authenticate with full administrative privileges. Check Point said a handful of customers were targeted in the wild and were notified.
