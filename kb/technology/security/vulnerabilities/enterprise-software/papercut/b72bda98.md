# PaperCut NG/MF auth bypass chained with RCE against schools and universities

Arctic Wolf's Adversary Research Team observed threat actors chaining two newly disclosed PaperCut NG/MF vulnerabilities — CVE-2026-81578 (authentication bypass) and CVE-2026-82078 (unsafe dynamic class loading leading to remote code execution) — against print-management servers in the education sector across the U.S. and Europe, from K-12 schools through universities. Post-exploitation activity included reconnaissance commands, creation of a privileged account named Administrator17, downloading credential-harvesting tools via certutil, Meterpreter Java payloads for remote sessions, searching PaperCut configuration files for passwords, secrets, LDAP settings and tokens, and data staging. PaperCut disclosed active exploitation on August 27, 2026 and CISA added both CVEs to its Known Exploited Vulnerabilities catalog on August 31, 2026. No CVSS scores were stated in the reporting.
