# PaperCut NG/MF: two chained flaws (CVE-2026-81578 auth bypass + CVE-2026-82078 RCE) exploited in the wild, August 2026

MERGED from two records of the same August 2026 PaperCut exploitation. They describe the same two-flaw chain from different angles — one supplies the CVE identifiers and the observed post-exploitation commands, the other the authorization-logic mechanism and the vendor response. Nothing from either is dropped.

THE CHAIN. Threat actors are chaining two flaws in PaperCut NG and PaperCut MF to execute arbitrary code on susceptible instances. CVE-2026-81578 allows AUTHENTICATION BYPASS; from there an attacker EDITS A CONFIGURATION FILE to exploit CVE-2026-82078 for REMOTE CODE EXECUTION. This is per Jake Knott, head of threat intelligence at watchTowr, speaking to The Hacker News.

THE MECHANISM. Huntress researchers John Hammond and Andrew Brandt described the result as giving an unauthenticated attacker remote control over PaperCut's trusted configuration, enabling execution of arbitrary JAVA CODE INSIDE THE APPLICATION'S PROCESS. The technique abuses a request that references ONE PAGE FOR RENDERING THE RESPONSE and ANOTHER PAGE OWNING THE COMPONENT OR ACTION BEING EXECUTED — so PaperCut's authorization check trusts the rendered page and MISSES THE PERMISSIONS REQUIRED BY THE COMPONENT BEHIND IT.

OBSERVED EXPLOITATION. Huntress observed LIMITED exploitation in TWO CUSTOMER ENVIRONMENTS, with attackers executing Base64-encoded commands on the targeted server as part of post-exploitation activity to determine user account and operating system, using the chained command 'whoami & ver'.

VENDOR RESPONSE. PaperCut released an emergency fix with additional hardening; the security bulletin is dated 27 August 2026.

WHAT THIS DOES NOT MEAN:
- 'Exploited in the wild' here rests on TWO OBSERVED CUSTOMER ENVIRONMENTS reported by one vendor (Huntress). It is not a measured prevalence figure and should not be cited as widespread compromise.
- The authentication bypass is what makes the chain UNAUTHENTICATED. Neither flaw alone is described as reaching code execution from an unauthenticated position.
- This record does NOT supersede the earlier-stage disclosure snapshot at kb/technology/security/vulnerabilities/active-exploitation/f5f2b480.md, which records the point at which PaperCut had announced active zero-day exploitation across ALL NG and MF versions with the flaw details undisclosed, and which carries the published indicators of compromise (suspicious pc-app.exe post-exploitation activity; missing, truncated, or deleted server.log files; specific server.log error strings). That snapshot is the IoC source and is deliberately kept separate.
