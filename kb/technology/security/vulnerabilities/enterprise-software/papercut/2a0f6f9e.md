# PaperCut NG/MF unauthenticated RCE chain actively exploited (Aug 2026)

In August 2026, attackers were observed exploiting a newly patched flaw in PaperCut NG and PaperCut MF to execute arbitrary code on vulnerable instances; PaperCut released an emergency fix with additional hardening (security bulletin dated 27 August 2026). Huntress researchers John Hammond and Andrew Brandt described it as giving an unauthenticated attacker remote control over PaperCut's trusted configuration, enabling execution of arbitrary Java code inside the application's process. The technique abuses a request that references one page for rendering the response and another page owning the component or action being executed, so PaperCut's authorization check trusts the rendered page and misses the permissions required by the component behind it. Two flaws are chained to reach unauthenticated code execution.
