# PaperCut NG/MF auth bypass chained with RCE in sustained education-sector campaign (2026)

Arctic Wolf's Adversary Research Team observed threat actors chaining two newly disclosed PaperCut NG/MF vulnerabilities — CVE-2026-81578 (authentication bypass) and CVE-2026-82078 (unsafe dynamic class loading leading to remote code execution) — against print-management servers in the education sector across the U.S. and Europe, from K-12 schools through universities.

Post-exploitation activity included reconnaissance commands, creation of a privileged account named Administrator17, downloading credential-harvesting tools via certutil, Meterpreter Java payloads for remote sessions, searching PaperCut configuration files for passwords, secrets, LDAP settings and tokens, and data staging.

Attribution and scale: a suspected Russian-speaking actor used AI to build the exploits and compromised 440+ instances across the US, UK, France, Spain, Canada, Belgium, Portugal, Australia, Germany and Switzerland, operating from IP 45.142.193[.]132.

Timeline and remediation: PaperCut disclosed active exploitation on 2026-08-27; CISA added both CVEs to its Known Exploited Vulnerabilities catalog on 2026-08-31. PaperCut subsequently released maintenance versions 26.0.5, 25.0.13 and 24.1.10, superseding three earlier emergency patches. No CVSS scores were stated in the reporting.
