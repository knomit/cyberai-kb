# CVE-2026-12569: CISA adds actively exploited PTC Windchill RCE to KEV catalog

On Thursday June 25/26, 2026, CISA added CVE-2026-12569 (CVSS 9.3) — a critical remote code execution flaw in PTC Windchill PDMLink and PTC FlexPLM enterprise PDM/PLM software — to its Known Exploited Vulnerabilities (KEV) catalog, citing active exploitation. The bug is an improper-input-validation issue exploitable via deserialization of untrusted data, allowing arbitrary code execution through a malicious network request. Although PTC released patches the prior week, as of June 25 it confirmed continued heightened threat activity, with unknown attackers exploiting the flaw to deploy JSP web shells.
