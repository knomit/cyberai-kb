# CVE-2026-58231: maximum-severity SAP Commerce Cloud RCE hit honeypots three days after patch

CVE-2026-58231 is a CVSS 10.0 vulnerability in SAP Commerce Cloud arising from insufficient authorization checks and input validation: an unauthenticated attacker can abuse a default authentication client and submit crafted input to functions lacking validation, enabling arbitrary code execution and compromise of internal components. Defused Cyber observed exploitation attempts against its honeypots merely three days after the patch was released, despite no public proof-of-concept existing at the time.
