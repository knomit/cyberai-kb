# PaperCut shipped maintenance releases superseding three emergency patches for CVE-2026-81578 and CVE-2026-82078

PaperCut released a security maintenance release on September 10, 2026 that replaces all previously published emergency patches for two flaws under active exploitation in the wild. CVE-2026-81578 and CVE-2026-82078 are being chained to bypass authentication and execute arbitrary code. The fixed builds are PaperCut NG/MF 26.0.5, 25.0.13 and 24.1.10. The maintenance releases contain every security fix issued in Emergency Patch Releases 1, 2 and 3, plus additional security hardening, so customers on any of the emergency patches should still move to the maintenance release rather than treating the emergency patch as final. These are the same flaws an AI-agent-driven campaign used to compromise 440+ PaperCut instances.
