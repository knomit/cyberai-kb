# SolarWinds ARM CVE-2026-28326: hard-coded static key enables unauthenticated RCE, fixed in ARM 2026.2.1

SolarWinds published an advisory on 2026-09-17 for CVE-2026-28326, a high-severity unauthenticated remote code execution vulnerability in Access Rights Manager (ARM) rated 8.8 out of 10.0 on CVSS. The root cause is a hard-coded static key. The flaw affects all versions of Access Rights Manager 2026.2 and prior, and is patched in ARM 2026.2.1. SolarWinds credited Armadin security researcher Kai Huang with discovery and reporting, and makes no mention of exploitation in the wild. Context: this follows by nearly two months SolarWinds' fixes for a critical Web Help Desk flaw, CVE-2026-28323, CVSS 9.8. Operational consequence: because the vulnerability requires no authentication and stems from a static key shared across installations, upgrading to 2026.2.1 is the remediation — access controls or network restrictions in front of ARM do not address the underlying key.
