# Unpatched Unisoc T612 modem flaw chains with RCE to gain Android kernel privileges via video call

Researchers disclosed a new unpatched flaw in Unisoc T612 modem firmware that, chained with a previously disclosed and also unpatched remote code execution vulnerability, could grant elevated access to the Android kernel. The exploit requires first delivering a malicious payload to the phone's modem via the RCE flaw, then placing a video call the victim must answer. SSD Secure Disclosure explained that by disabling protections on the first memory region (ID 0) of the Memory Protection Unit, an attacker gains unrestricted read and write access to physical memory, enabling local privilege escalation including modification of kernel code.
