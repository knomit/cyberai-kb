# Chinese actor uses leaked DarkSword kit to deploy GHOSTBLADE on iOS

An unknown Chinese-speaking threat actor was observed targeting Apple iOS devices using a publicly leaked version of the DarkSword full-chain exploit kit to deploy an implant called GHOSTBLADE. Attack-surface firm Censys (researcher Aidan Holland, analysis July 31, 2026) identified the actor running 100+ web properties, mostly fake AWS sign-in pages, on a domain that also hosts the exploit toolkit, with hosting concentrated in Hong Kong and reaching Japan, the U.S. and Europe. DarkSword was previously detailed by Google Threat Intelligence Group (GTIG), iVerify and Lookout as a kit used by commercial surveillance vendors and suspected state actors.
