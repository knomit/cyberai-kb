# Claude Code 'don't ask again' approvals leak secrets into 1,122 public settings.local.json copies

Apiiro reported (Nov 2026) that when a Claude Code user picks 'Yes, and don't ask again', the assistant can save the approved command word-for-word, including any password or API key typed in it, into the project file .claude/settings.local.json. Apiiro found 1,122 public GitHub copies of that file containing at least one secret; it did not test whether the secrets still work, though one notified company confirmed its key was live. Deleting the file from a project does not undo the leak because older versions persist in git history and forks. Consequence: rotate every credential the file has ever held first, then clean up; do not treat file removal as remediation.
