# CrowdStrike 2026 Threat Hunting Report: AI agents cut exploit time to hours

CrowdStrike released its 2026 Threat Hunting Report on August 3, 2026. Key findings: cloud-focused cybercrime rose 171% year-over-year; AI agents set off 2.5x more security alerts than human users; and 88% of known software flaws are now attacked within two days of public release, challenging the traditional 30-day patch window. CrowdStrike's Adam Meyers said the vulnerability-to-exploit window has shrunk from months to hours, and that AI systems are now both hacking tools and targets (model access, API keys, agent permissions).
