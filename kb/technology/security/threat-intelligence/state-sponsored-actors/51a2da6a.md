# A Midnight Blizzard-matching operation used Claude to rebuild malware in a loop until it evaded detection

Anthropic disrupted a cyber espionage operation whose tradecraft and targeting match the Russian state-nexus group tracked as Midnight Blizzard. The operators used Claude to monitor whether their malware evaded security products; when a tool was flagged, AI agents automatically modified, rebuilt and redeployed it, repeating until detection stopped. Anthropic argues this 'closes the loop' faster than defenders can develop and deploy controls. The same actor compromised at least three hospitality vendors operating hotel guest Wi-Fi and used stolen admin credentials to redirect guest traffic via DNS hijacking in a campaign called CaptiveCrunch, bulk-exported mailboxes at drone component manufacturers, and stole a complete SDK for a drone vision system. Anthropic's broader conclusion is that AI has collapsed the skill gap that distinguished state-sponsored hackers from low-skill operators, so sophistication is 'no longer a reliable signal of who is behind an operation', and that security through obscurity is no longer viable because unique and obscure configurations are made clear and exploitable by AI.
