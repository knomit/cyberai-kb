# WhatsApp help pages hid instructions telling support chatbot not to point users to privacy regulators

Redact found hidden text in WhatsApp help-page code (removed by Oct 18, 2026) instructing WhatsApp's AI support chatbot not to recommend a data protection authority to users unable to delete accounts, and another block saying not to cite privacy laws like GDPR once a user mentions a lawyer, lawsuit or court. Unknown whether the chatbot followed them (Redact read the instructions, not answers). WhatsApp told WIRED it was a bug, now fixed. Contradicts WhatsApp's own European privacy policy, which says users can complain to a regulator.
