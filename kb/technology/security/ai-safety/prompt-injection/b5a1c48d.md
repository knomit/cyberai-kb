# Microsoft 365 Copilot for Word can self-propagate hidden prompt injections

Researcher Håkon Måløy disclosed (July 28, 2026, 144 days after reporting) that hidden instructions in a Word document can make Microsoft 365 Copilot rewrite report figures and copy the same instructions into the generated file, which then re-triggers the behavior in a later Copilot session — a self-propagating prompt-injection ('worm') pattern. Microsoft confirmed the behavior March 31 and deployed two mitigations (blocking the original wording and upgrading the model to GPT-5.5), but Måløy said the attack class still reproduced on GPT-5.6 and remained exploitable at publication. It is not zero-click and does not run conventional malware.
