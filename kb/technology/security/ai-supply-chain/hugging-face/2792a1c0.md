# Malicious Hugging Face repos abuse trust_remote_code for cryptomining/backdoors

Pluto Security reports malicious Hugging Face model repos targeting GPU hosts (Xinference, GPUStack, rented GPUs, notebooks, CI jobs) abuse trust_remote_code=true so the model's shipped Python runs on load; no poisoned weights or pickle exploits needed. Never enable trust_remote_code on unreviewed repos.
