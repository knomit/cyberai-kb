# Hugging Face Diffusers flaws could let model repos execute arbitrary code

Three high-severity vulnerabilities (CVE-2026-44827, CVE-2026-45804, CVE-2026-44513) were disclosed in Hugging Face's Diffusers library that could allow crafted model repositories to stealthily execute arbitrary code on machines that load them, expanding the AI/ML supply-chain attack surface.
