# GhostAction-linked GitHub Actions credential-theft workflow pushed to tens of thousands of repos (Oct 2026)

A credential-theft campaign compromised two open-source maintainer accounts to push a malicious GitHub Actions workflow. Per StepSecurity: the account of Takashi Kitao (author of game engine pyxel, 18,400 stars) pushed it to 27 repositories starting 13:20 UTC; eight hours later the account of Henry Wu (henrywoo, original author of Uber's athenadriver) pushed it to 318 repositories in a 16-minute window (21:10-21:26 UTC), i.e. over 340 repos. As of 2026-10-09 Socket identified more than 500 GitHub accounts that committed the malicious workflow to tens of thousands of repositories since 2026-10-07. Activity is attributed to GhostAction, a supply-chain campaign first disclosed in September 2025. Consequence: audit .github/workflows for unexpected additions and rotate secrets exposed to Actions.
