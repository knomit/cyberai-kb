# Gheist campaign plants secret-dumping GitHub Actions workflow using stolen tokens

Wiz tracks Gheist, which plants a workflow named 'sync-check' in every repository reachable by stolen GitHub tokens to print secrets into logs, downloads the log via the API and deletes the run seconds later. Wiz recovered over 13,500 planted branches from more than 850 compromised accounts; first detected mid-September 2026.
