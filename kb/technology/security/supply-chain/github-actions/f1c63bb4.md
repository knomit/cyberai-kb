# GitGuardian: GhostAction spike Oct 8-9 2026 compromised ~1,900 GitHub accounts, targeted 30,000+ repos

GitGuardian observed a GhostAction spike on 2026-10-08/09: about 1,900 GitHub user accounts compromised, over 30,000 repositories across ~3,000 users and organizations targeted, and 3,174 secrets from public repositories' CI attempted to be extracted. GhostAction was first discovered in September 2025; attackers use stolen Personal Access Tokens or infostealer-harvested credentials to gain write access and inject malicious GitHub Actions workflows. Complements the StepSecurity/Socket account-level view of the same campaign. Consequence: rotate PATs and CI secrets, audit workflow files.
