# Two actions-cool GitHub Actions resumed Mini Shai-Hulud malware after briefly reopening

Two GitHub Actions, actions-cool/issues-helper and actions-cool/maintain-one-comment, were originally compromised on May 18, 2026 to run malicious code as part of the 'Mini Shai-Hulud' npm/GitHub supply-chain malware campaign. In Sept 2026 the repositories became accessible again and resumed executing the Mini Shai-Hulud payload, prompting GitHub to disable them for a second time.
