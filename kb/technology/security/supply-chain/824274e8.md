# LLM code generation is opening a new software supply-chain attack surface, prompting defensive controls

AI-assisted development is creating novel supply-chain risk. Socket research found frontier LLMs (Claude Sonnet 4.6, Claude Haiku 4.5, GPT-5.4-mini, Gemini 2.5 Pro, DeepSeek V3.2) repeatedly hallucinate the same non-existent package names; 53 of 127 identified names (41 PyPI, 12 npm) were registrable as of April 2026, enabling cross-provider 'slopsquatting'. In response, defensive tooling is adapting—e.g., GitHub added a 3-day Dependabot cooldown so poisoned or compromised releases are not auto-adopted immediately. Together these show attackers and defenders both reorienting around machine-generated dependency choices.
