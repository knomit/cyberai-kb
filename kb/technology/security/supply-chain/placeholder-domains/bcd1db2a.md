# third-party[.]com placeholder domain, in ~1.7K repos, registered and serving ClickFix lures

THN (2026-09-28) citing Manifold Security: third-party[.]com, used as a documentation placeholder in roughly 1,700 repos, is not IANA-reserved (unlike example.com); someone registered it and serves a ClickFix lure to Windows browsers and a decoy to others. Flagged malicious by VirusTotal and Google Safe Browsing. Manifold found 13 more non-reserved placeholder domains; yoursite[.]com and your-domain[.]com serve scams/scareware to macOS visitors. Use only IANA-reserved names (example.com/.org/.net, .test, .invalid) in docs and tests.
