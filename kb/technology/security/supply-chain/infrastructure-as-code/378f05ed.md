# Coder module registry served malicious Terraform modules after Cloudflare infra compromise (Aug 31, 2026)

An unidentified attacker gained access to Coder's Cloudflare infrastructure and added unauthorized IP addresses (rogue registry servers) to the pool backing Coder's module registry; those addresses served a version of the registry containing malicious Terraform modules. The delivery window was 07:35 to 21:45 UTC on Monday, August 31, 2026.

The trojanized modules searched provisioner environments for cloud and AI-tooling API keys, CI/CD credentials, configuration-file secrets, terminal history, OIDC tokens, SSH keys, one-time authentication tokens, external authentication tokens, and Coder database passwords, and exfiltrated them to the lookalike domain coder-infra[.]com.

Remediation: patched versions are 2.37.0, 2.36.4, 2.35.7 and 2.34.9. Coder tells customers to search provisioner logs for data.external.telemetry (the Terraform external data source the malicious modules used), delete affected caches, and preemptively rotate any credential that could have been exposed.

WHAT THIS DOES NOT MEAN: the attack path was the registry's serving infrastructure, not a compromised package maintainer account; maintainer-account hardening alone would not have prevented it.
