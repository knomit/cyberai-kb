# Coder module registry served malicious Terraform modules after Cloudflare infra compromise

An unidentified attacker gained access to Coder's Cloudflare infrastructure and added unauthorized IP addresses to the pool backing Coder's module registry; those addresses served a version of the registry containing malicious artifacts. The delivery window was 07:35 to 21:45 UTC on Monday, August 31, 2026. The trojanized Terraform modules searched provisioner environments for cloud and AI-tooling API keys, CI/CD credentials, configuration-file secrets, terminal history, OIDC tokens, SSH keys, one-time authentication tokens, external authentication tokens, and Coder database passwords, exfiltrating them to the lookalike domain coder-infra[.]com. Coder tells customers to search provisioner logs for data.external.telemetry, the Terraform external data source the malicious modules used. Patched versions are 2.37.0, 2.36.4, 2.35.7, and 2.34.9; Coder also recommends deleting affected caches and preemptively rotating any credential that could have been exposed. Note the attack path was the registry's serving infrastructure, not a compromised package maintainer account.
