# GitHub adds 3-day Dependabot cooldown to limit poisoned-package adoption

GitHub announced a cooldown mechanism in Dependabot that waits at least three days after a release is published before opening a pull request, reducing the window in which a poisoned or compromised package version is automatically adopted.
