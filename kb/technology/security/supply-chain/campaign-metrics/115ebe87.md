# Mini Shai-Hulud campaign scale is measured in packages, developers and repos — not organizations

Reported scale figures for the Mini Shai-Hulud campaign as of mid-2026: 502 unique packages across 1,055 versions tracked over the full campaign; a single burst on May 19, 2026 published 639 malicious versions across 323 unique packages in roughly one hour (largest single-hour package count of any Shai-Hulud wave); ~1,800 developers affected across PyPI, npm and PHP ecosystems; 1,800+ repositories created containing stolen developer credentials (OX Security); 2,500+ compromised GitHub repositories (Phoenix Security); 170+ packages across npm and PyPI with ~518 million cumulative downloads.

MEASUREMENT CAVEAT — load-bearing: every published figure counts packages, versions, downloads, developers, or repositories. None counts affected ORGANIZATIONS. Developers and repositories are not organizations: one org may account for many of each, and a compromised personal developer credential may implicate no organization at all. Any claim about organizational blast radius derived from these figures is an inference, not a reported fact. As of mid-July 2026 no source appears to be producing an organization-level victim count for this campaign, and there is no indication one is forthcoming.
