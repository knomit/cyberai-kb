# Hola Browser for Windows compromised to deliver crypto miner

Sophos found an XMRig cryptocurrency-miner binary bundled within a certified Hola Browser installer for Windows. Hola attributed it to a supply-chain compromise of its update distribution pipeline affecting 0.1% of users, said no user data was accessed, and rebuilt its pipeline with stronger code-signing verification, tighter access controls, and continuous monitoring.
