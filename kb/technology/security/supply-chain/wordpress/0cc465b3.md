# WordPress plugin scripts tampered to plant backdoors (PushEngage, OptinMonster, TrustPulse)

An attacker tampered with trusted JavaScript files served by WordPress sites running PushEngage, OptinMonster, and TrustPulse (all run by Awesome Motive). When a logged-in administrator loaded the script, the code created an attacker-controlled admin account and installed a hidden backdoor plugin; ordinary visitors did not trigger it. Security firm Sansec disclosed the campaign on June 13, 2026; PushEngage confirmed its own incident a day later. Affected sites should be treated as compromised. Reported by The Hacker News.
