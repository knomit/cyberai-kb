# Rank Math PRO malicious builds (Oct 15-16, 2026); clean version 3.0.124

Rank Math PRO copies downloaded from rankmath.com or delivered as updates between 20:02 UTC Oct 15 and 07:12 UTC Oct 16, 2026 contained malware with a self-restoring backdoor that can recreate itself on site visits. Affected sites should be treated as compromised. Clean version 3.0.124 replaces the plugin but does not remove files, admin accounts or scheduled tasks already planted (Wordfence advisory, Oct 17). Version number alone does not show exposure (3.0.123 dates to Oct 7, before the window).
