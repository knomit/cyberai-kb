# Plugin4Shell: SHA-pinning bypass gives zero-click RCE in Claude Code, Codex, Copilot and Gemini CLI

AIR Security demonstrated 'Plugin4Shell', a zero-click remote code execution vulnerability affecting four major AI coding agents simultaneously: Claude Code, OpenAI Codex, GitHub Copilot, and Google Gemini CLI.

The mechanism, quoted from AIR Security: 'It is a plugin SHA-pinning bypass: the agent checks out the exact commit the marketplace pinned but never verifies it landed there, so an attacker who controls the plugin's repo makes the checkout resolve to malicious code while the pin still looks honored.' Both halves of the condition are required and both are present: the agent DOES pin a commit SHA, and the agent does NOT verify the resulting checkout matches that SHA. The pin is therefore decorative.

AIR Security's stated consequence: 'a trusted plugin is silently swapped for a malicious one and auto-installed past the agent's SHA pinning — a flaw no marketplace can fix, so users must update their agent.' Do NOT read SHA-pinning as protection against this class of attack unless the implementation verifies the checked-out tree against the pin; the presence of a pin in the manifest proves nothing.
