# VS Code adds 2-hour extension auto-update delay against supply-chain attacks

Microsoft will apply a two-hour delay before Visual Studio Code automatically updates extensions to a newer version, a mitigation intended to give time to catch and pull malicious extension releases before they propagate widely — reducing the window for software supply-chain attacks through the IDE marketplace. Reported June 8, 2026.
