# North Korea sustains parallel open-source registry supply-chain campaigns

As of mid-2026, North Korea-aligned actors run multiple concurrent open-source package supply-chain operations targeting developers. Two distinct July 2026 disclosures illustrate the pattern: the PolinRider campaign (Socket) published 108 malicious packages across npm, Packagist, Go, and Chrome via compromised maintainer accounts, tied to the recruitment-themed Contagious Interview cluster; separately JFrog flagged typosquatted npm packages impersonating Rollup polyfill tooling (rollup-packages-polyfill-core, rollup-runtime-polyfill-core). Common tradecraft: mimicking legitimate package metadata/naming, chaining dependencies to load a hidden payload, and abusing developer trust in package registries for remote access and secret theft.
