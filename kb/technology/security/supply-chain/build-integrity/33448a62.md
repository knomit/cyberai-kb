# Mini Shai-Hulud produced malicious npm packages carrying valid SLSA Build Level 3 provenance attestations

TeamPCP's Mini Shai-Hulud worm published malicious package versions through TanStack's own GitHub Actions release pipeline using hijacked OIDC tokens. Because the packages were built by the project's legitimate pipeline, they carried VALID SLSA Build Level 3 provenance attestations — reported as the first documented npm worm producing validly-attested malicious packages.

Significance: SLSA provenance attests that an artifact was built by the claimed pipeline from the claimed source. It does not attest that the pipeline's inputs or credentials were uncompromised. An attacker who steals CI/CD secrets inherits the pipeline's attestation authority, so provenance verification passes on malicious output. This defeats the central assumption behind build-integrity controls: that attestation distinguishes trustworthy from untrustworthy artifacts.

This is the closest structural analogue in the campaign to the SolarWinds pattern (subversion of a trusted build pipeline rather than of a package), and is distinct from the campaign's more commonly reported credential-worm behavior.
