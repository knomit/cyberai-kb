# Hijacked npm and Go packages deploy Python infostealer via VS Code tasks

Researchers uncovered two hijacked npm packages and a cluster of Go packages designed to deploy a Python-based information stealer using VS Code tasks on compromised Windows, Linux, and macOS hosts.
