# Poisoned Ruby Gems and Go Modules: sleeper packages for CI pipeline credential theft and GitHub Actions tampering

A software supply chain attack campaign (May 2, 2026) uses sleeper packages in Ruby Gems and Go Modules as conduits to push malicious payloads. Capabilities include credential theft, GitHub Actions tampering, and SSH persistence. Sleeper approach: packages lie dormant until a trigger condition activates the payload, making pre-deployment scanning ineffective.
