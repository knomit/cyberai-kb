# Over 400 Arch Linux AUR packages hijacked to deploy infostealer and eBPF rootkit

Attackers took over more than 400 packages in the Arch User Repository (AUR) in the week of June 2026 and rewrote their build scripts to install a credential-stealer on any machine that built them. The malware is a Rust binary built to harvest developer secrets; when run with root it can load an eBPF rootkit to hide itself. The AUR is Arch Linux's community package collection and is separate from the official Arch repositories, which were not affected. Packages updated on or after June 11 are suspect. The attack targeted the trust model rather than a software flaw: compromised packages kept their names, histories, and trust, with only the build instructions changed.
