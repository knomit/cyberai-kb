# Hundreds of Arch Linux AUR packages compromised in 'Atomic Arch' campaign

Unknown threat actors compromised hundreds of legitimate-but-abandoned packages in the Arch User Repository (AUR), modifying them with preinstall scripts that download and execute a malicious npm package called atomic-lockfile. Sonatype codenamed the campaign 'Atomic Arch'; the bundled Linux payload includes credential harvesting, stealth, anti-debugging, and data-exfiltration functionality. Reported by The Hacker News, June 2026.
