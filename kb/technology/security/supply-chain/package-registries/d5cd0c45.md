# Hades PyPI Campaign: 37 Malicious Artifacts in 19 Packages (Miasma/Mini Shai-Hulud Continuation)

A new supply-chain attack wave called Hades placed 37 malicious wheel artifacts across 19 PyPI packages. Each package auto-executes a Bun-based credential stealer on install. Hades is an extension of the Miasma campaign / Mini Shai-Hulud strain attributed to TeamPCP, which previously targeted npm packages (IronWorm) and Microsoft GitHub repos. The campaign has now expanded from npm to PyPI, broadening the supply-chain footprint.
