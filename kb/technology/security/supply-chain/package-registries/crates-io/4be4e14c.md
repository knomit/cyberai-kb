# Rust supply-chain attack injected build-time malware into arrayref, internment, and append-only-vec

On 2026-08-20 a compromised maintainer account on crates.io published malicious releases of three widely used Rust crates: arrayref 0.3.10, internment 0.8.7, and append-only-vec 0.1.9. The crates collectively account for roughly 245 million downloads.

The releases added a typosquatted dependency whose build script downloaded and executed a remote payload at compile time. Because the malicious code lived in the injected dependency's build script, merely building a project that resolved the dependency was enough to run the payload — none of the crates' own APIs had to be called.

The Rust Project deleted all three malicious versions within 86 to 107 minutes of publication. The Rust Security Response Team also unyanked versions that the attacker had maliciously yanked. There is no patched version and no CVE identifier was assigned. Developers are advised to search ~/.cargo/registry/cache for the deleted crate files and to pin arrayref at 0.3.9 or earlier.
