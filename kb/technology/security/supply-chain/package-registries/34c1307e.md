# IronWorm and a new Miasma variant hit npm via 50+ poisoned packages

Multiple software supply-chain attacks struck the npm ecosystem, with threat actors using malicious and poisoned versions of over 50 legitimate packages to distribute a Rust-based information stealer and a self-replicating worm. The campaign involves 'IronWorm' and a new variant of the Miasma worm. Reported by The Hacker News, June 6, 2026.
