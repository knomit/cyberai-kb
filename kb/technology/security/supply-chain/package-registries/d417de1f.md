# Malicious npm/PyPI packages keep weaponizing post-install hooks

The Hacker News weekly recap (June 8, 2026) catalogued multiple open-source package supply-chain attacks sharing a post-install-hook pattern. Trojanized npm packages 'turbo-axios' and 'faster-axios' (typosquatting axios) used a postinstall hook to fetch and eval() remote JavaScript, ending in Epsilon Stealer, an Electron infostealer-as-a-service. 'cms-store-ren' exfiltrated developer data to Telegram while leaking its own Telegram bot API token. Other npm packages impersonated an AI coding tool to prompt users for OpenAI/Anthropic API keys while harvesting credential files. A PyPI typosquat 'parsimonius' (of parsimonious) bundled real functionality plus a Telegram backdoor and reached 2,474 downloads before removal.
