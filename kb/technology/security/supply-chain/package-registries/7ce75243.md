# Shai-Hulud worm variant expanded credential scanning to 469 locations

GitGuardian researchers found in early August 2026 that a recent variant of the Shai-Hulud infostealer worm scans for credentials across 469 distinct locations spanning developer environments, CI/CD tooling, cloud configuration, AI agent and AI tool configs, and crypto wallets. Earlier variants of the same worm checked only 189 paths. GitGuardian's framing is that the operators are not breaking trust relationships but harvesting the credentials that already make those relationships work, and that modern developer environments hold a large amount of reusable authority in predictable file locations. No CVE is involved; this is a malware capability change, not a product vulnerability.
