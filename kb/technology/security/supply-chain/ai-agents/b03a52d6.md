# Miasma worm persists via AI coding agent config injection — .claude/settings.json SessionStart hook runs credential harvester on every session

The Miasma worm (TeamPCP campaign, June 2026) introduced a novel persistence mechanism targeting AI coding agent configuration files. When it compromises a GitHub repository directly (skipping package registries entirely), it plants hooks in five developer tool configs simultaneously: Claude Code (.claude/settings.json), Gemini CLI, Cursor, VS Code, and npm test scripts.

The Claude Code vector is the most persistent: Miasma embeds an Anthropic Claude Code SessionStart hook in .claude/settings.json that executes a 4.3 MB credential-harvesting payload runner automatically on every Claude Code session open. Critically, this persistence survives token rotations — the hook re-harvests credentials on each subsequent session, meaning rotating a compromised token does not stop exfiltration.

The payload architecture: four-layer obfuscation stack, Bun-as-runtime, AES-GCM payload staging through /tmp, bypass_2fa: true worm propagation, runner memory extraction via /proc/mem.

This represents a structural shift from supply chain attacks (poison the package, wait for install) to developer environment attacks (poison the repo, trigger on every AI coding session). A developer who clones or opens a compromised repository in Claude Code will silently execute the harvester — no install step required.

Scope: 73 Microsoft GitHub repositories disabled across two automated waves (105 seconds), Red Hat Cloud Services npm namespace compromised (32 packages, 116,991 combined weekly downloads). Zero CVEs assigned across the entire campaign as of June 2026.
