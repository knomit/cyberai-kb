# Microsoft Shuts Down 70+ GitHub Repositories Following AI Agent Supply-Chain Hack

Microsoft shut down more than 70 GitHub repositories in early June 2026 in response to an AI agent-driven hack. This is consistent with the Miasma/TeamPCP supply-chain campaign that previously exfiltrated data from 3,800+ internal Microsoft GitHub repositories (confirmed May 20, 2026). The repository takedown represents one of the first large-scale corporate remediation actions explicitly attributed to an AI-agent supply-chain compromise.
