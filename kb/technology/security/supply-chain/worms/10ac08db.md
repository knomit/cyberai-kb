# Miasma supply-chain worm hit 73 Microsoft GitHub repositories

The self-replicating 'Miasma' supply-chain worm compromised 73 Microsoft GitHub repositories across four organizations (Azure, Azure-Samples, Microsoft, MicrosoftDocs), prompting GitHub to disable access to them. Miasma is assessed to be a variant of the 'Mini Shai-Hulud' worm publicly released by TeamPCP in mid-May 2026. The Hacker News named it threat of the week (June 8, 2026).
