# Brevo supply chain attack: a compromised Cloudflare API key injected ClickFix scripts into 100,000+ customer sites for 5.5 hours

On 2026-09-14, an attacker used a COMPROMISED BREVO CLOUDFLARE API KEY to deploy a Cloudflare Worker on Brevo's account. For about five and a half hours the Worker injected a malicious script into pages of brevo.com and sibforms.com and into three JavaScript files that customers embed on their own websites. The blast radius: Brevo's own site plus over 100,000 customer sites.

The payload had two components: a malicious WordPress plugin installed when site admins visited their own site, and a ClickFix overlay shown to everyone browsing a customer site or clicking a link in a Brevo-sent campaign email — including the unsubscribe link. The overlay presented a fake Cloudflare CAPTCHA instructing visitors to paste and run a command on their computer. Sansec characterized it as attackers piggy-backing on embedded Brevo widgets to install WordPress malware on customer sites and launch ClickFix attacks against visitors.

Note the compound reach: an embedded-widget vendor's CDN credential turned into code execution on the vendor's site, on every customer site embedding its JS, AND in email click paths. A vendor compromise scoped to 'their infrastructure' is not scoped to their infrastructure when customers embed the vendor's JavaScript.
