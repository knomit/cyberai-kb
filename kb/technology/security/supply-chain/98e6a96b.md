# TeamPCP 'Mini Shai Hulud': supply chain attacks weaponizing legitimate CI/CD pipelines across npm/PyPI/Packagist

TeamPCP continued its supply chain attack campaign with 'Mini Shai Hulud,' compromising packages across npm, PyPI, and Packagist ecosystems. The group previously compromised Trivy (Aqua Security security scanner), KICS (Checkmarx static analysis tool), LiteLLM, and Telnyx. New approach: weaponizing legitimate CI/CD pipelines to push poisoned versions under real developer identities, making activity indistinguishable from normal development. Each compromised pipeline spreads to the next, turning credential theft into a scaling problem. VECT 2.0 ransomware announced a partnership with TeamPCP. Upwind threat researcher Amit Genkin: 'If you're relying on traditional scanning or known indicators, this type of activity is easy to miss.'
