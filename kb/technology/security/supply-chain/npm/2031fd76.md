# 145 Mastra npm packages compromised in 'easy-day-js' supply-chain attack

About 145 npm packages in the Mastra namespace (@mastra/*, a JS/TS framework for building AI applications) were compromised in a supply-chain attack codenamed easy-day-js. A single npm account ('ehindero') mass-published 140+ malicious packages within an 88-minute automated campaign on 2026-06-17. The packages contained no malicious code themselves; instead each added a dependency 'easy-day-js' — a clone of the 'dayjs' date library — that downloads and runs a cryptominer. Reported by Endor Labs, JFrog, OX Security, SafeDep, Socket, StepSecurity, and Snyk.
