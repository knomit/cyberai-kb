# RedC2 4.0 Linux implant delivered via 14 trojanized npm packages

In August 2026, TrendAI (Trend Micro's enterprise cybersecurity business) reported 14 trojanized npm packages posing as working calendar/streak/date utilities that bundle a native binary (named variously math-core.bin, math-calc.bin, calc-math.dat, calc-cache.bin, calc.bin, calc-mapping.bin) under dist/ or dist/internal/. The binary is the RedShell Linux beacon for the RedC2 4.0 C2 framework. Delivery is handled by the package entry file dist/index.mjs acting as a trojan loader: no npm install hook is required — a single import anywhere in the dependency graph, even transitive, marks the binary executable and launches it as a detached background process. Named packages include streak-metrics-math@1.0.0/1.0.1, kit-map-vim, streak-map-cache, streak-map-kit, map-streak-kit, streak-cache-map, streak-calc-metrics, streak-calc-math, streak-math-abz, streak-metricsaz, streak-math-metrics, streak-metricazbd, streak-metricsazb, streak-kit-map (all @1.0.0). Researcher: Aliakbar Zahravi.
