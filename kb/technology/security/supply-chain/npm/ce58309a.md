# MALFEX npm package 'imgdecode' hides Windows shellcode loader

Per The Hacker News (Oct 2026), citing SafeDep: npm package 'imgdecode' (uploaded Sept 30, 2026 by user 'malfexteste8'; 979 downloads at writing; latest 1.0.3) is part of the MALFEX supply-chain campaign first documented by Checkmarx and CloudSEK. Its nine-line JS file loads a Windows DLL (compiled Node.js addon); when require('imgdecode') runs from a Windows console, the DLL downloads encrypted shellcode from GitHub, decrypts it and injects it into a new dllhost.exe process. Consequence: Windows developers who installed it should treat the host as compromised. Does not affect non-Windows or non-console invocations as described.
