# 24 npm packages used as free phishing hosting via unpkg CDN mirrors

OX Security researchers Moshe Siman Tov Bustan and Vitalii Chepurko disclosed a campaign using a cluster of 24 npm packages purely as free, trusted-domain phishing infrastructure. Each package contains only a single HTML page; installing it is harmless. The attack works because CDN mirrors such as unpkg render the packaged HTML as a live page (e.g. unpkg.com/<pkg>@1.0.0/index.html), producing a fake Cloudflare CAPTCHA verification page served from a trusted domain that redirects victims to ClickFix-style phishing infrastructure. Early iterations posted requests to a Microsoft login typosquat (login.microsofte.live); after Chrome Safe Browsing blocklisted that domain, the actor rotated infrastructure. This demonstrates package registries and their mirrors being abused as validated malware storage rather than as a developer-infection vector.
