# Shai-Hulud npm worm delivered via the official MCP Registry

OX Security reported the first observed case of a Shai-Hulud payload delivered through the official Model Context Protocol (MCP) Registry (registry.modelcontextprotocol.io). The npm/PyPI package linked by the MCP server was clean, but opening or cloning the linked MCP server GitHub repository (e.g. 'jUXTAPOSITION1/V.A.P.E') inside Claude Code or VS Code triggered malware that collected developer tokens, cloud credentials and session keys. The worm spread through roughly 440 unique npm packages.
