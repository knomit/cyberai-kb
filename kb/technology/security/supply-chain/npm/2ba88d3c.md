# Keyv-linked npm worm poisons hundreds of packages

A credential-stealing npm worm that first appeared in keyv@6.0.0 spread beyond the Keyv and Cacheable namespaces into hundreds of packages across multiple organizations on August 4, 2026. Security firm SafeDep verified 353 poisoned packages. The worm plants malicious Claude Code and VS Code hooks.
