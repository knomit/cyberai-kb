# Cordyceps CI/CD workflow flaw exposes 300+ GitHub repositories

Novee Security flagged a new class of CI/CD workflow weakness, codenamed Cordyceps, that lets attackers hijack workflows and compromise open-source software supply chains. Per researcher Elad Meged, the flaw is exploitable by any unauthenticated user — a free account suffices to forge approvals, push code, or steal credentials, with no org membership or special privileges. A scan of ~30,000 high-impact repositories found more than 300 fully exploitable, including at organizations such as Microsoft, Google, Apache, and Cloudflare, enabling attacker-controlled code execution, credential theft, and supply-chain compromise.
