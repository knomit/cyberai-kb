# Pattern: attackers increasingly subvert trust models rather than exploit software flaws

Two June 2026 intrusions show adversaries attacking trust and integrity rather than code vulnerabilities. The Arch Linux AUR hijack (400+ packages) left package names, histories, and reputations intact and changed only the build scripts, abusing user trust in established packages to deploy a Rust infostealer and eBPF rootkit. Separately, China-nexus group Velvet Ant backdoored the very Linux login programs (PAM/OpenSSH) that decide who is trusted, persisting ~a decade (since 2016) by modifying trusted components so activity looked like normal administration—no exploit required. Both illustrate that integrity of the software supply chain and of trusted system components is a primary defense gap.
