# Malicious npm packages impersonate PostCSS tools to drop Windows RAT

JFrog reported a set of malicious npm packages published over the prior month by npm user 'abdrizak' that deliver a Windows-based remote access trojan (RAT): aes-decode-runner-pro (145 downloads), postcss-minify-selector (256 downloads), and postcss-minify-selector-parser (615 downloads). They masquerade as PostCSS selector tools, typosquatting the legitimate 'postcss-selector-parser' library (127M+ weekly downloads), and were still live on npm at time of reporting.
