# ShapedPlugin WordPress Pro plugins backdoored in supply chain attack

Wordfence reported that attackers compromised ShapedPlugin's build and distribution pipeline, injecting backdoor code into Pro plugin releases delivered through the vendor's Easy Digital Downloads infrastructure at account.shapedplugin[.]com. Affected: Product Slider Pro for WooCommerce (before 3.5.4), Real Testimonials Pro (3.2.5), and Smart Post Show Pro (before 4.0.2). Free versions on WordPress.org are not impacted. A CVE (CVE-2026-4xxx) was assigned to the Product Slider Pro compromise.
