# Slopsquatting research: 53 hallucinated package names available for malicious registration

Socket research found frontier LLMs (Claude Sonnet 4.6, Claude Haiku 4.5, GPT-5.4-mini, Gemini 2.5 Pro, DeepSeek V3.2) hallucinate non-existent package names. Of 127 names identified, 53 (41 on PyPI, 12 on npm) were still available for registration as of April 2026. Because multiple models invent the same names, one malicious registration ('slopsquatting') could target users across providers.
