# Coder supply chain attack served malicious Terraform modules

Attackers compromised Coder's Cloudflare infrastructure to add rogue registry servers serving malicious Terraform modules that harvested credentials and secrets, exfiltrating them to the lookalike domain coder-infra[.]com. Fixed in Coder versions 2.37.0, 2.36.4, 2.35.7 and 2.34.9.
