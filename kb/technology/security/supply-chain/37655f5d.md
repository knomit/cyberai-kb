# Install-time and CI lifecycle execution is the load-bearing supply-chain attack surface in 2026

Two 2026 data points converge on the same structural weakness: install-time/lifecycle code execution and CI pipelines as the primary supply-chain attack surface. Attackers used 'sleeper' Ruby Gems and Go Modules (dormant until a trigger) to steal credentials, tamper with GitHub Actions, and establish SSH persistence — defeating pre-deployment scanning. In response, GitHub announced npm v12 (~July 2026) will disable install scripts by default, calling install-time lifecycle scripts the 'single largest code-execution surface in the npm ecosystem' because 'npm install' runs scripts from every transitive dependency on developer machines and CI runners. The defensive trend is to remove implicit code execution at install time and require explicit approval, but sleeper/trigger-based payloads show scanning alone is insufficient.
