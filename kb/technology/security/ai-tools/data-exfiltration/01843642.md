# xAI Grok Build CLI uploads entire Git repositories to xAI cloud storage

Analysis of xAI's official Grok Build coding CLI found it transmits the contents of files it reads to xAI verbatim and unredacted, and uploads entire Git repositories — full commit history included — to a Google Cloud Storage bucket run by xAI, not just the files a coding task needs. A researcher publishing as 'cerebla'/'cereblab' documented the behavior. There is no proof that xAI trains on the uploaded data. Covered by both TLDR AI and The Hacker News.
