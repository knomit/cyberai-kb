# CVE-2026-82533: DeepSeek Harness sandbox escape let AI coding agents disable their own sandbox

CVE-2026-82533 is a sandbox-escape flaw in DeepSeek Harness, DeepSeek's open-source tool for running AI coding agents on a developer's machine. The harness normally executes an agent's commands inside an operating-system sandbox so an agent working on untrusted files cannot write outside its workspace. From inside that sandbox the agent could reach the harness's own unauthenticated local web API and elevate its session to 'danger-full-access' with the approval mode set to 'never'; every command after that ran unconfined and without any approval prompt. VulnCheck rated the flaw 9.4/10. Exploitation required attacker-supplied text that the agent read (i.e. prompt injection via untrusted content) to induce the agent to make the call, and it worked on a default installation. DeepSeek fixed the tool on August 27; fixed npm releases start at 0.1.2-alpha.2. No in-the-wild exploitation was reported.
