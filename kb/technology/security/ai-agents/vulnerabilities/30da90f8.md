# ChatGPT 'AgentForger' flaw could deploy rogue Workspace agents via a phishing link

Cybersecurity researchers disclosed a critical vulnerability, dubbed AgentForger, in OpenAI's ChatGPT Workspace Agents that could have allowed a single phishing link to stealthily build, authorize, and deploy an autonomous AI agent inside a victim's workspace. Reported by The Hacker News on July 24, 2026.
