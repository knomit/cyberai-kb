# Mid-2026: AI is both a weapon and a first-class attack surface; agent/tool trust and an agent's blast radius are the core failure mode

Across June 2026 reporting a unified pattern holds: AI sits on both sides of the security equation, and the dominant new failure mode is untrusted input becoming executable action through an agent's own trust, permissions, and tool access. AS A WEAPON: criminals weaponized Google's Gemini to mass-produce phishing/smishing pages (Outsider PhaaS). AS AN ATTACK SURFACE, recurring sub-patterns: (1) classic bugs in agent/dev infrastructure yielding RCE that are patchable — LangGraph's SQLi-to-RCE chain (CVE-2025-67644, CVE-2026-28277, Check Point), and the Amazon Q Developer flaw (CVE-2026-12957, CVSS 8.5, Wiz Research) where a single attacker-supplied MCP config file (.amazonq/mcp.json) in a cloned repo spawned processes inheriting the developer's full environment (AWS keys, cloud tokens, SSH sockets), turning 'git clone' into cloud-credential compromise; (2) indirect prompt injection abusing the agent's own permissions, which patches cannot fully fix — OpenClaw driven to run code or exfiltrate secrets via contacts/vCards/location pins/plain emails (Imperva, Varonis), Anthropic's Claude Code GitHub Action hijackable via a single issue, rogue agent 'skills' past guard scanners (Trail of Bits), ~20,000 Instagram accounts hijacked via Meta's AI support chatbot; (3) compromised trust boundaries in connected tooling that relay untrusted data as trusted — 'Agentjacking' via the Sentry MCP server feeding attacker input to Claude Code/Cursor as system output (Tenet Security). Underlying all three is the 'lethal trifecta': an agent combining internet access, local identity/permissions, and sensitive-code/data access becomes a single point of catastrophic compromise — which is why defenders shift from brittle guard/scanner detection toward capability-restriction, treating tool output as untrusted, sandboxing, audit logging, and moving agents into remote pre-hardened environments (e.g., OpenAI's ChatGPT 'Lockdown Mode'; remote managed agent workspaces). National-security concern escalates in parallel (U.S. order to suspend Anthropic's most advanced models for foreign nationals). Net: the AI agent/tooling stack — models, frameworks, MCP servers, skills, CI/CD integrations, dev assistants — is now a first-class security and policy battleground, and an agent's access is the attacker's blast radius.
