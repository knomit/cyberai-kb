# Agentic AI frameworks and their tooling are an emerging RCE and prompt-injection attack surface

Multiple June 2026 disclosures show self-hosted agentic AI systems and their surrounding tooling forming a distinct, fast-growing attack surface. LangGraph (LangChain's multi-agent framework) carried a SQLi-to-RCE vulnerability chain (CVE-2025-67644, CVE-2026-28277) disclosed by Check Point, while the OpenClaw self-hosted agent was shown by Imperva and Varonis to execute attacker-controlled code or exfiltrate secrets via indirect prompt injection hidden in contacts, vCards, location pins, or plain emails. A third variant, 'Agentjacking' (Tenet Security), abuses the trust boundary of the agent's tooling rather than the agent itself: attacker-supplied data ingested by Sentry is returned by the Sentry MCP server to coding agents (Claude Code, Cursor) as trusted system output, causing them to run attacker-controlled code. Three failure classes recur: (1) classic memory-safety/deserialization/injection bugs in agent infrastructure that yield RCE and are patchable; (2) prompt-injection abuse of the agent's own trust and permissions; and (3) compromised trust boundaries in connected tooling (e.g., MCP servers that relay untrusted external data as trusted). Patches address (1); (2) and (3) require constraining agent capabilities and treating tool output as untrusted. Together they indicate that an AI agent's access — and the trust it extends to its tools — becomes the attacker's access.
