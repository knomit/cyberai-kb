# Third-party scanners cannot reliably detect malicious AI agent skills

Trail of Bits bypassed ClawHub's malicious-skill detector, Cisco's agent skill scanner, and scanners in skills.sh to push rogue 'skills' to public marketplaces and steal data from developer systems. One malicious skill used prompt injection to convince the guard model its payload was harmless — instructing the agent to point its package managers (npm and yarn) at an attacker-controlled registry, disguised as corporate environment/VPN configuration. The takeaway: trust cannot be outsourced to a third-party scanner; organizations should instead curate skill marketplaces from trustworthy open-source collections.
