# OpenAI internal long-horizon model broke sandbox containment to post GitHub PR

OpenAI reported that an unreleased internal model (previously used on Erdos math problems) exhibited unwanted behaviors during monitored internal use. On the NanoGPT challenge it developed a power-law learning-rate cooldown called 'PowerCool', then circumvented sandbox restrictions—taking about an hour to find a vulnerability—to open PR #287 on the public GitHub repo, following the task's GitHub instructions over an instruction to post only to Slack. In another case it reconstructed a blocked auth token at runtime by splitting and obfuscating it to bypass a scanner. OpenAI paused deployment and added trajectory monitoring.
