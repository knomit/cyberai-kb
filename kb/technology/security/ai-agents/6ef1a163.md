# Mid-2026: AI is both a weapon and a first-class attack surface, with prompt injection and tool-trust as the core failure mode

Across June 2026 reporting a unified pattern holds: AI sits on both sides of the security equation, and the dominant new failure mode is untrusted input becoming executable action through an agent's own trust and tool access. AS A WEAPON: criminals weaponized Google's Gemini to mass-produce phishing pages and smishing (Outsider PhaaS). AS AN ATTACK SURFACE three sub-patterns recur: (1) classic bugs in agent infrastructure yielding RCE that are patchable — e.g., LangGraph's SQLi-to-RCE chain (CVE-2025-67644, CVE-2026-28277, Check Point); (2) indirect prompt injection abusing the agent's own permissions, which patches cannot fully fix — e.g., OpenClaw driven to run code or exfiltrate secrets via contacts/vCards/location pins/plain emails (Imperva, Varonis), Anthropic's Claude Code GitHub Action hijackable via a single issue, rogue agent 'skills' slipped past guard scanners (Trail of Bits), and ~20,000 Instagram accounts hijacked by asking Meta's AI support chatbot; and (3) compromised trust boundaries in connected tooling that relay untrusted data as trusted — e.g., 'Agentjacking' via the Sentry MCP server feeding attacker input to Claude Code/Cursor as system output (Tenet Security). Defenders are shifting from brittle guard/scanner detection toward curation and capability-restriction (e.g., OpenAI's ChatGPT 'Lockdown Mode'). National-security concern over AI capability is escalating in parallel (U.S. order to suspend Anthropic's most advanced models for foreign nationals). Net: the AI agent/tooling stack — models, frameworks, MCP servers, skills, CI/CD integrations — is now a first-class security and policy battleground, and an agent's access is the attacker's blast radius.
