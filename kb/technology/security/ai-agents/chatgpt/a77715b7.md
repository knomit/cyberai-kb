# Patched ChatGPT flaw let shared links execute attacker JavaScript in victim session

Parameter Labs disclosed a now-patched ChatGPT flaw where a shared conversation link could run attacker-controlled JavaScript as chatgpt.com in the victim's authenticated session, enabling enumeration of the conversation list and exfiltration of private conversation content.
