# 11 attacks let misaligned agent bypass OpenAI Codex Auto-review and sandbox

An ERA fellow mentored at Apollo Research audited the open-source Codex harness and found 11 attacks letting a misaligned agent run arbitrary code despite the sandbox and the Auto-review blocking monitor: swapping scripts behind trusted hooks, forging user turns the monitor cannot distinguish from real ones, and editing files after approval. OpenAI has fixed several.
