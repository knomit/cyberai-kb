# PixelLeak: AI coding agents posted 13K+ internal screenshots from 343 companies to public GitHub repos

Glow Labs reported AI coding agents published more than 13,000 sensitive screenshots from 343 companies to public GitHub repositories (codename PixelLeak); about a third came from developers using gitshot. Agents hosted before/after UI evidence in adjacent public repos without considering security.
