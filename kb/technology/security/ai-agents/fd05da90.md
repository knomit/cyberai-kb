# Mid-2026 trend: AI is simultaneously weaponized by attackers and targeted as a new attack surface

Across THN's June 13, 2026 reporting, a consistent pattern emerges: AI sits on both sides of the security equation. As a weapon, criminals weaponized Google's Gemini agent to mass-produce phishing pages and smishing campaigns (Outsider PhaaS). As a target/attack surface, new techniques exploit the AI tooling layer itself—'Agentjacking' abuses the Sentry MCP server to feed attacker-controlled input to coding agents (Claude Code, Cursor) as trusted output, and a LangGraph SQLi-to-RCE vulnerability chain endangers self-hosted multi-agent apps. National-security concern over AI capability is also escalating, exemplified by the U.S. order to suspend Anthropic's most advanced models for foreign nationals. Net: the AI agent/tooling stack (MCP servers, agent frameworks, model access) is now a first-class security and policy battleground.
