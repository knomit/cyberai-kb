# Fake AI agent 'skill' passed every scanner and reached ~26,000 agents

Security firm AIR built a deliberately fake AI agent skill named 'brand-landingpage' (claiming to build landing pages via Google's Stitch design tool), distributed it through a popular skill marketplace and an Instagram ad, and says it reached roughly 26,000 agents, including some on corporate accounts. Every skill security scanner tested marked it safe, and trust signals like GitHub stars and open-source reputation failed to flag it. The payload was harmless by design (it only collected the user's email), demonstrating a supply-chain trust gap: a skill is a bundle of instructions an agent loads with roughly user-prompt authority.
