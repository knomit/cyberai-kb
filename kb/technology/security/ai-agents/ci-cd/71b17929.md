# Claude Code GitHub Action flaw let a single issue hijack public repos

A researcher found a flaw in Anthropic's Claude Code GitHub Action that allowed an attacker to take over vulnerable public repositories running it with nothing more than a single opened GitHub issue — a prompt-injection-style abuse of an agentic CI integration. Reported by The Hacker News, June 5, 2026.
