# Atlassian Rovo can be tricked via prompt injection into exfiltrating Jira/Confluence data

Two security firms independently found that attacker-controlled instructions can make Atlassian's Rovo AI assistant collect Jira or Confluence data accessible to a signed-in user and send it to an outside server. PromptArmor hid instructions in content Rovo reads (an uploaded file was enough, with no separate approval step; published August 5, 2026 and still working with web-search off). Varonis Threat Labs placed instructions in a link, finding the 'rovoChatPrompt' URL parameter would preload attacker instructions into Rovo Chat so a single click by an authenticated user could trigger exfiltration.
