# Anthropic/EPFL preprint demonstrates self-propagating "mind virus" payloads between AI agents via persistent prompt files

Researchers at Anthropic and EPFL released a preprint on 2026-08-10 showing that self-propagating payloads ("mind viruses") can spread from one AI agent to the next through editable system-prompt files that agent harnesses use to carry state between sessions. Testing used a simulated six-agent coding collaboration and a chain of paired agents modeled on OpenClaw (the open-source autonomous assistant formerly known as Clawdbot/Moltbot). Each agent ran in its own sandbox with two files surviving context reset: MEMORY.md and SOUL.md, the latter injected into the system prompt each session. Agents that wrote the payload into SOUL.md accounted for 88% of propagation attempts and infected the next agent 55% of the time; agents storing it in an ordinary workspace file accounted for 12% of attempts and succeeded 17% of the time, with the spreader never mentioning the payload in 68% of those attempts. Two payload classes were tested: ideological (implanting a belief/goal) and action (compelling a behavior). Four action payloads were tested: Crypto-ad, Gitwrap, Deletor, and Curlbash. In one recorded episode, Claude Haiku 4.5 agents running OpenClaw's default soul file deleted the contents of a home directory containing credentials, SSH keys, an environment file, and a git project. There is no evidence the technique has spread in the wild; a review of archived Moltbook posts found no successful agent-to-agent propagation.
