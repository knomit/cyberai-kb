# Cloudflare's Agent Access Model (AAM) for securing software agents

Cloudflare's Agent Access Model (AAM) redefines enterprise access control for software agents around task-specific, ephemeral credentials. It removes implicit trust in task-execution graphs and evaluates every action against the task's state to minimize agent capabilities. Core principles: short-lived credentials, harness and network enforcement, minimal human oversight, evidence-based grant reviews, and unidirectional capability changes.
