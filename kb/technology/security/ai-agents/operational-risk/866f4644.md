# 'Lethal trifecta' risk of running autonomous coding agents on local laptops

Security commentators describe a 'lethal trifecta' that arises when an autonomous coding agent (e.g. Claude Code) runs on a local laptop: combining internet access, local permissions/identity, and access to sensitive code in one place. Such an agent can read credentials, delete files, assume the user's identity, and expose internal services to the internet, which is why IT/InfoSec teams frequently block desktop agents or restrict them to senior engineers who can manage sandboxing. A proposed mitigation is to move agents off the laptop into remote, centrally managed, pre-hardened environments with centralized tool-permission controls and audit logging (the approach advocated in a Deep View edition sponsored by Coder).
