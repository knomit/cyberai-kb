# NVIDIA OpenShell: kernel-level policy runtime for autonomous agents

NVIDIA's open-source OpenShell is a policy-controlled runtime for autonomous agents enforcing file, system-call, network and credential access at the kernel level, and uses formal verification to flag risky permissions before policy changes are applied.
