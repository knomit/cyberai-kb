# Meta Muse Mac app: undocumented dictation-endpoint preference lets local malware hijack the assistant

Patrick Wardle released a proof-of-concept (Sept 21, 2026) showing that malware already running as the logged-in user on a Mac can change an undocumented Muse preference, endo_voyager_dictation_endpoint, without extra permissions, redirecting dictated prompts to an attacker. The attacker can then read dictation, inject instructions Muse trusts and acts on, and capture a Muse account token to read chat history and control the assistant. Limits: Mac app only, and it requires existing code execution as the user (it cannot break into a Mac by itself); Wardle noted a ClickFix-style lure could provide that foothold remotely.
