# LLM Agent Exploits Salesforce Community Portals: 263 Objects, 55 Apex Methods Exposed

Researchers demonstrated an LLM-based AI agent autonomously exploiting Salesforce community portals. At a single target portal the agent enumerated 263 objects and 55 Apex methods, subsequently extracting PII and files. The attack illustrates how LLM-driven reconnaissance can scale enumeration of enterprise SaaS APIs far faster than manual testing, turning misconfigured Salesforce portals into significant data exposure risks.
