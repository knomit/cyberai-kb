# AI agent capability and security blast-radius are scaling together: each new autonomy primitive opens a matching attack surface

H1 2026 shows agent capability gains and agent attack surface expanding in lockstep — each new autonomy primitive creates a corresponding security exposure. Persistent memory and config files (Claude Code's .claude/settings.json, OpenClaw's SOUL.md) became a persistence vector: the Miasma worm plants a SessionStart hook that re-harvests credentials on every session and survives token rotation. Autonomous payments (AWS Bedrock AgentCore Payments via USDC/Stripe) let agents pay downstream services without per-transaction human approval — explicitly introducing 'unauthorized agent spend' risk. Broad tool/connector access made indirect prompt injection the primary attack vector (Google: +32% detections Nov 2025–Feb 2026) and enabled the tool-trust failures catalogued in the master AI-security synthesis (Agentjacking via Sentry MCP, OpenClaw IPI, the 'lethal trifecta'). The skill/marketplace supply chain remains largely unguarded (a fake skill reached ~26,000 agents past every scanner; an audit found 12% of OpenClaw marketplace skills carried injection payloads). The defensive response is moving down the stack toward capability-restriction and hardware-rooted trust: Proton Pass AI access tokens (scoped, expiring, audited) and a Confidential Computing Summit push (Google, Apple, Microsoft, AMD, Intel, Anthropic) for chip-level cryptographic agent identities, on the argument that software-only constraints keep failing. Net: securing agents is now an infrastructure problem that must scale with each capability they gain, not a bolt-on control.
