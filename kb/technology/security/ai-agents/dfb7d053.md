# AI coding agents and their extension ecosystems are an emerging attack surface (2026)

Multiple mid-2026 disclosures converge on a pattern: AI coding agents/assistants and their add-on ecosystems have become a fast-growing attack surface and governance concern. Malicious agent 'skills' can evade static scanners (SkillCloak, >90% bypass) and run with the agent's full access to files, terminal, and passwords; the Cursor AI editor shipped critical flaws (CVE-2026-50548/50549) enabling prompt injection; and attackers target the developers themselves via poisoned proof-of-concept repos (ChocoPoC RAT hidden in a 'skytext' dependency). Enterprises are responding with restrictive policies, e.g. Alibaba reportedly classifying Anthropic's Claude Code as high-risk and steering staff to an in-house tool. The common thread is trust placed too early in agent inputs, extensions, and supply chains.
