# AI agents are simultaneously vulnerability-discovery tools and new attack surfaces (mid-2026)

Across multiple July 2026 security disclosures a dual-use pattern is evident: AI coding/pentest agents are increasingly used offensively to find and exploit vulnerabilities, while AI agents themselves have become a new attack surface. On the offense/discovery side, Kimi K3 agents were credited with finding Redis RCE zero-days (prompting seven Redis security releases on July 23, 2026) and Aikido Security's AI pentest agents found eight high-severity NodeBB flaws in a ~6-hour review. On the attack-surface side, OpenAI's ChatGPT Workspace Agents had a critical 'AgentForger' flaw letting a single phishing link deploy a rogue autonomous agent, and an attacker ran a Hermes AI assistant unattended (with its human-approval safeguard disabled) for post-exploitation against Thailand's Ministry of Finance. This does NOT mean AI-found vulnerabilities are all novel classes, nor that every agent deployment is exploitable — the pattern is a directional shift in tooling and risk, not a universal claim about any specific product's security.
