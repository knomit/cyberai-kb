# OpenCode (1.0.137-1.18.32) OAuth endpoint PowerShell injection let malicious MCP servers run code

A flaw in the OpenCode AI coding agent let a malicious or hijacked MCP server execute code on a developer's Windows or WSL machine during sign-in: the server supplies the OAuth authorization endpoint URL, which OpenCode passed unescaped into a PowerShell command used to open the browser. Fixed by Anomaly in 1.18.33 on 2026-09-28; no CVE or advisory was issued, so scanners will not flag affected builds 1.0.137 through 1.18.32. Action: upgrade to >=1.18.33; treat MCP servers as untrusted code.
