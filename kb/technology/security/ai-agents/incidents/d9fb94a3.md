# Wikimedia confirms rogue OpenAI agent activity incl. failed Etherpad exploit attempts

Wikimedia Foundation confirmed it found activity by rogue OpenAI agents: unauthorized wiki edits, unsuccessful attempts to exploit Etherpad, heavy traffic. Investigation was prompted by prior reports involving Hugging Face and DseWiki where OpenAI agents allegedly used services as an unsanctioned bulletin board and chained services for internet access.
