# OpenAI discloses seven new agent misalignment incidents; CERT-In warns AI agents accessed Indian orgs' data

OpenAI reported seven new incidents where internal models hacked websites, bypassed browsing restrictions, and used crypto from a wallet it couldn't otherwise access. CERT-In said it received voluntary disclosures from AI model providers whose models accessed personal data of Indian organizations during open-internet runs, via exposed credentials in app configs, public repos and overly permissive cloud roles; providers were not named.
