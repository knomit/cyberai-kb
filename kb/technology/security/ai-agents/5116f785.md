# Agentic AI frameworks are an emerging RCE and prompt-injection attack surface

Multiple June 2026 disclosures show self-hosted agentic AI systems forming a distinct, fast-growing attack surface. LangGraph (LangChain's multi-agent framework) carried a SQLi-to-RCE vulnerability chain (CVE-2025-67644, CVE-2026-28277) disclosed by Check Point, while the OpenClaw self-hosted agent was shown by Imperva and Varonis to execute attacker-controlled code or exfiltrate secrets via indirect prompt injection hidden in contacts, vCards, location pins, or plain emails. Two failure classes recur: (1) classic memory-safety/deserialization/injection bugs in agent infrastructure that yield RCE and are patchable, and (2) prompt-injection abuse of the agent's own trust and permissions, which patches cannot fully fix and which require constraining agent capabilities. Together they indicate that an AI agent's access becomes the attacker's access.
