# Mid-2026: AI is both a weapon and a first-class attack surface; prompt injection and tool-trust are the core failure mode

June 2026 reporting shows AI on both sides of the security equation, with untrusted input becoming executable action via an agent's own trust and tool access as the dominant new failure mode. AS A WEAPON: criminals weaponized Google's Gemini to mass-produce phishing pages and smishing (Outsider PhaaS). AS AN ATTACK SURFACE, three sub-patterns recur: (1) classic infrastructure bugs yielding RCE that are patchable — LangGraph's SQLi-to-RCE chain (CVE-2025-67644, CVE-2026-28277, Check Point); (2) indirect prompt injection abusing the agent's own permissions, which patches cannot fully fix — OpenClaw driven to run code/exfiltrate secrets via contacts/vCards/location pins/plain emails (Imperva, Varonis), Claude Code's GitHub Action hijackable via one issue, rogue agent 'skills' slipped past guard scanners (Trail of Bits), ~20,000 Instagram accounts hijacked via Meta's AI support chatbot; and (3) compromised trust boundaries in connected tooling relaying untrusted data as trusted — 'Agentjacking' via the Sentry MCP server feeding attacker input to Claude Code/Cursor as system output (Tenet Security). Defenders are shifting from brittle guard/scanner detection toward curation and capability-restriction (e.g., OpenAI's ChatGPT 'Lockdown Mode'). National-security concern is escalating in parallel (U.S. order to suspend Anthropic's most advanced models for foreign nationals). Net: the AI agent/tooling stack — models, frameworks, MCP servers, skills, CI/CD integrations — is a first-class security and policy battleground, and an agent's access is the attacker's blast radius.
