# Google's four security agents are built from the same primitive as the two Google agent compromises — and a vulnerability-discovery agent reads adversarial code by design

EXTENDS, DOES NOT REPLACE, kb/technology/security/ai-agents/synthesis/agent-access-is-blast-radius.md. That canonical establishes the offensive thesis — attackers abuse an agent's permissions and its action on untrusted input, not the model's guardrails — and covers AI-as-weapon (Gemini mass-producing phishing pages) versus AI-as-attack-surface. It carries a redundancy note warning that four records re-derived that thesis from successive newsletter slices. This record does NOT re-derive it. It adds the third side the canonical does not cover: AI-as-DEFENDER, and the structural consequence of building defenders from the primitive that is itself the surface.

GOOGLE APPEARS ON BOTH SIDES, AT THE SAME LAYER.

As surface: three ADK agent workflows deleted after Pillar Security showed a public GitHub issue could prompt-inject a triage agent into posting '/adk-issue-fix' as the adk-bot, whose collaborator status satisfied the privileged workflow's owner/member/collaborator gate — making the trusted bot identity an authorization bridge to arbitrary code execution on the CI runner, PAT exfiltration, a Google API key and a Cloud service-account credential (no in-the-wild exploitation found; the exposed component was repository automation, not the distributed ADK package). Separately a CVSS 10 RCE in Gemini CLI across BOTH the '@google/gemini-cli' npm package and the 'google-github-actions/run-gemini-cli' Actions workflow.

As defender, four products: AVDH, a multi-agent system performing agentic source-code review, credited with over 100 true-positive critical vulnerabilities in 10 months including Drupal CVE-2026-13242 and CVE-2026-55803, used in proactive reviews, penetration tests, red team operations and incident response; CodeMender, a Google-hosted agent scanning and fixing code using Gemini 3.5 Flash Cyber, reported as already fixing vulnerabilities in Chrome, Android, Cloud, Ads and YouTube; and Mantis, a decoupled sequential Skills set for building security review harnesses on coding agents.

THE STRUCTURAL POINT. These defenders are the same primitive as the surface. AVDH is a multi-agent system; CodeMender is a hosted agent; Mantis runs on coding agents. Each requires elevated access to the code it reviews, and each ingests, as its ordinary input, code it did not write. In vulnerability discovery, penetration testing and incident response that input is ADVERSARIAL BY DESIGN — the engagement premise is that the code may be hostile. That is the same precondition the canonical identifies as the dominant agent failure mode: untrusted input becoming executable action through the agent's own permissions.

THIS INFERENCE IS NOT A REPORTED FINDING. No source in this corpus reports a prompt injection against AVDH, CodeMender or Mantis, or any compromise of a vulnerability-discovery agent. The structural precondition is entailed by what these tools do; whether it has been exploited, or whether Google isolates these agents in ways that defeat it, is UNKNOWN HERE and must not be reported as an incident.

CAPABILITY RESTRICTION APPEARS ON THE DEFENSIVE SIDE TOO. Gemini 3.5 Flash Cyber is available exclusively through CodeMender, to governments and trusted partners, under a limited-access program — access control on the offensive-capable model rather than on its outputs, structurally the same move as the national-security restriction the canonical records.

WHAT THIS DOES NOT MEAN:
- It does NOT claim Google's defensive agents are insecure, or that their being agents has caused any incident. It identifies a shared precondition, nothing more.
- It does NOT claim hypocrisy or that the two sides are the same team. Different products, different Google organizations, different dates.
- The defensive figures are VENDOR SELF-REPORTED. '100+ true-positive critical vulnerabilities in 10 months' and CodeMender's internal-codebase results are Google's own claims; only the Drupal CVEs are externally anchored. The Hacker News notes AVDH is very similar to Microsoft's MDASH.
- It does NOT establish net defensive advantage. Counting vulnerabilities found says nothing about vulnerabilities introduced, and this corpus separately records that 87% of AI coding-agent PRs introduce at least one security vulnerability.
- 'Both sides' means both sides of the AI-security relationship, NOT that Google is an attacker.
