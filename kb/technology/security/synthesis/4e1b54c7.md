# Trusted/abandoned software components remain a prime supply-chain attack vector (mid-2026)

Mid-2026 disclosures show attackers repeatedly weaponizing trusted or neglected software distribution channels rather than exploiting memory bugs: hundreds of abandoned Arch Linux AUR packages were hijacked to deliver the atomic-lockfile payload ('Atomic Arch', per Sonatype); JavaScript served by popular WordPress plugins PushEngage, OptinMonster, and TrustPulse (all Awesome Motive) was tampered to create rogue admin accounts and backdoor plugins (disclosed by Sansec); and a network of 152 Chrome 'wallpaper' extensions (~105K installs) pushed adware/PUPs. Common thread: developer-trust surfaces (package repos, plugin scripts, browser extension stores) are exploited because users implicitly trust them and abandoned components lack maintainer oversight.
