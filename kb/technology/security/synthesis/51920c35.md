# Daily professional tools (IDE, AI assistant, database, email) have become the primary exfiltration attack surface — perimeter is bypassed by design

The Jun 4 2026 threat cluster shows a consistent pattern: every significant attack targets tools professionals use every day in trusted contexts, not network perimeters. (1) VS Code / GitHub.dev: one click steals a full GitHub OAuth token — not scoped to a repo, giving read/write access to all the victim's private repos. The attack vector is webview message-passing inside the IDE. (2) Google Gemini on Android: a poisoned WhatsApp, Slack, SMS, or Signal notification hijacks the voice assistant — no malicious app required, just a notification treated as context. Gemini had previously been hardened against this class, demonstrating that each new input channel requires its own hardening. (3) Redis CVE-2026-23479: RCE via a 2-year-old use-after-free in database code; most Redis cloud instances run with the default user having full privileges, meaning authentication is effectively not a barrier. (4) Stock exchange exec Outlook: 5 months of continuous inbox exfiltration, blended with normal traffic via Dropbox and OneDrive. The unifying characteristic: all four attacks exploit the fact that daily professional tools — IDEs, AI assistants, databases, email clients — sit inside the trusted zone, use legitimate protocols, and generate traffic that is structurally indistinguishable from legitimate use. Traditional perimeter defense is irrelevant when the attacker is operating through the same channels the victim uses to do their job. Compound risk: Apple Silicon is now the de facto developer platform (90% of frontier lab developers, Mac-first app launches), which concentrates this attack surface — compromising VS Code or Gemini on a Mac mini running as an AI agent means direct access to the developer's full repository history and AI memory.
