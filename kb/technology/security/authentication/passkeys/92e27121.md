# Passkey-themed vishing used to enroll attacker authenticators and hijack Microsoft cloud accounts

Microsoft disclosed a campaign, observed across cloud intrusions since May 2026, in which attackers hijack Microsoft 365 accounts using passkey-themed social engineering rather than any flaw in passkeys themselves. It begins with calls and texts to employees: the attacker poses as IT support, claims a passkey, MFA or single sign-on setting needs attention, and directs the target to a lookalike sign-in page. The observed intrusion pattern is an unusual sign-in followed by registration of new authentication methods (giving the attacker durable access), then Microsoft Graph queries and bulk downloads from SharePoint, OneDrive and email. Microsoft attributed the initial-access activity to several actors including Storm-3121 and Storm-3032, whose tradecraft overlaps with a loose cybercrime collective tracked elsewhere as Cordial Spider, O-UNC-045, PREY-0058 and UNC6671. Microsoft disclosed this alongside a separate campaign that sent over a million CEO-impersonation scam emails between August 3 and 5, 2026, pressing accounts-payable staff to make ACH transfers for a supposed ServiceNow annual subscription, with evidence the operators used generative AI to write and tailor the templates.
