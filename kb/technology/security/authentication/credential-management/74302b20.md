# Android added encrypted password manager switching that also transfers passkeys

Google introduced a password manager switching experience on Android that no longer requires downloading a CSV file to migrate to a new app. Google stated that historically moving passwords meant downloading them into an unencrypted text file, leaving them unprotected on the device, and that passkeys could not be transferred at all, forcing users to recreate them site by site. The new transfer experience is available initially on Google Password Manager, 1Password, Bitwarden Password Manager, and Dashlane, with more to follow.
