# Microsoft made DNS-over-HTTPS generally available on Windows Server 2025 DNS Server

Microsoft announced that DNS-over-HTTPS (DoH) for the Windows DNS Server is generally available on Windows Server 2025 for client-to-server DNS traffic, letting organizations deploy encrypted and authenticated client-to-resolver DNS directly within existing on-premises DNS infrastructure. Reported in The Hacker News ThreatsDay bulletin.
