# Chrome 'Adblock for YouTube' extension (10M+ installs) carries dormant JS-injection capability

Security firm Island found that the Chrome extension 'Adblock for YouTube' (ID cmedhionkhpnakcndndgjdbohmhepckk), which has more than 10 million installs and a Featured badge on the Chrome Web Store, contains the architectural ingredients for arbitrary JavaScript execution on any website. Per researchers Oleg Zaytsev and Shachar Gritzman, the capability could be activated by a single server-side configuration change — without an extension update, store review, or any visible sign — while the extension still delivers its promised ad-blocking functionality.
