# Claude Mythos Preview derived new attacks on HAWK-256 and 7-round AES-128

Anthropic reported that Claude Mythos Preview helped derive an end-to-end key-recovery attack against the HAWK-256 lattice signature scheme by exploiting a previously unused symmetry in the underlying lattice; the released implementation has an expected runtime of about 3 hours 42 minutes on a 96-core server. Claude also produced a 200- to 800-fold speedup for an attack on seven-round AES-128, removing a 256-way guessing step from an existing meet-in-the-middle attack (it applies to 7 of AES-128's 10 rounds and still requires an impractical number of chosen plaintexts). Anthropic said neither result affects production systems; HAWK remains a candidate in NIST's post-quantum standardization process and the public recovery code only targets the smaller HAWK-256 parameter.
