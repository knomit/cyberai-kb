# ClickFix delivered via a Google Doc sidebar built as a bound Apps Script, requiring no download to run

Huntress disclosed a ClickFix attack in which a threat actor posing as a crypto marketing executive targeted a security researcher on X and sent a link to a REAL Google Doc with a custom sidebar. The sidebar displayed a fake decryption-failure message with supposed remediation instructions per operating system, including commands to copy and paste into Terminal, plus a 'manual update' button — those are what delivered the malware: an AMOS infostealer on macOS or a PowerShell loader chain on Windows.

The critical mechanism: 'The sidebar itself was a Google Apps Script bound to the document, so nothing had to be downloaded for it to run.' The Apps Script executed CLIENT-SIDE in the victim's browser and collected the victim's public IP address and geolocation and scanned for crypto wallets.

The defensive consequence: a link to a legitimate docs.google.com document is not a safe link, and download-based detection sees nothing here. Treat bound Apps Scripts on shared documents as executable content, and never run terminal commands a document instructs you to paste.
