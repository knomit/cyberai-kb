# In four 2025-26 Microsoft assistant and agent disclosures the vendor's own component was the exploit vehicle, not just the target — so first-party allow-listing gives no coverage

EXTENDS, DOES NOT REPLACE, two existing records. kb/technology/security/ai-agents/synthesis/agent-access-is-blast-radius.md establishes that agents are compromised through their permissions and their action on untrusted input rather than through model guardrails. kb/technology/security/phishing/d39aa68b.md establishes the analogous point one layer up, for users: 2026 phishing increasingly runs inside genuine vendor channels, so 'is this page real?' stops being a useful check. This record adds the INFRASTRUCTURE-layer version that neither states: in each of four separate disclosures, a FIRST-PARTY Microsoft component supplied the capability the attack needed.

THE FOUR CASES, AND WHICH FIRST-PARTY COMPONENT CARRIED THE ATTACK.
- ECHOLEAK (CVE-2025-32711, CVSS 9.3, Microsoft 365 Copilot). Hidden instructions in an inbound email are ingested as data during ordinary use ('summarize my inbox'); document contents are base64-encoded into an img URL and auto-fetched. The exfiltration was PROXIED THROUGH MICROSOFT'S OWN TEAMS ASYNC PREVIEW API, so it APPEARS AS AN INTERNAL MICROSOFT REQUEST. Four techniques defeated Microsoft's XPIA classifier, one of which was using that Teams proxy to bypass content security policy.
- AZURE DEVOPS MCP SERVER (Manifold Security). Microsoft's OFFICIAL MCP server had one tool returning pull-request descriptions WITHOUT the prompt-injection guardrail applied to its other tools. Because PR descriptions accept Markdown and therefore invisible HTML comments, hidden instructions execute in a reviewer's coding agent WITH THAT USER'S OWN PERMISSIONS.
- COSNITCH (CVE-2026-24301, Varonis Threat Labs, Copilot Personal). Three flaws allowing one-click exfiltration from connected apps, reached in part via AN UNDOCUMENTED URL PARAMETER THE ASSISTANT ITSELF SURFACED under repeated questioning — the product disclosed its own attack surface.
- AUTOJACK (Microsoft researchers, AutoGen Studio 0.4.2.2). An attacker's web page, once loaded by a browsing agent, reaches A PRIVILEGED LOCAL SERVICE ON THE SAME MACHINE — that service being AutoGen Studio, Microsoft Research's own prototyping interface — and spawns a host process with no credentials and no further user interaction.

WHAT FOLLOWS FOR DEFENCE. Controls that decide by PROVENANCE OF THE COMPONENT — allow-list Microsoft domains, trust the official MCP server, treat first-party API traffic as internal — have no purchase on any of these. In each case the component is genuinely Microsoft's; only what it was made to carry differs. The controls that would have applied are per-tool guardrail parity (the Azure DevOps case is a guardrail applied to some tools and not others), egress scrutiny that does not exempt first-party endpoints (the EchoLeak case), and restricting what a local privileged service will accept from page-originated requests (AutoJack).

WHAT THIS DOES NOT MEAN — load-bearing:
- THESE ARE FOUR UNRELATED DISCLOSURES by four different parties (Aim/undisclosed for EchoLeak, Manifold Security, Varonis Threat Labs, Microsoft's own researchers) with NO shared attribution, infrastructure, or actor. The connection is a shared technique class, not a campaign.
- IT DOES NOT CLAIM MICROSOFT IS UNUSUAL. This corpus records the same shape elsewhere against other vendors' own components, and no comparison across vendors is offered here. The cluster is Microsoft-heavy because the source records are.
- SCOPE LIMITS FROM THE SOURCES MUST SURVIVE CITATION. CoSnitch is scoped to COPILOT PERSONAL at copilot.microsoft.com; the research does NOT state Microsoft 365 Copilot was affected, patches shipped 18 August 2026, and researchers found NO EVIDENCE OF IN-THE-WILD EXPLOITATION. EchoLeak is a 2025 CVE, not a 2026 one. AutoJack's record carries ZERO recorded sources and concerns a prototyping interface rather than a production product.
- IT DOES NOT CLAIM THESE REMAIN EXPLOITABLE. EchoLeak, CoSnitch and the Azure DevOps guardrail gap are recorded as disclosed and addressed; no source here reports current exposure.
- IT DOES NOT ESTABLISH A RATE. Four disclosures over roughly a year is what this corpus happens to record, not a measured frequency, and the corpus's own selection toward notable disclosures should be assumed.
