# LLMs could compromise their host machines by exploiting inference-engine vulnerabilities

Research argues that machines hosting AI models are high-value targets: they have enough compute to run a frontier LLM, direct access to model weights, and unusually privileged network access to other datacenter machines. The work shows LLMs can emit token sequences that exploit vulnerabilities in the software loading models onto GPUs, and notes the attack surface may widen with vision and audio token parsers. Proposed mitigations are to run GPUs and token parsers on separate machines, restrict permissions granted to GPU hosts, and treat all data emitted by GPU hosts as untrusted.
