# AI models let attackers cheaply retry failed intrusion steps like privilege escalation

Security researchers report that the nearer-term effect of AI on cyberattacks is not a wholly new attack capability but a collapse in the cost of retrying failed attack steps. In the routine case, an attacker reaching a low-privilege cloud account whose first privilege-escalation attempt fails would previously face hours of documentation reading, permission checks, and script debugging (often getting stuck); with an AI model in the loop, the error gets explained, the script gets fixed, and a fresh enumeration path is under test within minutes. No individual step is a new capability, but together they strip time, skill, and cost out of the research-and-troubleshooting middle stage of an intrusion.
