# Windows PnP USB auto-install abused for SYSTEM takeover (Plug And Pwn)

Researchers Alejandro Hernando and Borja Martinez described 'Plug And Pwn: Weaponizing Windows PnP Auto-Install' (prepared for DEF CON 34): Windows Plug and Play can be abused to fetch signed vendor software for an emulated USB device and execute privileged installation components, which they chained to SYSTEM code execution on a fully updated Windows 11 machine by an unprivileged user. The path can also be triggered over Remote Desktop via USB redirection where enabled; Microsoft says such redirection is not allowed by default.
