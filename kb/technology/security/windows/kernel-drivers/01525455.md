# BTR Reforged: Microsoft Defender's BTR.sys driver weaponized as a kernel operation primitive

Check Point Research disclosed 'BTR Reforged', a technique abusing Microsoft Defender's own legitimately signed boot-time remediation driver BTR.sys (Boot Time Removal Tool) to perform arbitrary kernel-level file and registry operations on Windows 7 through Windows 11 25H2. No software vulnerability is exploited and no external driver is imported. BTR.sys is embedded in Defender's MpEngine.dll as the BOOTTIMETOOL resource and is deployed when Defender must finish removing malware after reboot. Because it is a required Windows component it cannot be added to Microsoft's Vulnerable Driver Blocklist or blocked via WDAC without breaking Defender. Jiří Vinopal of Check Point Research reverse-engineered the driver's undocumented transaction protocol and found every configuration blob is RC4-encrypted with a 256-byte key hard-coded in the .rdata section, unchanged across 18 unique 64-bit builds since Windows 7. The technique registers the driver via direct registry writes (Type=1, Start=1, Group='Boot Bus Extender'), bypassing the Service Control Manager and producing no Event ID 7045. Operations execute from Ring 0 attributed to the System process (PID 4) during a 'golden window' after the filesystem becomes writable but before Defender's user-mode services start, allowing removal of security binaries such as WdFilter.sys and MsMpEng.exe. Presented at Black Hat USA 2026 and DEF CON 34; paper and proof-of-concept tool BTR_CLI published August 20, 2026. Check Point found no evidence of real-world abuse.
