# AI coding-agent and assistant tooling is emerging as a distinct attack surface (mid-2026)

Multiple late-July-2026 disclosures show AI developer tooling and assistants becoming a security attack surface in their own right. Ruflo, an open-source agent meta-harness for Claude Code and OpenAI Codex, exposed an unauthenticated Model Context Protocol bridge (CVE-2026-59726, CVSS 10.0) enabling remote code execution, API-key theft, and poisoning of the agent's persisted 'AgentDB' memory. Separately, a prompt-injection technique against Microsoft 365 Copilot for Word showed hidden document instructions can not only alter generated output but propagate themselves into newly created documents. Common thread: attacks target the agent's tool bridge and its persistent memory/output rather than a traditional app endpoint, and self-propagation / memory-poisoning are recurring goals. This is a pattern observation from single-source news items, not a comprehensive survey.
