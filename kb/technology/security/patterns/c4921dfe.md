# AI-tooling vendors are leaving reported flaws unpatched long enough that researchers resort to full disclosure

Pattern observed across two independent July 2026 disclosures against AI developer/agent tooling. (1) Mindgard reported Cursor's Windows git.exe repo-root execution flaw on 2025-12-15 and published full technical details seven months later, on 2026-07-14; as of 2026-07-15 there was still no patch, no Cursor advisory, and no assigned CVE. (2) Manifold Security found Claude for Chrome still honors forged (isTrusted:false) clicks on #claude-onboarding-button to launch allowlisted Gmail/Docs/Calendar tasks in v1.0.80 — eight versions after Anthropic's May 2026 ClaudeBleed response, with the researchers' proposed one-line fix (reject synthetic clicks at the top of the handler) unshipped.

Common shape: the vulnerable path is mundane and non-AI (a binary-resolution search order; a missing trusted-event check), not prompt injection or model misbehavior — in both cases no agent or model is in the loop. Vendors shipped many releases in the interim without fixing. Researchers ultimately published without a patch, framing full disclosure as the remaining protection. In both cases the only available user remedies are configuration workarounds, not updates: for Cursor, AppLocker/Windows App Control path-based deny rules under workspace roots or opening untrusted repos in a disposable VM/Windows Sandbox; for Claude for Chrome, disabling 'Act without asking' and auditing extensions with claude.ai permissions.

SCOPE AND CAVEATS: This is a two-instance pattern from a single day's reporting, not a measured industry rate. Mindgard's most recent dated confirmation was 2026-04-30 against Cursor 3.2.16 while the current release was 3.11, so the Cursor flaw's presence in the newest build is inferred rather than confirmed by the researcher; The Hacker News did independently unpack the Claude for Chrome build and confirm both mechanisms in v1.0.80. WHAT THIS DOES NOT MEAN: it does not establish that AI tooling is less responsive than software vendors generally, nor that either vendor's delay was deliberate — neither vendor's reasoning is known, and both were still being asked for comment at publication.
