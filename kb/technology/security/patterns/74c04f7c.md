# Cryptocurrency wallet keys are a convergent target across software-supply-chain and hardware attack vectors

Mid-2026 disclosures show attackers converging on cryptocurrency wallet secrets through very different vectors. In a software-supply-chain path, a compromised Injective Labs GitHub repo pushed a malicious npm package (@injectivelabs/sdk-ts@1.20.21) that exfiltrated wallet private keys and seed phrases. In a hardware path, Ledger's Donjon team showed a ~$250k laser fault-injection attack that resets the password on unpatchable Tangem wallet cards to seize funds. The pattern: wallet key/seed material is a high-value objective that draws both remote supply-chain compromise and physical side-channel attacks, so key custody must assume adversaries at both layers.
