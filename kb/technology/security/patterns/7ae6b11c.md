# Default/unconditional-trust misconfigurations are a recurring exploitable root cause

Across mid-2026 disclosures, a recurring root cause of exploited exposure is software or appliances that grant access by default rather than verifying it. The Gravity SMTP WordPress plugin (CVE-2026-4020) registered a REST endpoint whose permission_callback unconditionally returned true, letting any unauthenticated visitor pull a full System Report with API keys and tokens. In the FortiBleed campaign against FortiGate appliances, the majority of compromised credentials were generic admin (35%) and built-in Fortinet system (28.3%) accounts, reflecting widespread failure to rename default accounts or rotate factory credentials. The pattern: insecure defaults and missing authorization checks repeatedly turn into mass-exploitation events, so auditing default-allow code paths and factory credentials is a high-leverage defensive control.
