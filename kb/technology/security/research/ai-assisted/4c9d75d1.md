# AI-assisted 'HTTP Terminator' found novel HTTP desync techniques and an Apache zero-day

PortSwigger reported that HTTP Terminator, an AI-assisted research system built by James Kettle, generated and proved new HTTP request-smuggling/desynchronization techniques after exploring roughly 30,000 candidate desync variations, and surfaced an Apache zero-day. Reported by The Hacker News, Aug 7, 2026.
