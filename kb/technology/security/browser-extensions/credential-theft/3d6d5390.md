# Twitch extension 'Twitch Enhanced Viewer | JeetBot' forwarded OAuth tokens of ~31,000 users to a Russian bot service

A malicious cross-store browser extension named 'Twitch Enhanced Viewer | JeetBot' leaked Twitch OAuth tokens from nearly 31,000 users to proxy servers run by a Russian commercial bot service. It was published on the Chrome Web Store on June 26, 2025 (about 30,000 users) and on Mozilla Firefox Add-Ons on July 7, 2025 (604 users). Current builds forward the token inline as an &auth= query parameter on a network-layer redirect to the operator's proxy. Because the token is a bearer credential, anyone holding it can read chat, send whispers and change account settings with no password and no two-factor prompt. The extension carried an allowlist of ten channels, mostly Russian-speaking streamers each with up to 1.1 million followers, for which it would stop forwarding viewers' tokens. The operator is identified in the site footer as a Cyprus-based developer named Aleksandr Popov. Firefox add-on version 85.8.7 fixes the behavior; an equivalent Chrome version was under review at the time of reporting. Research credited to Socket.
