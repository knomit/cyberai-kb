# Trellix source code breach: unauthorized access to source code repository

Cybersecurity company Trellix (formerly McAfee Enterprise + FireEye) confirmed (May 2, 2026) it suffered a breach enabling unauthorized access to 'a portion' of its source code repository. The breach was 'recently identified.' Source code breach of a major cybersecurity vendor is significant as it could expose internal detection logic, vulnerability research, and proprietary threat intelligence.
