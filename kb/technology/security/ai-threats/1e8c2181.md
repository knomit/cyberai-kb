# AI-enabled juvenile attackers: 17-year-old extracts 7M+ user records using AI-generated code

On December 4, 2025, a 17-year-old was arrested in Osaka, Japan under the Unauthorized Access Prohibition Act for using AI-generated malicious code to extract personal data of over 7 million users from Kaikatsu Club. Cited as a milestone example of 2026 as 'the year of AI-assisted attacks,' dramatically lowering the technical barrier to large-scale data breaches.
