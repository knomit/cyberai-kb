# First fully AI-agent-run ransomware attack (JADEPUFFER) identified by Sysdig

Security firm Sysdig's Threat Research Team reported what it believes is the first ransomware attack run from start to finish by an AI agent. The team named the operator JADEPUFFER; a large language model drove the intrusion, which exploited a remote code execution (RCE) vulnerability in Langflow to automate a database ransomware attack. Reported by The Hacker News, July 2, 2026.
