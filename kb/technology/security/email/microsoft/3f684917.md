# Empty SMTP envelope sender bypasses Microsoft RejectDirectSend (ReliaQuest)

ReliaQuest found an empty SMTP envelope sender can bypass Microsoft's RejectDirectSend control, letting external phishing carry an internal-looking address with no credentials or lookalike domain; attackers observed targeting leadership.
