# Malicious SIM card can run code inside cellular IoT modems

Researchers at the University of Birmingham and security firm Fuzzware showed a malicious SIM card (using proactive SIM/STK-style commands) can order its host cellular module to run attacker-chosen commands. They tested 26 phones and cellular modules, found the capability enabled in 9, and executed their own code on a commercial EV charger. Six of eight cellular modules accepted the command (five were Quectel parts, pulled from an EV charger, industrial router, and a car telematics unit); only 3 of 18 phones were affected (OPPO Find X5, OPPO Reno 14 F 5G, ASUS Zenfone 9 — no iPhone or Pixel). The attack requires a hostile card physically placed in the SIM slot.
