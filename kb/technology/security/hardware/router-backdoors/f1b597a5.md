# Zbtlink routers ship with factory 'ENDLESSDOORS' backdoor (VulnCheck)

VulnCheck reported a factory-shipped backdoor implanted across all 21 firmware images currently available from Chinese router vendor Zbtlink, spanning more than 2 years and at least 20 router models. Codenamed ENDLESSDOORS, the implant is built on a small tool called rctl (remote control linux). It starts automatically, runs as a userland process with root privileges while masquerading as a Linux kernel thread (blending with legitimate kworker processes), and beacons to Chinese command-and-control infrastructure as often as every 35 seconds. VulnCheck CTO Jacob Baines described the findings.
