# DDRop interposer attack breaks freshness guarantee in Intel TDX and AMD SEV-SNP

Researchers disclosed DDRop, a hardware attack that defeats memory integrity in Intel TDX, Intel Scalable SGX, and AMD SEV-SNP confidential computing. An attacker who already controls the server's software and can briefly physically access the machine inserts an interposer board (under $200 to build) between CPU and memory module; the interposer silently drops writes, so the processor reads stale ciphertext that still decrypts correctly and the encryption engine detects nothing. The underlying gap is that these designs omit a freshness guarantee in order to cover large cloud memory footprints — they prove memory is encrypted, not that it holds the latest written value. DDRop is the first active interposer attack against DDR5 in current cloud servers and the first to break integrity (not just confidentiality) on an up-to-date Intel TDX system; prior DDR5 work like TEE.fail was passive, and active DDR4 attacks such as Battering RAM relied on address-swapping that DDR5's redesigned command format blocks. Note both preconditions are required: software control AND brief physical access — it is not a remote attack.
