# Bit2Watt: cloud GPU tenants could destabilize power grids with no exploit

Three Zhejiang University researchers described 'Bit2Watt', an attack in which a cloud tenant using only ordinary GPU access can modulate a data center's power draw fast enough to threaten the electrical grid it runs on—without any exploit, malware, or stolen credentials. Because a GPU's power draw tracks its computation, toggling tensor-core saturation against idle on a schedule produces a controllable power oscillation at the wall socket. The team measured the power modulation on real GPUs and simulated the resulting grid destabilization. The paper was accepted to CHES 2026, the IACR's hardware-security conference.
