# CERT/CC warns of undocumented admin backdoor in Tenda router firmware

CERT/CC warned that several firmware versions from Chinese network device manufacturer Tenda embed an undocumented authentication backdoor that enables administrative access to the devices' web management interface, as reported by The Hacker News.
