# usbliter8 unpatchable exploit on Apple A12/A13 SecureROM

Security researchers at Paradigm Shift published a working exploit dubbed usbliter8 that achieves arbitrary code execution inside the SecureROM of Apple's A12 and A13 chips (the public PoC also supports S4 and S5 SoCs; A12X/A12Z theoretically possible but not yet implemented). Because SecureROM code is burned into silicon at manufacture, no software update can patch it, so affected devices remain vulnerable for their service life. The attack is not remote: it requires physical possession with the device in DFU mode connected via USB to a dedicated RP2350-based microcontroller board, after which the exploit completes in under two seconds, before Apple's signed boot chain loads. The full write-up and PoC went public on June 18, 2026, following coordinated disclosure with Apple Product Security.
