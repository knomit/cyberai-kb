# Anthropic shares Claude Mythos 5's security findings with defenders without exposing the model itself

Anthropic made Claude Mythos 5 — its most capable model — available for code scanning inside Claude Security for Claude Enterprise plan customers, letting them scan codebases for vulnerabilities and receive suggested patches. The access model is deliberately asymmetric: users of partner tools receive suggested patches or alerts but have no way to prompt the model directly, so they cannot ask it to write an exploit. Anthropic also announced a Defender Advantage Fund (0xDAF) providing $35 million in credits to organizations patching vulnerabilities in open-source projects, automating scanning and patching, and experimenting with new security approaches.
