# China-linked Velvet Ant backdoored Linux login software (PAM/OpenSSH) for nearly a decade

Security firm Sygnia reported that a China-nexus group it tracks as Velvet Ant backdoored the PAM and OpenSSH components that control Linux logins, hiding access where ordinary cleanup could not reach. The earliest traces go back to 2016. Rather than dropping new malware, the attacker modified trusted login programs themselves, so activity resembled normal administration and required no exploit. On many machines the attacker replaced the main PAM login module with backdoored copies—some allowing entry via a secret password, others silently recording real usernames and passwords as users logged in. The targeted network had no direct internet access, so the group first staged through internet-facing systems.
