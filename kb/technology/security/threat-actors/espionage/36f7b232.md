# BlueMoon exploit kit chaining Chrome and Windows zero-days spread across four espionage groups in a week

BlueMoon is a previously undocumented exploit kit that chains two zero-day issues in Chromium-based browsers - one giving remote code execution in the renderer and one giving sandbox escape, both in Chrome's V8 engine - with a Windows kernel local privilege escalation, delivered via phishing. Its first observed in-the-wild use is attributed to the China-aligned state-sponsored group APT31 on August 28, 2026. Within days several other espionage-motivated clusters, the majority with a suspected China nexus, were using the same kit, making four groups inside about a week. Analysts assessed that its ease of adoption makes further proliferation to both espionage-motivated and financially motivated actors likely, until patched versions are fully rolled out across all Chromium-based browsers.
