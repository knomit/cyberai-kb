# CVE-2026-51990: UNC3569 chained Sogou Input Method weaknesses for one-click GRAYRABBIT backdoor install

Gen Digital published research on September 10-11, 2026 describing how the China-linked group UNC3569 exploited Sogou Input Method - one of the most widely used tools for typing Chinese characters on Windows, made by Tencent - to install a backdoor from a single crafted link, ending with the attacker able to do anything the logged-in user could. The chain combines unvalidated command-line argument injection through the sgbiz: URI handler with a known vulnerability in Sogou's bundled, outdated Chromium 80 engine; because that browser runs without a sandbox and with important web-security protections disabled, the exploit reaches code execution. Gen reported the issue to Tencent on April 9, 2026; Tencent replied the next day and confirmed on April 21 that a fix was complete and would reach all users by automatic update in version 16.3.0.3498. It is tracked as CVE-2026-51990. The payload is GRAYRABBIT, a small first-stage implant the group has used for years that provides a remote command shell, bidirectional file transfer, and on-demand loading of additional modules. Google Threat Intelligence has tracked UNC3569 since 2021, ties it to China's hacker-for-hire scene, and says it targets government, education, technology, and finance mostly in East and Southeast Asia.
