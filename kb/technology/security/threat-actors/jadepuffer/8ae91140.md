# JADEPUFFER-linked (Storm-3168) attackers deleted Azure resources via compromised service principals

Microsoft, tracking the activity as Storm-3168, reported that JADEPUFFER-linked attackers ran a destructive attack in an Azure environment in early June 2026 over about 18 hours, using compromised service principals to target Storage Accounts, SQL databases, Key Vaults, Function Apps, recovery protection locks, VMs and App Services. Microsoft calls it an evolution of the actor's tradecraft. Consequence: service-principal credentials and recovery locks are a destructive-attack path in cloud tenants, not only a data-theft path.
