# Iran-linked (MOIS) hackers deploy new 'Cavern' C2 framework against Israeli orgs

An Iranian hacking group affiliated with Iran's Ministry of Intelligence and Security (MOIS) used a previously undocumented modular command-and-control framework dubbed Cavern (aka Cav3rn) to target Israeli organizations, per The Hacker News.
