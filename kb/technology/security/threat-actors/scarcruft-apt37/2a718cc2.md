# ScarCruft (APT37) uses fake Microsoft alerts to deploy NarwhalRAT

North Korean state-sponsored group ScarCruft (aka APT37) was observed in 2026 using spear-phishing emails impersonating Microsoft Account security notifications to deliver malware called NarwhalRAT, per Genians Security Center (GSC). The lure warned of 'abnormal activity' and repeated one-time-password generation to create concern over account compromise and induce the recipient to open the attachment. The attachment was not an HWP document but a ZIP archive containing a malicious LNK file.
