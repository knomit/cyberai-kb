# REF9403: North Korean 'Contagious Interview' hides OtterCookie malware in SVG images

Elastic Security Labs reported a campaign (tracked as REF9403) in which North Korean threat actors linked to the 'Contagious Interview' operation used steganography in SVG image files to conceal malicious payloads, delivered through fake job postings and coding challenges. Any developer who ran the project received a four-stage payload aligned with OTTERCOOKIE: a browser-credential and crypto-wallet stealer, a file stealer, a Socket.IO-based remote access trojan, and a clipboard stealer. The campaign continues DPRK-aligned targeting of software developers to steal sensitive data and cryptocurrency. Elastic discovered it after the actors targeted members of its own community.
