# HoneyMyte (Mustang Panda) adds a signed kernel-mode rootkit to the CoolClient backdoor

Kaspersky reports the threat actor HoneyMyte (aka Mustang Panda) is deploying an updated CoolClient backdoor bundled with a previously undocumented signed Windows kernel-mode rootkit that hides and protects malicious processes, files, registry objects and C2 network information. Victims were identified in Myanmar, Mongolia, Pakistan and Russia, including confirmed government entities, with CoolClient consistently deployed as a secondary backdoor following a PlugX infection. The kernel component is only deployed when CoolClient has full access to the Service Control Manager and the SeTcbPrivilege privilege; otherwise the malware skips driver deployment. CoolClient supports keylogging, clipboard theft, credential harvesting, file management, system reconnaissance and plugin-delivered functionality.
