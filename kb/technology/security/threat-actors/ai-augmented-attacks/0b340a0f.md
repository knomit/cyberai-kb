# CyberXero IAB uses Claude Code orchestration; 628,000+ Ukrainian records stolen (SOCRadar)

SOCRadar reported CyberXero, a Russian-speaking financially motivated initial access broker active since at least July 2026, running two parallel pipelines: a global automated campaign against WordPress/e-commerce (wp2shell CVE-2026-63030 and CVE-2026-60137, and CVE-2026-4815 SQLi in Support Board) and a curated manual campaign against Ukrainian energy and critical infrastructure. It combines commodity tools such as Cobalt Strike with an AI orchestration layer powered by Anthropic's Claude Code. Headline reports 628,000+ Ukrainian records stolen. Does not imply Claude Code itself is vulnerable; it is being misused as tooling.
