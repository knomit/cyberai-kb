# Kaspersky reports NightEagle, Hacking Cat and Toy Ghouls targeting Russian enterprises

Kaspersky reported that enterprises in Russia are the target of three threat activity clusters tracked as NightEagle (aka APT-Q-95), Hacking Cat, and Toy Ghouls, deploying backdoors, ransomware, and wipers. NightEagle, active since at least 2023, gained access in most incidents using compromised valid credentials against corporate VPNs, with connections originating from Russian-segment IP addresses linked to Cloudflare WARP tunnels and from European virtual infrastructure providers. It deployed GhostContainer, a modular backdoor granting complete access to a victim's Microsoft Exchange server, assembled from publicly available GitHub components including an exploit for CVE-2020-0688 and the GhostWebShell class from ysoserial. The suspected delivery path was extracting the server's cryptographic keys from the ASP.NET configuration, overwriting the VIEWSTATE parameter, and injecting a payload so the backdoor launches in memory. For lateral movement NightEagle downloaded tunneling tools to redirect RDP traffic via Microsoft dev tunnels and the open-source rdp2tcp, and exploited Active Directory vulnerabilities for privilege escalation. Operational consequence: valid-credential VPN access plus commodity GitHub tooling was sufficient for full Exchange compromise, so detection should not rely on novel malware signatures.
