# UAT-10147 uses AI throughout the attack cycle to scale web server compromises

Cisco Talos disclosed a Chinese-speaking cybercrime group dubbed UAT-10147 targeting Windows and Linux web servers globally across education, media, technology, and gaming sectors. The majority of victims are in Brazil, Bolivia, China, Canada, and Vietnam. The activity came to light via an open directory at 139.180.197[.]150 communicating with a compromised machine. The actor exploited publicly disclosed vulnerabilities to gain initial access at scale, using open-source offensive frameworks including Metasploit, ysoserial, PentestGPT, DeepAudit, and multiple privilege escalation exploits. AI tools were integrated at multiple phases: refining exploits, troubleshooting logic, automating post-exploitation workflows, validating exploits, reconnaissance, payload generation, persistence, and generating operational documentation. The exposed directory held a target list of roughly 170,000 URLs, split into 17 files of about 10,000 each; the top five destination countries were the U.S., India, the U.K., Germany, and the Netherlands. Attack chains exploit known flaws for RCE on a website or vulnerable IIS server, then run automated scripts to deploy SEO fraud malware, along with a payload named SPECTRE featuring EDR bypass and a Linux rootkit.
