# UTA0560 used reflected XSS on a university site to deliver the GRIMWEDGE backdoor to NGOs

Volexity reported that Chinese threat cluster UTA0560 ran a spear-phishing campaign against multiple NGOs on September 1, 2026, delivering a JavaScript backdoor called GRIMWEDGE that supports host reconnaissance, file and process management, command execution, and payload delivery. The delivery path is the notable part: the phishing emails linked to a legitimate US university website, abusing a reflected cross-site scripting flaw there to redirect recipients onto attacker-controlled infrastructure. That infrastructure fingerprinted visitors and served the exploit chain only to Chrome-on-Windows systems, filtering everyone else out. Because the link in the email pointed at a trusted third-party domain, URL reputation filtering would not have flagged it, and the selective serving suppresses the artifact from non-matching analyst environments. The exploit chain used is the BlueMoon chain documented separately.
