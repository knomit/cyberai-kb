# Russia's UAC-0145 (Sandworm) uses ClickFix fake CAPTCHAs against Ukraine

CERT-UA attributed a malware campaign to UAC-0145, a sub-cluster of Sandworm, the advanced hacking unit affiliated with Russia's GRU military intelligence. The attackers use the ClickFix technique—fake CAPTCHA checks on compromised websites that instruct victims to run a PowerShell command in a terminal—to trick Ukrainian targets into infecting their own machines with data-stealing malware. One variant downloads and saves a VBS file to the Startup autorun directory; a sample was named GHETTOVIBE.
