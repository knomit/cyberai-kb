# Head Mare exploits TrueConf server flaws to deploy PhantomCore RAT

The threat actor Head Mare was observed (detected by Kaspersky in July 2026) weaponizing a vulnerability chain in unpatched TrueConf videoconferencing servers to attack Russian companies across instrumentation, electronics, transport, energy, IT and software sectors. The flaws (KLCERT-26-057 and KLCERT-26-058) enable arbitrary code execution with elevated privileges and affect TrueConf server versions through 5.5.5 and earlier; attackers replace legitimate TrueConf client installers with poisoned versions that deliver the PhantomCore backdoor/RAT, connecting over default TCP port 4307.
