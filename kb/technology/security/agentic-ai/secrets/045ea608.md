# AI-assisted code commits leak secrets at roughly twice the rate of human-written commits

GitGuardian's 2026 State of Secrets Sprawl Report found that commits identified as AI-assisted leak secrets at approximately twice the rate of human-written commits, and most of the fastest-growing categories of leaked credentials are now connected to AI services (coding agents, MCP servers). Security teams should treat this as a non-human-identity (NHI) access-control problem, not merely a model-behavior problem, since AI coding agents can read .env/config files, duplicate secrets across CI/CD, tickets and chat tools that repo scanners don't cover, and are often over-permissioned.
