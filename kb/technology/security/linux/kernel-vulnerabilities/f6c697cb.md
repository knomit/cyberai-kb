# CVE-2026-46331 'pedit COW' Linux kernel local root exploit

CVE-2026-46331, nicknamed 'pedit COW', is an out-of-bounds write in the Linux kernel traffic-control subsystem's packet-editing action (act_pedit) that corrupts shared page-cache memory, allowing a local unprivileged user to gain root. The exploit never touches disk: it poisons the cached copy of the setuid-root /bin/su binary in memory, injects a payload, and runs the altered image as root, so file-integrity checks pass while a root shell is open. It requires act_pedit to be loadable and unprivileged user namespaces enabled (granting namespace-local CAP_NET_ADMIN). A public working exploit appeared within a day of the CVE assignment on June 16, 2026; Red Hat rates the flaw as 'important', and tested RHEL and Debian targets were vulnerable.
