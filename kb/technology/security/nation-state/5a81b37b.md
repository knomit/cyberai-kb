# ScarCruft (North Korea) compromises gaming platform supply chain, deploys BirdCall malware

North Korea-aligned ScarCruft hacked a video game platform in a supply chain espionage attack (May 2026), trojanizing its components with a backdoor called BirdCall targeting Android and Windows devices. Victims likely targeted through game client downloads. Continues the DPRK pattern of using gaming/developer ecosystems as attack vectors.
