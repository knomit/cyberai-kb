# Wiz 2026 SDLC Security Report: GitHub Actions ~45-50%, AI coding assistants 70%+ of environments

Wiz Research's 2026 SDLC Security Report (promoted via a The Hacker News sponsored email) reports that 45-50% of organizations now have GitHub Actions enabled, while AI coding assistants are present in over 70% of environments. The report argues modern application risk is no longer isolated to individual vulnerabilities, and covers AI-copilot/developer-tooling risk, dependency concentration and supply-chain exposure, secret-leakage trends, and CI/CD and GitHub Actions attack paths.
