# Shark RV2320EDUS robot vacuum certificate flaw enables region-wide takeover

A researcher using the handle tokay0 published a method (Monday, week of July 13, 2026) showing that extracting the certificate from the flash of a Shark RV2320EDUS robot vacuum allows running root commands on other Shark vacuums across the same AWS region — enabling camera access, driving the robot, reading the house map, and retrieving the Wi-Fi password in plaintext. The root cause is that the certificate's IoT policy was never scoped to the device holding it, so Shark's cloud broker accepts messages addressed to any device it serves. The attack requires no memory corruption, privilege escalation, or password guessing; the executed command is an ordinary field in the AWS device shadow. The researcher reported the issue to SharkNinja in March 2026 and it remained unpatched at time of publication.
