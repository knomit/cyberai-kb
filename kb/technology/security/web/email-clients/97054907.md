# New CSS-based attacks can break webmail interfaces across major providers

PortSwigger researcher Gareth Heyes (presenting at Black Hat USA 2026) showed that CSS inside an email can escape its message boundary and interfere with the webmail interface. Across attack chains spanning Outlook, Gmail, Fastmail, Proton Mail, Yahoo Mail and AOL Mail, the techniques can capture passwords, take over third-party accounts, leak tokens, hijack trusted UI actions, and manipulate AI tools that read email (e.g. spoofing a Microsoft sign-in in Outlook/Firefox, or exfiltrating a Slack token via a Gmail chain after prompt injection). The work is proof-of-concept; Fastmail and Proton Mail fixed some issues.
