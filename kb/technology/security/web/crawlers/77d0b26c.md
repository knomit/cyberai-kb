# Cloudflare introduced per-purpose AI crawler controls and bot monetization

Cloudflare, serving nearly 20% of the internet, introduced AI traffic controls that let publishers separately allow or block crawlers by purpose (search indexing, AI training, or AI agents), blocking training and agent bots by default on ad-bearing pages while allowing search-only crawlers; controls apply from September 15. It also announced a monetization tool to charge visitors (human or bot) per request, and BotBase, a public database classifying bots by behavior. Cloudflare says 57.5% of all HTTP requests now come from automated systems.
