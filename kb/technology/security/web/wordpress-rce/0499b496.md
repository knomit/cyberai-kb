# WordPress 'wp2shell' chain (CVE-2026-63030 + CVE-2026-60137) actively exploited for unauthenticated RCE

Two critical WordPress vulnerabilities, tracked as CVE-2026-63030 and CVE-2026-60137 and codenamed 'wp2shell', can be chained to achieve unauthenticated remote code execution and full site compromise. The flaws stem from WordPress core's REST batch API. Mass exploitation began in the early hours of Saturday (UTC), initially using public exploit code to exfiltrate hashed credentials, with RCE following once further details became public. watchTowr principal researcher Jake Knott reported widespread impact across organizations of every size and vertical.
