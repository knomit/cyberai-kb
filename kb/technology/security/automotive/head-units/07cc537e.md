# First documented malware infecting Android car head units via built-in firmware updaters

Kaspersky discovered in June 2026 a malware family targeting Android-based vehicle head unit firmware developed by DoFun — described by researcher Dmitry Kalinin as the first documented case of malware on a car head unit with an infection chain specific to that device type. The malware spreads through the head unit's own built-in software updater: a legitimate system app TWCore ('com.tw.core'), which collects analytics and fetches APK updates via an MQTT broker on a 'cardoor[.]cn' subdomain, downloading to <TWCore external cache dir>/push/apk/. Attackers weaponized this update channel to deliver a dropper dubbed JarService, which launches a loader that POSTs implant information to an attacker server and retrieves a next-stage payload (observed at 144.217.243[.]201/vr34der34/dex3.68.png). The final trojan polls a C2 endpoint (/cpc/api/task) every 90 minutes by default, receiving either updated C2 configuration or integer command identifiers the attackers call 'productId', stored as serialized JSON via the SharedPreferences API. It supports nine commands for displaying unwanted ads, committing ad fraud and downloading additional modules, and exfiltrates display resolution, device model, connected Wi-Fi identifier and MAC address. Kaspersky attributes the activity with high confidence to the MoYu Group, previously linked by HUMAN's Satori team to the BADBOX ad-fraud and residential-proxy scheme; Google sued 25 unnamed China-based parties over BADBOX in July 2025.
