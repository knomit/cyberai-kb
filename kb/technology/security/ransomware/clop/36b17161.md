# Cl0p deployed a bespoke JSP web shell against PTC Windchill/FlexPLM that decrypts the entire keystore

Following exploitation of a critical flaw in PTC Windchill and FlexPLM servers, a JavaServer Pages web shell purpose-built for that enterprise Product Lifecycle Management software was deployed; ReliaQuest links the activity to Cl0p (Clop).

Per ReliaQuest the web shell is a fully equipped extortion platform: it maps sensitive vault data, decrypts EVERY credential in the Windchill keystore, and runs additional code via a custom Java class loader — making it a backdoor for remote access and post-exploitation activity including lateral movement, ransomware deployment, and persistence.

Why this is notable: threat actors typically reuse lightweight or open-source web shells such as Behinder or China Chopper rather than building software-specific ones. Cl0p has done this before, deploying the custom web shells DEWMODE and LEMURLOOT after exploiting SQL injection flaws in Accellion (CVE-2021-27101) and MOVEit Transfer (CVE-2023-34362).

Scale and timeline: as of 2026-08-12 the gang began releasing alleged victims' full names; over 40 organizations are said to have been targeted.
