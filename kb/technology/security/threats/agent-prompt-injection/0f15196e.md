# Malicious AGENTS.md in ~/Downloads tricked a coding agent into installing npm package 'function-color' (MALFEX)

Forever Security found a malicious AGENTS.md in a customer's Downloads folder that made an AI coding agent rewrite its config and install rogue npm package 'function-color', part of the MALFEX supply-chain campaign. A website can drop a file into ~/Downloads without a click, and agents trust AGENTS.md, so the web can plant instructions. Mitigation: do not run coding agents where untrusted files sit in trusted instruction locations.
