# CrowdStrike: four new threat actors use Claude Code to decide and execute commands in intrusion campaigns

CrowdStrike reported four previously unreported actors using Claude Code for decision-making and command execution (e.g. 15+ Argentina healthcare entities, government breaches in two countries, an Indonesian actor with 819 skills, Russian-speaking actors hitting a US CRM vendor), arguing agentic AI is commoditizing baseline offensive operations.
