# x47.c botnet advertises 'AI API drain' to exhaust victims' paid AI credits

THN (2026-09-28) citing Qrator Research Labs: Windows botnet x47.c, sold by WraithTools ($200 base, $150 DDoS add-on, $950 full), offers 18 DDoS methods, credential theft, SOCKS5 proxies, a Grok-based persistence module and an 'AI API drain' command that uses a valid API key to burn the account's credits, denying legitimate users. Set spend limits on AI API keys.
