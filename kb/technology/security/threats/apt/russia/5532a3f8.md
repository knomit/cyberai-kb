# Russian hackers exploit OWA XSS flaw CVE-2026-42897 with persistent OWAReaper implant

Russian threat actors (previously tied to a Zimbra zero-day) exploited CVE-2026-42897 (CVSS 8.1), a cross-site scripting flaw in Microsoft Outlook Web Access, starting July 22, 2026, targeting US and European government, telecom, financial, hospitality and aerospace entities. The attack deploys OWAReaper, a previously unknown JavaScript browser-based implant for persistent webmail access. Persistence lives server-side and survives credential rotation and full device re-imaging; it requires deliberate removal from the Exchange server. OWAReaper abuses Outlook add-ins with ReadWriteMailbox permission to steal OAuth tokens and grants Owner-level permissions to the Default user on every mail folder.
