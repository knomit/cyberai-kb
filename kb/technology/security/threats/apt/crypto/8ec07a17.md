# JINX-0164: new threat actor targets crypto firms via fake LinkedIn recruiter + macOS AUDIOFIX malware

Wiz researchers (Shira Ayal, Eden Abergil, Andre Maccarone, Yuval Dan, Benjamin Read) documented a previously undocumented threat actor, JINX-0164, targeting cryptocurrency organizations to steal digital assets. Attack chain: (1) Credible LinkedIn profiles contact victims offering virtual meetings; invite redirects to a rogue domain impersonating a teleconference provider. (2) Victims download a malicious 'meeting client' file, which executes a bash script from 'apple.driver-store[.]com' (fake driver store). (3) The script drops AUDIOFIX — a Python-based macOS infostealer + remote access trojan, architecture-aware (Intel + Apple Silicon). AUDIOFIX masquerades as system audio driver 'coreaudiod', saved as 'ChromeUpdater', persisted via launchctl. (4) Post-compromise: lateral movement from employee laptops to CI/CD and code distribution infrastructure; AUDIOFIX payload injected; source code modified to steal crypto wallet credentials. Data captured: password managers, web browsers, iCloud Keychain, local admin creds, SSH keys, config files, console history, Discord/Slack/Telegram sessions, crypto wallet extensions (MetaMask, Coinbase, BinanceChain, Phantom, TronLink, Ronin, Exodus, etc.), wallet addresses. AUDIOFIX also supports manual recon, arbitrary shell command execution, file deletion, and payload retrieval from C2.
