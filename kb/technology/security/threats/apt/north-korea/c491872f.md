# Kimsuky 2026: HTTPSpy + HelloDoor (Rust/LLM) + VS Code tunnels targeting South Korea (ENKI + Kaspersky)

Two separate reports (ENKI + Kaspersky) detail Kimsuky (aka Velvet Chollima) campaigns in March–April 2026 targeting South Korean military and corporate entities. ENKI campaign: Social engineering via (a) spoofed nProtect/AhnLab security software pages delivering nos-setup.exe/astx-setup.exe → MemLoader.dll via regsvr32 → scheduled-task persistence → C2 retrieves unknown payload; (b) counterfeit Cisco Webex meeting page → user downloads fix-camera.jse ZIP → mTSTCv8.mdxm PowerShell downloader (anti-analysis) → engine.dat/spyInster.dll → cacheMon.dat loader → HTTPSpy. HTTPSpy (full-featured RAT, first used 2022): shell commands, upload/download, execute processes, screenshots, DLL injection, self-erase. Also deploys 'meeting.html' redirecting to a real Webex room linked to a stolen meeting schedule. JSONPing technique: fake pages querying local server to verify malware execution status. Kaspersky campaign: VS Code tunneling for persistence + DWAgent (open-source RMM) for post-exploitation. Droppers (JSE/PIF/SCR/EXE) deliver malware families: HelloDoor (Rust-based PebbleDash variant, first seen Aug 2025, likely LLM-developed: set directory, sleep, run commands); HttpMalice (PebbleDash backdoor, emerged ≤Dec 2025: sysinfo, persistence, recon, screenshots, payload loading, command exec, exfil); HttpTroy (MemLoad-delivered backdoor: file upload/download, screenshots, command exec, reverse shell, in-memory executable loading, trace removal); AppleSeed Dropper + Spy (Spy: docs/screenshots/keystrokes/USB/C:\GPKI directory mirroring similar to Troll Stealer); HappyDoor (advanced AppleSeed, first surfaced 2021). PebbleDash also targeted defense orgs in Brazil and Germany.
