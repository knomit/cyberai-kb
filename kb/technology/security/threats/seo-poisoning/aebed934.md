# BengalSEO search-poisoning operation ran for over a decade

The DFIR Report exposed "BengalSEO," a search-poisoning campaign active since 2015 out of Rajasthan, India, run by WeConnect Solutions LLC (formerly iConnect Soft Solutions) and Garage2Global, which poisons Bing results to deliver MayaBot malware and tech-support scams.
