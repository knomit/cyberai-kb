# SkillCloak evades scanners for malicious AI-agent skills

Researchers at the Hong Kong University of Science and Technology showed that scanners meant to catch malicious add-on 'skills' for AI coding agents can be defeated. Their SkillCloak technique (using self-extracting packing) slipped past every tested static scanner more than 90% of the time. Skills are small packages (a Markdown instruction file plus scripts) loaded by agents such as Claude Code, OpenAI Codex, and OpenClaw, and run with the agent's full access to files, terminal, and saved passwords. The team also built a runtime checker that catches most disguised skills.
