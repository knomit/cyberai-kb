# Lazarus Group exploited Windows zero-day CVE-2026-68820 against defense/aerospace firms

North Korea's Lazarus Group exploited CVE-2026-68820 (CVSS 7.0), a privilege-escalation zero-day in the Windows Ancillary Function Driver for WinSock (AFD.sys), to gain SYSTEM access and deploy a never-before-seen backdoor. Microsoft patched the flaw in its August 2026 Patch Tuesday updates. Per Check Point Research, the activity is part of the long-running 'Operation Dream Job' espionage campaign and targeted defense and aerospace companies in France, Germany, Brazil, and India, using fake job offers (e.g., posing as recruiters for Lockheed Martin and Enveil on LinkedIn).
