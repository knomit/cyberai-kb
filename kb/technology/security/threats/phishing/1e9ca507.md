# 'Phantom squatting' abuses AI-hallucinated domains

Palo Alto Networks' Unit 42 documented 'phantom squatting': attackers register web domains that LLMs hallucinate in order to host phishing/malware and capture AI-directed traffic. Unit 42 asked two AI models 685,339 questions about 913 well-known brands; the models produced 2.1 million links, of which threat intelligence had already flagged 13,229 as outright malicious.
