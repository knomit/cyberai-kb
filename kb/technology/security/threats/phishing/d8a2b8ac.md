# Microsoft warns of 'Photo ZIP' phishing targeting hotels with Node.js implant

Microsoft reported an active phishing campaign running since April 2026 that targets hotels and other hospitality organizations across Europe and Asia using photo-themed ZIP files to drop a Node.js implant onto front-desk machines. Emails use the display name 'Booking Manager (via Calendly)' and reference guest complaints, bedbug infestations, room inquiries, health inspections, and reviews, with lures in Japanese (most common), Danish, and Dutch. The operators route messages through Calendly's email notification system and Google's URL redirect service. Microsoft has not attributed the activity to a known threat actor, and the end goal remains unclear.
