# Misconfigured server exposed three Evilginx phishing operations targeting Microsoft 365

An attacker running a live Microsoft 365 phishing operation left a Python web server (python3 -m http.server 8080) publicly listening with directory listing enabled, exposing three separate Evilginx phishing operations.
