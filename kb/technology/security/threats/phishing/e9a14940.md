# Phishing campaign uses invisible Unicode tags to evade filters

Microsoft disclosed a high-volume phishing campaign active since February 2026 that uses invisible Unicode tag characters — "ASCII smuggling" — to split words like "funding" so that keyword-based email filters fail to match them while the rendered text looks normal to the reader.
