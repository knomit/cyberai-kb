# Wazza phishkit uses multi-stage routing and Adobe-themed device-code phishing

ANY.RUN identified Wazza, a phishkit targeting banking, manufacturing and government organizations in the US, Europe and Australia. It uses a multi-stage routing chain that screens visitors and automated traffic before serving an Adobe-themed Device Code phishing page, so the initial URL is less informative for detection.
