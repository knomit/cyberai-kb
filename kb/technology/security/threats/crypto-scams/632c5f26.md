# 236,000 DCloud Uni-App sites used in crypto scams

Infoblox found that more than 236,000 websites use investment scam templates built with DCloud Uni-App, a legitimate Chinese open-source cross-platform application development framework, to run crypto scams, phishing, and wallet drainers.
