# Unit 42: Chinese actor used DeepSeek + Hermes agent to autonomously attack 460+ targets

Palo Alto Networks' Unit 42 reported a Chinese-speaking threat actor (aliases knaithe/KnYuan) used DeepSeek via the open-source Hermes Agent framework, triggered by a single Telegram instruction, to autonomously find internet-facing systems and select public exploits — attempting exploitation against more than 460 targets across seven exploit tracks spanning eight CVEs. Autonomous attacks against Langflow and n8n failed due to unmet configuration requirements.
