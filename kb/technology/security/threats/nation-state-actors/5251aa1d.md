# UNC3569 exploited Sogou Input Method to deploy GRAYRABBIT backdoor

China-linked group UNC3569, tracked by Google as a hacker-for-hire operation active since 2021, exploited a Sogou Input Method flaw patched by Tencent in April 2026 via a crafted link to install the GRAYRABBIT backdoor, providing a remote command shell and file transfer. Discovered by Gen Digital.
