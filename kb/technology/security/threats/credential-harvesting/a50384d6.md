# FortiBleed: credential-harvesting operation targeting 430,000+ FortiGate firewalls

A financially motivated Russian-speaking initial access broker (IAB) is assessed (per a SOCRadar report) to be behind FortiBleed, a large-scale credential-harvesting operation active since February 2026 that has targeted over 430,000 FortiGate firewalls globally and is tied to roughly 110 million harvested credentials. It deploys a Golang-based tool, FortigateSniffer (Windows and Unix variants), which abuses the FortiOS built-in 'diagnose sniffer packet' diagnostic command to passively capture cleartext and hashed authentication traffic; the actors then crack, validate, and reuse credentials against Active Directory domains and other exposed services.
