# Developer toolchain is the dominant initial-access surface for high-value credential theft (2025–2026)

Three distinct campaigns in May 2026 all converged on the developer toolchain as the preferred attack vector: GlassWorm (npm packages, VSCode/VSCodium extensions, Python packages, compromised GitHub repos), JINX-0164 (fake meeting client delivered via LinkedIn social engineering targeting crypto firm developers, with subsequent lateral movement to CI/CD and code distribution systems), and Malware-Slop (malicious npm package targeting Claude AI workspace at /mnt/user-data/). The pattern: developers hold disproportionate access — GitHub/NPM tokens, cloud platform credentials, CI/CD pipelines, package registries, and crypto wallet files — making their toolchain a force multiplier for attackers. Initial access via trusted developer tools (IDE extensions, package managers) is noisy-hard to detect precisely because these channels are legitimized by normal workflows. This cluster represents a structural shift: attackers are not going after end-users or perimeter infrastructure first; they are targeting the software build and AI-assisted development pipeline directly.
