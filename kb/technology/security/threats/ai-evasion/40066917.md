# Cisco Talos: malware embeds natural-language 'AI-Analysis Evasion' instructions (A3)

Cisco Talos found malware families FRUITSHELL, PLOTSAFE, HOLLOWCLAD and MANTLEMAZE embedding natural-language comments/instructions (including notes claiming the model is a monitored honeypot) to steer LLM-based automated analysis; technique has evolved from direct instruction to 'template spraying' targeting multiple models. LLM-assisted malware triage should treat sample contents as untrusted input.
