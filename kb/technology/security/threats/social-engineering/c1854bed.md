# TerminalFix: ClickFix variant that targets Windows Terminal and PowerShell

TerminalFix is a new ClickFix variant that tricks users into running a malicious command in Windows Terminal or PowerShell rather than the Windows Run dialog. Compromised websites serve fake Cloudflare CAPTCHA verifications prompting visitors to copy and execute a PowerShell command. Per Microsoft, the multi-stage chain uses DLL sideloading, steganographic payload extraction, extensive Active Directory reconnaissance, and a bespoke reverse-tunnel implant granting persistent network-level proxy access through the infected machine.
