# Arctic Wolf: recurring Microsoft Teams 'IT Support' external-chat scams deliver malware

Arctic Wolf Labs reports a recurring pattern across hundreds of cases where attackers use Microsoft Teams' external chat creation to impersonate IT support and deliver malware/ransomware: throwaway Microsoft 365 tenants, 'IT Support (Internal)' style display names (or friendly first names) to subvert external-user warnings, the same remote-access tools and increasingly the same payload domains. Defenders can hunt on these shared indicators.
