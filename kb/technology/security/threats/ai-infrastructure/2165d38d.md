# Greeter framework abuses Flowise CVE-2024-58351; 21.5% of 4,372 exposed instances had no auth

Era Security observed a Chinese-language exploitation framework, Greeter, hitting Flowise honeypots using CVE-2024-58351 code injection with stored chat messages of only 'hello' while the payload arrived in overrideConfig.javascriptFunction per request, leaving saved chatflows clean. It performed discovery, env var and cloud-metadata theft, SSH key search and persistence attempts. Of 4,372 exposed Flowise instances, 703 (21.5%) had no authentication.
