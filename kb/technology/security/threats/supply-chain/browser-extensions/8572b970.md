# 'Superior' campaign: 19 Chrome/Edge extensions carried wallet-stealing and crypto-draining code

Socket security researcher Karlo Zanki disclosed (August 2026) a cluster of 18 Google Chrome extensions and one Microsoft Edge extension, published over the preceding six months, that harbored wallet-secret-stealing and cryptocurrency-draining capabilities. Socket tracks the activity as 'Superior'; shared code and tradecraft indicate the campaign may have been active since February 2024. The operator either acquired legitimate extensions with working functionality or first published a clean, malware-free version, then pushed a malicious update once the extension accumulated downloads. Of the 19 extensions, 14 were created by the threat actor and five were purchased from previous owners.
