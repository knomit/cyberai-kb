# ValleyRAT delivered via trojanized QN Wallpaper installer, 100k+ detections

Kaspersky reported a malicious installer disguised as adware that deploys a modified version of the Chinese wallpaper tool QN Wallpaper, using DLL sideloading and a Startup-folder drop for persistence before launching ValleyRAT — a backdoor linked to the threat actor Silver Fox. Capabilities include system information collection, reboot/shutdown, screenshots, log wiping, C2 address updates, additional module download, and keylogger/clipboard exfiltration. Kaspersky telemetry recorded over 100,000 detections of ValleyRAT and related components, affecting more than 1,500 unique users, mainly in China and India.
