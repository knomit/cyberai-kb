# Dormant GitHub accounts used to map corporate orgs

Per The Hacker News, Datadog Security Labs warned of several overlapping campaigns systematically enumerating corporate GitHub organizations, repositories, and user accounts through the GitHub API, using dormant accounts to blend in.
