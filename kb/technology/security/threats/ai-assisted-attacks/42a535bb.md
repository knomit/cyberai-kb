# Attacker used suspected AI-generated PowerShell to enumerate Active Directory

Cybersecurity researchers flagged an intrusion in which a threat actor used a suspected AI-generated ('vibe-coded') PowerShell script to enumerate Active Directory, including locating the Domain Controller.
