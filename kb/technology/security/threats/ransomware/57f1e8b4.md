# The Gentlemen RaaS develops GentleKiller EDR-killer framework

The Gentlemen ransomware-as-a-service (RaaS) operation actively develops and maintains a suite of endpoint detection and response (EDR) killers, centered on a framework called GentleKiller, that it provides to affiliates to impair defenses before deploying the encryptor; the tooling targets around 400 security processes. According to ESET researcher Jakub Souček, the operation also incorporates third-party or leaked tools such as HexKiller, ThrottleBlood, and HavocKiller, standardized through a shared defense-evasion layer that impersonates security vendors using fake version information and copied legitimate certificates and icons.
