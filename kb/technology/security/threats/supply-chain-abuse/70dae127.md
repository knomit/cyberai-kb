# Attackers weaponized compromised GitHub repos and Actions runners to target cPanel/WHM

Researchers disclosed a large-scale campaign that turned compromised GitHub repositories into distributed attack infrastructure, abusing GitHub Actions runners to target cPanel and WebHost Manager (WHM) server instances.
