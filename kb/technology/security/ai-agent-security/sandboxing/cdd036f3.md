# DeepSeek Harness flaw let a sandboxed AI agent disable its own sandbox

DeepSeek Harness, an open-source AI coding-agent sandbox tool, had CVE-2026-82533 (CVSS 9.4), which let a sandboxed agent disable its own OS sandbox via a single local API call with no approval prompt. DeepSeek fixed it on August 27, 2026; reported by OX Research. The containment boundary was reachable from inside the thing it was containing.
