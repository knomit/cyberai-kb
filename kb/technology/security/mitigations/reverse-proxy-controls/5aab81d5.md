# GeoNetwork interim mitigation is blocking write methods to the formatter endpoint at the reverse proxy

Until GeoNetwork 4.4.12 or 4.2.17 is applied, administrators can block write methods to the formatter endpoint at the reverse proxy: on Apache httpd, deny POST, PUT and PATCH to the /geonetwork/srv/api/formatters location; on Nginx, restrict that location to GET, HEAD and OPTIONS. Trade-off to state explicitly: this also blocks legitimate formatter uploads through the admin console, so it is a stopgap rather than a permanent configuration.
