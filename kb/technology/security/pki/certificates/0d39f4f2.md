# Let's Encrypt cutting default cert lifetime from 90 to 64 days from Feb 2027

Let's Encrypt announced default TLS certificate lifetimes drop from 90 to 64 days starting February 2027, in preparation for 45-day lifetimes planned for 2028. Automated renewal is effectively required.
