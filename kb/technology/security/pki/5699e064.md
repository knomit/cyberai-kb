# Eight eMudhra intermediate CA keys compromised via weak randomness

Mozilla and Chrome Root Program confirmed on 2026-10-20 that private keys of eight eMudhra intermediate CA certificates are compromised. A researcher reported it on Oct 17; Chrome and Firefox blocked the certificates within hours. Keys were generated with too little randomness, so they can be computed from public certificates. No certificate chaining to the six website-use intermediates had been logged to Certificate Transparency before the block, so none would be trusted by default in CT-enforcing browsers.
