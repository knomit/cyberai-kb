# eMudhra exits TLS market after eight intermediate CAs found with weak private keys; Apple, Python block roots

Eight eMudhra intermediate CA certificates used weak private keys, potentially allowing forged trusted certificates. Apple began blocking 12 certificates on Oct 19, 2026 and the emSign ECC Root CA - G3 on Oct 23 via automatic config updates; Python updated certifi, pip, uv, sigstore, conda and pixi to remove the emSign root. eMudhra is exiting certificate issuance.
