# Azure Cosmos DB 'CosmosEscape' flaw exposed platform-wide key

Wiz disclosed CosmosEscape, a now-patched Azure Cosmos DB vulnerability chain that let an attacker escape the Gremlin query sandbox, achieve code execution on a multi-tenant gateway, and obtain a platform-wide signing secret plus a regional account directory, ultimately gaining full read/write access to any tenant's databases. Microsoft blocked the vulnerable Gremlin entry point within 48 hours of the November 2025 report and completed the full multi-region fix (eliminating the platform-wide key) in July 2026.
