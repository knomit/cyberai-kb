# OAuth client ID spoofing used to validate stolen Microsoft Entra credentials

At least two distinct threat actors are weaponizing a novel evasion technique called 'OAuth client ID spoofing' in cloud campaigns. The technique lets attackers validate stolen Microsoft Entra credentials and enumerate user accounts while slipping past telemetry/detection. Reported by The Hacker News.
