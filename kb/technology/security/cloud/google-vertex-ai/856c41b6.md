# Google Vertex AI SDK 'Pickle in the Middle' bucket-squatting flaw patched

Palo Alto Networks Unit 42 found a flaw in the Google Cloud Vertex AI SDK for Python ('Pickle in the Middle') that let an attacker with no access to a victim's project hijack the victim's ML model upload and run code in Google's serving infrastructure. The SDK generated a predictable temporary Cloud Storage bucket name from the (often public) project ID and region without verifying ownership, enabling bucket squatting — needing only the attacker's own GCP project and the victim's project ID. Google patched it; users should update to SDK v1.148.0 or later. No in-the-wild exploitation was observed.
