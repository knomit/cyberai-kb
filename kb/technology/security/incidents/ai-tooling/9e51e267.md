# OpenCode Console breach (Oct 16) may expose saved OpenAI/Anthropic/Google keys for 1.4% of users

An intruder reached a legacy OpenCode system on the night of Oct 16, 2026, possibly exposing provider API keys saved in OpenCode Console (optional hosted service). 1.4% of Console users with an outside provider linked are affected; they were emailed Oct 17 (subject 'Action Required: Potential provider key breach') to revoke and replace keys. Keys stored locally by the CLI/desktop apps in SQLite are distinct from Console-stored keys.
