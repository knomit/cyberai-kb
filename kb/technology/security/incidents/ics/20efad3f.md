# Attacks on Danfoss/Copeland refrigeration controllers heated 700+ French supermarkets to 50C

Attacks on internet-facing Danfoss- and Copeland-managed refrigeration systems with outdated firmware pushed temperatures up to 50C for about six hours at 700+ French supermarkets. Kevin Beaumont says logins used admin with a daily password equal to the current date. Pen Test Partners: remove controllers from the public internet, use VPN plus IP allowlist, change default credentials, patch.
