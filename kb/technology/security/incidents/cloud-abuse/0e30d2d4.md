# PCPJack hijacked 230 cloud servers into a covert SMTP relay network

The threat actor PCPJack hijacked roughly 230 servers across AWS, Google Cloud, and Microsoft Azure to build a covert SMTP email-relay network, using compromised business servers to send mail. Separately, attackers were actively exploiting a critical flaw in the Everest Forms Pro WordPress plugin (~4,000 active installs) to execute arbitrary code and fully compromise sites. Reported by The Hacker News, June 5, 2026.
