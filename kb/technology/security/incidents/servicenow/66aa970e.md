# ServiceNow flaw exploited for unauthorized access to customer instances (June 2026)

ServiceNow disclosed a security incident in which unknown threat actors exploited a flaw to gain deeper-than-intended unauthorized access to instances. On June 5, 2026 it applied a security update to hosted customer instances limiting a vulnerable endpoint to authenticated users; the issue (no CVE assigned, details first surfaced on Reddit) could let an unauthenticated user gain greater access. ServiceNow observed anomalous activity and evidence of successful queries of instance tables against a subset of customers.
