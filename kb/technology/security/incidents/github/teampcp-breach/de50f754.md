# GitHub confirmed the TeamPCP breach was limited to internal repositories with no customer data affected (May 20, 2026)

On May 20, 2026, GitHub confirmed it was investigating unauthorized access to thousands of internal code repositories after an employee's device was compromised via a malicious VS Code extension (Nx Console 18.95.0, published May 18, 2026).

GitHub's stated findings: the breach was 'detected and contained'; it was limited to INTERNAL repositories rather than any customer data; critical credentials were rotated the same day the breach was detected, most sensitive secrets first; and the attacker's claim of ~3,800 repositories stolen was 'directionally consistent' with GitHub's own findings. GitHub said it would publish a fuller report once its investigation is complete — so this is a preliminary statement, not a closed investigation.

Context: TeamPCP advertised the stolen source code on a cybercrime forum for $50,000, threatening to leak it free if no buyer emerged — an extortion motive rather than an espionage one. GitHub hosts code for more than 100 million developers.

EPISTEMIC NOTE: this is a first-party statement from the breached company, made while its own investigation was ongoing. It should not be treated as an independently verified conclusion.
