# GitHub breached via poisoned Nx Console VS Code extension — TeamPCP stole 3,800 repos

GitHub confirmed its internal repositories were breached through a compromised employee device infected via a poisoned version of the 'nrwl.angular-console' Nx Console VS Code extension. The threat actor, cybercriminal group TeamPCP, exfiltrated ~3,800 repositories. The Nx extension was compromised after an Nx developer's system was hacked via the TanStack supply chain attack. Other TanStack victims included OpenAI, Mistral AI, and Grafana Labs. Grafana Labs refused to pay extortion demands. This is part of the broader 'Mini Shai-Hulud campaign.' TeamPCP publicly released the Shai-Hulud code, providing a blueprint for similar open-source supply chain worms.
