# TanStack npm compromise (CVE-2026-45321) led to copy of ~170 CrowdSec private GitHub repos via a departed employee's token

CrowdSec disclosed on 2026-09-18 that an attacker copied approximately 170 of its private GitHub repositories on 2026-05-22 using a GitHub OAuth token belonging to an employee who had just left the company. The full causal chain has several components and dropping any one of them makes the lesson wrong: (1) on 2026-05-11, 84 malicious versions of 42 TanStack npm packages were published (tracked as CVE-2026-45321); installing one ran code that stole credentials from the developer's machine including GitHub tokens, SSH keys, and cloud credentials; (2) the former employee's laptop was compromised in that attack; (3) CrowdSec had deliberately kept his GitHub access open after departure so he could finish outstanding work, while his other access had already been revoked; (4) the copy occurred 11 days after the malicious packages were published; (5) CrowdSec removed his account from its GitHub organization on 2026-05-25, three days after the copy and months before learning of the leak. The code surfaced on an online forum on 2026-09-16 and contained, alongside source, the email addresses of 83 CrowdSec users and the names, email addresses, and investment context of 51 potential investors from 2020. CrowdSec says the account was used only to copy code — infrastructure and databases were not accessed and no code was changed — and attributes the absence of suspicious AWS activity to the prior revocation of his other access. The token left no trace in the GitHub logs CrowdSec could check and no longer existed when the leak was discovered; GitHub support traced the token's history and confirmed TanStack as the source. CrowdSec did not disclose which malicious package reached the laptop or when, and its report does not include GitHub's own findings. Operational consequence: partial offboarding is the failure mode — revoking most access while leaving one system open for convenience preserves the exact credential an upstream supply-chain compromise needs.
