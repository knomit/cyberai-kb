# ConnectWise disables seven app identities and suspends Cloud Backup after M365 tenant compromises

ConnectWise disabled seven ConnectWise application identities on Oct 17, 2026 07:00 UTC after unknown actors obtained unauthorized access to them and compromised Microsoft 365 tenants. It also suspended Cloud Backup by revoking certificates used for affected application connections across all users. Investigation was ongoing. THN Daily (Oct 19) repeats this.
