# Cursor Marketplace Claude Code extension 2.1.313 trojanized with SSH backdoor

Per The Hacker News (Oct 30, 2026): a trojanized anthropic.claude-code v2.1.313 was distributed via the Cursor Marketplace on Oct 29 (~2:27am-1:35pm PT), affecting at most 5,000 users. It adds an attacker key labeled 'svc-telemetry' to ~/.ssh/authorized_keys, opens a reverse tunnel to 134.209.82[.]225, installs persistence (scheduled task, crontab, LaunchAgent) and beacons host recon (up to 40 secret-like env var names). Not found on Open VSX or Microsoft's VS Code Marketplace; Anthropic published clean v2.1.314. Remediation: isolate hosts, remove the key/persistence, rotate credentials.
