# Compromised ConnectWise Cloud Backup credential used to sign in to 173 M365 tenants

Per The Hacker News citing Huntress (Oct 2026): threat actors abused a compromised Microsoft 365 credential belonging to ConnectWise Cloud Backup (formerly SkyKick). The app is granted broad access to mailboxes, OneDrive, SharePoint, Teams and directory data in every tenant where it is installed; Huntress observed confirmed unauthorized sign-ins in 173 partner/customer tenants. The credential works against every tenant where the app is consented, so every organization with the app installed is exposed. Consequence: MSP-delivered backup apps with tenant-wide consent are a high-value single credential target.
