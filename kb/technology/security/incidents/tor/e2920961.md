# 333 Tor exit relays redirected SSH to credential-stealing servers (Oct 2026)

A researcher (kaba) scanned Tor's ~3,000 exits on Oct 2, 2026 and found 333 redirecting SSH to the same 12 interception servers. Only password SSH logins via Tor between Oct 1-5 that accepted the interception server's host key could be captured. Tor Project began flagging relays Oct 4; none remained in consensus by Oct 5. At peak (Oct 4) the relays were 7.46% of exit capacity by consensus weight.
