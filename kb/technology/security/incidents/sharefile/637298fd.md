# Progress tells ShareFile customers to shut down Storage Zone Controllers

Progress Software urged ShareFile customers to shut down the Windows servers running their Storage Zone Controllers, confirming it is responding to a 'credible external security threat.' It temporarily disabled access to affected accounts as a precaution. This was THN's Threat of the Week.
