# BTCPay Server hot wallets drained on instances running 2.4.1 or earlier; upgrade to 2.4.7

From about 1 Nov 2026 attackers stole Bitcoin and Litecoin from hot wallets on unpatched BTCPay Server instances (2.4.1 or earlier), reportedly via a different method against the flaw fixed in 2.4.2 (7 Aug 2026), which let unauthenticated attackers obtain LND .macaroon files. No CVE or total stolen was given. Guidance: upgrade to 2.4.7; those on 2.4.1 or earlier should migrate to a fresh server with a new wallet; treat the machine as compromised if theft is suspected; keep minimal funds in hot wallets.
