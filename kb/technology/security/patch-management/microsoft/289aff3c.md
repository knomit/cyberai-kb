# Microsoft June 2026 Patch Tuesday fixes record 206 flaws incl. 3 zero-days

Microsoft's June 2026 Patch Tuesday addressed a record 206 vulnerabilities (39 Critical, 167 Important), including three publicly disclosed at release. Breakdown: 63 privilege escalation, 56 RCE, 30 information disclosure, 27 spoofing, 20 security feature bypass, 7 DoS, 3 tampering. Topping the list is CVE-2026-45657 (CVSS 9.8), a use-after-free in Windows. Also included two non-Microsoft CVEs: CVE-2025-10263 (Windows Kernel privilege escalation) and CVE-2026-8863 (UEFI Secure Boot bypass).
