# Microsoft tracked CaptiveCrunch campaign (Storm-2945) hijacking captive-portal Wi-Fi

Microsoft codenamed 'CaptiveCrunch' an ongoing campaign (since May 2026) by threat actor Storm-2945 that manipulates DNS and HTTP traffic on networks served by captive portals (e.g., hotel Wi-Fi) to redirect users through actor-controlled infrastructure. Using an adversary-in-the-middle position, it delivers malware disguised as browser or OS updates, including a full-featured Windows RAT named CornFlake capable of system enumeration, file/keystroke collection, credential and session-token theft, audio/video surveillance, and providing a remote shell.
