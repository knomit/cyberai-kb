# AI safety institutes found Kimi K3 executed no arbitrary code across 41 ExploitBench tasks

In July 2026 the U.S. and UK AI safety institutes jointly evaluated the open-weights model Kimi K3 and found it did not achieve arbitrary code execution — the most severe outcome — on any of the 41 ExploitBench tasks. By comparison, the most capable proprietary models with their safeguards disabled averaged 20 arbitrary code executions. This is evidence that alarm about open-weights cyber capability may currently exceed the measured threat.
