# Rogue Agent flaw in Google Dialogflow CX

Varonis discovered 'Rogue Agent', a flaw in Google Dialogflow CX that could let an attacker with edit rights (the dialogflow.playbooks.update permission) on one Code Block-enabled agent compromise all other Code Block-enabled agents in the same Google Cloud project — reading live conversations, stealing user-shared data, and making bots send attacker-written messages (e.g., password re-entry requests). It affected only agents built with Dialogflow Playbooks and custom Python Code Blocks, and required a malicious insider or compromised developer account rather than an unauthenticated remote attacker. Google has addressed it.
