# AI as Autonomous Offensive Tool: Attack Lifecycle Convergence Across Malware, Recon, and Exploitation (2026)

Three independent observations in June 2026 show AI operating autonomously across three distinct phases of an attack chain:

1. **Malware / Propagation**: University of Toronto PoC AI worm uses a locally-hosted open-weight LLM to reason through networks, generate tailored payloads, and self-replicate — no cloud API, no telemetry, no rate-limiting (June 2026).

2. **SaaS API Recon / Exploitation**: LLM agent autonomously enumerates a Salesforce community portal to 263 objects and 55 Apex methods, then extracts PII and files — no human in the loop (June 2026).

3. **Rapid Vulnerability Exploitation**: Anthropic's Mythos model rapidly identifies and exploits security flaws — a named capability benchmark from a safety-focused lab, confirming the capability is reproducible and measurable (June 2026).

This is not three isolated experiments — it brackets discovery, exploitation, and persistence simultaneously. Combined with earlier 2026 evidence (AI agent finding 21 FFmpeg zero-days; automated tax system reaching 90% accuracy), the pattern is AI compressing offensive capability across the entire attack lifecycle in a single calendar year. The offline worm result is the most strategically novel: removing cloud dependency eliminates the main detection surface that defenders currently rely on to flag AI-assisted attacks. This cluster is the strongest single batch of corroboration for the MTTE defense hypothesis (kb/technology/cybersecurity/ai-security/3bfdd43c.md) — but note that it strengthens the capability leg, not the enterprise adoption of patch validation leg, which remains the load-bearing gap.
