# Encrypted-reasoning API flaw lets weaker models decode stronger models' hidden reasoning

Researchers behind the paper 'Stealing Reasoning Traces from Proprietary LLM APIs' disclosed that OpenAI, Anthropic, and Google return encrypted chain-of-thought/reasoning blocks that can be replayed across sessions, users, and models — including handed to a weaker sibling model in the same family to make it reveal the hidden content, recovering the stronger model's plaintext reasoning without directly attacking it or triggering anti-distillation safeguards. Across 6,708 public agent trajectories the team decoded 315,320 thinking blocks and, after excluding benchmark sources, counted 704 distinct privacy artifacts including API keys and passwords. Four demonstrated abuse paths: model-distillation theft, extracting private data from others' published traces, recovering harmful content hidden behind a safe answer, and hiding prompt injections inside opaque reasoning blocks.
