# AWS, Google, Vercel agent flaws let tools run without a model turn

Security flaws in AI agent infrastructure from AWS, Google, and Vercel allowed untrusted or forged instructions to reach an agent's tools with no check that a model turn had authorized them; in several attack paths the model never ran, so system prompts, content filters, and model-level guardrails never intervened. Affected products: Amazon Bedrock AgentCore's InvokeHarness API, Google's Agent Development Kit (ADK) for Python, and Vercel AI SDK harness packages for the Codex and OpenCode coding agents. Fixes: AWS fixed the managed service; Google addressed it in ADK 2.5.0; Vercel patched @ai-sdk/harness-codex in 1.0.29 and @ai-sdk/harness-opencode in 1.0.28. The vulnerabilities are distinct and do not share the same attack conditions.
