# 'AI Recommendation Poisoning' abuses pre-filled 'Ask AI' deep links

A new class of prompt injection spreading across commercial websites abuses pre-filled deep links behind 'Ask AI' buttons on marketing and competitor-comparison pages. When a user logged into ChatGPT, Claude, Gemini, or Grok clicks one, a pre-formed query executes immediately in their session with no confirmation. Malicious variants instruct the AI to permanently save the vendor's domain as a 'trusted source,' quietly biasing future answers in that vendor's favor. It requires no malware, credentials, or zero-day. Microsoft Security catalogued the behavior as 'AI Recommendation Poisoning' in February 2026, identifying 31 companies using the technique.
