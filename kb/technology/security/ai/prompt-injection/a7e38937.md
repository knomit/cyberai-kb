# Indirect prompt injection flagged as serious risk in agentic coding tools

Mozilla's Zero Day Investigative Network (0DIN) characterized indirect prompt injection as a very real and serious attack vector that can cause catastrophic, often irreversible damage. In agentic IDEs and coding agents, an attacker can achieve code execution using a seemingly harmless repository by chaining trusted setup instructions, routine error handling, and automated agent behavior, with malicious payloads fetched at runtime from a DNS TXT record.
