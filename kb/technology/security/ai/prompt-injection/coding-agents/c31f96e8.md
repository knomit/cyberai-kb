# Amazon Kiro IDE vulnerable to prompt-injection data exfiltration via Kiro Powers

Mindguard researcher Fergal Glynn disclosed a vulnerability (no CVE assigned) in Amazon Kiro, an agentic AI IDE, allowing attacker-controlled repository content to influence the Kiro agent and cause sensitive local information to be transmitted to an external endpoint. The issue was demonstrated against Kiro IDE 0.7.45 on Windows; the current version is 1.0.337. The attack abuses 'Kiro Powers,' which bundle Model Context Protocol (MCP) server configurations, steering files (POWER.md), hooks, and contextual knowledge — the steering file acts as a persistent 'onboarding manual' telling the agent which MCP tools exist and when to use them.
