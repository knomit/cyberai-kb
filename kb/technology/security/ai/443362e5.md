# AI's dual role (offense and attack surface) amid supply-chain and edge-appliance threats, mid-2026

As of mid-2026, AI plays a dual role in the security threat landscape evidenced across same-day reporting: (1) as offensive tooling — security researchers (Reco) demonstrated fully autonomous LLM agents performing end-to-end exploitation of Salesforce Experience Cloud sites, and real threat groups like ShinyHunters incorporate LLMs into reconnaissance/exploitation; and (2) as a new attack surface — AI application platforms are themselves targets, e.g. the open-source AI builder Langflow's CVE-2026-5027 path-traversal RCE under active exploitation. In parallel, software supply chain remains a dominant vector (GitHub disabling npm install scripts by default; OceanLotus's FireAnt Metakit supply-chain compromise), and unauthenticated critical RCE/auth-bypass flaws in enterprise edge and security appliances (Fortinet FortiSandbox, Ivanti Sentry, SAP NetWeaver) continue at scale.
