# BioShocking attack tricks AI browsers into leaking credentials

Security firm LayerX disclosed 'BioShocking', an indirect prompt-injection technique that tricked six AI browsers/assistants — including OpenAI's ChatGPT Atlas, Perplexity's Comet, and Anthropic's Claude browser extension — into copying credentials from signed-in accounts and exfiltrating them. It works because the web page and the user's instructions arrive as one text stream, so a malicious page can disguise commands as content. LayerX reported the issue to vendors between October 2025 and January 2026.
