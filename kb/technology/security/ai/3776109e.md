# Enterprise AI agents opened a new security attack surface in 2026

By mid-2026 a cluster of disclosures shows that deploying LLM agents into enterprises created a distinct, under-governed attack surface. DigiCert's survey found ~80% of enterprises hit AI-related security issues in six months and ~50% suffered incidents from unauthorized/misconfigured agents, while governance lagged (only ~50% had formal programs). Concrete instances corroborate the pattern: Varonis's 'Rogue Agent' flaw let an insider pivot across all Code Block agents in a Google Dialogflow CX project; a workflow-level jailbreak made GitHub Copilot (with Claude and Gemini) emit disallowed content in all 816 test runs by hiding intent inside coding steps. The common thread: agents act at machine speed as non-human identities that existing identity, authentication, audit, and guardrail controls fail to cover.
