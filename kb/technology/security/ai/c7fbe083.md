# Agentic AI is emerging as both a security target and an attack vector

Mid-2026 reporting shows AI agents becoming a distinct security frontier on three fronts at once. (1) Targets: the Gaslight macOS malware embeds prompt-injection payloads that attack an LLM-assisted analysis agent's perception to make it abort triage. (2) Distribution/supply chain: a deliberately fake AI agent 'skill' (brand-landingpage) passed every skill scanner and reached ~26,000 agents, exploiting the fact that a skill loads into an agent's context with roughly user-prompt authority and that trust signals (scanners, GitHub stars, reputation) fail to catch it. (3) Governance response: the Linux Foundation's Agent Name Service (ANS) aims to give every enterprise agent a verified identity and tamper-proof audit trail, alongside hardware-rooted confidential computing for 'sovereign AI.' Net: defending AI agents requires treating them as untrusted execution contexts with verifiable identity, not as trusted tools.
