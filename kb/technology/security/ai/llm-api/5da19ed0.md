# Reasoning-API flaw lets attackers steal hidden LLM reasoning traces and secrets

Research paper 'Stealing Reasoning Traces from Proprietary LLM APIs' disclosed a flaw in how OpenAI, Anthropic, and Google carried encrypted hidden reasoning objects between API calls. A reasoning block created in one session could be replayed into another and, in testing, handed to a weaker model in the same provider family to reveal the concealed content. Researchers demonstrated four abuse paths (distillation of proprietary reasoning, extracting private data from others' published traces, recovering harmful content behind a safe visible answer, and hiding prompt injections in opaque blocks). Across 6,708 public agent trajectories they decoded 315,320 thinking blocks and recovered secrets including API keys and passwords.
