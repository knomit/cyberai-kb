# AgentForger CSRF flaw in OpenAI ChatGPT Agent Builder (patched June 8, 2026)

Zenity Labs disclosed a critical vulnerability, codenamed AgentForger, in OpenAI's ChatGPT Workspace Agents / Agent Builder, reported by The Hacker News on July 25, 2026. A single phishing link could stealthily build, authorize, and deploy an attacker-controlled autonomous AI agent inside a victim's organization, using a real employee's access with its approvals switched off. The flaw is a cross-site request forgery (CSRF) that, when an employee clicks a benign-looking ChatGPT link, spawns an attacker-controlled agent within the company's trust boundary that does the attacker's bidding. OpenAI addressed the issue as of June 8, 2026, following responsible disclosure.
