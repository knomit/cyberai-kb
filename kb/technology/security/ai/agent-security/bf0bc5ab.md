# Fake AI agent skill reached ~26,000 agents, evaded all scanners

Security firm AIR built a deliberately benign fake AI agent skill named 'brand-landingpage' (claiming to build a landing page via Google's Stitch tool, aimed at non-technical users), distributed it through a popular skill marketplace and an Instagram ad, and says it reached roughly 26,000 agents, including some on corporate accounts. Every skill-security scanner tested marked it safe, and neither GitHub stars nor open-source reputation flagged it. The demonstration highlights that a skill is a bundle of instructions an agent loads into its context with roughly user-prompt authority, making trust signals unreliable.
