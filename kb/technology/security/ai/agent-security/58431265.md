# Google removed 3 ADK agent workflows after prompt-injection via GitHub issue could trigger privileged agent

Google deleted three AI agent workflows from its Agent Development Kit (ADK) Python repository after Pillar Security showed a public GitHub issue could prompt-inject a triage agent into posting '/adk-issue-fix' as the adk-bot. Because the bot was a repo collaborator, that comment satisfied the privileged code-fixing workflow's owner/member/collaborator gate, making the trusted bot identity an authorization bridge. Researchers demonstrated arbitrary code execution on the CI runner and exfiltration of the bot's personal access token; the privileged job also held a Google API key and a Google Cloud service-account credential. The proof-of-concept found no in-the-wild exploitation; the exposed component was repository automation, not the distributed ADK Python package. Reported by The Hacker News.
