# Microsoft Azure DevOps MCP server vulnerable to hidden PR-comment prompt injection

Manifold Security disclosed a confused-deputy vulnerability in Microsoft's official Azure DevOps MCP server. One of its tools returned pull request descriptions without a prompt-injection guardrail that had been applied to other tools. Because Azure DevOps PR descriptions accept Markdown (and thus HTML comments that render invisibly), an attacker can embed hidden instructions that a reviewer's AI coding agent will execute with the user's own permissions—driving it into projects the attacker cannot access and leaking data.
