# OpenAI GPT-5.6-Cyber and Daybreak defender tiers

OpenAI introduced GPT-5.6-Cyber, a specialized model for vulnerability research, exploit validation and other advanced cybersecurity tasks, and expanded its 'Project Daybreak' program with Blue and Red access tiers intended to give approved defenders access to increasingly capable AI tools 'as the cyber-defense window narrows.'
