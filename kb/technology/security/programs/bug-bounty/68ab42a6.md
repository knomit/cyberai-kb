# Meta paid ~$1.2M in Muse AI bug bounties; $300K bug was a trusted-header auth flaw

Meta said it paid nearly $1.2M to researchers for Muse AI assistant bugs since the program went public in September 2026. The largest award, $300,000, was for an auth check that treated a header from a local HTTPS proxy as trusted; a migration added a second proxy layer so external requests could carry the header, exposing pre-release VM conversations and tokens.
