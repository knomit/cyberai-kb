# OpenAI raises security bug bounty: up to $30,000 for critical core-product bugs, $172,000 with bonuses

OpenAI increased Security Bug Bounty payouts: a critical vulnerability in ChatGPT, Codex or the API Platform earns up to $30,000; exceptional critical findings up to $100,000, and up to $172,000 with bonuses.
