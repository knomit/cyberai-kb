# Spectre attack on Cloudflare Workers leaked a co-located Worker's JWT at 12 bits/second

Researchers demonstrated a remote Spectre attack against Cloudflare Workers that leaked a JSON Web Token from a co-located Worker in the production environment at up to 12 bits per second — 360 times the rate of an earlier attack demonstrated in 2021. The end-to-end experiment used an attacker Worker and a victim Worker both controlled by the researchers, with the JWT intentionally placed in the victim's memory; no customer data was accessed. The researchers concluded that the production implementation of Dynamic Process Isolation (DyPrIs) was insufficient. Cloudflare said the attack has been mitigated in production by improving DyPrIs, integrating the V8 Sandbox, and deploying Memory Protection Keys (MPK)-based in-process isolation, and reported no indicators of active exploitation over the previous three years.
