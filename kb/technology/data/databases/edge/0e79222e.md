# Databricks acquired Electric (PGlite) to enable local AI-agent databases

On Tuesday Aug 11-12, 2026, Databricks announced it acquired Electric, maker of PGlite — a lightweight WebAssembly (WASM) build of Postgres that runs directly on laptops, tablets, phones, browsers, or AI agent sandboxes (even a Raspberry Pi). Running locally cuts latency, works offline, lowers cloud cost, and speeds agent loops by avoiding network round-trips. Databricks pairs PGlite with real-time sync to its central Lakebase Postgres database, enabling apps built on mobile/edge to scale and deploy across an organization. Databricks VP of engineering is Nikita Shamgunov.
