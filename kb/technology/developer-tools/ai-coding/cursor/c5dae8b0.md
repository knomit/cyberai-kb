# Cursor launched Origin, a code hosting platform, during a multi-hour GitHub outage

Cursor began rolling out Origin, its own code hosting platform, to paid users. The launch coincided with a GitHub outage lasting over six hours. Origin lets users connect existing GitHub repositories rather than migrating, so GitHub can remain the source of truth. That design lowers adoption friction: organizations can trial Origin at no switching cost and nothing breaks if they abandon it.
