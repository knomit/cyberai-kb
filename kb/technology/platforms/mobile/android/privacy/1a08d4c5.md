# Android 17 adds OS-wide Encrypted Client Hello (ECH)

Google announced (late August 2026) new network security protections in Android 17, headlined by OS-wide support for Encrypted Client Hello (ECH), a privacy standard that prevents networks from observing which websites a user visits. Google engineers Bram Bonne and Shuaibo Huang said ECH works in tandem with private DNS to obscure visited domain names, hiding metadata usable for profiling, so that for supported websites and apps network providers and snoopers can no longer easily see which sites are being accessed. Google's Jigsaw division published a parallel report explaining that ECH hides the domain name using a secret encryption key only the destination website can decipher — with the caveat that not all web servers support it. The Android 17 release also addresses cellular vulnerabilities and adds home/local-network privacy protections (local network permission).
