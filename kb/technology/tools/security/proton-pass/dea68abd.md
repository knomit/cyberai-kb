# Proton Pass adds AI access tokens for secure credential sharing with AI agents

Proton Pass (E2EE password manager) added AI access tokens in May 2026. Allows users to grant AI agents access to specific items with logged access including reason for access. Tokens can be set to expire (1 hour to 1 year). Provides an auditable trail of agent credential use — relevant as agentic AI becomes mainstream.
