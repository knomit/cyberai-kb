# CVE-2026-46333: 9-Year-Old Linux Kernel Flaw Enables Root Command Execution on Major Distributions

Cybersecurity researchers disclosed CVE-2026-46333 (CVSS 5.5) in May 2026 — a Linux kernel vulnerability that had remained undetected for nine years. The flaw involves improper privilege control in the kernel and enables root command execution on major Linux distributions. Despite the relatively modest CVSS score (5.5), the ability to achieve root execution and the nine-year dwell time in the codebase make this a high-priority patch. The disclosure adds to the pattern of long-lived Linux kernel vulnerabilities being uncovered as AI-assisted code review and fuzzing tools accelerate vulnerability discovery. This also corroborates the established pattern of Linux authentication and privilege layers as a primary attack surface (cf. QLNX, PamDOORa, Fragnesia synthesis).
