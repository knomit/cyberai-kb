# CISA KEV: Trend Micro Apex One CVE-2026-34926 (CVSS 6.7) — Directory Traversal Enables Agent Compromise on Endpoint Security Platform

CISA added CVE-2026-34926 (CVSS 6.7) in Trend Micro Apex One to its KEV catalog on May 22, 2026, citing active exploitation evidence.

**Vulnerability**: A directory traversal vulnerability in on-premise versions of Trend Micro Apex One. A pre-authenticated local attacker can modify a key table on the server to inject malicious code that deploys to agents on affected installations.

**Constraint**: Exploitable only on on-premise (not cloud) Apex One, and requires the attacker to already have access within the environment and have obtained administrative credentials to the Apex One Server via some other method.

**Active exploitation**: Trend Micro observed at least one instance of attempted active exploitation in the wild.

**Patch deadline**: FCEB agencies required to apply fixes by June 4, 2026.

Note: Like Defender CVE-2026-41091, this is a vulnerability in endpoint security software itself — attackers compromising the security tool can use it as a pivot to deploy malicious code across all managed endpoints.
