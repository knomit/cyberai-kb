# Microsoft Defender CVE-2026-41091: Actively Exploited Privilege Escalation (CVSS 7.8) Plus DoS Zero-Day

Microsoft disclosed two actively exploited vulnerabilities in Microsoft Defender in May 2026:

**CVE-2026-41091** (CVSS 7.8): A privilege escalation vulnerability in Defender under active exploitation in the wild. An attacker who can execute code on a target system can use this flaw to escalate privileges, likely chaining with an initial access vector for full system compromise.

**Second flaw** (CVE not specified in reporting): A denial-of-service vulnerability in Defender also under active exploitation.

Both flaws are particularly significant because Defender is the endpoint protection layer itself — vulnerabilities in the security tool compromise the protection layer that defenders rely on to detect and block other attacks. Active exploitation means patching is urgent.
