# Adobe Acrobat Reader CVE-2026-34621: prototype pollution 0-day exploited since December 2025

Adobe released emergency patches in April 2026 for CVE-2026-34621 (CVSS 8.6) in Adobe Acrobat Reader — a prototype pollution vulnerability enabling arbitrary code execution when opening specially crafted PDF documents. Active exploitation confirmed; security researcher Haifei Li (EXPMON founder) disclosed details of zero-day exploitation running malicious JavaScript via crafted PDFs. Evidence suggests exploitation began December 2025, meaning attackers had ~4 months of undetected access before patching. Widely used enterprise software across all sectors makes this high-impact. Patch is available; organizations should treat as urgent remediation.
