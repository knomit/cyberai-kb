# CVE-2026-23918: Critical Apache HTTP/2 Double-Free Enables Trivial DoS and RCE

The Apache Software Foundation released security updates addressing CVE-2026-23918, a critical vulnerability (CVSS 8.8) in Apache HTTP Server 2.4.66's HTTP/2 module.

- **Type**: Double-free vulnerability in mod_http2, specifically in the stream cleanup path of `h2_mplx.c`
- **Affected version**: Apache HTTP Server 2.4.66
- **Fixed version**: Apache HTTP Server 2.4.67
- **DoS exploitation**: Trivial — requires only one TCP connection and two frames, no authentication, crashes the worker process and drops all requests on the crashed worker
- **RCE**: Working proof-of-concept built on x86_64; harder to achieve than DoS but demonstrated
- **Discovered by**: Bartlomiej Dmitruk (Striga.ai) and Stanislaw Strzalkowski (ISEC.pl)
