# Microsoft Patch Tuesday April 2026: record 169 CVEs including actively exploited SharePoint zero-day; 3 Defender zero-days still active

Microsoft's April 2026 Patch Tuesday addressed a record 169 security flaws including one actively exploited SharePoint zero-day. Separate from the Patch Tuesday release: Huntress issued a warning that three recently disclosed Microsoft Defender vulnerabilities are being actively exploited for privilege escalation, with two of the three still unpatched at time of warning. Combined, this represents one of the most significant Microsoft patch cycles in recent memory. Also in the week: Cisco patched four critical security flaws in Identity Services and Webex Services enabling arbitrary code execution and user impersonation. NIST announced limitations to CVE enrichment after a 263% surge in vulnerability submissions overwhelmed the National Vulnerability Database (NVD) capacity.
