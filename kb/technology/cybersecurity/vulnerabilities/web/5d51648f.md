# CVE-2026-8181: Critical Auth Bypass in Burst Statistics WordPress Plugin (200K+ Installs) Under Active Exploitation

CVE-2026-8181 (CVSS 9.8) is a critical authentication bypass vulnerability in the Burst Statistics WordPress analytics plugin, which has over 200,000 active installations. The flaw allows unauthenticated attackers who know a valid administrator username to fully impersonate that administrator for any REST API request by supplying an arbitrary incorrect password in a Basic Authentication header. An attacker can exploit this to create new administrator-level accounts with no prior authentication and seize full control of the site. Wordfence has blocked thousands of active exploitation attempts targeting this vulnerability. The plugin's widespread installation base makes this a high-priority patch.
