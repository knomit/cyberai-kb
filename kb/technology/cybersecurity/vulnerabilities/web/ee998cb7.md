# Drupal Core 'Highly Critical' RCE Vulnerability Affecting PostgreSQL Sites

Drupal released security updates in May 2026 for a 'highly critical' vulnerability in Drupal Core that affects sites using PostgreSQL databases. The flaw can be exploited to achieve remote code execution, privilege escalation, or information disclosure on vulnerable installations. Drupal powers a significant share of government, nonprofit, and enterprise websites globally. PostgreSQL-backed Drupal sites are specifically at risk, making this a targeted but broadly impactful vulnerability given the prevalence of both components in public sector and open-source deployments.
