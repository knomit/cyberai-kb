# NGINX CVE-2026-42945: Remote Code Execution in HTTP/3 Parser, CVSS 9.8

CVE-2026-42945 is a critical remote code execution vulnerability (CVSS 9.8) in NGINX's HTTP/3 (QUIC) protocol parser, disclosed in May 2026. The vulnerability allows an unauthenticated attacker to achieve remote code execution on NGINX instances with HTTP/3 enabled by sending a crafted QUIC packet that triggers a heap buffer overflow in the parser. NGINX is the most widely deployed web server and reverse proxy globally, running in the majority of enterprise and cloud infrastructure stacks. HTTP/3 adoption has been accelerating, meaning the vulnerable code path is increasingly reachable in production deployments. CISA added CVE-2026-42945 to the Known Exploited Vulnerabilities catalog on the day of disclosure, indicating confirmed in-the-wild exploitation.
