# CVE-2026-0300: Critical PAN-OS Buffer Overflow Under Active Exploitation (Unpatched)

Palo Alto Networks issued an advisory warning that CVE-2026-0300, a critical buffer overflow vulnerability in PAN-OS's User-ID Authentication Portal (Captive Portal service), is being actively exploited in the wild.

- **Type**: Unauthenticated Remote Code Execution (buffer overflow)
- **CVSS**: 9.3 if User-ID Authentication Portal is internet-accessible; 8.7 if restricted to trusted internal IPs
- **Impact**: Allows unauthenticated attacker to execute arbitrary code with root privileges on PA-Series and VM-Series firewalls via specially crafted packets
- **Exploitation**: 'Limited exploitation' observed, specifically targeting instances where the Authentication Portal is publicly accessible
- **Patch status**: UNPATCHED as of May 6, 2026; Palo Alto Networks plans to release fixes starting May 13, 2026
- **Mitigations**: Restrict User-ID Authentication Portal access to trusted zones only, or disable it entirely if not required
