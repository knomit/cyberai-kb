# Cisco CVE-2026-20223 CVSS 10.0: Unauthenticated Remote Data Access via Secure Workload REST API

Cisco patched CVE-2026-20223 (CVSS 10.0 — maximum severity) in Secure Workload (formerly Tetration), its enterprise microsegmentation and workload security platform, in May 2026.

**Vulnerability**: Insufficient validation and authentication when accessing REST API endpoints. An unauthenticated, remote attacker can send a crafted API request to an affected endpoint. Successful exploitation allows the attacker to read sensitive data.

**Affected product**: Cisco Secure Workload — used by large enterprises for east-west traffic segmentation, workload policy enforcement, and cloud security posture management. It typically has access to sensitive network topology data, workload inventory, and potentially secrets used in policy enforcement.

The maximum CVSS score (10.0) reflects the combination of: network-accessible attack vector, no authentication required, and high impact on confidentiality/integrity of sensitive data.
