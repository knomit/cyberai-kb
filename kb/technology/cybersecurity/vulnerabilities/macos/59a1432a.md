# Apple M5 MIE Bypass: First Public macOS Kernel Memory Corruption Exploit on M5 Silicon, Found via Anthropic Mythos Testing

A researcher identified as Calif discovered a novel bypass of Apple's Memory Integrity Enforcement (MIE) — a hardware-assisted memory safety system — achieving privilege escalation to root on macOS 26.4.1 (build 25E253) on M5 hardware. The discovery was made while testing an early version of Anthropic's Mythos Preview in April 2026. This is the first public macOS kernel memory corruption exploit on M5 silicon that survives MIE. The exploit is a data-only kernel local privilege escalation chain: starting from an unprivileged local user, using only normal system calls, targeting two vulnerabilities to achieve a root shell on bare-metal M5 hardware with kernel MIE enabled. Full technical details are withheld pending Apple's fix. The disclosure demonstrates that AI safety research tools (Mythos Preview) are being used by security researchers to discover zero-day vulnerabilities.
