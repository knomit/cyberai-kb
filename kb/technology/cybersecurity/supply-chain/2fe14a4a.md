# May 2026 software supply chain crisis: simultaneous coordinated attacks across ecosystems

The week of May 19–25, 2026 saw an unprecedented cluster of software supply chain attacks across all major ecosystems: (1) Mini Shai-Hulud / TanStack compromise: infected Nx Console VS Code extension (nrwl.angular-console), breached GitHub (3,800 repos exfiltrated), OpenAI, Mistral AI, and Grafana Labs via developer device compromise by TeamPCP; Shai-Hulud worm code publicly released, creating a ready-made blueprint for future attacks. (2) TrapDoor: 34+ malicious packages across npm, PyPI, and Crates.io spreading credential stealers. (3) Packagist: 8 PHP packages compromised with GitHub-hosted Linux malware. (4) Megalodon: 5,718 malicious commits pushed to 5,561 GitHub repos in 6 hours using throwaway accounts. In response, npm rolled out 2FA-gated publishing and install controls. The Verizon 2026 DBIR simultaneously reported that vulnerability exploitation has overtaken credentials as the #1 initial access vector. The convergence suggests a strategic shift toward attacking the software build and distribution layer rather than targeting end-user systems directly.
