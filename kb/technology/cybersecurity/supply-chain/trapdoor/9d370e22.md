# TrapDoor: coordinated supply chain attack across npm, PyPI, and Crates.io (May 2026)

A new campaign codenamed TrapDoor (reported May 25, 2026) spread credential-stealing malware across 34+ malicious packages on npm, PyPI, and Crates.io simultaneously. Separate Packagist attack compromised 8 PHP packages using GitHub-hosted Linux malware binaries. npm responded by rolling out 2FA-gated publishing and package install controls to improve supply chain security. Also: Megalodon GitHub attack pushed 5,718 malicious commits to 5,561 GitHub repos within a 6-hour window using throwaway accounts.
