# GitHub breached via poisoned Nx Console VS Code extension (TeamPCP, Mini Shai-Hulud)

GitHub confirmed (week of May 25, 2026) its internal repositories were breached via a compromised Nx Console VS Code extension (nrwl.angular-console) after a Nous Research developer's system was hacked in the TanStack supply chain attack. Threat actor: TeamPCP. Exfiltrated ~3,800 repositories. GitHub rotated critical secrets. Other victims of the TanStack compromise: OpenAI, Mistral AI, Grafana Labs. Grafana Labs refused an extortion demand. All part of the 'Mini Shai-Hulud campaign'. TeamPCP's public release of the Shai-Hulud code gives attackers a ready-made worm blueprint for targeting open-source repos and developer environments.
