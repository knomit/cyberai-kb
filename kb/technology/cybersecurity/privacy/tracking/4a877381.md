# Microsoft's Global Device Identifier (GDID) publicly confirmed in July 2026 FBI complaint against Scattered Spider suspect

Microsoft publicly acknowledged the existence of the Global Device Identifier (GDID) for the first time in a 39-page federal criminal complaint unsealed July 1, 2026, against Peter Stokes, a 19-year-old dual US-Estonian citizen alleged to be a member of Scattered Spider. Microsoft's representative described GDID in the filing as a persistent, device-level identifier that uniquely identifies a Windows OS installation on a physical device or VM across certain Microsoft services and scenarios.

Key properties: the GDID is minted server-side by Microsoft (not derived purely from hardware) during Windows setup/identity and account-registration flows, with hardware signals feeding the request, and is stored locally in the registry. It survives Windows updates but NOT a clean reinstall — a reinstall yields a new GDID. However, signing back into the same Microsoft Account gives Microsoft a straightforward path to relink the new GDID to prior activity, so reinstalling is not the reset users assume. Microsoft's own footnote acknowledges one user may have multiple GDIDs over an account's lifetime.

Investigative use: the FBI obtained Stokes' GDID from Microsoft. Microsoft's records correlated the same GDID with IP addresses in Tallinn, New York, and Thailand matching Stokes' travel, and with a visit to ngrok's signup page at the time the attacker's ngrok account was created, plus Snapchat and Facebook logins. The GDID remained constant while IPs and countries changed, defeating VPN/proxy-based attribution evasion. Stokes was arrested at Helsinki Airport in April 2026 on an Interpol Red Notice and extradited to the US.

Privacy criticism: there is no consent screen and no user-facing off switch. Blocking GDID assignment reportedly breaks Windows activation and Microsoft Store/UWP apps, per Massgrave (the Microsoft Activation Scripts group). Microsoft's only public documentation is a single sentence in the Azure Monitor reference for Delivery Optimization reporting, describing a GlobalDeviceId column as an internal Microsoft identifier — so Zerotrace Labs and others had to reverse-engineer its behavior. Critics contrast this with Apple's IDFA (App Tracking Transparency prompt plus visible reset) and Android's equivalent controls. Matthew Hickey characterized Windows as surveillance software; Costin Raiu raised on the Three Buddy Problem podcast the question of how much equivalent functionality exists on other platforms. GDPR compliance has been questioned publicly but no regulatory action is confirmed as of early August 2026.

Important scoping caveats — what this is NOT: the complaint does not claim GDID is transmitted to arbitrary third-party websites, does not claim it defeats encryption, and does not describe it as a general-purpose monitoring mechanism for everything a user does. The demonstrated capability is correlation within Microsoft's own telemetry and service logs (IP activity, account activity, update delivery, SmartScreen/browser events), which Microsoft can then disclose to law enforcement. GDID is also distinct from the Windows Advertising ID and from the Microsoft Account user ID. Unverified forum claims that a GDID exists without any Microsoft Account sign-in, or that a permanent hardware-resident identifier survives clean install, are not corroborated by the complaint or by the reverse-engineering write-ups.

Mitigations reported: use a local account rather than a Microsoft Account; disable optional diagnostic data (Settings > Privacy & security > Diagnostics & feedback); disable personalized ads and app launch tracking (Privacy & security > Recommendations & offers). None of these eliminate the GDID itself. Windscribe released a tool called deGDID aimed at blocking it — note the vendor's commercial interest in the narrative.
