# Attackers increasingly weaponize trusted legitimate tools for evasion and initial access

A consistent pattern across multiple threat actors in Apr 2026: attackers exploit trusted, legitimate software rather than custom malware to evade detection. Cases: (1) MuddyWater abused Microsoft Teams (IT impersonation) + Deno runtime for in-memory payload execution; (2) UNC6692 abused Teams for SNOW malware delivery; (3) QEMU abused by STAC4713/STAC3725 to hide malware inside VMs invisible to EDR; (4) Context.ai third-party AI tool was the entry point for the Vercel breach; (5) PHANTOMPULSE used Obsidian note app + Ethereum blockchain for C2. Pattern: legitimate cloud tools, developer runtimes, note-taking apps, and virtualization software are becoming the preferred attack surface.
