# AI Tooling as Primary Attack Surface: Local Runners, Agentic Frameworks, and Model Hubs (May 2026)

AI developer tooling has emerged as a distinct, high-value attack surface category in 2026. Three vectors are being actively exploited:

**Local AI runners**: Ollama out-of-bounds read (CVE-2026-7482) allows unauthenticated remote attackers to dump the entire process memory — model weights, API keys, conversation data. No authentication required.

**Agentic frameworks**: Two critical agentic infrastructure vulnerabilities: (1) PraisonAI CVE-2026-44338 (authentication bypass) exploited within 4 hours of disclosure — the shortest exploitation window seen for AI framework vulns; (2) Cline Kanban CVSS 9.7 — any website can silently RCE a developer's AI agent via localhost WebSocket (no same-origin enforcement). Attack requires no user interaction.

**Model hubs**: Fake OpenAI 'Privacy Filter' repo reached #1 trending on Hugging Face with 244K downloads before takedown, delivering a Rust infostealer. Supply chain attacks now extend from code packages to AI model distribution platforms.

**Pattern**: AI tools run with developer-level privileges in development environments, typically with weaker security hygiene than production systems. The combination of local execution, broad file/network access, and developer trust makes this attack surface disproportionately valuable to attackers targeting software supply chains. The 4-hour exploitation window for PraisonAI suggests attackers are monitoring AI security disclosures as a high-priority feed.
