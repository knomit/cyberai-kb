# OpenAI GPT-5.5-Cyber: Security-Focused Model Variant in Limited Preview (May 2026)

OpenAI rolled out GPT-5.5-Cyber, a security-focused variant of GPT-5.5, in limited preview to select cybersecurity teams, one month after Anthropic's Mythos debut. OpenAI: 'The initial preview is not intended to significantly increase cyber capability beyond GPT-5.5 — it is primarily trained to be more permissive on security-related tasks.' Positions AI as a dual-use security tool alongside Anthropic Mythos.
