# Microsoft MDASH AI System Discovers 16 Windows Flaws Fixed in May 2026 Patch Tuesday

Microsoft unveiled MDASH (Multi-model AI-Driven Automated Security Helper), an AI system using multiple models to facilitate vulnerability discovery and remediation at scale. MDASH discovered 16 Windows vulnerabilities that were fixed in May 2026 Patch Tuesday. The system is being tested by select customers. Validates AI-assisted vulnerability research as a production-ready capability at Microsoft.
