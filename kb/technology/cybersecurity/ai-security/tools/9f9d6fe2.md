# Mozilla Uses Anthropic Mythos to Fix 423 Firefox Security Bugs in April 2026 (vs 31 a Year Prior)

Mozilla revealed that Anthropic's Mythos Preview and other AI models helped identify and ship 423 Firefox security bug fixes in April 2026, up from only 31 in April 2025 (13x increase). Included a 20-year-old use-after-free bug in XSLTProcessor DOM API exploitable without user interaction, plus various sandbox flaws. Validates AI-assisted vulnerability discovery at production scale for browser security.
