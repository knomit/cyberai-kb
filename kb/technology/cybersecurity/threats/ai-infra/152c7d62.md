# Ollama Out-of-Bounds Read: Remote Unauthenticated Full Process Memory Leak (May 2026)

Critical security vulnerability in Ollama (local LLM runner) disclosed: an out-of-bounds read vulnerability allows a remote, unauthenticated attacker to leak the entire Ollama process memory. This could expose model weights, API keys, conversation data, and other sensitive information stored in process memory. CVE-2026-7482 (also CVE-2026-42248 and CVE-2026-42249 for Windows variant).
