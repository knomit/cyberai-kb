# Cline Kanban Server Critical Vuln (CVSS 9.7): Any Website Can RCE Developer's AI Agent (May 2026)

Oasis Security discovered a critical vulnerability (CVSS 9.7) in Cline's local Kanban server. Root cause: localhost WebSocket server lacks origin validation and authentication. Since browsers don't enforce same-origin policy on WebSocket connections, any website visited while Cline is running can connect to the local endpoints and achieve: (1) information disclosure via runtime state stream; (2) remote code execution via terminal I/O endpoint; (3) denial-of-service via terminal control endpoint. Attack is silent — developer sees nothing unusual. Fixed in Cline Kanban v0.1.66.
