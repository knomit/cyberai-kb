# ConsentFix V3: Automated Microsoft Account Hijacking via OAuth Consent Phishing (May 2026)

Push Security identified ConsentFix V3, a new toolkit advertised on XSS criminal forum that combines ClickFix social engineering with OAuth consent phishing. Capabilities: full attack chain automation from infrastructure spinup to OAuth token capture and account hijack. Infrastructure: Cloudflare Workers (phishing pages), ZoomInfo (target identification), Dropbox (PDF hosting), Pipedream (exfiltration). Exchanges captured OAuth tokens for session and refresh tokens, establishing persistent account access.
