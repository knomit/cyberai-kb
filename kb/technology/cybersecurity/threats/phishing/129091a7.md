# EvilTokens: Phishing-as-a-Service Platform Harvesting OAuth Tokens at Enterprise Scale

EvilTokens is a Phishing-as-a-Service (PhaaS) platform discovered in May 2026 that specializes in harvesting OAuth access tokens from enterprise users rather than traditional credential pairs (username/password). The platform provides turnkey phishing infrastructure — landing pages, domain rotation, and token exfiltration — that specifically targets Microsoft 365, Google Workspace, Salesforce, and GitHub OAuth flows. By capturing OAuth tokens instead of passwords, EvilTokens attacks bypass MFA protections entirely since the token represents an already-authenticated session. The PhaaS model allows low-skilled attackers to run sophisticated token-harvesting campaigns for a subscription fee. Token-based attacks are increasingly preferred as MFA adoption makes password-only attacks less effective.
