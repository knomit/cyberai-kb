# MuddyWater picks the category its incidents appear to belong to, so triaging one of its intrusions as ransomware mis-scopes an espionage operation against credential-dense infrastructure

Two separately reported 2026 MuddyWater tracks, read together, say something neither says alone: what this actor is after and what its incidents look like are chosen independently.

WHAT IT IS AFTER. CISA added CVE-2025-34291 (CVSS 9.4) in Langflow — the open-source AI workflow orchestration tool — to its Known Exploited Vulnerabilities catalog on 22 May 2026, citing active exploitation. The flaw combines a permissive CORS configuration, missing CSRF protection, and an endpoint that executes code by design. Per the source: 'Successful exploitation not only compromises the Langflow instance but also exposes ALL SENSITIVE ACCESS TOKENS AND API KEYS STORED WITHIN THE WORKSPACE,' cascading to every integrated downstream cloud and SaaS service. MuddyWater, an Iranian state-sponsored group, is named as exploiting it for initial access (per Ctrl-Alt-Intel, March 2026; Obsidian Security first reported the flaw in December 2025). This is a target chosen for credential density.

WHAT ITS INCIDENTS LOOK LIKE. In a separate early-2026 campaign entered through Microsoft Teams social engineering, MuddyWater ran reconnaissance, credential harvesting and data exfiltration — and NO FILE-ENCRYPTING RANSOMWARE WAS DEPLOYED AT ALL. The victim was nonetheless added to the Chaos ransomware data-leak site as cover. Infrastructure and code-signing certificate evidence point to MuddyWater; Rapid7 found no evidence it is a Chaos affiliate.

THE JOIN: the category a defender reads off an incident — a leak-site listing, a ransom brand — is an output the attacker controls, and it was set here to something other than what the operation was. An organisation that classifies the event as commodity ransomware runs the matching playbook: assess encryption scope, evaluate restore-versus-pay, notify on a data-leak-extortion footing, and close. That playbook does not ask which API keys and service tokens left the environment, which is the question the Langflow track shows this actor is actually pursuing. Absence of encryption in an apparent ransomware case is therefore a signal to widen scope, not a reason to relax.

SCOPE AND CAVEATS: these are two separately reported campaigns, and this record does NOT claim they were one operation, shared infrastructure, or ran concurrently — only that both are attributed to the same actor in this corpus. The false-flag reading is an assessment resting on infrastructure and certificate evidence plus Rapid7's negative finding on affiliation, not a confession; the Langflow attribution is a single analyst firm's, though the KEV listing and the vulnerability details are CISA's. WHAT THIS DOES NOT MEAN: this does not claim ransomware branding is generally a false flag — the overwhelming majority of leak-site listings reflect real extortion — nor that MuddyWater never encrypts, nor that AI orchestration platforms are this actor's only target. It claims that for THIS actor, category and objective have been observed to diverge, and that the divergence has a specific cost for responders.
