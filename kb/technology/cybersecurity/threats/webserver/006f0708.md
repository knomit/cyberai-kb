# 18-Year-Old NGINX Rewrite Module Flaw Enables Unauthenticated RCE (May 2026)

Security researchers at depthfirst disclosed multiple vulnerabilities in NGINX Plus and NGINX Open Source, including a critical flaw that remained undetected for 18 years. The vulnerability enables unauthenticated remote code execution (RCE). Affects both NGINX Plus and NGINX Open Source.
