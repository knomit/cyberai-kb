# YellowKey BitLocker Bypass: CVE-2026-45585 Windows Full-Disk Encryption Defeated Without TPM

CVE-2026-45585, dubbed YellowKey, is a Windows vulnerability that allows attackers to bypass BitLocker full-disk encryption without requiring TPM chip interaction. The vulnerability enables an attacker with physical or OS-level access to extract BitLocker volume master keys, rendering full-disk encryption ineffective for endpoint data protection. BitLocker is the default encryption mechanism on Windows enterprise deployments and is mandated by many compliance frameworks (HIPAA, FedRAMP, PCI-DSS). YellowKey directly undermines the data-at-rest protection layer that organizations rely on for stolen-device scenarios. As of May 2026, active exploitation status was being tracked.
