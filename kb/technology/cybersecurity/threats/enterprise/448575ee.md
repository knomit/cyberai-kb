# MS Exchange On-Premise CVE-2026-42897: Actively Exploited 0-Day via Crafted Email

Microsoft disclosed CVE-2026-42897, a new security vulnerability in on-premise versions of Exchange Server that has come under active exploitation in the wild. The vulnerability is triggered via a crafted email, requiring no user interaction beyond receiving the message. CVSS score is high (exact score not disclosed in source). This continues the pattern of Exchange Server as a high-value, persistently exploited attack surface — consistent with Mandiant's M-Trends finding that exploits are increasingly preceding patches.
