# Ivanti EPMM CVE-2026-6973 and Palo Alto PAN-OS CVE-2026-0300 Actively Exploited (May 2026)

Two high-profile network device vulnerabilities under active exploitation: (1) Ivanti EPMM CVE-2026-6973: improper input validation allowing authenticated admins to execute code remotely; (2) Palo Alto PAN-OS CVE-2026-0300: memory corruption in authentication portal allowing unauthenticated RCE with root privileges on PA-Series and VM-Series firewalls. Censys detected ~263,000 internet-exposed PAN-OS hosts. Exploitation attempts began as early as April 9, 2026. Patches expected starting May 13, 2026.
