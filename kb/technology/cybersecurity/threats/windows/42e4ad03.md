# MiniPlasma Windows 0-Day: Kernel Privilege Escalation via Session Manager Exploit

MiniPlasma is a Windows kernel zero-day vulnerability discovered in May 2026 that enables local privilege escalation to SYSTEM via exploitation of the Windows Session Manager (smss.exe) subsystem. The vulnerability allows an attacker with standard user access to escalate to full kernel privileges without triggering common EDR detection mechanisms, as smss.exe is a trusted Windows process with no behavioral alerts generated for standard execution patterns. MiniPlasma was found being exploited in the wild before a patch was available. The attack chain typically follows an initial access event (phishing, RCE) with MiniPlasma enabling the pivot to full system control. Microsoft issued an out-of-band patch given active exploitation.
