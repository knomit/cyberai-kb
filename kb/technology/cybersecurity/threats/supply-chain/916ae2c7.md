# AntV npm Packages Compromised via Maintainer Account Takeover in Mini Shai-Hulud Wave

AntV, the data visualization library suite maintained by Alibaba's Ant Group and widely used in enterprise dashboards and React applications, had multiple npm packages compromised in May 2026 via a maintainer account takeover. The attack follows the Mini Shai-Hulud supply chain pattern: rather than injecting malicious code at the package level, the threat actor (TeamPCP) compromised a legitimate maintainer's credentials and published trojanized versions with malicious payloads. AntV packages have tens of millions of weekly downloads, giving this compromise massive downstream exposure across enterprise frontend applications. The attack method of maintainer account takeover highlights a gap in npm's security model — package signing does not verify the identity integrity of the publisher account.
