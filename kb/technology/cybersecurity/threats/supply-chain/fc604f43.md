# TeamPCP Open-Sources Mini Shai-Hulud Worm: Supply Chain Attack Toolkit Now Available to All Threat Actors

TeamPCP, the threat actor behind the Mini Shai-Hulud supply chain attack campaign, published the full source code of the Shai-Hulud worm on a dark web code repository in May 2026. The open-sourcing of the attack toolkit represents a critical threat escalation: what was previously a capability limited to a sophisticated, organized threat actor is now available to any party willing to adapt and deploy it. The Shai-Hulud worm's code includes modules for npm registry credential harvesting, package version injection, maintainer account takeover via credential stuffing, and CI/CD pipeline secret exfiltration. Security researchers warn that open-sourcing the toolkit will likely trigger a wave of copycat campaigns using modified versions of the worm against previously unaffected package ecosystems (PyPI, RubyGems, Maven Central, NuGet). This event materially raises the baseline threat level for all open-source software supply chains.
