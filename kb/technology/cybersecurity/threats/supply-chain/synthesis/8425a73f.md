# Open-Source Distribution Stack Systematically Compromised: TeamPCP Collapses Trust Across npm, CI/CD, IDE, VCS, and AI Model Registries

By May 2026, the TeamPCP / Mini Shai-Hulud campaign had achieved systematic compromise of every major layer in the open-source software distribution stack:

**Package layer**: TanStack, Mistral AI, UiPath, Guardrails AI, AntV (Ant Group), OpenSearch, and PyPI-hosted packages — via worm injection and maintainer account takeover.
**CI/CD layer**: GitHub Actions (actions-cool/issues-helper) — secrets intercepted during pipeline runs.
**IDE layer**: Nx Console VS Code extension — full local machine access via auto-updated IDE extensions.
**Version control infrastructure**: GitHub itself — 3,800+ internal repos exfiltrated via compromised employee device.
**Observability infrastructure**: Grafana — breached via TanStack dependency.
**AI model registry**: Hugging Face — fake repository (Open-OSS/privacy-filter) delivering Rust stealer by impersonating OpenAI's model.
**Attack toolkit democratization**: TeamPCP open-sourced the Shai-Hulud worm in May 2026, making the full attack methodology available to all threat actors for copycat campaigns against PyPI, RubyGems, Maven Central, and NuGet.
**Credential monetization**: TeamPCP uses Trufflehog to validate harvested credentials automatically, then operates as an initial access broker selling validated access to ransomware affiliates.

Pattern: No single layer of the software supply chain is now reliably trusted without out-of-band verification. The attack surface has expanded from code packages to CI/CD pipelines, IDE extensions, VCS infrastructure, and AI model distribution channels. Government response (CISA + allies joint SBOM guidance for AI systems, May 2026) confirms that regulators recognize AI model registries as part of the software supply chain requiring the same rigor as traditional packages.

Structural implication: The industry's default trust model for open-source distribution — 'packages from registries signed by maintainers are safe' — has been broken at every layer simultaneously. Defending against this class of attack requires: (a) runtime behavioral attestation, not just package signing; (b) cryptographic provenance tracking at publish time; (c) SBOM coverage extended to model weights and training data; (d) zero-trust CI/CD secret management.
