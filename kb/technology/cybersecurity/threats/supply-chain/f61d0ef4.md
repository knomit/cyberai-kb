# TeamPCP Uses Trufflehog to Validate Stolen Credentials; OpenSearch and PyPI Added to Victim List

Additional details on the TeamPCP / Mini Shai-Hulud supply chain campaign (May 2026): The threat actor uses Trufflehog — a legitimate open-source secrets scanning tool — to automatically validate credentials and API keys harvested from compromised packages before using them for downstream access. TeamPCP has expanded beyond the initially known victims (TanStack, Mistral AI, UiPath, Guardrails AI, AntV, GitHub Actions, Nx Console) to also compromise packages tied to OpenSearch and PyPI-hosted projects. The threat actor is functioning as an initial access broker, selling or sharing validated credentials with ransomware affiliates and other cybercrime groups. The escalating blast radius demonstrates that the TeamPCP campaign is not a targeted operation but a broad opportunistic sweep of the entire open-source ecosystem.
