# Megalodon: Automated Campaign Pushes 5,718 Malicious CI/CD Commits to 5,561 GitHub Repos in 6 Hours

Cybersecurity researchers (SafeDep) disclosed details of a new automated campaign called Megalodon that pushed 5,718 malicious commits to 5,561 GitHub repositories within a 6-hour window on May 18, 2026 (11:36 a.m.–5:48 p.m. UTC). This is a DISTINCT campaign from TeamPCP/Mini Shai-Hulud — different name, different infrastructure, different C2 (216.126.225[.]129:8443).

**Attack mechanics**: Using throwaway GitHub accounts with random 8-character usernames (e.g., rkb8el9r, bhlru9nr, lo6wt4t6), the attacker rotated through 4 author names (build-bot, auto-ci, ci-bot, pipeline-bot) and 7 commit messages mimicking routine CI maintenance. Compromised PATs or deploy keys were used to push malicious GitHub Actions workflows containing base64-encoded bash payloads.

**Two payload variants**:
- SysDiag (mass): adds workflow triggered on every push/pull — guarantees execution on every commit to master
- Optimize-Build (targeted): activates only on `workflow_dispatch` trigger — used for on-demand credential exfiltration without triggering on every push

**Data exfiltrated**:
- CI environment variables, /proc/*/environ, PID 1 environment
- AWS credentials, Google Cloud access tokens, Azure IMDS endpoint instance role credentials
- GitHub Actions OIDC tokens, GITHUB_TOKEN, GitLab CI/CD tokens, Bitbucket tokens
- SSH private keys, Docker/Kubernetes configs, Vault tokens, Terraform credentials
- .env files, credentials.json, service-account.json, other configuration files

**Known impacted packages**: @tiledesk/tiledesk-server (example confirmed victim).

Significance: With 5,700+ repos compromised and even a small fraction yielding a usable GITHUB_TOKEN, the workflow_dispatch variant gives the attacker on-demand triggering capability against a massive victim pool. The timing — days after Mini Shai-Hulud's open-sourcing — raises the question of whether Megalodon is a copycat campaign using elements of the open-sourced worm toolkit.
