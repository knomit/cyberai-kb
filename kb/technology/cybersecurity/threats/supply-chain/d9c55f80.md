# Nx Console VS Code Extension Compromised: Developer IDE Backdoor in TeamPCP Supply Chain Wave

The Nx Console VS Code extension — the official tooling extension for the Nx monorepo build system, with millions of installs across enterprise development environments — was compromised in May 2026 as part of the TeamPCP / Mini Shai-Hulud supply chain attack campaign. A trojanized version was published to the VS Code Marketplace that executes malicious code within the developer's IDE environment, where it has access to local files, environment variables, and any credentials stored in the workspace. Nx is widely used in large-scale TypeScript/JavaScript monorepo projects at enterprises. The VS Code extension attack surface is particularly dangerous because extensions run with full local machine permissions and are auto-updated by default.
