# GemStuffer Campaign: 150+ Malicious RubyGems Used as Data Exfiltration Channel (May 2026)

Security researchers identified a campaign called GemStuffer that uploaded 150+ malicious RubyGems packages targeting the Ruby package registry. Uniquely, the gems were used as a data exfiltration channel rather than for code execution — scraping U.K. council portal data and exfiltrating it via the RubyGems registry itself. RubyGems temporarily suspended new account signups following the 'major malicious attack.'
