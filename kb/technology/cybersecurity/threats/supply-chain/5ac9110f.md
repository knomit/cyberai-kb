# node-ipc npm Stealer Backdoor: 3 Versions Targeting Developer Secrets (May 2026)

Security researchers from Socket and StepSecurity discovered that three different versions of the node-ipc npm package contained malicious activity — specifically, a stealer backdoor designed to target developer secrets. node-ipc is a widely used inter-process communication library in the Node.js ecosystem.

This follows the established pattern of attackers targeting developer toolchain packages to harvest credentials, tokens, and API keys from developer environments. It is a direct continuation of the broader trend: AI coding agents and automated pipelines that consume npm packages without review create a dramatically expanded surface for this class of attack. Consistent with the 87% AI coding agent PR vulnerability rate documented in prior synthesis.
