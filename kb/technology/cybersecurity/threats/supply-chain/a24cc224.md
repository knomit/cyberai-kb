# GitHub Officially Confirms Breach Caused by Poisoned Nx Console VS Code Extension — TeamPCP Attribution Complete

GitHub officially confirmed on May 21, 2026 that the breach of its internal repositories (3,800+ repos exfiltrated) was caused by a compromised employee device running a poisoned version of the Nx Console VS Code extension — the same extension compromised by TeamPCP as part of the Mini Shai-Hulud supply chain campaign. This closes the attribution loop on the GitHub breach: the attack vector is now confirmed as the Nx Console VS Code extension (not a separate intrusion vector), directly linking the GitHub infrastructure breach to the broader TeamPCP supply chain campaign that also hit TanStack, Mistral AI, UiPath, Guardrails AI, AntV, GitHub Actions, and Grafana. The VS Code Marketplace auto-update mechanism was the delivery mechanism — an employee device silently received the malicious extension update.
