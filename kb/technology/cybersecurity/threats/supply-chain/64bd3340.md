# GitHub Actions actions-cool/issues-helper Compromised: CI/CD Pipeline Backdoor in Mini Shai-Hulud Campaign

The GitHub Actions action 'actions-cool/issues-helper' — a widely-used workflow action for automated GitHub issue management — was compromised in May 2026 as part of the Mini Shai-Hulud supply chain campaign by TeamPCP. The malicious version executes during CI/CD pipeline runs, allowing the attacker to intercept environment variables, secrets, and tokens available in the GitHub Actions runner environment. Because GitHub Actions actions run with repository-scoped secrets (including GITHUB_TOKEN, cloud provider credentials, and deployment keys), compromise of a popular action can grant access to the full deployment pipeline of any repository using it. The actions-cool/issues-helper action had millions of uses across open-source and enterprise repositories.
