# TeamPCP Mini Shai-Hulud Wave: GitHub Actions, AntV npm, and Nx Console VS Code Extension Compromised

Three additional developer toolchain components were compromised in the May 2026 TeamPCP / Mini Shai-Hulud supply chain campaign wave:

**GitHub Actions — actions-cool/issues-helper**: A widely-used workflow action (millions of uses across open-source and enterprise repos) was backdoored with a malicious version that intercepts environment variables, secrets, and tokens during CI/CD pipeline runs — including GITHUB_TOKEN, cloud credentials, and deployment keys.

**AntV npm packages (Ant Group)**: Multiple packages from Alibaba's AntV data visualization suite (tens of millions of weekly downloads) were compromised via maintainer account takeover — TeamPCP obtained legitimate maintainer credentials and published trojanized versions. Highlights the gap in npm's security model: package signing does not verify publisher account integrity.

**Nx Console VS Code extension**: The official tooling extension for the Nx monorepo build system (millions of installs in enterprise TypeScript/JavaScript environments) was backdoored via a malicious VS Code Marketplace publication. Extensions run with full local machine permissions and auto-update by default, making them a high-value IDE attack surface.

All three follow the same TeamPCP playbook: compromise a trusted, high-download developer tool to harvest credentials, API keys, and secrets at scale. The attack surface has expanded from npm packages (TanStack, UiPath, Mistral AI, AntV) to CI/CD actions (GitHub Actions) and IDE extensions (VS Code Marketplace).
