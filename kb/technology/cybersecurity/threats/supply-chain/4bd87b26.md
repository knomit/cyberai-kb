# GitHub Breached by TeamPCP: 3,800+ Internal Repos Exfiltrated via Mini Shai-Hulud Supply Chain Attack

GitHub confirmed a major breach in May 2026 in which the TeamPCP threat actor — the same group behind the Mini Shai-Hulud supply chain worm — exfiltrated over 3,800 internal source code repositories. Attack vector officially confirmed (May 21, 2026): a poisoned version of the Nx Console VS Code extension was auto-updated on an employee device, giving TeamPCP a foothold that led to internal repo exfiltration. This directly links the GitHub infrastructure breach to the broader Mini Shai-Hulud campaign — the same Nx Console extension previously flagged as compromised in the supply chain wave.

GitHub is the substrate of global software supply chains; this breach represents the most significant infrastructure-level impact of the Mini Shai-Hulud campaign to date. The stolen repositories could expose proprietary GitHub platform code, CI/CD pipeline logic, internal tooling, and potentially customer code stored in private repositories. The VS Code Marketplace auto-update mechanism was the delivery vector — the employee received the malicious extension silently.
