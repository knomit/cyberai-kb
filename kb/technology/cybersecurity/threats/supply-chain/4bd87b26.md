# GitHub Breached by TeamPCP: 3,800+ Internal Repos Exfiltrated via Mini Shai-Hulud Supply Chain Attack

GitHub confirmed a major breach in May 2026 in which the TeamPCP threat actor — the same group behind the Mini Shai-Hulud supply chain worm — exfiltrated over 3,800 internal source code repositories. The attack vector was a compromised employee device, traced back to the ongoing Mini Shai-Hulud / TeamPCP supply chain attack wave that had previously hit TanStack, Mistral AI, UiPath, Guardrails AI, AntV, and affected two OpenAI employee devices. GitHub is the substrate of global software supply chains; this breach represents the most significant infrastructure-level impact of the Mini Shai-Hulud campaign to date and may constitute the SolarWinds-scale event predicted in hypothesis 7cc50183. The stolen repositories could expose proprietary GitHub platform code, CI/CD pipeline logic, internal tooling, and potentially customer code stored in private repositories. The scope of downstream exposure is unknown at time of reporting.
