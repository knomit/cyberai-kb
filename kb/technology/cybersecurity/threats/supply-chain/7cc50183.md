# Hypothesis: A SolarWinds-Scale Supply Chain Compromise Will Occur via an AI Developer Tool by End of 2026

Prediction: By end of 2026, the Mini Shai-Hulud / TeamPCP supply chain attack wave will be confirmed as a SolarWinds-scale compromise event — defined as: (a) 3+ major developer infrastructure platforms compromised, (b) downstream victim count in the thousands of organizations, and (c) attribution to a persistent, sophisticated threat actor with ongoing campaign infrastructure.

Evidence accumulation as of June 2026:
- TanStack compromised (widely used UI query library, millions of downstream dependents)
- Mistral AI, UiPath, Guardrails AI compromised via same worm
- Two OpenAI employee devices compromised (insider-adjacent impact)
- AntV npm packages compromised via maintainer account takeover
- GitHub Actions (actions-cool/issues-helper) compromised
- Nx Console VS Code extension compromised
- Grafana breached via TanStack dependency
- GitHub itself breached: 3,800+ internal source code repositories exfiltrated by TeamPCP via compromised employee device (May 2026)
- IronWorm + new Miasma variant: 50+ poisoned npm packages distributing Rust-based stealer and self-replicating worm (June 6, 2026)
- Hades/PyPI: TeamPCP expanded to PyPI — 37 malicious wheel artifacts across 19 packages, Bun credential stealer (June 9, 2026)
- Microsoft shut down 70+ GitHub repositories in response to the AI-agent hack (early June 2026) — first large-scale corporate remediation action attributed to this campaign

Criterion (a) — 3+ major developer infrastructure platforms — is now strongly met: npm, PyPI, GitHub, GitHub Actions, VS Code extension marketplace. The campaign has demonstrated a deliberate registry-hopping strategy (npm → PyPI) and platform diversification.

Criterion (b) — thousands of downstream orgs — remains the load-bearing pending signal. Whether GitHub's investigation concludes customer repo/secret exposure determines whether this crosses SolarWinds scale.

Criterion (c) — persistent sophisticated actor — confirmed: TeamPCP has maintained campaign infrastructure across multiple months and platforms.

Falsifiable signal: If GitHub discloses that stolen repos contained secrets/tokens used to access customer code, or if downstream org count breaches 500+, the SolarWinds-scale label is confirmed. If GitHub's investigation concludes stolen repos were internal-only with no customer exposure and the attack wave ceases, hypothesis is disconfirmed.

Confidence raised 0.82 → 0.85: Hades/PyPI adds third package registry to criterion (a); Microsoft 70-repo shutdown confirms organizational-scale impact and corporate acknowledgment of the breach.
