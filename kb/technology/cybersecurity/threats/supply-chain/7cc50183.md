# Hypothesis: A SolarWinds-Scale Supply Chain Compromise Will Occur via an AI Developer Tool by End of 2026

Prediction: By end of 2026, the Mini Shai-Hulud / TeamPCP supply chain attack wave will be confirmed as a SolarWinds-scale compromise event — defined as: (a) 3+ major developer infrastructure platforms compromised, (b) downstream victim count in the thousands of organizations, and (c) attribution to a persistent, sophisticated threat actor with ongoing campaign infrastructure.

Evidence accumulation as of May 2026:
- TanStack compromised (widely used UI query library, millions of downstream dependents)
- Mistral AI, UiPath, Guardrails AI compromised via same worm
- Two OpenAI employee devices compromised (insider-adjacent impact)
- AntV npm packages compromised via maintainer account takeover
- GitHub Actions (actions-cool/issues-helper) compromised
- Nx Console VS Code extension compromised
- Grafana breached via TanStack dependency
- GitHub itself breached: 3,800+ internal source code repositories exfiltrated by TeamPCP via compromised employee device

The GitHub breach is the most significant event. GitHub is the literal substrate of global software supply chains. Exfiltration of 3,800+ internal repos may expose platform logic, CI/CD pipeline code, and potentially customer repository data. This event meets criterion (a) — multiple major developer infrastructure platforms. Whether criteria (b) and (c) are met at SolarWinds scale depends on downstream impact disclosure still pending.

Falsifiable signal: If GitHub discloses that stolen repos contained secrets/tokens that were used to access customer code, or if downstream org count breaches 500+, the SolarWinds-scale label is confirmed. If GitHub's investigation concludes the stolen repos were internal-only with no customer exposure and the attack wave ceases without further infrastructure victims, the hypothesis is disconfirmed.

Confidence raised from 0.75 → 0.82 based on GitHub breach as infrastructure-level inflection point.
