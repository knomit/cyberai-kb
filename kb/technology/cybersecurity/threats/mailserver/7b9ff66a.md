# Exim BDAT Vulnerability: Memory Corruption RCE in GnuTLS Builds (May 2026)

Exim released security updates addressing a critical vulnerability in its BDAT (Binary DATA) implementation affecting builds compiled with GnuTLS. The flaw enables memory corruption and potential remote code execution. Exim is a widely used open-source Mail Transfer Agent (MTA), making this a high-impact server-side vulnerability for mail infrastructure.
