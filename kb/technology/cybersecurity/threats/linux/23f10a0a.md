# THN May 8 2026: Linux Supply Chain & Infrastructure Threat Cluster

Cluster of coordinated Linux-targeting threats reported by The Hacker News (May 8, 2026): (1) Quasar Linux RAT (QLNX) — previously undocumented Linux implant targeting developer systems for software supply chain compromise; establishes persistent silent foothold; (2) PamDOORa backdoor — uses PAM modules to steal SSH credentials; advertised on Rehub Russian cybercrime forum at $1,600 by threat actor 'darkworm'; targets Linux authentication layer directly; (3) Dirty Frag LPE — unpatched local privilege escalation in Linux kernel; successor to Copy Fail (CVE-2026-31431, CVSS 7.x); enables root access across major distributions; (4) Ivanti EPMM CVE-2026-6973 — CVSS 7.2 RCE vulnerability in Endpoint Manager Mobile under active exploitation in the wild; grants admin-level access via improper input validation; (5) PCPJack credential stealer — exploits 5 CVEs, spreads worm-like across cloud systems, specifically targets and removes TeamPCP artifacts. Meta-pattern: developer systems and authentication layers (SSH/PAM) are primary Linux attack surfaces in 2026. Supply chain attacks (targeting developer credentials) are as prominent as infrastructure attacks.
