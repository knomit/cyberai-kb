# Quasar Linux RAT (QLNX): P2P Mesh Rootkit with PAM Backdoor Targeting Linux Infrastructure (May 2026)

New modular Linux RAT called QLNX (Quasar Linux) discovered by Trend Micro. Key capabilities: (1) P2P mesh network — infected hosts communicate peer-to-peer rather than through centralized C2, making it resilient to takedowns; (2) Kernel-level rootkit; (3) PAM-based authentication backdoor; (4) Process hiding under legitimate Linux service names; (5) Keylogging and credential harvesting. Embeds C source code for PAM backdoor and LD_PRELOAD rootkit as string literals in binary. Designed for supply chain and cloud infrastructure breaches.
