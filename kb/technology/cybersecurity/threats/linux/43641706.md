# Fragnesia: Third Linux Kernel LPE Variant — Root Access via Page Cache Corruption (May 2026)

A new Linux local privilege escalation vulnerability called 'Fragnesia' has been disclosed, allowing local attackers to gain root access via page cache corruption. It is a variant of the 'Dirty Frag' vulnerability family and is the third such bug identified in this class. Enables local privilege escalation to root.
