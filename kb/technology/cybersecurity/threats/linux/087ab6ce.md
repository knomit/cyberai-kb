# PamDOORa: Linux PAM Backdoor Sold on Russian Cybercrime Forum for $1,600 (May 2026)

Cybersecurity researchers disclosed PamDOORa, a new Linux backdoor advertised on the Rehub Russian cybercrime forum for $1,600 by a threat actor called 'darkworm.' The backdoor uses PAM (Pluggable Authentication Modules) to intercept and steal SSH credentials on compromised Linux systems, granting persistent covert access while appearing as a legitimate authentication module.
