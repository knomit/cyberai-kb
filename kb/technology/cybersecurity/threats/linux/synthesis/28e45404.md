# Linux PAM Authentication Layer as 2026's Primary Linux Attack Surface: Three Simultaneous Exploits

Three distinct threats disclosed in May 2026 independently converged on Linux's PAM (Pluggable Authentication Modules) authentication layer and kernel privilege escalation:

1. **QLNX (Quasar Linux RAT)** — Modular RAT with P2P mesh C2 (takedown-resilient), kernel rootkit, and embedded PAM backdoor + LD_PRELOAD rootkit source code. Targets developer systems for supply chain compromise. Discovered by Trend Micro.

2. **PamDOORa** — Standalone PAM backdoor sold for $1,600 on Rehub Russian cybercrime forum by 'darkworm'. Intercepts and steals SSH credentials. Appears as a legitimate authentication module.

3. **Fragnesia** — Third Linux kernel LPE via page cache corruption (Dirty Frag family). Enables root access on all major distributions without network access.

**Pattern**: PAM is the authentication chokepoint for Linux systems — controlling SSH, sudo, and all local logins. Compromising PAM via a malicious module grants persistent, covert, auth-layer-level access that survives reboots and persists across legitimate user sessions. The commercial availability of PAM-targeting malware (PamDOORa at $1,600) alongside sophisticated nation-state-grade tools (QLNX) signals this is both a commodity and advanced threat. Defenders should audit installed PAM modules and implement PAM module integrity checking as a baseline control.
