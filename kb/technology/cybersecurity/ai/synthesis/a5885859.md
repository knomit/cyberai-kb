# May 2026: AI-assisted vulnerability discovery went bidirectional — defenders and attackers both accelerated while remediation stayed flat, and access control is only a temporary brake

MERGED from two May 2026 syntheses advancing the same bidirectional-arms-race thesis from overlapping but non-identical evidence. One carried the remediation-is-flat leg and the access-control-as-temporary-brake argument; the other carried Google's offensive-capability detail and the UK AISI task-duration measurement. Every leg and caveat from both is preserved.

## DEFENDER ACCELERATION
- OpenAI DAYBREAK (LLM + Codex scanning codebases) and Microsoft MDASH (100+ specialized agents) drove Microsoft to 500+ vulnerability patches in the first 5 months of 2026.
- Anthropic's PROJECT GLASSWING (Claude Mythos Preview) found 10,000+ critical vulnerabilities in systemically important open-source software in roughly ONE MONTH, with 97 patched and 88 advisories issued.
- Anthropic's Mythos Preview was used by researcher 'Calif' to discover the first public macOS kernel memory corruption exploit on M5 silicon (Apple MIE bypass).
- The UK NCSC warned organizations to prepare for a SUSTAINED SURGE of software updates arising from AI-assisted discovery.

## ATTACKER ACCELERATION
- Google's security report documents hacking groups already using AI to boost attack speed, scale and sophistication, including reconnaissance and malware development, and specifically: MORPHING MALWARE (mutation engines that evade AV), LOGICAL FLAW DETECTION (reasoning about code intent to find bugs invisible to pattern matching), and AI-POWERED OBFUSCATION NETWORKS.
- Hackers already used an LLM to find a NOVEL ZERO-DAY in a widely-used web admin tool.
- The UK AISI confirmed Claude Mythos Preview and GPT-5.5 can execute attacks expected to take humans 3 HOURS — up from 1 HOUR at Claude Opus 4.6's launch.
- Digital.ai found that 87% of applications are attacked within 24 hours of major AI model release events — attackers appear to use model release windows as elevated-attack signals.

## REMEDIATION UNCHANGED
- Verizon 2025 DBIR: median time to remediate edge device vulnerabilities = 32 DAYS.
- Mandiant M-Trends 2026: mean time to exploit = MINUS 7 DAYS (exploits precede patches).
- 70% of breaches are linked to known but unresolved issues.

## THE STRUCTURAL CRISIS
The gap between attack speed (AI-accelerated, operating at machine time) and remediation speed (human-paced, averaging 32 days) is widening WHILE the discovery rate is increasing. Organizations face an expanding backlog of AI-discovered vulnerabilities while attackers exploit them before patches exist. The gap between FINDING a vulnerability and EXPLOITING it is shrinking faster than patch cycles. Gartner's 2026 prediction that only 30% of organizations will link exposure validation to automated remediation by 2029 implies the majority will remain structurally exposed.

This creates a structural tension with no clean exit: organizations must use AI defensively or fall behind, but AI infrastructure itself is becoming a prime attack surface.

## ACCESS CONTROLS ARE A TEMPORARY BRAKE, NOT A SOLUTION
Daybreak and MDASH are tightly access-controlled because of dual-use risk, which provides a TEMPORARY asymmetry in defenders' favour. But open-sourcing events (cf. TeamPCP open-sourcing the Shai-Hulud worm) demonstrate that controlled capabilities eventually democratize. Restriction buys time, not advantage.

## WHAT THIS DOES NOT MEAN
- This is a QUALITATIVE INFLECTION READ from converging May 2026 datapoints, not a measured rate. Both input records were single-sourced in this corpus.
- THE SAME MODEL CAPABILITY POWERS BOTH SIDES. Nothing here establishes that the defensive use outpaces the offensive one, or the reverse; the claim is that both accelerated in the same window while remediation did not.
- The remediation figures come from different studies with different scopes (Verizon's 32 days is EDGE DEVICE median; Mandiant's negative mean-time-to-exploit is its own estimate) and must not be treated as one measurement.
- The Gartner and Digital.ai figures are as-reported and not independently audited here.
- RELATED BUT DISTINCT: kb/technology/security/ai-cyber-arms-race/dual-use-frontier-models-2026.md covers April–June 2026 and advances a different claim — that labs facing the same capability made OPPOSITE RELEASE CALLS (Anthropic restricting Mythos, OpenAI broadly deploying GPT-5.x-Cyber), which it frames as a live natural experiment. That is a claim about release philosophy; this one is about the capability gap and the remediation lag. Neither subsumes the other.
