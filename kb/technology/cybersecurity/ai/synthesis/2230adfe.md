# AI-Assisted Vulnerability Discovery Creates Structural Security Crisis: Both Sides Accelerating While Remediation Stays Flat

May 2026 marks the point where AI-assisted vulnerability discovery became a mainstream bidirectional arms race, creating a structural security crisis that metrics now make legible:

**Defender acceleration**: OpenAI Daybreak (LLM + Codex scanning codebases) and Microsoft MDASH (100+ specialized agents) have driven Microsoft to 500+ vulnerability patches in 5 months of 2026. Anthropic's Mythos Preview was used by researcher 'Calif' to discover the first public macOS kernel memory corruption exploit on M5 silicon (Apple MIE bypass). UK NCSC warned organizations to prepare for a sustained surge of software updates from AI-assisted discovery.

**Attacker acceleration**: Google documented that hacking groups are already using AI to boost attack speed, scale, and sophistication including reconnaissance and malware development. Digital.ai found that 87% of applications are attacked within 24 hours of major AI model release events — attackers appear to use model release windows as elevated-attack signals.

**Remediation unchanged**: Verizon 2025 DBIR: median time to remediate edge device vulnerabilities = 32 days. Mandiant M-Trends 2026: mean time to exploit = -7 days (exploits precede patches). 70% of breaches are linked to known but unresolved issues.

**Structural crisis**: The gap between attack speed (AI-accelerated, operating at machine time) and remediation speed (human-paced, averaging 32 days) is widening while the discovery rate is increasing. Organizations face an expanding backlog of AI-discovered vulnerabilities while attackers exploit them before patches exist. The 2026 Gartner prediction that only 30% of organizations will link exposure validation to automated remediation by 2029 implies the majority will remain structurally exposed.

**Access controls as temporary brake**: Daybreak and MDASH are tightly access-controlled due to dual-use risk. This provides a temporary asymmetry in defenders' favor — but open-sourcing events (cf. TeamPCP open-sourcing Shai-Hulud worm) demonstrate that controlled capabilities eventually democratize.
