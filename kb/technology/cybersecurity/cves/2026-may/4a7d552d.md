# Gitea unauthenticated container image pull vulnerability disclosed (May 2026)

Security researchers disclosed a vulnerability in Gitea (open-source self-hosted version control platform, May 27 2026) allowing unauthenticated remote attackers to pull private container images from Gitea deployments without authentication. Significant for organizations self-hosting Gitea for source code and container registry.
