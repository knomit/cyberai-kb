# EchoLeak CVE-2025-32711: First Zero-Click IPI Exploit in a Production LLM System

EchoLeak (CVE-2025-32711): first confirmed zero-click IPI exploit in a production LLM system. CVSS 9.3. Affected: Microsoft 365 Copilot.

**Attack mechanism:**
1. Attacker sends crafted email with hidden instructions in HTML to victim
2. Victim uses Copilot normally ('summarize my inbox') — no direct interaction with malicious email required
3. Copilot ingests the email as data; hidden instruction directs it to find sensitive SharePoint/OneDrive documents
4. Copilot encodes document contents as base64, embeds in img tag URL pointing to attacker's server
5. Browser auto-fetches image → GET request delivers stolen data
6. Exfiltration proxied through Microsoft's own Teams async preview API (appears as internal Microsoft request)

**Four-technique bypass chain (defeated Microsoft's XPIA classifier):**
- Reference-style Markdown encoding to evade instruction classifier
- Circumvented link redaction
- Exploited auto-fetched image behavior
- Used Microsoft Teams proxy to bypass content security policy

**Significance:** Zero user interaction required. Triggered by a single inbound email. With email-send permissions, blast radius extends to reply-all attacks, calendar exfiltration, OAuth grant initiation.
