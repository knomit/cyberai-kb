# Google report: LLMs enabling industrial-scale cyberattacks via morphing malware and logical flaw detection

Google security report (May 2026, per The Batch/DeepLearning.AI): LLMs are accelerating cyberattacks in four ways: (1) Morphing malware — mutation engines rewrite decryption routines and swap commands on each infection to evade AV while preserving function. (2) Logical flaw identification — unlike fuzzing/pattern tools, LLMs reason about code intent to find invisible vulnerabilities. (3) Obfuscation networks — AI tools route malicious traffic through compromised intermediaries while avoiding security monitor patterns. (4) Insecure AI infrastructure — AI tools, models, and accessories becoming prime attack entry points. Google found hackers already used an LLM to find a previously unknown 0-day to compromise a widely used web admin tool, thwarting a planned large-scale attack.
