# 2026 inflection: AI crosses dual-use threshold in cybersecurity — offense and defense simultaneously

Multiple converging data points in May 2026 mark a qualitative shift in AI's cybersecurity role. On the defensive side: Anthropic's Project Glasswing (Claude Mythos Preview) found 10,000+ critical vulnerabilities in open-source software in ~1 month, with 97 patched and 88 advisories issued. On the offensive side: Google's security report documents LLMs enabling morphing malware (mutation engines that evade AV), logical flaw detection (reasoning about code intent to find invisible bugs), and AI-powered obfuscation networks. Hackers already used an LLM to find a novel 0-day in a widely-used web admin tool. The UK AISI confirmed Claude Mythos Preview and GPT-5.5 can execute attacks expected to take humans 3 hours — up from 1 hour at Claude Opus 4.6's launch. The same model capability that powers proactive defense is available to attackers. The gap between finding a vulnerability and exploiting it is shrinking faster than patch cycles. This creates a structural tension: organizations must use AI defensively or fall behind, but AI infrastructure itself is becoming a prime attack surface.
