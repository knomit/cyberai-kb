# Non-Human Identities Outnumber Human Users 45:1 as AI Agents Expand Enterprise Access

As of May 2026, non-human identities (NHIs) — service accounts, API keys, machine credentials, agent tokens, and OAuth grants — outnumber human user identities in enterprise environments by 45:1. The ratio is accelerating as AI agents are deployed with expanded permissions to data, email, code repositories, and cloud infrastructure. NHIs represent the largest and fastest-growing identity governance gap in enterprise security: unlike human accounts, NHIs are rarely audited, often have excessive permissions (least-privilege principles are frequently not applied), and may persist long after their original use case ends. The MCP server vulnerabilities in Apache Doris, Apache Pinot, and Alibaba RDS (May 2026) represent an early wave of attacks specifically targeting NHI infrastructure.
