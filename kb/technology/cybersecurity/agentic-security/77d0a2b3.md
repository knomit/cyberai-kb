# Agent Security Observability Requires Two Correlated Event Streams: Intent and Execution

Full visibility into agent behavior requires joining two distinct event streams:

**Intent stream:** What the LLM decided to do — the tool_use block in the model's response, containing tool name and structured arguments (e.g. web_search(url='foobar.com')). Has semantic context but no confirmation that execution happened.

**Execution stream:** What the agent process actually did — network connections, DNS queries, process spawning observed at kernel level. Has ground truth but no semantic meaning (connect(104.21.x.x:443) not 'web search for foobar.com').

Joining produces: '{tool: web_search, args: {url: foobar.com}} → {dns: foobar.com→104.21.x.x, connect: 104.21.x.x:443}' — both intent and confirmed execution with semantic attribution.
