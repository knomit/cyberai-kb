# Claude Code LLM API Gateway: Compatibility Reality and Critical Gaps

Claude Code officially supports LLM API gateway routing via ANTHROPIC_BASE_URL and ANTHROPIC_AUTH_TOKEN env vars. Requirements and failure modes:

**Requirements:** Gateway must expose native Anthropic Messages format (/v1/messages). Must preserve all anthropic-beta headers. Translation to OpenAI format breaks tool_use handling.

**Real fragility — streaming tool_use:** Multi-step tool call cycles (tool_use → tool_result → continue reasoning) produce streaming errors on gateways that buffer or reformat the event stream. Active bug in LiteLLM (#26529). This is the scenario most relevant to security interception.

**Beta headers:** Bedrock-fronted gateways return 400s on some anthropic-beta flags. Extended thinking has compatibility issues on Bedrock and Vertex gateways.

**Critical gap for security use:** MCP tool connections are direct — Claude Code connects to MCP servers over stdio or HTTP without going through the LLM API. An LLM API gateway never sees MCP tool executions. The gateway sees Claude's *decision* to call an MCP tool but not the execution or result.
