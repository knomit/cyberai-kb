# Behavioral Monitoring Is Structurally Infeasible for AI Agents

Behavioral profiling is architecturally infeasible for AI agents — a structural limitation, not an implementation gap.

**Why traditional behavioral monitoring works:** Assumes finite, enumerable state space. Web servers have known endpoints. Users have habitual access patterns. Baseline the distribution; flag deviations.

**Why it breaks for agents:** Execution path is determined at inference time by the model, as a function of task, retrieved content, and stochasticity. Same agent + same task may legitimately produce different tool call sequences every time. The value of agents is handling novel tasks — any monitor calibrated on historical patterns will either generate massive false positives or be tuned permissively enough to miss attacks.

**What IS analyzable:** Blast radius (static) — given this agent's tool set and credential scope, what is the maximum damage if compromised? Useful for least-privilege design, not runtime defense.

**What behavioral monitoring vendors actually do:** Identity-level monitoring — which credentials accessed which resources at what time. 'Agent used Salesforce API key at 2am' is detectable. 'Agent executing anomalous tool call sequence suggesting injection' is not.

**Implication:** The security model for AI agents cannot be detection-based. It must be constraint-based.
