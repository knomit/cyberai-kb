# eBPF SSL Interception Eliminates MITM Certificate Requirements for LLM API Observation

Classical MITM for LLM API traffic inspection requires CA trust injection and breaks with certificate pinning. eBPF uprobes on SSL_write (plaintext before encryption) and SSL_read (plaintext after decryption) are strictly better for non-cooperative processes.

**What you capture:** Full HTTP request/response including tool_use blocks, PID-tagged, joinable with execution stream.

**Works for:** Python agents (OpenSSL), Node.js/Claude Code (BoringSSL), compiled binaries, processes with certificate pinning, processes you don't control.

**Requirement:** CAP_SYS_PTRACE or root. Reference implementation: bcc sslsniff.py. Used by Pixie and Cilium Hubble for Kubernetes TLS observability.
