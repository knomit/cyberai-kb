# Abundant AI-generated code shifts the engineering bottleneck to verification

Analysis argues that large language models are transforming software development by making code generation faster and cheaper, moving the primary challenge from creating code to trusting and verifying it. Engineering organizations including Stripe, Spotify and Amplitude have integrated AI-generated code into production, which raises the need for robust governance, context, and verification systems.
