# The July 2026 MCP specification revision removes sessions and deprecates DCR in favor of CIMD

The July 2026 revision of the Model Context Protocol specification is described as the largest since June 2025: transport-layer sessions are removed, Dynamic Client Registration (DCR) is deprecated in favor of CIMD, six new authorization SEPs are added, and Enterprise-Managed Authorization (EMA) is introduced to address consent sprawl. Note: this summary comes from a Descope vendor blog post that ran as sponsored placement in The Deep View, so it should be checked against the official MCP specification before being relied on.
