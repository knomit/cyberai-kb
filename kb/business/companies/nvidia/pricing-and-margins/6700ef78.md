# Nvidia plans to pass rising HBM memory costs to customers, raising AI server prices over 15%

Analysis of Nvidia's pricing strategy indicates it plans to pass rising memory costs onto customers, with AI server prices set to increase by more than 15% for systems shipping next year. Because HBM is treated as a relatively small share of the final accelerator price, this approach protects gross-profit dollars. The analysis argues the harder test comes in FY28, when new memory generations and increased memory content per system may limit Nvidia's ability to hold margin percentages.
