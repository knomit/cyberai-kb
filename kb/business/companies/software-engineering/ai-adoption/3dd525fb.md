# Big tech leaders report majority-AI-generated code: Google 75%, Snap 65%, Airbnb 60%

Executives at several large technology companies have publicly claimed that most of their code is now AI-generated. Google CEO Sundar Pichai said in April 2026 that 75% of the company's code is written by AI. Snap CEO Evan Spiegel said 65% of Snap's code is AI-generated. Airbnb CEO Brian Chesky said 60% of the code created by the company's engineers is now written by AI. These are self-reported executive claims rather than independently audited measurements, and the definition of "written by AI" is not standardized across the three.
