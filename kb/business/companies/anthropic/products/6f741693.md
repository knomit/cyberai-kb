# Anthropic launches Claude Tag, embedding Claude in Slack as a teammate

Anthropic unveiled Claude Tag, a system that embeds Claude into Slack so it can 'join as a team member': users grant it access to channels, tools, or codebases and delegate tasks by tagging it. Per Anthropic, it is 'multiplayer' (visible to all in a channel, can resume others' work), builds and retains context over time, can run asynchronously and schedule its own tasks, and supports an 'ambient' mode that surfaces relevant info. Available initially on Slack for Enterprise and Team customers, with plans to expand to other platforms. Anthropic calls it an evolution of Claude Code (stating 65% of its own code is created by an internal version) and follows earlier launches Claude Cowork (January) and Claude Design. Reported by The Deep View, June 24, 2026.
