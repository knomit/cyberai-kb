# Anthropic is preparing Claude Money, a bank-linked personal finance capability

Anthropic is preparing a feature called Claude Money that would let users link bank accounts and ask Claude about spending, plans and other financial questions, giving Claude persistent access to financial context instead of requiring manual upload of statements or transaction exports. As of mid-September 2026 the account types supported, the data provider behind it, the available actions, and the launch timeframe were all unknown. Context: Claude already supports third-party personal-finance connectors, and Anthropic has been building finance-specific agents and products aimed at professional users — so this is an extension of an existing direction, not a new one. Sourced from pre-announcement app teardown reporting, so treat specifics as unconfirmed.
