# G5 Labs raised $14M to make natural-language intent graphs the source code

G5 Labs, an MIT CSAIL spinout, raised $14 million to develop a platform where natural language, structured as intent graphs, serves as the source code rather than an input to code generation. The framing accompanying the raise is that 'programming is dead, engineering is thriving' — the claim being that the durable artifact moves up a level of abstraction from program text to structured intent.
