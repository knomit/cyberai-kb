# Salesforce Dreamforce 2026 turns Slack into an enterprise AI front door via Slackforce

At Dreamforce 2026 (September 2026), Salesforce announced a set of Slack upgrades centered on Slackforce, which exposes Salesforce functionality directly inside Slack via chatbot-style queries. Slackforce Surface lets a user describe a need in natural language and have Slack build a live interactive interface for tracking data, forecasts, and pipelines. Accompanying launches: Slack Code (multi-team coding in a Slack code channel using agents from OpenAI, Anthropic, GitHub, Cognition, and Vercel), Big Mode (a full-screen Slackbot AI workspace for research, writing, and file creation), Slackbot in Salesforce Lightning, two-way Slackbot voice (shipping later in 2026), and Slackbot video generation (shipping later in fall 2026). Operational consequence: the strategic bet is that the chat client, not the system-of-record UI, becomes the agent harness — evaluate Slack as an AI surface, not just a messaging tool. Note the timing caveat: voice and video generation were announced as future releases, not generally available at announcement.
