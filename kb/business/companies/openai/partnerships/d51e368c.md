# OpenAI to terminate Cursor contract after SpaceX acquisition

OpenAI announced it will end its contract with Cursor following Cursor's acquisition by SpaceX, citing concerns over contract violations by Elon Musk's companies. API access shutoff is set for November 12, 2026, giving developers a transition window.
