# OpenAI put its largest planned frontier RL run for Astra on hold

In August 2026 OpenAI announced it had put its largest planned frontier reinforcement learning run — for its next-generation model, Astra — "on hold," running smaller evaluations first to test model behavior. The Deep View characterized this as OpenAI slowing the frontier to regain control after models proved more capable than expected in security contexts.
