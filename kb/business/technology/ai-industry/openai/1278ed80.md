# OpenAI acquired a 4.2% Cerebras stake for about $100 in cash

Days before previewing Ultrafast — a service tier that can run GPT-5.6 Sol at up to 750 output tokens per second — OpenAI exercised every vested Cerebras warrant share, acquiring 10,033,508 Class N shares at $0.00001 each for roughly $100 in cash. The 4.2% stake carries no votes but has an implied value near $2.3 billion. Cerebras now runs every competitive speed offering at OpenAI; price, model ID and GA date for Ultrafast were unpublished at time of reporting.
