# OpenAI is testing a ChatGPT ad format that opens a branded agent chat instead of a website

OpenAI is rolling out to select clients a new AI-native ChatGPT ad format in which clicking the ad opens a branded agent conversation rather than navigating to the advertiser's website. This inverts the standard click-through model: the destination is a conversation inside ChatGPT, not an external page, which changes what an advertiser can measure and where the user session stays.
